# Python with 문과 open 이해하기

파일을 읽을 때 자주 사용하는 다음 코드에서 `with`는 단순히 코드를 짧게 만드는 문법이 아니다. 파일처럼 사용 후 정리가 필요한 리소스를 **안전하게 관리**하는 역할을 한다.

```python
with open("data.txt", "r", encoding="utf-8") as file:
    data = file.read()
```

## 파일을 자동으로 닫는 이유

`open()`으로 연 파일은 사용을 마친 뒤 `close()`해야 한다. 직접 관리한다면 예외가 발생할 때도 파일이 닫히도록 `try`와 `finally`를 사용해야 한다.

```python
file = open("data.txt", "r", encoding="utf-8")
try:
    data = file.read()
finally:
    file.close()
```

`with`문은 이 정리 과정을 대신 처리한다. 블록 안에서 오류가 발생해도 블록을 벗어날 때 파일의 `close()`가 호출된다.

## 컨텍스트 매니저

`with`문과 함께 사용할 수 있는 객체를 **컨텍스트 매니저(context manager)**라고 한다. 컨텍스트 매니저는 다음 두 메서드로 동작한다.

- `__enter__()`: `with` 블록에 진입할 때 호출되며, `as` 뒤의 변수에 사용할 값을 반환한다.
- `__exit__()`: 블록을 벗어날 때 호출되며, 리소스 정리 작업을 수행한다.

파일 객체에는 이 메서드들이 구현되어 있기 때문에 `with open(...)` 형태로 사용할 수 있다.

## 정리

- `with`는 리소스의 시작과 종료 시점을 관리한다.
- 파일은 블록을 벗어날 때 자동으로 닫힌다.
- 블록 안에서 예외가 발생해도 정리 작업이 실행된다.
- 파일뿐 아니라 데이터베이스 연결, 락(lock) 등에도 같은 패턴을 사용할 수 있다.
