# 1장 2강 : 패키지 구조와 개발 환경 설정

## 1. LangChain 패키지 구조

LangChain은 모든 기능을 하나의 패키지에 넣지 않고, **공통 기능과 모델 제공자별 연결 기능을 나누어 관리**한다.

| 패키지 | 역할 |
|---|---|
| `langchain` | 상위 수준의 LangChain 기능 제공 |
| `langchain-core` | Prompt, Message, Parser 등 공통 구성 요소 제공 |
| `langchain-openai` | OpenAI 모델을 LangChain ChatModel로 연결 |
| `openai` | OpenAI API를 직접 호출하는 공식 Python SDK |
| `python-dotenv` | `.env` 파일의 값을 환경변수로 불러옴 |

`python-dotenv`는 LangChain 패키지가 아니며, API Key 같은 값을 코드 밖에서 관리하기 위해 사용한다.

### 설치 이름과 import 이름

설치할 때 사용하는 이름과 Python에서 import하는 이름이 다를 수 있다.

```text
설치: langchain-core
import: langchain_core

설치: langchain-openai
import: langchain_openai

설치: python-dotenv
import: dotenv
```

## 2. 프로젝트 폴더와 VS Code 준비

수업은 **Windows + VS Code + uv + Python 3.12** 환경을 기준으로 진행한다.

VS Code에서는 파일 하나만 여는 것이 아니라 `pyproject.toml`, `uv.lock` 등이 들어 있는 **프로젝트 최상위 폴더 전체를 열어야 한다.**

프로젝트 폴더 전체를 열면 다음 항목을 하나의 프로젝트로 관리할 수 있다.

- `.env`
- `.venv`
- 각 강의의 Python 파일

Microsoft의 Python 확장이 설치되어 있는지도 확인한다.

현재 터미널 위치는 다음 명령으로 확인할 수 있다.

```powershell
Get-Location
```

---

## 3. uv로 Python 환경 준비

`uv`는 Python 버전, 프로젝트 의존성, 실행 환경을 관리한다.

프로젝트마다 `.venv` 가상환경을 만들어 패키지를 분리하므로 프로젝트 간 버전 충돌을 줄일 수 있다.

### uv 설치 확인

```powershell
uv --version
```

uv가 없다면 Windows에서 다음과 같이 설치할 수 있다.

```powershell
winget install --id=astral-sh.uv -e
```

### Python 3.12 준비

```powershell
uv python install 3.12
uv python find 3.12
```

수업에서는 Python 버전을 `3.12`로 사용한다.

### 프로젝트 환경 생성

`pyproject.toml`과 `uv.lock`이 있는 폴더에서 실행한다.

```powershell
uv sync --locked --python 3.12
```

이 명령을 실행하면 uv가:

```text
프로젝트 설정 확인
        ↓
.venv 생성
        ↓
uv.lock 기준으로 패키지 설치
```

를 수행한다.

별도로 `Activate.ps1`을 실행하거나 PowerShell 실행 정책을 변경하는 것은 필수 단계가 아니다.

### 실행 Python 확인

```powershell
uv run python --version
uv run python -c "import sys; print(sys.executable)"
```

정상이라면:

```text
Python 3.12.x
```

가 표시되고 Python 실행 경로에:

```text
.venv\Scripts\python.exe
```

가 포함되어야 한다.

## 4. 패키지 설치와 관리

수업 기준 버전은 다음과 같다.

| 항목 | 버전 |
|---|---|
| Python | `3.12` |
| `langchain` | `1.3.14` |
| `langchain-core` | `1.5.1` |
| `langchain-openai` | `1.4.1` |
| `openai` | `2.48.0` |
| `python-dotenv` | `1.2.2` |
| `pydantic` | `2.13.5` |

배포된 프로젝트에서는 다음 명령으로 설치 환경을 맞춘다.

```powershell
uv sync --locked --python 3.12
```

### `pyproject.toml`

직접 사용하는 패키지와 Python 버전 조건을 기록한다.

### `uv.lock`

직접 사용하는 패키지뿐 아니라 간접 의존성까지 포함한 실제 설치 버전을 기록한다.

새로운 패키지를 추가하거나 변경할 때는:

```powershell
uv add 패키지명
```

을 사용한다.

### 의존성 충돌 확인

```powershell
uv pip check
```

정상이면 다음과 같은 메시지가 표시된다.

```text
All installed packages are compatible
```

## 5. API Key를 `.env`로 관리

API Key는 코드에 직접 작성하지 않고 프로젝트 최상위 폴더의 `.env` 파일에 저장한다.

```env
OPENAI_API_KEY=실제_API_Key
OPENAI_MODEL=gpt-5.6-luna
```

API Key는 계정 사용 권한과 비용에 연결되는 비밀값이므로 코드나 화면에 직접 노출하지 않아야 한다.

### `.gitignore`

`.env`와 가상환경 등이 Git에 올라가지 않도록 설정한다.

```text
.env
.venv/
__pycache__/
```

`.gitignore`는 앞으로 Git에서 추적하지 않도록 하는 것이며, 이미 Git에 올라간 API Key를 자동으로 삭제하지는 않는다.

### Python에서 `.env` 읽기

```python
import os
from dotenv import load_dotenv

load_dotenv()

api_key_is_ready = bool(os.getenv("OPENAI_API_KEY"))

print(api_key_is_ready)
```

정상적으로 API Key가 설정되어 있다면:

```text
True
```

가 출력된다.

## 6. VS Code 인터프리터 설정

`uv run`이 사용하는 Python과 VS Code가 사용하는 Python을 같게 맞춰야 한다.

VS Code에서:

```text
Ctrl + Shift + P
        ↓
Python: Select Interpreter
        ↓
.venv\Scripts\python.exe 선택
```

현재 Python 실행 경로는 다음 코드로 확인할 수 있다.

```python
import sys

print(sys.executable)
```

출력 경로에 `.venv`가 포함되어 있는지 확인한다.

## 7. 기본 ChatModel 호출

환경 설정이 완료되면 `ChatOpenAI`를 이용해 모델을 호출할 수 있다.

```python
import os

from dotenv import load_dotenv
from langchain_openai import ChatOpenAI

load_dotenv()

model_name = os.getenv(
    "OPENAI_MODEL",
    "gpt-5.6-luna"
)

model = ChatOpenAI(
    model=model_name,
    reasoning_effort="none",
    use_responses_api=False,
    max_completion_tokens=600,
    timeout=30,
    max_retries=0,
)

response = model.invoke(
    "LangChain을 한 문장으로 소개해 주세요."
)

print(response.content)
```

`model.invoke()`의 결과는 단순 문자열이 아니라 **`AIMessage`**이다.

따라서 답변 본문은:

```python
response.content
```

으로 확인한다.

## 8. 실습 실행 순서

실습 파일은 다음 순서로 환경을 확인한다.

```text
현재 Python 경로 확인
        ↓
패키지 버전 확인
        ↓
API Key 설정 여부 확인
        ↓
ChatOpenAI 실제 호출
```

### API 호출 없이 확인

```powershell
uv run python 실습.py --offline
```

### 실제 API 호출

```powershell
uv run python 실습.py
```

`--offline`을 사용하면 API Key가 설정되어 있어도 실제 API는 호출하지 않는다.

## 9. 자주 발생하는 오류

### `uv` 명령을 찾지 못하는 경우

uv 설치 후 VS Code를 다시 실행하고 확인한다.

```powershell
uv --version
```

### Python 버전 또는 잠금 파일 오류

프로젝트에 `pyproject.toml`과 `uv.lock`이 있는지 확인한 후:

```powershell
uv python install 3.12
uv sync --locked --python 3.12
```

을 실행한다.

### `ModuleNotFoundError`

설치한 Python 환경과 실제 실행 환경이 다른지 확인한다.

```powershell
uv run python -c "import sys; print(sys.executable)"
```

VS Code 인터프리터도 같은 `.venv`를 사용해야 한다.

필요한 패키지는 프로젝트 폴더에서:

```powershell
uv add 패키지명
```

으로 추가한다.

### `.env`가 있는데 API Key를 찾지 못하는 경우

파일 이름이 정확히:

```text
.env
```

인지 확인한다.

Windows에서 확장자가 숨겨져 있으면 실제 파일 이름이:

```text
.env.txt
```

일 수 있다.

### 인증 또는 모델 접근 오류

다음을 확인한다.

- API Key가 유효한지
- 해당 모델을 사용할 수 있는지
- `.env`의 `OPENAI_MODEL` 값이 올바른지

`.env`에 설정된 모델명이 있으면 코드의 기본 모델명보다 환경변수의 값이 우선한다.

# 핵심 정리

```text
LangChain 패키지

langchain-core
→ Prompt, Message, Parser 등 공통 기능

langchain-openai
→ OpenAI 모델 연결

openai
→ OpenAI 공식 Python SDK

python-dotenv
→ .env 환경변수 불러오기
```

프로젝트 환경은:

```text
Python 3.12
   ↓
uv
   ↓
.venv
   ↓
패키지 설치
   ↓
VS Code 인터프리터를 .venv로 설정
   ↓
uv run으로 실행
```

API Key는:

```text
.env에 저장
   ↓
load_dotenv()
   ↓
환경변수로 읽기
   ↓
ChatOpenAI에서 사용
```

`uv sync --locked`는 `uv.lock`에 맞춰 프로젝트 환경을 준비하고, `uv run`은 그 환경의 Python과 패키지를 이용해 명령을 실행한다.
