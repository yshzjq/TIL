# 머신러닝 데이터 처리 및 모델 개발 과정

## 1. 수집(Acquisition)

머신러닝을 위해서는 학습에 사용할 데이터가 필요하다.

자연어 처리에서는 자연어 데이터의 집합을 **말뭉치 또는 코퍼스(Corpus)**라고 한다.

- 특정 조사나 연구 목적을 위해 수집된 텍스트 집합
- 데이터 형식: `txt`, `csv`, `xml` 등
- 데이터 출처: 음성 데이터, 웹 수집 데이터, 영화 리뷰 등

---

## 2. 점검 및 탐색(Inspection and Exploration)

수집한 데이터의 상태와 특징을 확인하는 단계이다.

주요 확인 내용:

- 데이터의 구조
- 노이즈 데이터
- 데이터 정제 방법
- 독립 변수와 종속 변수
- 변수 유형과 데이터 타입
- 데이터의 특징과 구조적 관계

이 과정을 **탐색적 데이터 분석(EDA, Exploratory Data Analysis)**이라고도 한다.

필요에 따라 **시각화**나 **간단한 통계 테스트**를 진행한다.

---

## 3. 전처리 및 정제(Preprocessing and Cleaning)

데이터를 머신러닝에 사용할 수 있도록 가공하는 단계이다.

자연어 처리의 경우 다음과 같은 작업을 수행할 수 있다.

- 토큰화
- 정제
- 정규화
- 불용어 제거

빠르고 정확한 전처리를 위해서는 Python과 관련 라이브러리에 대한 지식이 필요하다.

복잡한 전처리에서는 머신러닝이 사용되기도 한다.

---

## 4. 모델링 및 훈련(Modeling and Training)

전처리가 완료되면 적절한 머신러닝 알고리즘을 선택하고 모델을 만든다.

이후 전처리된 데이터를 모델에 학습시킨다.

**학습(Learning)**과 **훈련(Training)**은 혼용해서 사용한다.

훈련된 모델은 다음과 같은 자연어 처리 작업을 수행할 수 있다.

- 기계 번역
- 음성 인식
- 텍스트 분류

### 데이터 분리

모든 데이터를 훈련에 사용하면 안 된다.

일반적으로 데이터를 다음과 같이 나눈다.

| 데이터 | 역할 | 시험 비유 |
|---|---|---|
| 훈련용 데이터 | 모델을 학습시키는 데이터 | 학습지 |
| 검증용 데이터 | 모델의 성능을 확인하고 개선하는 데이터 | 모의고사 |
| 테스트용 데이터 | 최종 모델의 성능을 평가하는 데이터 | 수능 |

### 훈련용 데이터

모델이 실제로 학습하는 데 사용한다.

### 검증용 데이터

훈련 과정에서 현재 모델의 성능을 확인하고 모델을 개선하는 데 사용한다.

### 테스트용 데이터

훈련이 끝난 모델의 **최종 성능을 평가**하는 데 사용한다.

모델을 개선하기 위한 데이터가 아니라 최종 성능을 수치화하는 데 사용한다.

실습에서는 상황에 따라

- 훈련용 + 테스트용
- 훈련용 + 검증용 + 테스트용

형태로 사용할 수 있다.

현업에서는 검증용 데이터를 사용하는 것이 중요하다.

---

## 5. 평가(Evaluation)

훈련이 끝난 모델을 **테스트용 데이터**를 이용하여 평가한다.

모델이 예측한 결과와 테스트 데이터의 실제 정답이 얼마나 가까운지를 측정한다.

---

## 6. 배포(Deployment)

평가 결과 모델이 성공적으로 훈련되었다고 판단되면 모델을 배포한다.

배포 이후 피드백으로 인해 모델을 업데이트해야 한다면 다시 **데이터 수집 단계**로 돌아갈 수 있다.

---

## 전체 흐름

```text
데이터 수집
   ↓
데이터 점검 및 탐색(EDA)
   ↓
전처리 및 정제
   ↓
모델링 및 훈련
   ↓
평가
   ↓
배포
   ↓
필요하면 다시 데이터 수집
```
