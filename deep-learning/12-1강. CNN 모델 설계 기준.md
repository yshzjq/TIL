## 1. 이번에 배울것

CNN 모델 설계 흐름

```
데이터 shape 확인
-> Conv block 설계
-> feature map shape 확인
-> classifier 연결
-> logits shape 검증
```

## 2. 설계 기준 1: 입력 shape 확인

CIFAR-10처럼 RGB 32x32 이미지를 사용한다면 입력 shape는 다음과 같다.

```
(batch_size, 3, 32, 32)
```

따라서 첫 번째 Conv layer는 `in_channels=3`이어야 한다

```python
import torch

images = torch.randn(16, 3, 32, 32)
labels = torch.randint(0, 10, size=(16,))

print("images:", images.shape)
print("labels:", labels.shape)
```

## 3. 설계 기준 2: Conv block 구성

```
Conv2d -> ReLU -> MaxPool2d
```

```python
import torch.nn as nn

block = nn.Sequential(
    nn.Conv2d(3, 16, kernel_size=3, padding=1),
    nn.ReLU(),
    nn.MaxPool2d(2)
)
```

각 layer의 역할

| Layer | 역할 |
| --- | --- |
| `Conv2d` | 이미지에서 지역 패턴을 찾습니다. |
| `ReLU` | 비선형성을 추가합니다. |
| `MaxPool2d` | 공간 크기를 줄이고 강한 반응을 남깁니다. |

## 4. 설계 기준 3: 너무 큰 모델부터 시작하지 않는다

처음부터 filter 수를 크게 만들면 GPU memory와 학습 시간이 늘어난다.
처음에는 작은 모델로 시작하고, 학습이 잘 되는지 확인한 뒤 키우는 것이 좋다.

CNN의 filter는 이미지의 작은 영역을 훑으면서 특정 패턴을 찾아내는 학습 가능한 가중치이며,<br>
filter 하나가 feature map 하나를 만든다.

좋은 실험은 처음부터 큰 모델로 한 번에 해결하는 것이 아니라,<br>
작은 baseline에서 출발해서 근거를 가지고 키우는 과정이다

## 5. 기준 CNN 모델 만들기

### MaxPool만 2번 해도 되지 않을까?

Conv는 특징을 학습하고, MaxPool은 특징의 공간 크기를 줄인다.<br>
따라서 Conv를 빼고 MaxPool만 두 번 하면 크기는 줄어들지만 새로운 특징을 학습하지 못한다.

```
nn.Conv2d(3, 16, kernel_size=3, padding=1),
            nn.ReLU(),
            nn.MaxPool2d(2),  # 32x32 -> 16x16


    
            # 두 번째 block: 16채널을 32채널 feature map으로 변환합니다.
            nn.Conv2d(16, 32, kernel_size=3, padding=1),
            nn.ReLU(),
            nn.MaxPool2d(2),  # 16x16 -> 8x8
```

16개의 feature map을 재료로 사용해서 32개의 새로운 feature map을 만든다

```python
import torch
import torch.nn as nn

class SmallCNN(nn.Module):
    """
    CIFAR-10 이미지 분류를 위한 작은 CNN baseline입니다.
    입력:  (N, 3, 32, 32)
    출력:  (N, num_classes)
    """
    def __init__(self, num_classes=10):
        super().__init__()

        self.features = nn.Sequential(
            # 첫 번째 block: RGB 3채널을 16채널 feature map으로 변환합니다.
            nn.Conv2d(3, 16, kernel_size=3, padding=1),
            nn.ReLU(),
            nn.MaxPool2d(2),  # 32x32 -> 16x16


    
            # 두 번째 block: 16채널을 32채널 feature map으로 변환합니다.
            nn.Conv2d(16, 32, kernel_size=3, padding=1),
            nn.ReLU(),
            nn.MaxPool2d(2),  # 16x16 -> 8x8
        )

        self.flatten = nn.Flatten()
        self.classifier = nn.Linear(32 * 8 * 8, num_classes)

    def forward(self, x):
        x = self.features(x)
        x = self.flatten(x)
        logits = self.classifier(x)
        return logits

model = SmallCNN(num_classes=10)
images = torch.randn(16, 3, 32, 32)
logits = model(images)

print("logits shape:", logits.shape)
assert logits.shape == (images.size(0), 10)
```

## 6. 파라미터 수 확인

```python
def count_parameters(model):
    """
    학습 가능한 parameter 수를 계산합니다.
    requires_grad=True인 parameter만 세기 때문에 학습 대상 수를 확인할 수 있습니다.
    """
    return sum(p.numel() for p in model.parameters() if p.requires_grad)

print("parameters:", count_parameters(model))
# 이 SmallCNN의 예상 출력: parameters: 25578
```

파라미터 수가 많을수록 항상 좋은 것은 아니다.<br>
데이터가 적거나 학습 epoch가 짧으면 오히려 과적합될 수 있다.
