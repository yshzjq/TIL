## 2. ReLU는 어떤 함수인가

ReLU는 입력값이 0보다 작으면 0을 출력, 0보다 크면 입력값을 그대로 출력

| 입력 x | ReLU(x) |
| --- | --- |
| -3 | 0 |
| -1 | 0 |
| 0 | 0 |
| 2 | 2 |
| 5 | 5 |

이 성질 때문에 ReLU는 다음 특징을 가집니다.

| 특징 | 설명 |
| --- | --- |
| 계산이 단순합니다 | `max(0, x)`만 계산하면 됩니다. |
| 양수 영역에서 gradient가 잘 흐릅니다 | 양수 입력에서는 기울기가 1입니다. |
| 음수 영역은 0이 됩니다 | 현재 뉴런의 음수 출력을 다음 층에 전달하지 않습니다. |
| shape를 바꾸지 않습니다 | 입력과 출력 Tensor의 shape는 같습니다. |

gradient(그래디언트)는 쉽게 말하면 "어느 방향으로, 얼마나 값을 바꿔야 Loss가 줄어드는지 알려주는 값

ReLU는 Tensor의 **shape를 바꾸는 층이 아니라 값을 바꾸는 층**이다

## 3. Tensor 값으로 ReLU 확인

직접 Tensor를 넣어 확인

```python
import torch
import torch.nn as nn

# 음수, 0, 양수가 섞인 Tensor입니다.
x = torch.tensor([-3.0, -1.0, 0.0, 2.0, 5.0])

# ReLU layer를 만듭니다.
relu = nn.ReLU()

# ReLU를 적용합니다.
y = relu(x)

print("x:", x)
print("y:", y)
print("x shape:", x.shape)
print("y shape:", y.shape)
```

출력

```plain
x: tensor([-3., -1.,  0.,  2.,  5.])
y: tensor([0., 0., 0., 2., 5.])
x shape: torch.Size([5])
y shape: torch.Size([5])
```

음수 값은 0이 되었고, 양수 값은 그대로 남는다, shape는 바뀌지 않는다.

## 4. MLP에서 ReLU는 어디에 넣나요?

일반적인 MLP에서는 `Linear` 은닉층 뒤에 ReLU를 넣는다.

```plain
입력 -> Linear -> ReLU -> Linear -> ReLU -> Linear -> 출력 logits
```

이 순서가 중요한 이유

1. `Linear`가 feature를 새로운 공간으로 변환한다.
2. `ReLU`가 그 변환 결과를 비선형적으로 꺾는다.
3. 다음 `Linear`가 꺾인 표현을 다시 조합.

`Linear`와 `ReLU`가 번갈아 나오면서 모델은 더 복잡한 패턴을 표현할 수 있다.

ReLU를 마지막 출력층 뒤에 무조건 붙이면 안 된다. <br>출력층은 이진 분류, 다중 분류, 회귀인지에 따라 다르게 설계해야 한다

## 5. `nn.Sequential`로 ReLU 적용 MLP 만들기

가장 간단한 구현은 `nn.Sequential`입니다.

```python
import torch
import torch.nn as nn

# 입력 feature 4개를 받아 class 3개에 대한 logits를 출력하는 MLP입니다.
model = nn.Sequential(
    nn.Linear(4, 16),  # feature 4개 -> hidden feature 16개
    nn.ReLU(),         # 첫 번째 은닉층 활성화 함수
    nn.Linear(16, 8),  # hidden feature 16개 -> hidden feature 8개
    nn.ReLU(),         # 두 번째 은닉층 활성화 함수
    nn.Linear(8, 3)    # hidden feature 8개 -> class 3개 logits
)

# 샘플 5개, feature 4개 입력입니다.
x = torch.randn(5, 4)

logits = model(x)

print("x shape     :", x.shape)
print("logits shape:", logits.shape)
```

출력

```plain
x shape     : torch.Size([5, 4])
logits shape: torch.Size([5, 3])
```

여기서 ReLU는 중간 feature의 값을 바꾸지만 batch size는 바꾸지 않는다.

## 6. `nn.Module`로 ReLU 적용 MLP 만들기

`nn.Module` 방식으로 구현

```python
import torch
import torch.nn as nn

class ReLUClassifier(nn.Module):
    """
    feature 4개를 입력받아 class 3개 logits를 출력하는 간단한 MLP입니다.
    """
    def __init__(self, input_dim=4, hidden_dim=16, num_classes=3):
        super().__init__()

        # 첫 번째 선형층입니다.
        self.fc1 = nn.Linear(input_dim, hidden_dim)

        # 은닉층 뒤에 적용할 ReLU입니다.
        self.relu = nn.ReLU()

        # 출력층입니다.
        self.fc2 = nn.Linear(hidden_dim, num_classes)

    def forward(self, x):
        # x shape: (batch_size, input_dim)
        x = self.fc1(x)

        # x shape: (batch_size, hidden_dim)
        # ReLU는 shape를 유지하면서 음수 값을 0으로 바꿉니다.
        x = self.relu(x)

        # logits shape: (batch_size, num_classes)
        logits = self.fc2(x)
        return logits

model = ReLUClassifier()
x = torch.randn(5, 4)
logits = model(x)

print("logits shape:", logits.shape)
assert logits.shape == torch.Size([5, 3])
```

nn.Sequential은 블록을 순서대로 쌓을 때 편하고, nn.Module은 중간 shape 출력, 조건문, 여러 입력 처리처럼 구조를 직접 제어할 때 편하다.

## 7. gradient 흐름과 dead ReLU 직관

gradient는 각 값을 조금 바꿀 때 loss가 어느 방향으로 얼마나 민감하게 변하는지를 나타낸다<br>
optimizer는 보통 이 gradient의 반대 방향으로 parameter를 업데이트한다.

ReLU는 양수 영역에서는 기울기가 1이고, 음수 영역에서는 기울기가 0입니다.

```plain
x > 0이면 gradient가 흐릅니다.
x < 0이면 gradient가 0이 됩니다.
```

간단한 autograd 코드로 확인

```python
import torch
import torch.nn as nn

# gradient를 확인하기 위해 requires_grad=True를 설정합니다.
x = torch.tensor([-2.0, 3.0], requires_grad=True)

relu = nn.ReLU()
y = relu(x)

# y는 Tensor이므로 합계를 만들어 scalar로 바꾼 뒤 backward를 호출합니다.
loss = y.sum()
loss.backward()

print("x:", x)
print("relu(x):", y)
print("x.grad:", x.grad)
```

출력

```plain
x: tensor([-2.,  3.], requires_grad=True)
relu(x): tensor([0., 3.], grad_fn=<ReluBackward0>)
x.grad: tensor([0., 1.])
```

- `-2`는 ReLU를 지나 0이 되었고 gradient도 0입니다. `3`은 그대로 통과했고 gradient는 1입니다.

### Dead ReLU란?

어떤 뉴런이 계속 음수 값만 출력해서 ReLU 뒤에 항상 0이 된다면, 그 뉴런은 학습 신호를 거의 받지 못할 수 있다. 

이런 상황을 직관적으로 **dead ReLU**라고 부른다.

Dead ReLU = 어떤 ReLU 뉴런의 입력이 계속 음수라서 출력도 계속 0이 되고, gradient도 거의 전달되지 않아 학습에 기여하지 못하는 상태

ReLU는 x=0에서 왼쪽 기울기와 오른쪽 기울기가 달라 수학적으로 미분 가능하지 않는다.<br>
PyTorch autograd는 이 지점의 gradient를 0으로 사용합니다. 일반적인 실습에서는 이 규칙을 직접 지정할 필요가 없습니다.
