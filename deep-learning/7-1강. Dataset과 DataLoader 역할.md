## 1. 이번에 우리가 배울 것

지금까지는 더미 Tensor를 직접 만들어 모델에 넣었습니다.

하지만 실제 학습에서는 데이터가 훨씬 많다. <br>
전체 데이터를 한 번에 모델에 넣으면 메모리가 부족할 수 있고,<br> 매번 직접 slicing해서 batch를 만드는 것도 번거롭다

이 문제를 해결하기 위해 PyTorch는 `Dataset`과 `DataLoader`를 제공한다

```
Dataset   : 샘플과 label을 어떻게 보관하고 꺼낼지 정의합니다.
DataLoader: Dataset에서 샘플을 여러 개 묶어 batch로 만들어 줍니다.
```

Dataset -> DataLoader -> Batch 흐름

Dataset은 개별 샘플 접근을 담당하고, DataLoader는 batch 생성과 반복을 담당한다

## 2. 왜 데이터 파이프라인이 필요한가요?

딥러닝 학습 코드는 크게 세 부분으로 나눌 수 있다

| 구성 요소 | 역할 |
| --- | --- |
| 모델 | 입력을 예측값으로 변환한다. |
| 학습 step | loss, backward, optimizer update를 수행한다. |
| 데이터 파이프라인 | 학습 step에 batch를 공급한다. 


데이터 파이프라인이 없으면 학습 코드 안에 데이터 전처리, 파일 읽기, batch 생성, shuffle 로직이 모두 섞인다.<br> 
그러면 코드가 길어지고 디버깅이 어려워진다

`Dataset`과 `DataLoader`는 학습 코드의 가독성과 재사용성을 높여주는 핵심 도구다

## 3. Dataset의 역할

Dataset은 “데이터 하나를 어떻게 꺼낼 것인가”를 담당한다

```
전체 데이터는 몇 개인가요?
idx번째 샘플은 무엇인가요?
idx번째 샘플의 label은 무엇인가요?
필요한 전처리는 어디서 적용하나요?
```

PyTorch에서 Dataset은 보통 다음 두 메서드를 가진다

| 메서드 | 역할 |
| --- | --- |
| `__len__` | 전체 샘플 개수를 반환합니다. |
| `__getitem__` | 특정 index의 샘플과 label을 반환합니다. |

## 4. DataLoader의 역할

DataLoader는 Dataset을 감싸서 batch 단위로 꺼낼 수 있게 해준다

DataLoader가 담당하는 대표 기능은 다음과 같다.

| 기능 | 설명 |
| --- | --- |
| batching | 여러 샘플을 하나의 batch로 묶습니다. |
| shuffling | 학습 데이터를 섞어 모델이 순서에 과하게 의존하지 않게 합니다. |
| iteration | `for batch in loader` 형태로 반복할 수 있게 합니다. |
| parallel loading | `num_workers`를 통해 데이터를 병렬로 읽을 수 있습니다. |

## 5. Tensor 데이터로 DataLoader 만들기

```python
import torch
from torch.utils.data import TensorDataset, DataLoader

# 샘플 20개, feature 4개입니다.
X = torch.randn(20, 4)

# 각 샘플의 class label입니다.
y = torch.tensor([0, 1] * 10, dtype=torch.long)

print("X shape:", X.shape)
print("y shape:", y.shape)
```

이제 `TensorDataset`으로 X와 y를 묶는다

```python
# TensorDataset은 여러 Tensor를 첫 번째 차원 기준으로 묶습니다.
dataset = TensorDataset(X, y)

print("dataset length:", len(dataset))

# 0번째 샘플을 꺼내봅니다.
sample_x, sample_y = dataset[0]

print("sample_x shape:", sample_x.shape)
print("sample_y:", sample_y)
```

출력

```
dataset length: 20
sample_x shape: torch.Size([4])
sample_y: tensor(0)
```

## 6. 첫 번째 batch 확인하기

이제 DataLoader를 만듭니다.

```python
loader = DataLoader(
    dataset,
    batch_size=5,
    shuffle=True
)

# 첫 번째 batch를 꺼냅니다.
batch_x, batch_y = next(iter(loader))

print("batch_x shape:", batch_x.shape)
print("batch_y shape:", batch_y.shape)
print("batch_y:", batch_y)
```
출력
```
batch_x shape: torch.Size([5, 4])
batch_y shape: torch.Size([5])
```
여기서 `batch_x`의 shape가 `(5, 4)`인 이유

```
batch_size = 5
feature 수 = 4

따라서 batch_x shape = (5, 4)
```

DataLoader를 처음 만들거나 전처리를 바꾼 직후에는 next(iter(loader))로 batch 하나를 꺼내 shape를 확인하면 좋다

## 7. 학습 루프와 연결하기


```python
import torch.nn as nn
import torch.optim as optim

model = nn.Linear(4, 2)
criterion = nn.CrossEntropyLoss()
optimizer = optim.Adam(model.parameters(), lr=0.001)

for batch_x, batch_y in loader:
    optimizer.zero_grad()

    # batch_x shape: (batch_size, 4)
    # logits shape : (batch_size, 2)
    logits = model(batch_x)

    # batch_y shape: (batch_size,)
    loss = criterion(logits, batch_y)

    loss.backward()
    optimizer.step()

    print("loss:", loss.item())
    break  # 예시에서는 첫 batch만 실행합니다.
```

## 8. 자주 하는 실수

### 실수 1. X와 y의 첫 번째 차원 길이가 다름

```python
X = torch.randn(20, 4)
# 0 하고 1 9개씩 번갈아서 나옴
y_wrong = torch.tensor([0, 1] * 9, dtype=torch.long)  # 길이 18


try:
    dataset_wrong = TensorDataset(X, y_wrong)
except AssertionError as e:
    print("오류 발생!")
    print(e)
```

X와 y는 샘플 개수가 같아야 합니다.

### 실수 2. batch shape 확인 없이 모델에 바로 넣기

```python
# 좋지 않은 습관이다.
for batch_x, batch_y in loader:
    logits = model(batch_x)
    break
```

처음에는 반드시 shape를 출력하면 좋다
```python
for batch_x, batch_y in loader:
    print(batch_x.shape)
    print(batch_y.shape)
    break
```

### 실수 3. label dtype을 확인하지 않음

`CrossEntropyLoss`를 사용할 때 class index label은 `torch.long`이어야 합니다.

```python
print(batch_y.dtype)
```
