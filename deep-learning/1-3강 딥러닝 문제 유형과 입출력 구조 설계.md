## 1. 이번에 우리가 배울 것

딥러닝 모델을 만들기 전에 가장 먼저 해야 할 일은 문제 유형을 정하는 것입니다.

```
이 문제는 숫자를 예측하는 문제인가요?
두 가지 중 하나를 고르는 문제인가요?
여러 class 중 하나를 고르는 문제인가요?
```

이 질문에 따라 아래 항목이 모두 달라진다

```
정답 y의 형태
모델 마지막 출력층
손실 함수
평가 지표
예측 후처리 방식
```

딥러닝에서 모델 구조는 문제 유형과 분리해서 생각할 수 없습니다.

문제 유형을 잘못 이해하면 출력층 shape, loss, metric이 모두 어긋난다.

## 2. 문제 유형을 먼저 정해야 하는 이유

예를 들어 고객 데이터를 보고 어떤 값을 예측한다고 해보자

| 질문 | 문제 유형 |
| --- | --- |
| 다음 달 구매 금액은 얼마인가요? | 회귀 |
| 이 고객이 이탈할까요? | 이진 분류 |
| 이 문의는 배송/환불/결제/계정 중 어디에 속하나요? | 다중 분류 |

문제 유형이 바뀌면 모델 마지막 layer도 달라진다<br> **logit**은 Sigmoid나 Softmax를 적용하기 전, 모델이 만든 원시 점수입니다.

```
회귀: 필요한 개수의 실수값 출력
이진 분류: logit 1개 출력
다중 클래스 분류: class 개수만큼 logits 출력
```

손실 함수와 정답 Tensor 형식도 달라집니다.

```
회귀: float target + MSELoss
이진 분류: 0/1 float target + BCEWithLogitsLoss
다중 클래스 분류: class index long target + CrossEntropyLoss
```

아래의 짧은 PyTorch 예제를 위에서 아래로 실행하려면 먼저 이 준비 셀을 실행합니다.

```python
import torch
from torch import nn
```

먼저 PyTorch를 import하는 준비 코드를 실행하세요. 그 다음에 나오는 loss_fn 코드는 이 준비가 되어 있어야 실행할 수 있습니다. 반면 logits가 예시로만 나오는 일부 코드는 실제 실행용이 아니라, 변수의 모양(shape)을 설명하기 위한 코드

**다중 클래스와 다중 레이블을 구분하세요.**

- 다중 클래스: 여러 class 중 **하나**를 고른다. 출력은 class별 logits, loss는 보통 `CrossEntropyLoss`입니다.
- 다중 레이블: 한 샘플에 여러 label이 **동시에** 참일 수 있다. label마다 logit 1개를 출력하고 보통 `BCEWithLogitsLoss`를 사용합니다.

## 3. 회귀 문제

회귀는 연속적인 숫자를 예측하는 문제입니다.

### 예시

```
집값 예측
매출 예측
온도 예측
배송 소요 시간 예측
```

### 입출력 구조

```
입력 x: 고객 정보, 상품 정보, 날짜 정보 등
정답 y: 실제 숫자값
모델 출력: 숫자값
```

```
x.shape = [batch_size, feature_dim]
y.shape = [batch_size, 1]
preds.shape = [batch_size, 1]
```

파란 점 데이터에 빨간 회귀 직선을 맞춘 예시입니다.

대표 손실 함수는 다음과 같습니다.

```python
loss_fn = nn.MSELoss()
```

## 4. 이진 분류 문제

이진 분류는 두 가지 class 중 하나를 예측하는 문제다

### 예시

```
스팸 / 정상
이탈 / 유지
불량 / 정상
위험 / 안전
```

### 입출력 구조

```
입력 x: 샘플 feature
정답 y: 0 또는 1
모델 출력: logit 1개
```

```
x.shape = [batch_size, feature_dim]
y.shape = [batch_size, 1]
logits.shape = [batch_size, 1]
```


이진 분류에서는 모델이 확률을 바로 출력한다고 생각하기 쉽지만, PyTorch에서는 보통 **logit**을 출력하고 `BCEWithLogitsLoss`에 넣는다.
```
loss_fn = nn.BCEWithLogitsLoss()

logits = model(X)
loss = loss_fn(logits, y)
```

예측 label이 필요할 때는 sigmoid를 적용한 뒤 threshold를 사용합니다.

```
# sigmoid : 0~1 사이 확률로 바꾼다.
probs = torch.sigmoid(logits)

# 이 코드는 확률이 0.5 이상이면 1, 아니면 0으로 분류
pred_labels = (probs >= 0.5).long()
```

모델의 logit을 sigmoid로 확률로 바꾸고, 그 확률이 0.5 이상인지 판단해서 최종 class label 0 또는 1을 만든다.

⛔ **주의사항**

`BCEWithLogitsLoss`를 사용할 때는 모델 마지막에 Sigmoid를 직접 넣지 않는 것이 일반적이다. 이 손실 함수가 Sigmoid와 BCE를 함께 처리하기 때문이다.
## 5. 다중 분류 문제

다중 분류는 여러 class 중 하나를 고르는 문제입니다.

### 예시

```
이미지: 고양이 / 강아지 / 자동차 / 비행기
문의 유형: 배송 / 환불 / 결제 / 계정
문서 주제: 법률 / 의료 / 금융 / 기술
```

### 입출력 구조

```
입력 x: 샘플 feature
정답 y: class index
모델 출력: class 개수만큼의 logits
```

예를 들어 class가 4개라면 다음과 같습니다.

```
x.shape = [batch_size, feature_dim]
y.shape = [batch_size]
logits.shape = [batch_size, 4]
```

대표 손실 함수는 다음과 같습니다.

```python
loss_fn = nn.CrossEntropyLoss()
```

예측 label이 필요할 때는 가장 큰 logit의 index를 고릅니다. 아래는 `logits.shape == [batch_size, class_count]`일 때의 **읽기용 코드 조각**이다.

```
pred_labels = torch.argmax(logits, dim=1)
```

## 6. 데이터 유형별 입력 구조

딥러닝에서는 데이터 유형에 따라 입력 Tensor의 shape이 달라집니다.

| 데이터 유형 | 예시 | 일반적인 입력 shape |
| --- | --- | --- |
| Tabular | 고객 정보, 거래 데이터 | `[batch_size, feature_dim]` |
| Image | 상품 이미지, 의료 이미지 | `[batch_size, channels, height, width]` |
| 텍스트 token ID | 정수로 바꾼 문장 | `[batch_size, sequence_length]` (`torch.long`) |
| 텍스트 embedding | token별 실수 벡터 | `[batch_size, sequence_length, embedding_dim]` |
| 시계열 | 시간별 센서·수치 feature | `[batch_size, sequence_length, feature_dim]` |

### 6-1. Tabular 데이터

표 데이터는 보통 feature vector로 표현합니다.

```
고객 1명 = [나이, 구매 횟수, 방문 횟수, 평균 결제 금액]
```

이 경우 MLP를 먼저 baseline으로 사용할 수 있다.

MLP = 여러 개의 완전연결층(Linear)과 활성화 함수를 쌓아서 만든 기본적인 신경망
```python
model = nn.Sequential(
    nn.Linear(4, 16),   # 완전연결층
    nn.ReLU(),          # 활성화 함수
    nn.Linear(16, 8),
    nn.ReLU(),
    nn.Linear(8, 1)      # 완전연결층(출력층)
)
```
### 6-2. Image 데이터

이미지는 픽셀의 2차원 공간 구조를 가진다.

```
RGB 이미지 1장 = [3, height, width]
batch 이미지 = [batch_size, 3, height, width]
```

이미지에서는 공간적 특징을 활용하기 위해 CNN을 사용합니다.

CNN = 작은 필터로 이미지의 부분부분을 살펴보며 선·모양·물체 같은 공간적 특징을 학습하는 신경망.

### 6-3. Sequence 데이터

시퀀스는 순서가 중요한 데이터입니다.

```
token ID 문장: [B, L]              # 정수 index, 보통 torch.long
embedding 결과: [B, L, D]         # token마다 D차원 실수 벡터
다변량 시계열: [B, L, F]          # 시점마다 F개 실수 feature
```

여기서 `B`는 batch 크기, `L`은 sequence 길이, `D`는 embedding 차원, `F`는 시계열 feature 수입니다. `nn.RNN(..., batch_first=True)`처럼 `batch_first=True`를 사용하면 입력은 `[B, L, F]`입니다. `batch_first=False`이면 `[L, B, F]`가 되므로, 실제 코드에서는 설정과 `x.shape`를 함께 확인해야 합니다.

이후 Transformer는 이런 순차 처리 한계를 개선하기 위해 등장한 중요한 구조로 연결됩니다.

## 7. 모델 선택 흐름

| 데이터 | 기본 모델 후보 | 이유 |
| --- | --- | --- |
| 표 데이터 | MLP | feature vector를 입력으로 사용하기 쉽습니다. |
| 이미지 데이터 | CNN | 공간적 패턴과 지역 특징을 활용합니다. |
| 시퀀스 데이터 | RNN/LSTM | 순서 정보를 hidden state로 전달합니다. |
| 긴 텍스트/문맥 | Transformer | 긴 문맥과 병렬 처리를 더 잘 다룹니다. |

처음부터 최신 모델을 고르는 것이 목표가 아닙니다. 데이터 구조와 문제 유형을 보고, 가장 단순한 baseline부터 시작한 뒤 필요할 때 모델을 복잡하게 만드는 습관이 중요하다.

## 8. 문제 유형과 입출력 구조 간단 정리

```
회귀는 연속적인 숫자를 예측합니다.
이진 분류는 두 class 중 하나를 예측합니다.
다중 분류는 여러 class 중 하나를 예측합니다.
문제 유형에 따라 출력층 shape, loss, metric이 달라집니다.
데이터 유형에 따라 MLP, CNN, RNN/LSTM 같은 모델 후보가 달라집니다.
```
