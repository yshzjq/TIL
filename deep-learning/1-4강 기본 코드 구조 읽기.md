## 2. PyTorch 코드의 기본 구조

딥러닝 학습 코드는 보통 아래 순서를 따릅니다.

```
import
-> 설정값 정의
-> 데이터 준비
-> 모델 정의
-> loss / optimizer 정의
-> train 함수
-> validate 함수
-> epoch 반복
-> 로그 출력
-> 모델 저장
```

코드를 읽을 때는 아래 질문을 순서대로 던지면 좋다.

```
이 코드는 어떤 라이브러리를 쓰나요?
데이터는 어디서 오나요?
입력과 정답 shape은 무엇인가요?
모델은 어떤 구조인가요?
loss는 무엇인가요?
optimizer는 무엇인가요?
train loop에서 parameter가 업데이트되나요?
validation loop에서 gradient 계산을 끄고 있나요?
metric은 어디서 계산하나요?
모델은 어디에 저장하나요?
```

## 3. import 영역 읽기

import 영역에서는 어떤 도구를 사용하는지 확인

```python
import torch
from torch import nn
from torch.utils.data import DataLoader, TensorDataset
```

| 코드 | 의미 |
| --- | --- |
| `torch` | Tensor 연산과 PyTorch 핵심 기능을 사용합니다. |
| `nn` | neural network layer와 loss function을 사용합니다. |
| `DataLoader` | 데이터를 batch 단위로 꺼냅니다. |
| `TensorDataset` | Tensor 여러 개를 묶어 Dataset으로 만듭니다. |

import 영역을 보면 이 코드가 어떤 작업을 할지 대략 짐작할 수 있다

예를 들어 torchvision이 보이면 이미지 데이터일 가능성이 높고, transformers가 보이면 NLP 또는 LLM 관련 코드일 가능성이 높다


## 4. 데이터 영역 읽기

데이터 영역에서는 입력과 정답을 확인.

```python
dataset = TensorDataset(X, y)
train_loader = DataLoader(dataset, batch_size=32, shuffle=True)
```

확인해야 할 질문은 다음과 같습니다.

```
X는 어떤 shape인가요?
y는 어떤 shape인가요?
batch_size는 얼마인가요?
shuffle은 True인가요?
train과 validation이 나누어져 있나요?
```

DataLoader는 Dataset에서 한 번에 하나씩 가져오는 feature와 label을 minibatch로 전달하고, epoch마다 데이터를 섞는(Shuffle) 등의 복잡성을 추상화해 준다.

epoch(에포크)는 전체 학습 데이터를 모델이 한 번 전부 본 것

## 5. 모델 영역 읽기

## 6. loss와 optimizer 영역 읽기

loss와 optimizer는 학습 목표와 업데이트 방식을 결정합니다.

```python
loss_fn = nn.MSELoss()
optimizer = torch.optim.SGD(model.parameters(), lr=0.05)
```

| 코드 | 의미 |
| --- | --- |
| `nn.MSELoss()` | 회귀 문제에서 예측값과 정답의 평균제곱오차를 계산합니다. |
| `model.parameters()` | optimizer가 업데이트할 parameter 목록입니다. |
| `lr=0.05` | learning rate입니다. 한 번 업데이트할 때 이동하는 크기를 의미합니다. |

최적화는 각 학습 단계에서 모델의 오류를 줄이기 위해 모델 매개변수를 조정하는 과정

## 7. train/valid loop 영역 읽기

train loop에서 반드시 확인할 코드

```python
model.train()
optimizer.zero_grad()
preds = model(batch_x)
loss = loss_fn(preds, batch_y)
loss.backward()
optimizer.step()
```


validation loop에서는 다음을 확인

```python
model.eval()

with torch.no_grad():
    preds = model(batch_x)
```

`model.eval()`은 Dropout·BatchNorm 같은 층을 평가 모드로 바꾸고, `torch.no_grad()`는 gradient 기록을 끕니다. 서로 다른 역할이므로 보통 함께 사용.

validation loop에서는 parameter를 업데이트하지 않는다

⛔ **주의사항**

train loop와 validation loop를 섞어 쓰면 안 됩니다.

검증 단계에서 `optimizer.step()`이 실행되면 검증 데이터로 모델이 학습되어 평가가 왜곡됩니다.

## 8. metric과 checkpoint 영역 읽기

### 8-1. metric 기록 위치

metric은 보통 epoch마다 기록합니다.

metric = 측정한 성능 값(epoch가 끝난 시점의 모델 성능을 측정해서 기록)


```python
history.append({
    "epoch": epoch,
    "train_loss": train_loss,
    "valid_loss": valid_loss,
})
```

학습이 잘 되고 있는지 확인하려면 loss와 metric을 함께 봐야한다

```
train loss는 줄어드나요?
valid loss도 줄어드나요?
train loss만 줄고 valid loss는 증가하지 않나요?
```

### 8-2. checkpoint 저장 위치

checkpoint는 모델을 나중에 다시 불러오기 위해 저장하는 파일입니다.

```python
torch.save(model.state_dict(), "model.pt")
```

이후 수업에서는 단순히 모델만 저장하는 것이 아니라 아래 정보까지 함께 저장하는 방법을 배웁니다.

```
model_state_dict
optimizer_state_dict
epoch
best_valid_loss
config
```

⭐ **중요**

좋은 실험 코드는 한 번 실행되는 코드가 아니라, 나중에 다시 실행하고 비교할 수 있는 코드다.

## 9. 코드스니펫: 구조 해석용 학습 코드

아래 코드를 읽고 각 블록이 어떤 역할인지 주석으로 확인하세요.

### [코드스니펫] 기본 코드 구조 읽기

아래 블록은 import·데이터 생성·모델·학습·검증을 모두 포함한 **독립 실행 예제**입니다. 새 런타임에서 이 블록 하나를 위에서 아래로 실행합니다.

```python
# 1. import
import torch
from torch import nn
from torch.utils.data import DataLoader, TensorDataset, random_split

# 2. config / hyperparameter
SEED = 42
BATCH_SIZE = 32
LR = 0.05
EPOCHS = 5

torch.manual_seed(SEED)

# 3. data
X = torch.randn(200, 4)
true_w = torch.tensor([[2.0], [-1.0], [0.5], [3.0]])
y = X @ true_w + 0.1 * torch.randn(200, 1)

dataset = TensorDataset(X, y)
train_dataset, valid_dataset = random_split(dataset, [160, 40])

train_loader = DataLoader(train_dataset, batch_size=BATCH_SIZE, shuffle=True)
valid_loader = DataLoader(valid_dataset, batch_size=BATCH_SIZE, shuffle=False)

# 4. device
device = torch.device("cuda" if torch.cuda.is_available() else "cpu")

# 5. model
model = nn.Sequential(
    nn.Linear(4, 16),
    nn.ReLU(),
    nn.Linear(16, 1),
).to(device)

# 6. loss / optimizer
loss_fn = nn.MSELoss()
optimizer = torch.optim.SGD(model.parameters(), lr=LR)

# 7. train function
def train_one_epoch(model, dataloader, loss_fn, optimizer, device):
    model.train()
    total_loss = 0.0

    for batch_x, batch_y in dataloader:
        batch_x = batch_x.to(device)
        batch_y = batch_y.to(device)

        optimizer.zero_grad()
        preds = model(batch_x)
        loss = loss_fn(preds, batch_y)
        loss.backward()
        optimizer.step()

        total_loss += loss.item() * batch_x.size(0)

    return total_loss / len(dataloader.dataset)

# 8. validation function
@torch.no_grad()
def validate(model, dataloader, loss_fn, device):
    model.eval()
    total_loss = 0.0

    for batch_x, batch_y in dataloader:
        batch_x = batch_x.to(device)
        batch_y = batch_y.to(device)

        preds = model(batch_x)
        loss = loss_fn(preds, batch_y)

        total_loss += loss.item() * batch_x.size(0)

    return total_loss / len(dataloader.dataset)

# 9. epoch loop / logging
history = []

for epoch in range(1, EPOCHS + 1):
    train_loss = train_one_epoch(model, train_loader, loss_fn, optimizer, device)
    valid_loss = validate(model, valid_loader, loss_fn, device)

    log = {
        "epoch": epoch,
        "train_loss": train_loss,
        "valid_loss": valid_loss,
    }
    history.append(log)

    print(
        f"Epoch {epoch} | "
        f"train_loss={train_loss:.4f} | "
        f"valid_loss={valid_loss:.4f}"
    )

# 10. checkpoint
torch.save(model.state_dict(), "basic_mlp_regression.pt")
```

실행하면 epoch마다 아래 형식의 로그가 한 줄씩 출력된다.

```
Epoch 1 | train_loss=... | valid_loss=...
...
Epoch 5 | train_loss=... | valid_loss=...
```

무작위 초기값과 실행 환경에 따라 소수점 값은 달라질 수 있다. 

각 epoch에서 train/valid loss가 모두 기록되는지와 마지막에 basic_mlp_regression.pt 파일이 저장되는지를 확인
