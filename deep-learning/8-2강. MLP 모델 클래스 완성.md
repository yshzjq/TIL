## 1. 이번에 우리가 배울 것

```
입력 이미지 -> Flatten -> Linear -> ReLU -> Linear -> logits
```

## 2. MLP 구조

MLP는 입력을 feature 벡터로 바꾼 뒤, 여러 선형층과 활성화 함수를 통과시키는 구조

```
(batch_size, 1, 28, 28)
-> (batch_size, 784)
-> (batch_size, hidden_dim)
-> (batch_size, num_classes)
```

여기서 `num_classes=10`이라면 마지막 출력은 class 10개에 대한 점수다

다중 분류에서 마지막 출력은 softmax 확률이 아니라 logits다. <br>`CrossEntropyLoss`와 연결할 때는 logits를 그대로 사용한다.

## 3. 입력 shape에서 `input_dim` 계산하기

28x28 흑백 이미지는 다음 shape를 가진다

```
(1, 28, 28)
```

샘플 하나의 전체 feature 수는 다음과 같다.

```
1 * 28 * 28 = 784
```

따라서 첫 번째 `nn.Linear`의 `in_features`는 784가 된다

```python
input_dim = 1 * 28 * 28
print(input_dim)
```

출력

```
784
```

## 4. MLP 클래스 작성

```python
import torch
import torch.nn as nn

class MLPClassifier(nn.Module):
    """
    28x28 흑백 이미지를 입력으로 받아
    10개 class에 대한 logits를 출력하는 MLP 모델입니다.
    """
    def __init__(self, input_dim=784, hidden_dim=128, num_classes=10):
        super().__init__()

        # 이미지 입력을 (batch_size, input_dim) 형태로 펼칩니다.
        self.flatten = nn.Flatten()

        # 첫 번째 선형층입니다.
        self.fc1 = nn.Linear(input_dim, hidden_dim)

        # 비선형성을 추가하는 활성화 함수입니다.
        self.relu = nn.ReLU()

        # 출력층입니다.
        self.fc2 = nn.Linear(hidden_dim, num_classes)

    def forward(self, x):
        # x shape: (batch_size, 1, 28, 28)
        x = self.flatten(x)

        # x shape: (batch_size, 784)
        x = self.fc1(x)

        # x shape: (batch_size, hidden_dim)
        x = self.relu(x)

        # logits shape: (batch_size, num_classes)
        logits = self.fc2(x)
        return logits
```

## 5. hidden size와 class 수를 바꿔보기

좋은 모델 코드는 hidden size와 class 수가 바뀌어도 정상 동작해야 한다

```python
images = torch.randn(4, 1, 28, 28)

for hidden_dim in [32, 64, 128]:
    model = MLPClassifier(input_dim=784, hidden_dim=hidden_dim, num_classes=10)
    logits = model(images)
    print(f"hidden_dim={hidden_dim:3d} -> logits shape={logits.shape}")
```
출력
```
hidden_dim= 32 -> logits shape=torch.Size([4, 10])
hidden_dim= 64 -> logits shape=torch.Size([4, 10])
hidden_dim=128 -> logits shape=torch.Size([4, 10])
```

hidden size는 중간 표현의 크기를 바꾸지만, 마지막 class 수가 10이면 최종 logits shape는 `(batch_size, 10)`다.

## 6. parameter 수 확인하기

모델이 커질수록 parameter 수가 늘어난다. <br>
parameter 수는 학습 시간, 메모리 사용량, 과적합 가능성과 연결된다

```python
# 모델의 모든 weight와 bias 중에서 requires_grad=True인 학습 가능한 parameter만 골라 원소 개수를 모두 더하는 코드

def count_parameters(model):
    """
    학습 가능한 parameter 수를 계산한다
    """
    return sum(p.numel() for p in model.parameters() if p.requires_grad)

model = MLPClassifier(input_dim=784, hidden_dim=128, num_classes=10)
print("parameter count:", count_parameters(model))
```
출력

```
fc1 weight: 784 * 128 = 100,352
fc1 bias  : 128
fc2 weight: 128 * 10 = 1,280
fc2 bias  : 10
전체       : 100,352 + 128 + 1,280 + 10 = 101,770
```

## 7. 모델 구조 점검 함수 만들기

```python
def check_model(model, sample_input, expected_shape):
    """
    모델 출력 shape와 parameter 수를 함께 확인
    """
    logits = model(sample_input)

    print("input shape    :", sample_input.shape)
    print("logits shape   :", logits.shape)
    print("parameter count:", count_parameters(model))

    assert logits.shape == expected_shape, (
        f"출력 shape가 다릅니다. expected={expected_shape}, actual={logits.shape}"
    )

    return logits

images = torch.randn(8, 1, 28, 28)
model = MLPClassifier(hidden_dim=64)
logits = check_model(model, images, torch.Size([8, 10]))
```
## 8. 자주 하는 실수

### 실수 1. `input_dim`을 이미지 한 변 길이로 넣기
```python
# 잘못된 예시입니다.
# 28x28 이미지를 flatten하면 784인데 28만 넣었습니다.
model = MLPClassifier(input_dim=28, hidden_dim=64, num_classes=10)
```

수정

```python
model = MLPClassifier(input_dim=1 * 28 * 28, hidden_dim=64, num_classes=10)
```

### 실수 2. 출력 class 수를 label 종류와 다르게 설정하기

class가 10개인 문제라면 출력층의 `num_classes`도 10이어야 한다

```python
# class가 10개라면
model = MLPClassifier(num_classes=10)
```

`CrossEntropyLoss`를 사용할 때 logits shape는 `(batch_size, num_classes)`, label shape는 `(batch_size,)`여야 합니다.
