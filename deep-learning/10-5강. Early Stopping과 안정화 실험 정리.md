Early Stopping은 validation 성능이 더 이상 좋아지지 않으면 학습을 멈추는 방법

```
epoch 반복
-> validation loss 확인
-> 이전 best보다 좋아졌는지 확인
-> 좋아졌다면 checkpoint 저장
-> 오래 개선되지 않으면 학습 중단
```

validation loss가 가장 낮은 epoch를 best epoch로 보고, 이후 일정 epoch 동안 개선이 없으면 학습을 멈춘다


## 2. Early Stopping이란 무엇인가요?

Early Stopping은 validation 성능이 개선되지 않을 때 학습을 멈추는 방법입

모델은 epoch가 늘어날수록 train 데이터에 더 잘 맞아갑니다. 하지만 어느 시점 이후에는 validation loss가 다시 올라갈 수 있다.<br>
이때 계속 학습하면 과적합이 심해질 수 있다.

```
초반: train loss ↓, valid loss ↓
중반: valid loss 최저점 도달
후반: train loss는 계속 ↓, valid loss는 ↑
```

Early Stopping은 보통 validation loss를 기준으로 판단

## 3. best checkpoint를 저장해야 하는 이유

학습을 마지막 epoch까지 진행했다고 해서 마지막 모델이 가장 좋은 모델이라는 보장은 없다.

예시

| epoch | valid loss |
| --- | --- |
| 8 | 0.45 |
| 9 | 0.41 |
| 10 | 0.39 |
| 11 | 0.42 |
| 12 | 0.46 |

이 경우 가장 좋은 모델은 12 epoch 모델이 아니라 10 epoch 모델이다

Early Stopping을 사용할 때는 단순히 학습을 멈추는 것뿐 아니라, validation loss가 가장 좋았던 모델을 저장해야 한다

## 4. patience와 min_delta

Early Stopping에서 자주 쓰는 두 인자가 있다

| 인자 | 의미 |
| --- | --- |
| `patience` | 몇 epoch 동안 개선이 없어도 기다릴지 정합니다. |
| `min_delta` | best loss보다 실제로 낮아진 폭이 이 값 이상일 때 개선으로 봅니다. |

`patience=3`, `min_delta=0.001`이라면

```
best validation loss보다 실제로 0.001 이상 낮아지지 않은 epoch가
3번 연속 발생하면 학습을 멈춥니다.
같은 값은 min_delta가 0이어도 개선으로 세지 않습니다.
```

`patience`는 성급하게 멈추지 않기 위한 기다림이다<br>
validation loss는 조금 흔들릴 수 있으므로 한 번 나빠졌다고 바로 멈추면 안 된다

## 5. EarlyStopping 클래스 구현

아래 구현은 validation loss가 유한한 값인지 확인하고, 중단 판단과 “best checkpoint를 저장해야 하는가”를 함께 반환한다

```python
import math

class EarlyStopping:
    """validation loss 기준 Early Stopping 상태를 관리합니다."""

    def __init__(self, patience=3, min_delta=0.0):
        if (
            isinstance(patience, bool)
            or not isinstance(patience, int)
            or patience < 1
        ):
            raise ValueError("patience는 1 이상의 정수여야 합니다.")

        min_delta = float(min_delta)
        if not math.isfinite(min_delta) or min_delta < 0:
            raise ValueError("min_delta는 0 이상의 유한한 값이어야 합니다.")

        self.patience = patience
        self.min_delta = min_delta
        self.best_loss = None
        self.counter = 0
        self.should_stop = False

    def step(self, valid_loss):
        """
        반환값:
            (should_stop, improved)
        """

        valid_loss = float(valid_loss)
        if not math.isfinite(valid_loss):
            raise ValueError(
                "valid_loss가 NaN 또는 inf입니다. 학습과 데이터를 점검하세요."
            )

        # 이미 중단 조건에 도달한 상태를 다시 진행하지 않습니다.
        if self.should_stop:
            return True, False

        # 첫 유한 loss는 항상 best이므로 checkpoint를 저장합니다.
        if self.best_loss is None:
            self.best_loss = valid_loss
            self.counter = 0
            return False, True

        improvement = self.best_loss - valid_loss

        # 실제로 더 낮고, 개선 폭이 min_delta 이상이어야 합니다.
        # 따라서 min_delta=0이어도 같은 loss는 개선이 아닙니다.
        improved = (
            improvement > 0.0
            and improvement >= self.min_delta
        )

        if improved:
            self.best_loss = valid_loss
            self.counter = 0
        else:
            self.counter += 1

        self.should_stop = self.counter >= self.patience
        return self.should_stop, improved

    def state_dict(self):
        """학습 재개용으로 내부 상태를 기본 자료형으로 반환합니다."""

        return {
            "patience": self.patience,
            "min_delta": self.min_delta,
            "best_loss": self.best_loss,
            "counter": self.counter,
            "should_stop": self.should_stop,
        }

    def load_state_dict(self, state):
        """checkpoint에서 EarlyStopping 상태를 복원합니다."""

        required_keys = {
            "patience",
            "min_delta",
            "best_loss",
            "counter",
            "should_stop",
        }
        missing_keys = required_keys - state.keys()
        if missing_keys:
            raise KeyError(
                f"EarlyStopping 상태 key가 없습니다: {sorted(missing_keys)}"
            )

        patience = int(state["patience"])
        min_delta = float(state["min_delta"])
        best_loss = state["best_loss"]
        counter = int(state["counter"])

        if patience < 1:
            raise ValueError("복원한 patience가 1보다 작습니다.")
        if not math.isfinite(min_delta) or min_delta < 0:
            raise ValueError("복원한 min_delta가 올바르지 않습니다.")

        if best_loss is not None:
            best_loss = float(best_loss)
            if not math.isfinite(best_loss):
                raise ValueError("복원한 best_loss가 유한하지 않습니다.")

        if counter < 0:
            raise ValueError("복원한 counter가 음수입니다.")

        self.patience = patience
        self.min_delta = min_delta
        self.best_loss = best_loss
        self.counter = counter
        self.should_stop = bool(state["should_stop"])
```

상태 저장과 복원을 간단히 확인

```python
early_stopper = EarlyStopping(patience=3, min_delta=0.001)
should_stop, improved = early_stopper.step(0.50)

saved_state = early_stopper.state_dict()

restored_stopper = EarlyStopping()
restored_stopper.load_state_dict(saved_state)

print("improved:", improved)
print("restored best_loss:", restored_stopper.best_loss)
print("restored counter:", restored_stopper.counter)
```

출력

```
improved: True
restored best_loss: 0.5
restored counter: 0
```

## 6. 학습 루프에 Early Stopping 연결

```python
import random
from pathlib import Path

import numpy as np
import torch
import torch.nn as nn
from torch.utils.data import DataLoader, TensorDataset, random_split

# =========================================================
# 1. 재현성을 위한 seed 고정
# =========================================================

SEED = 42

random.seed(SEED)
np.random.seed(SEED)
torch.manual_seed(SEED)

if torch.cuda.is_available():
    torch.cuda.manual_seed_all(SEED)

# 사용할 device를 정합니다.
device = torch.device(
    "cuda" if torch.cuda.is_available() else "cpu"
)

print("device:", device)

# =========================================================
# 2. 간단한 가상 분류 데이터 만들기
# =========================================================

# 입력 feature 수와 class 수입니다.
input_dim = 20
num_classes = 3
num_samples = 1200

# 데이터 생성 자체도 재현 가능하게 별도의 Generator를 사용합니다.
data_generator = torch.Generator().manual_seed(SEED)

# 입력 데이터
X = torch.randn(
    num_samples,
    input_dim,
    generator=data_generator,
)

# 정답 label을 만들기 위한 가상의 weight와 bias입니다.
true_weight = torch.randn(
    input_dim,
    num_classes,
    generator=data_generator,
)

true_bias = torch.randn(
    num_classes,
    generator=data_generator,
)

# 각 class에 대한 score를 만듭니다.
scores = X @ true_weight + true_bias

# 너무 단순한 데이터가 되지 않도록 약간의 noise를 추가합니다.
scores += 0.5 * torch.randn(
    scores.shape,
    generator=data_generator,
)

# 가장 큰 score를 가진 class를 정답으로 사용합니다.
y = scores.argmax(dim=1)

dataset = TensorDataset(X, y)

print("X shape:", X.shape)
print("y shape:", y.shape)

# =========================================================
# 3. train / valid / test 분리
# =========================================================

# 전체 1200개 데이터를
# train 800 / valid 200 / test 200으로 나눕니다.
split_generator = torch.Generator().manual_seed(SEED)

train_dataset, valid_dataset, test_dataset = random_split(
    dataset,
    lengths=[800, 200, 200],
    generator=split_generator,
)

print("train:", len(train_dataset))
print("valid:", len(valid_dataset))
print("test :", len(test_dataset))

# =========================================================
# 4. DataLoader 만들기
# =========================================================

# train DataLoader의 shuffle 순서를 제어하기 위한 Generator입니다.
# fit_with_early_stopping()의 loader_generator 인자로도 전달합니다.
loader_generator = torch.Generator().manual_seed(SEED)

train_loader = DataLoader(
    train_dataset,
    batch_size=64,
    shuffle=True,
    generator=loader_generator,
)

valid_loader = DataLoader(
    valid_dataset,
    batch_size=64,
    shuffle=False,
)

test_loader = DataLoader(
    test_dataset,
    batch_size=64,
    shuffle=False,
)

# =========================================================
# 5. 간단한 MLP 모델
# =========================================================

class EarlyStoppingDemoMLP(nn.Module):
    def __init__(self, input_dim, num_classes):
        super().__init__()

        self.net = nn.Sequential(
            nn.Linear(input_dim, 64),
            nn.ReLU(),
            nn.Dropout(p=0.2),
            nn.Linear(64, num_classes),
        )

    def forward(self, x):
        return self.net(x)

model = EarlyStoppingDemoMLP(
    input_dim=input_dim,
    num_classes=num_classes,
).to(device)

# =========================================================
# 6. Loss와 Optimizer
# =========================================================

criterion = nn.CrossEntropyLoss()

optimizer = torch.optim.Adam(
    model.parameters(),
    lr=0.001,
)

# =========================================================
# 7. history와 config
# =========================================================

history = {
    "train_loss": [],
    "train_acc": [],
    "valid_loss": [],
    "valid_acc": [],
}

config = {
    "seed": SEED,
    "input_dim": input_dim,
    "num_classes": num_classes,
    "batch_size": 64,
    "learning_rate": 0.001,
}

# checkpoint가 저장될 폴더입니다.
run_dir = Path("runs/early_stopping_demo")
run_dir.mkdir(parents=True, exist_ok=True)

# =========================================================
# 8. 1 epoch 학습 함수
# =========================================================

def train_one_epoch(
    model,
    train_loader,
    criterion,
    optimizer,
    device,
):
    model.train()

    total_loss = 0.0
    total_correct = 0
    total_samples = 0

    for X_batch, y_batch in train_loader:
        X_batch = X_batch.to(device)
        y_batch = y_batch.to(device)

        optimizer.zero_grad()

        logits = model(X_batch)
        loss = criterion(logits, y_batch)

        loss.backward()
        optimizer.step()

        batch_size = X_batch.size(0)

        total_loss += loss.item() * batch_size
        total_correct += (
            logits.argmax(dim=1) == y_batch
        ).sum().item()

        total_samples += batch_size

    average_loss = total_loss / total_samples
    accuracy = total_correct / total_samples

    return average_loss, accuracy

# =========================================================
# 9. validation / test 평가 함수
# =========================================================

@torch.no_grad()
def validate(
    model,
    data_loader,
    criterion,
    device,
):
    model.eval()

    total_loss = 0.0
    total_correct = 0
    total_samples = 0

    for X_batch, y_batch in data_loader:
        X_batch = X_batch.to(device)
        y_batch = y_batch.to(device)

        logits = model(X_batch)
        loss = criterion(logits, y_batch)

        batch_size = X_batch.size(0)

        total_loss += loss.item() * batch_size
        total_correct += (
            logits.argmax(dim=1) == y_batch
        ).sum().item()

        total_samples += batch_size

    average_loss = total_loss / total_samples
    accuracy = total_correct / total_samples

    return average_loss, accuracy

# =========================================================
# 10. 실습용 checkpoint 저장 함수
# =========================================================

def save_checkpoint(
    model,
    optimizer,
    completed_epochs,
    best_valid_loss,
    history,
    config,
    loader_generator,
    path,
    early_stopper,
):
    path = Path(path)
    path.parent.mkdir(parents=True, exist_ok=True)

    checkpoint = {
        "model_state_dict": model.state_dict(),
        "optimizer_state_dict": optimizer.state_dict(),
        "completed_epochs": completed_epochs,
        "best_valid_loss": best_valid_loss,
        "history": history,
        "config": config,

        # train DataLoader의 shuffle 상태
        "loader_generator_state": loader_generator.get_state(),

        # EarlyStopping 내부 상태
        "early_stopper_state": early_stopper.state_dict(),

        # PyTorch 난수 상태
        "torch_rng_state": torch.get_rng_state(),
    }

    if torch.cuda.is_available():
        checkpoint["cuda_rng_state_all"] = (
            torch.cuda.get_rng_state_all()
        )

    temporary_path = path.with_suffix(
        path.suffix + ".tmp"
    )

    torch.save(checkpoint, temporary_path)
    temporary_path.replace(path)

print("실행 준비 완료!")
```

```python
from pathlib import Path
import torch

def fit_with_early_stopping(
    model,
    train_loader,
    valid_loader,
    test_loader,
    criterion,
    optimizer,
    device,
    num_epochs,
    history,
    config,
    loader_generator,
    run_dir,
    train_one_epoch_fn,
    validate_fn,
    save_checkpoint_fn,
    patience=3,
    min_delta=0.001,
):
    early_stopper = EarlyStopping(
        patience=patience,
        min_delta=min_delta,
    )

    run_dir = Path(run_dir)
    best_model_path = run_dir / "checkpoints" / "best_weights.pt"
    last_checkpoint_path = run_dir / "checkpoints" / "last.pt"
    best_model_path.parent.mkdir(parents=True, exist_ok=True)

    for epoch in range(1, num_epochs + 1):
        train_loss, train_acc = train_one_epoch_fn(
            model,
            train_loader,
            criterion,
            optimizer,
            device,
        )
        valid_loss, valid_acc = validate_fn(
            model,
            valid_loader,
            criterion,
            device,
        )

        # 완료된 epoch의 metric을 먼저 기록합니다.
        history["train_loss"].append(train_loss)
        history["train_acc"].append(train_acc)
        history["valid_loss"].append(valid_loss)
        history["valid_acc"].append(valid_acc)

        # 한 번만 판단해 중단 여부와 best 저장 여부를 함께 받습니다.
        should_stop, improved = early_stopper.step(valid_loss)

        if improved:
            temporary_path = best_model_path.with_suffix(
                best_model_path.suffix + ".tmp"
            )
            torch.save(model.state_dict(), temporary_path)
            temporary_path.replace(best_model_path)
            print(f"  -> best model saved: {best_model_path}")

        # EarlyStopping 갱신까지 끝난 완료-epoch 경계를 저장합니다.
        save_checkpoint_fn(
            model=model,
            optimizer=optimizer,
            completed_epochs=epoch,
            best_valid_loss=early_stopper.best_loss,
            history=history,
            config=config,
            loader_generator=loader_generator,
            path=last_checkpoint_path,
            early_stopper=early_stopper,
        )

        print(
            f"Epoch {epoch:03d}/{num_epochs:03d} | "
            f"train_loss={train_loss:.4f} | "
            f"train_acc={train_acc:.4f} | "
            f"valid_loss={valid_loss:.4f} | "
            f"valid_acc={valid_acc:.4f}"
        )

        if should_stop:
            print(f"Early stopping triggered at epoch {epoch}")
            break

    # 마지막 weight가 아니라 best validation weight를 복원합니다.
    best_state = torch.load(
        best_model_path,
        map_location="cpu",
        weights_only=True,
    )
    model.load_state_dict(best_state)
    model.eval()

    # 모든 설정 선택이 끝난 뒤 test set을 한 번만 평가합니다.
    test_loss, test_acc = validate_fn(
        model,
        test_loader,
        criterion,
        device,
    )
    print(f"test_loss={test_loss:.4f} test_acc={test_acc:.4f}")

    return model, history, test_loss, test_acc
```

재개할 때는 같은 설정으로 EarlyStopping 객체를 먼저 만들고, <br>`load_checkpoint`에 전달해 상태를 복원합니다. 

새 epoch의 DataLoader iterator를 만들기 전에 모든 난수와 generator 상태까지 복원해야 한다

Early Stopping으로 loop를 멈춘 뒤 메모리의 model은 마지막 epoch 상태다.

최종 평가나 배포 전에는 반드시 best weight를 다시 불러오고 `model.eval()`을 호출합니다. test 결과를 보고 설정을 다시 바꾸지 않습니다.

## 7. 안정화 실험 결과 정리


실제 보고서에는 같은 데이터 split과 평가 절차로 직접 실행한 값만 기록하고,<br> 
가능하면 여러 seed의 평균과 변동도 함께 표시하면 좋다

| 실험명 | Dropout | BatchNorm | Early Stopping | best valid loss | best valid acc | 메모 |
| --- | --- | --- | --- | --- | --- | --- |
| baseline | X | X | X | 0.51 | 0.82 | 과적합 발생 |
| dropout | O | X | X | 0.47 | 0.84 | train acc는 낮아졌지만 valid 개선 |
| batchnorm | X | O | X | 0.45 | 0.85 | 학습 곡선 안정화 |
| dropout+bn+early | O | O | O | 0.42 | 0.87 | best 모델 저장 |

실험 리포트에는 단순히 성능이 좋아졌다가 아니라 다음 내용을 함께 적어야 한다

```
어떤 설정을 바꿨는가?
valid loss와 valid acc가 어떻게 변했는가?
과적합 gap이 줄었는가?
best epoch는 몇 epoch였는가?
```

## 8. 자주 하는 실수

### 실수 1. 마지막 epoch 모델만 저장

마지막 모델이 best 모델이라는 보장은 없다.<br>
 validation loss가 가장 낮았던 시점의 모델을 저장해야한다.

### 실수 2. train loss 기준으로 Early Stopping을 적용합니다

Early Stopping은 일반적으로 validation loss를 기준으로 적용한다<br>
train loss는 계속 낮아질 수 있기 때문입니다.

### 실수 3. patience를 너무 작게 둡니다

`patience=1`처럼 너무 작게 설정하면 validation loss가 한 번 흔들린 것만으로 학습이 멈출 수 있다.
