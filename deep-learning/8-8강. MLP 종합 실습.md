## 1. 이번에 우리가 만들 것

```
데이터 생성
-> TensorDataset
-> train/valid split
-> DataLoader
-> MLP 모델
-> loss/optimizer
-> train loop
-> validation loop
-> history 저장
-> 그래프 시각화
```

이 흐름은 앞으로 CNN, RNN, Transformer 계열 모델을 학습할 때도 거의 그대로 반복된다
모델 구조는 달라지지만, 학습 파이프라인의 뼈대는 크게 바뀌지 않는다

## 2. 전체 파이프라인 구조

먼저 전체 코드를 크게 나누면 다음과 같다.

| 단계 | 역할 |
| --- | --- |
| 데이터 준비 | 입력 Tensor와 정답 Tensor 생성 |
| Dataset 구성 | 입력과 정답을 하나의 데이터셋으로 묶기 |
| DataLoader 구성 | batch 단위로 데이터를 공급하기 |
| 모델 정의 | MLP 구조 만들기 |
| 학습 준비 | loss와 optimizer 설정 |
| 학습/검증 | epoch 단위로 train과 validation 실행 |
| 결과 확인 | 로그 출력과 그래프 시각화 |


## 3. 데이터 만들기

외부 데이터셋을 다운로드하지 않고, PyTorch Tensor만으로 간단한 분류 데이터를 만들어본다.

```python
import torch

# 결과 재현을 위해 seed를 고정합니다.
torch.manual_seed(42)

# 샘플 수와 feature 수를 정합니다.
num_samples = 1000
num_features = 4
num_classes = 3

# 입력 데이터 X를 만듭니다.
# shape: (1000, 4)
X = torch.randn(num_samples, num_features)

# 정답을 만들기 위한 임시 weight입니다.
# 실제 학습할 모델의 weight가 아니라, synthetic label을 만들기 위한 도구입니다.
true_W = torch.tensor([
    [1.0, -1.0, 0.5],
    [0.5, 1.5, -1.0],
    [-1.0, 0.5, 1.0],
    [1.0, 0.2, -0.5]
])

# 각 class에 대한 점수를 만듭니다.
# shape: (1000, 3)
logits_for_label = X @ true_W

# 가장 큰 점수를 가진 class를 정답으로 사용합니다.
# shape: (1000,)
y = logits_for_label.argmax(dim=1)

print("X shape:", X.shape)
print("y shape:", y.shape)
print("class counts:", torch.bincount(y))
```

여기서 만든 데이터는 실제 비즈니스 데이터가 아닙니다. 하지만 학습 파이프라인을 연습하기에는 충분하다. <br>
실제 데이터셋으로 넘어가기 전에 파이프라인이 정상적으로 동작하는지 확인하는 용도로 좋다


## 4. train/valid/test split과 DataLoader 구성

입력과 정답을 `TensorDataset`으로 묶고, train/valid/test 데이터로 나눈다.<br> 
전처리 통계와 모델 학습에는 train만 사용하고, valid는 모델 선택, test는 최종 평가에 사용된다.

```python
from torch.utils.data import TensorDataset, DataLoader, random_split

# X와 y를 하나의 Dataset으로 묶습니다.
# dataset[i]를 호출하면 (X[i], y[i])가 반환됩니다.
dataset = TensorDataset(X, y)

# train, validation, test 비율을 정합니다.
train_size = int(len(dataset) * 0.70)
valid_size = int(len(dataset) * 0.15)
test_size = len(dataset) - train_size - valid_size

# random_split은 Dataset을 지정한 길이대로 나눕니다.
# generator에 seed를 넣으면 같은 split을 재현하기 쉽습니다.
generator = torch.Generator().manual_seed(42)
train_dataset, valid_dataset, test_dataset = random_split(
    dataset,
    [train_size, valid_size, test_size],
    generator=generator
)

# DataLoader는 Dataset을 batch 단위로 공급합니다.
train_loader = DataLoader(
    train_dataset,
    batch_size=32,
    shuffle=True
)

valid_loader = DataLoader(
    valid_dataset,
    batch_size=64,
    shuffle=False
)

test_loader = DataLoader(
    test_dataset,
    batch_size=64,
    shuffle=False
)

# batch 하나를 꺼내 shape를 확인합니다.
batch_X, batch_y = next(iter(train_loader))
print("batch_X shape:", batch_X.shape)
print("batch_y shape:", batch_y.shape)
```

validation과 test loader에서는 보통 `shuffle=False`를 사용<br>
validation은 모델 선택에 사용하지만, test는 모든 선택이 끝날 때까지 확인하지 않는다.

## 5. MLP 모델 정의

4개의 feature를 입력받아 3개 class logits를 출력하는 MLP를 만든다

```python
import torch.nn as nn

class SimpleMLP(nn.Module):
    """
    tabular 입력을 받아 class별 logits를 출력하는 간단한 MLP입니다.
    """

    def __init__(self, input_dim=4, hidden_dim=32, num_classes=3):
        super().__init__()

        # 첫 번째 Linear는 입력 feature를 hidden feature로 바꿉니다.
        self.fc1 = nn.Linear(input_dim, hidden_dim)

        # ReLU는 은닉층에 비선형성을 추가합니다.
        self.relu = nn.ReLU()

        # 두 번째 Linear는 hidden feature를 class 수만큼의 logits로 바꿉니다.
        self.fc2 = nn.Linear(hidden_dim, num_classes)

    def forward(self, x):
        # x shape: (batch_size, input_dim)
        x = self.fc1(x)

        # x shape: (batch_size, hidden_dim)
        x = self.relu(x)

        # logits shape: (batch_size, num_classes)
        logits = self.fc2(x)

        return logits
```

모델 출력 shape를 확인한다

```python
model = SimpleMLP(input_dim=4, hidden_dim=32, num_classes=3)

sample_X = torch.randn(5, 4)
sample_logits = model(sample_X)

print("sample_logits shape:", sample_logits.shape)
```

## 6. 학습 함수와 검증 함수 준비

```python
def count_correct(logits, labels):
    """
    logits에서 예측 class를 구하고 labels와 비교하여 맞힌 개수를 반환합니다.
    """
    preds = logits.argmax(dim=1)
    correct = (preds == labels).sum().item()
    total = labels.size(0)
    return correct, total
```

train 함수

```python
def train_one_epoch(model, train_loader, criterion, optimizer, device):
    model.train()

    total_loss = 0.0
    total_correct = 0
    total_samples = 0

    for inputs, labels in train_loader:
        inputs = inputs.to(device)
        labels = labels.to(device)

        optimizer.zero_grad()
        outputs = model(inputs)
        loss = criterion(outputs, labels)
        loss.backward()
        optimizer.step()

        batch_size = inputs.size(0)
        total_loss += loss.item() * batch_size

        correct, total = count_correct(outputs, labels)
        total_correct += correct
        total_samples += total

    if total_samples == 0:
        raise ValueError("DataLoader가 비어 있습니다.")

    avg_loss = total_loss / total_samples
    avg_acc = total_correct / total_samples

    return avg_loss, avg_acc
```

validation 함수입니다.

```python
def validate(model, valid_loader, criterion, device):
    model.eval()

    total_loss = 0.0
    total_correct = 0
    total_samples = 0

    with torch.no_grad():
        for inputs, labels in valid_loader:
            inputs = inputs.to(device)
            labels = labels.to(device)

            outputs = model(inputs)
            loss = criterion(outputs, labels)

            batch_size = inputs.size(0)
            total_loss += loss.item() * batch_size

            correct, total = count_correct(outputs, labels)
            total_correct += correct
            total_samples += total

    if total_samples == 0:
        raise ValueError("DataLoader가 비어 있습니다.")

    avg_loss = total_loss / total_samples
    avg_acc = total_correct / total_samples

    return avg_loss, avg_acc
```

## 7. fit 함수로 전체 학습 실행

전체 epoch loop를 작성

```python
def fit(model, train_loader, valid_loader, criterion, optimizer, device, epochs):
    """
    전체 학습을 실행하고 history와 best validation weight를 반환합니다.
    """

    history = {
        "train_loss": [],
        "train_acc": [],
        "valid_loss": [],
        "valid_acc": []
    }
    best_valid_loss = float("inf")
    best_epoch = 0
    best_state = None

    for epoch in range(1, epochs + 1):
        train_loss, train_acc = train_one_epoch(
            model, train_loader, criterion, optimizer, device
        )
        valid_loss, valid_acc = validate(
            model, valid_loader, criterion, device
        )

        history["train_loss"].append(train_loss)
        history["train_acc"].append(train_acc)
        history["valid_loss"].append(valid_loss)
        history["valid_acc"].append(valid_acc)

        # test는 보지 않고 validation loss만으로 best model을 선택합니다.
        if valid_loss < best_valid_loss:
            best_valid_loss = valid_loss
            best_epoch = epoch
            best_state = {
                name: value.detach().cpu().clone()
                for name, value in model.state_dict().items()
            }

        print(
            f"Epoch [{epoch:03d}/{epochs:03d}] "
            f"train_loss={train_loss:.4f} "
            f"train_acc={train_acc:.4f} "
            f"valid_loss={valid_loss:.4f} "
            f"valid_acc={valid_acc:.4f}"
        )

    return history, best_state, best_epoch
```

학습 실행

```python
# GPU가 있으면 GPU를 사용하고, 없으면 CPU를 사용합니다.
device = torch.device("cuda" if torch.cuda.is_available() else "cpu")

# 모델을 생성하고 device로 이동합니다.
model = SimpleMLP(input_dim=4, hidden_dim=32, num_classes=3).to(device)

# 다중 분류 문제이므로 CrossEntropyLoss를 사용합니다.
criterion = nn.CrossEntropyLoss()

# optimizer는 Adam을 사용합니다.
optimizer = torch.optim.Adam(model.parameters(), lr=0.01)

history, best_state, best_epoch = fit(
    model=model,
    train_loader=train_loader,
    valid_loader=valid_loader,
    criterion=criterion,
    optimizer=optimizer,
    device=device,
    epochs=20
)

# validation loss가 가장 낮았던 weight를 복원합니다.
model.load_state_dict(best_state)
print("best validation epoch:", best_epoch)
```

## 8. 결과 시각화와 최종 test 평가

```python
import matplotlib.pyplot as plt

def plot_history(history):
    """
    loss curve와 accuracy curve를 각각 출력합니다.
    """

    epochs = range(1, len(history["train_loss"]) + 1)

    plt.figure(figsize=(8, 5))
    plt.plot(epochs, history["train_loss"], label="train_loss")
    plt.plot(epochs, history["valid_loss"], label="valid_loss")
    plt.title("Loss Curve")
    plt.xlabel("Epoch")
    plt.ylabel("Loss")
    plt.legend()
    plt.grid(True)
    plt.show()

    plt.figure(figsize=(8, 5))
    plt.plot(epochs, history["train_acc"], label="train_acc")
    plt.plot(epochs, history["valid_acc"], label="valid_acc")
    plt.title("Accuracy Curve")
    plt.xlabel("Epoch")
    plt.ylabel("Accuracy")
    plt.legend()
    plt.grid(True)
    plt.show()

plot_history(history)

# validation으로 선택한 best weight를 복원한 모델만 test set에서 한 번 평가합니다.
test_loss, test_acc = validate(model, test_loader, criterion, device)
print(f"test_loss={test_loss:.4f} test_acc={test_acc:.4f}")
```

그래프는 train과 valid 곡선의 방향과 간격을 비교해 읽습니다. train만 계속 좋아지고 valid loss가 다시 오르면 과적합을 의심할 수 있습니다.<br> 
test 결과를 본 뒤 설정을 다시 바꾸면 test가 validation 역할을 하게 되므로, 최종 선택이 끝난 뒤 한 번만 확인한다
