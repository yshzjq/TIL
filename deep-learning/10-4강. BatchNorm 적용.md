## 1. 이번에 우리가 배울 것

BatchNorm은 layer의 중간 출력값 분포가 너무 치우치지 않도록 정규화한다

```
Linear 또는 Conv 출력
-> BatchNorm으로 분포 안정화
-> ReLU 적용
-> 다음 layer로 전달
```

BatchNorm은 현재 batch의 평균과 분산을 기준으로 중간 출력값을 정규화하여, 값의 중심과 퍼진 정도를 일정하게 맞춰준다

## 2. BatchNorm이 필요한 이유

딥러닝 모델의 중간 activation 값은 학습 중 계속 바뀐다

어떤 layer의 출력 분포가 너무 커지거나 한쪽으로 치우치면 다음 layer가 안정적으로 학습하기 어려워 질 수 있다

BatchNorm은 중간 activation을 정규화해서 다음 layer가 더 안정적인 입력을 받도록 돕는다.

activation = 신경망의 각 뉴런이 계산한 뒤 다음 layer에 전달하는 중간 출력값.

| 기대 효과 | 설명 |
| --- | --- |
| 학습 안정화 | activation 분포가 지나치게 흔들리는 것을 줄인다. |
| 더 빠른 수렴 가능성 | 학습이 안정되면 좋은 성능에 더 빨리 도달할 수 있다. |
| 약한 regularization 효과 | batch 통계 사용으로 약간의 noise가 들어갈 수 있다. |

Regularization = 모델이 너무 외우지 못하게 제약을 줘서 일반화 성능을 높이는 방법

## 3. BatchNorm의 직관

BatchNorm은 각 batch의 중간 activation 값의 평균과 분산을 일정한 범위로 조정하여,<br> 값의 분포가 지나치게 커지거나 치우치는 것을 줄이고 다음 layer가 안정적으로 학습할 수 있도록 돕는다
```
어떤 batch에서는 activation이 너무 큼
어떤 batch에서는 activation이 너무 작음
-> BatchNorm이 평균과 분산을 조정
-> 다음 layer가 더 안정적인 입력을 받음
```


## 4. MLP에서 BatchNorm1d 사용하기

MLP에서는 보통 `nn.BatchNorm1d`를 사용<br> 
입력 shape가 `(batch_size, features)`일 때 feature 차원에 대해 정규화합니다.

```python
import torch
import torch.nn as nn

class BatchNormMLP(nn.Module):
    """
    BatchNorm1d를 적용한 MLP 모델입니다.
    """

    def __init__(self, input_dim=784, hidden_dim=128, num_classes=10):
        super().__init__()

        # 이미지를 2차원 Tensor로 펼칩니다.
        self.flatten = nn.Flatten()

        # 첫 번째 선형층입니다.
        # 출력 feature 수가 hidden_dim이므로 BatchNorm1d도 hidden_dim을 받습니다.
        self.fc1 = nn.Linear(input_dim, hidden_dim)

        # BatchNorm1d는 feature 차원 수를 인자로 받습니다.
        # fc1의 출력이 (batch_size, hidden_dim)이므로 hidden_dim을 넣습니다.
        self.bn1 = nn.BatchNorm1d(hidden_dim)

        # BatchNorm 뒤에 ReLU를 적용하는 구조를 자주 사용합니다.
        self.relu = nn.ReLU()

        # 출력층입니다.
        self.fc2 = nn.Linear(hidden_dim, num_classes)

    def forward(self, x):
        # x shape: (batch_size, 1, 28, 28)
        x = self.flatten(x)

        # x shape: (batch_size, 784)
        x = self.fc1(x)

        # x shape: (batch_size, hidden_dim)
        # BatchNorm은 이 hidden feature 분포를 안정화합니다.
        x = self.bn1(x)

        # 정규화된 값을 ReLU에 통과시킵니다.
        x = self.relu(x)

        # logits shape: (batch_size, num_classes)
        logits = self.fc2(x)

        return logits
```

`nn.BatchNorm1d(hidden_dim)`의 `hidden_dim`은 batch size가 아니라
<br>
직전 layer의 출력 feature 수다


`(N, F)` 입력을 받는 `BatchNorm1d`는 학습 모드에서 batch의 통계를 계산하므로 <br>`N=1`인 batch에서 오류가 날 수 있습니다.<br>(여러 샘플들을 보고 평균과 분산을 계산해야 하는데 샘플이 하나라서 오류)

학습 batch size를 2 이상으로 두고, 마지막 training batch만 1개가 될 수 있다면 train loader에 `drop_last=True`를 고려하세요.

BatchNorm 계산

train()<br>
→ 현재 batch에서 평균/분산 계산<br>
→ 여러 샘플이 필요함<br>

eval()<br>
→ 학습 때 저장한 평균/분산 사용<br>
→ 현재 batch가 1개여도 가능(학습 중 저장한 running statistics(해당 모델의 레이어 내부에 저장됨)를 사용하기 때문)<br>

학습 자체를 항상 batch size 1로 해야 한다면 BatchNorm보다 LayerNorm처럼 batch 크기에 의존하지 않는 방법을 사용하는 것이 적절하다.


## 5. CNN에서 BatchNorm2d 사용하기

CNN에서는 feature map shape가 보통 `(N, C, H, W)`입니다. 이때는 `nn.BatchNorm2d(C)`를 사용합니다.

```python
class SmallCNNWithBatchNorm(nn.Module):
    """
    CNN에서 BatchNorm2d를 사용하는 예시입니다.
    """

    def __init__(self, num_classes=10):
        super().__init__()

        # Conv2d 출력 channel 수가 16입니다.
        self.conv1 = nn.Conv2d(in_channels=3, out_channels=16, kernel_size=3, padding=1)

        # BatchNorm2d에는 channel 수 16을 넣습니다.
        self.bn1 = nn.BatchNorm2d(16)

        self.relu = nn.ReLU()
        self.pool = nn.MaxPool2d(kernel_size=2)

        # 32x32 입력이 pool을 한 번 지나면 16x16이 됩니다.
        self.classifier = nn.Linear(16 * 16 * 16, num_classes)

    def forward(self, x):
        # x shape: (batch_size, 3, 32, 32)
        x = self.conv1(x)

        # x shape: (batch_size, 16, 32, 32)
        # BatchNorm2d는 channel별 activation 분포를 정규화합니다.
        x = self.bn1(x)

        # 비선형성을 추가합니다.
        x = self.relu(x)

        # 공간 크기를 줄입니다.
        x = self.pool(x)

        # x shape: (batch_size, 16, 16, 16)
        x = torch.flatten(x, start_dim=1)

        # logits shape: (batch_size, num_classes)
        logits = self.classifier(x)

        return logits
```

BatchNorm1d
(N, F)
→ feature별로 정규화

BatchNorm2d
(N, C, H, W)
→ channel별로 정규화


## 6. train mode와 eval mode의 running statistics

BatchNorm은 학습 중 batch 평균과 분산을 사용합니다. 동시에 `running_mean`, `running_var`라는 이동 평균 통계도 업데이트한다

| 모드 | BatchNorm 동작 |
| --- | --- |
| `model.train()` | 현재 batch 통계 사용, running statistics 업데이트 |
| `model.eval()` | 저장된 running statistics 사용 |

이 차이 때문에 validation과 inference에서는 `model.eval()`이 중요하다

```python
model = BatchNormMLP()

# 학습 단계에서는 train 모드를 사용합니다.
model.train()

# 검증 또는 추론 단계에서는 eval 모드를 사용합니다.
model.eval()
```

BatchNorm이 들어간 모델에서 validation 전에 `model.eval()`을 호출하지 않으면, <br>validation 데이터로 running statistics가 계속 변할 수 있다.

## 8. 자주 하는 실수

### 실수 1. BatchNorm의 feature 수를 잘못 넣습니다

```
[읽기용 코드 조각]
# 잘못된 예시입니다.
# fc1 출력 feature가 128인데 BatchNorm1d에 784를 넣었습니다.
self.fc1 = nn.Linear(784, 128)
self.bn1 = nn.BatchNorm1d(784)
```

수정

```
[읽기용 코드 조각]
self.fc1 = nn.Linear(784, 128)
self.bn1 = nn.BatchNorm1d(128)
```

### 실수 2. batch size가 너무 작다

BatchNorm은 batch 통계를 사용합니다. batch size가 너무 작으면 통계가 불안정할 수 있다.

### 실수 3. validation에서 `model.eval()`을 빼먹습니다

Dropout과 BatchNorm이 모두 들어간 모델은 validation 전에 반드시 `model.eval()`을 호출해야 한다
