## 1. 이번에 우리가 배울 것

 **다중 분류(multiclass classification)** 출력층을 설계한다.

 다중 분류 모델은 보통 class 수만큼 logits를 출력합니다.

```
logits shape: (batch_size, num_classes)
```

raw logits를 Softmax로 확률 분포처럼 바꾸고, 가장 큰 확률의 class를 `argmax`로 선택하는 흐름.

## 2. 다중 분류 출력층의 핵심 흐름

다중 분류의 예측 흐름은 다음과 같습니다.

```
입력 Tensor
-> MLP
-> class별 logits
-> Softmax
-> class별 probability
-> argmax
-> 예측 class index
```

하지만 이진 분류와 마찬가지로, 학습 단계에서는 Softmax를 모델 안에 넣지 않는 경우가 많다

PyTorch의 `nn.CrossEntropyLoss`는 raw logits와 target을 입력으로 받아 cross entropy loss를 계산한다.<br> 그래서 `CrossEntropyLoss`를 사용할 때는 모델 마지막에 `nn.Softmax()`를 넣지 않는 것이 일반적

CrossEntropyLoss를 사용할 때는 모델이 raw logits를 출력하도록 만들고, Softmax는 예측 결과를 해석할 때 사용


## 3. Softmax는 어떤 함수인가요?

### 3-1. 단순히 0~1로 만드는 것과 무엇이 다른가요?

Softmax는 각 logit에 지수 함수를 적용한 뒤, 같은 샘플의 모든 class 값을 합한 값으로 나눕니다.

```
softmax(z_i) = exp(z_i) / sum(exp(z_j))
```

한 class의 확률은 그 class logit 하나만으로 정해지지 않고 다른 class logits와의 상대적인 차이로 결정된다

예를 들어 class A의 logit이 `3.0`이어도 나머지가 `2.9, 2.8`이라면 A가 압도적이지 않다. 반대로 A가 `3.0`이고 나머지가 `-2.0, -3.0`이라면 A의 Softmax 값은 매우 커진다

```
[3.0, 2.9, 2.8] -> 세 class가 비슷하게 경쟁
[3.0, -2.0, -3.0] -> 첫 class가 크게 우세
```

### 3-2. 모든 logit에 같은 수를 더해도 결과가 같은 이유

Softmax는 절대 점수보다 class 간 차이를 봅니다. 그래서 다음 두 logits는 같은 확률 분포를 만든다

```
[2.0, 0.5, -1.0]
[12.0, 10.5, 9.0]  # 모두 10을 더함
```

모든 class에 같은 값을 더하면 순위와 점수 차이가 그대로이다. 실제 구현에서도 수치 안정성을 위해 각 행의 최댓값을 먼저 빼고 계산하는 방식이 자주 사용된다.

### 3-3. `dim`은 어느 값끼리 경쟁시킬지 정합니다

logits shape가 `(B, C)`라면 각 샘플의 `C`개 class가 경쟁하므로 `dim=1` 또는 `dim=-1`을 사용한다

```
(B, C)       -> class 축은 1번 또는 마지막 축
(B, L, C)    -> token마다 class C개가 경쟁하므로 dim=-1
```
`dim=0`을 사용하면 서로 다른 샘플끼리 합이 1이 되어 문제의 의미가 달라진다

Softmax는 같은 샘플 안의 class logits를 상대적으로 비교해, class 축의 합이 1인 분포로 바꾼다

Softmax는 여러 class 점수를 확률 분포처럼 바꾼다

예를 들어 class가 4개라면 모델은 샘플 하나에 대해 logit 4개를 출력합니다.

```python
import torch

logits = torch.tensor([[2.0, 0.5, -1.0, 1.2]])
probs = torch.softmax(logits, dim=1)

print("logits:", logits)
print("probs :", probs)
print("sum   :", probs.sum(dim=1))
```
출력

```
probs : tensor([[0.5806, 0.1296, 0.0289, 0.2609]])
sum   : tensor([1.])
```

첫 번째 class의 logit `2.0`이 가장 크므로 확률값도 약 `0.5806`으로 가장 큽니다. 네 값의 합은 1이다

Softmax를 적용하면 각 class 값은 0~1 사이가 되고, class dimension 방향 합은 1이 됩니다.

다중 분류에서 Softmax는 **class 차원**에 적용해야 합니다. 이 페이지의 logits shape는 `(batch_size, num_classes)`이므로 `dim=1`이 맞다.<br> class가 항상 마지막 차원인 코드에서는 `dim=-1`을 쓰면 `(B, C)`, `(B, L, C)` 모두 같은 원칙으로 읽을 수 있다.

## 4. 다중 분류 모델의 출력 shape

다중 분류 모델은 class 수만큼 logits를 출력합니다.

```python
import torch
import torch.nn as nn

class MultiClassMLP(nn.Module):
    """
    feature 4개를 입력받아 class 3개에 대한 logits를 출력하는 모델입니다.
    """
    def __init__(self, input_dim=4, hidden_dim=16, num_classes=3):
        super().__init__()
        self.net = nn.Sequential(
            nn.Linear(input_dim, hidden_dim),
            nn.ReLU(),
            nn.Linear(hidden_dim, num_classes)  # class 수만큼 logits 출력
        )

    def forward(self, x):
        logits = self.net(x)
        return logits

x = torch.randn(8, 4)
model = MultiClassMLP(num_classes=3)
logits = model(x)

print("x shape     :", x.shape)
print("logits shape:", logits.shape)
```

출력

```
x shape     : torch.Size([8, 4])
logits shape: torch.Size([8, 3])
```

`logits.shape == (8, 3)`의 의미는 다음과 같습니다.

```
샘플 8개에 대해,
각 샘플마다 class 3개 점수를 출력합니다.
```

## 5. `CrossEntropyLoss`를 사용할 때의 원칙

### 5-1. 왜 Softmax를 미리 적용하지 않나요?

`CrossEntropyLoss`는 내부에서 `log_softmax`와 정답 class의 negative log-likelihood 계산을 수치적으로 안정적인 형태로 결합한다.

```
권장: raw logits -> CrossEntropyLoss
예측 해석: raw logits -> Softmax -> probability
```

모델 마지막에 `nn.Softmax()`를 넣으면 loss가 기대하는 raw logits 대신 이미 압축된 확률을 전달하게 됩니다.<br>
실행 자체가 될 수는 있어도 학습 신호가 약해지고 의도한 계산과 달라진다.

### 5-2. target의 `long` 값은 크기를 뜻하지 않습니다

기본 다중 분류 target은 `0, 1, 2, ...` 같은 **class 위치를 가리키는 index**입니다. `2`가 `1`보다 두 배 큰 정답이라는 뜻이 아닙니다.

```
logits 한 행: [1.2, -0.5, 2.1, 0.3]
target = 2
-> 세 번째 위치(class index 2)가 정답이라는 뜻
```

`CrossEntropyLoss`는 이 index로 정답 위치를 조회하므로 target dtype을 `torch.long`으로 사용한다.<br>
target 값은 반드시 `0 <= target < num_classes` 범위에 있어야 합니다.


### 5-3. 왜 기본 target shape는 `(B,)`인가요?

샘플마다 정답 class 번호 하나만 저장하기 때문이다

```
logits: (B, C)  # 샘플마다 C개 class 점수
target: (B,)    # 샘플마다 정답 index 하나
```

one-hot은 `(B, C)` 공간을 사용하지만 class index는 `(B,)`만으로 같은 정답 위치를 표현할 수 있어 단순하다

one-hot target은 정답 클래스를 하나의 번호로 쓰지 않고, 클래스 개수만큼 0과 1로 펼쳐서 표현한 target입니다.

예시 

target = 2

one-hot으로 표현하면:

target = [0, 0, 1, 0]

의미는:

[0, 0, 1, 0]
 ↑  ↑  ↑  ↑
 0  1  2  3번 클래스

2번 위치만 1
→ 정답은 2번 클래스


### 5-4. 예외적으로 float target도 가능한가요?

현재 PyTorch는 class 확률 분포 형태의 float target도 지원.<br>
다만 label smoothing이나 soft label을 의도적으로 사용하는 경우에 해당한다<br>
초반에는 `(B,)` shape의 `long` class index 패턴을 기준으로 익힌다.

**디버깅 체크**

`logits.shape`, `target.shape`, `target.dtype`, `target.min()`, `target.max()`를 순서대로 출력.

---

다중 분류에서 자주 사용하는 loss는 `nn.CrossEntropyLoss`입니다.

```python
import torch
import torch.nn as nn

model = MultiClassMLP(input_dim=4, hidden_dim=16, num_classes=3)
criterion = nn.CrossEntropyLoss()

x = torch.randn(8, 4)

# target은 one-hot이 아니라 class index입니다.
# class가 3개라면 가능한 값은 0, 1, 2입니다.
target = torch.tensor([0, 1, 2, 1, 0, 2, 1, 0], dtype=torch.long)

logits = model(x)
loss = criterion(logits, target)

print("logits shape:", logits.shape)
print("target shape:", target.shape)
print("target dtype:", target.dtype)
print("loss:", loss)
```
출력은 다음과 비슷합니다.

```
logits shape: torch.Size([8, 3])
target shape: torch.Size([8])
target dtype: torch.int64
loss: tensor(..., grad_fn=<NllLossBackward0>)
```

`CrossEntropyLoss`에서 target은 보통 다음 형태입니다.

```
target shape: (batch_size,)
target dtype: torch.long
```

## 6. logits에서 확률과 예측 class 만들기

**예측 class만 필요하다면 Softmax 없이 logits에서 바로 argmax해도 된다.**

Softmax는 class 순서를 바꾸지 않는 단조 변환입니다. 따라서 가장 큰 logit의 index와 가장 큰 Softmax 값의 index는 같습니다.

```python
preds_from_logits = torch.argmax(logits, dim=1)
probs = torch.softmax(logits, dim=1)
preds_from_probs = torch.argmax(probs, dim=1)
assert torch.equal(preds_from_logits, preds_from_probs)
```

두 방식의 용도는 다릅니다.

| 필요한 결과 | 권장 계산 |
| --- | --- |
| 예측 class index만 필요 | `argmax(logits, dim=-1)` |
| class별 0~1 점수를 표시 | `softmax(logits, dim=-1)` |
| 학습 loss 계산 | raw logits를 `CrossEntropyLoss`에 입력 |


Softmax의 가장 큰 값이 0.9라고 해서 항상 실제 정답 빈도 90%와 일치하는 것은 아닙니다. <br>
Softmax 값은 모델이 자신의 점수를 바탕으로 만든 확률값이지만<br>그 숫자가 실제 정답 확률과 정확히 같다는 보장은 없다.


학습 중에는 raw logits를 loss에 넣지만, 예측 결과를 보여줄 때는 Softmax와 argmax를 사용할 수 있다.

```python
import torch

logits = torch.tensor([
    [2.0, 0.5, -1.0],
    [0.1, 1.7, 0.3],
    [-0.2, 0.4, 2.1]
])

# class dimension 방향으로 Softmax를 적용합니다.
probs = torch.softmax(logits, dim=1)

# 가장 큰 logit의 index를 예측 class로 사용합니다.
preds_from_logits = torch.argmax(logits, dim=1)

# Softmax 확률에서 argmax를 해도 같은 class가 나옵니다.
preds_from_probs = torch.argmax(probs, dim=1)

print("probs:")
print(probs)
print("preds_from_logits:", preds_from_logits)
print("preds_from_probs :", preds_from_probs)
```

출력

```
preds_from_logits: tensor([0, 1, 2])
preds_from_probs : tensor([0, 1, 2])
```

argmax로 class만 고를 때는 Softmax를 꼭 먼저 적용하지 않아도 된다<br>
Softmax는 값의 크기 순서를 유지하기 때문에 `argmax(logits)`와 `argmax(softmax(logits))`는 같은 class를 선택한다.<br>
 확률값을 화면에 보여주거나 confidence를 해석할 때 Softmax를 사용하면 된다.<br>
다만 Softmax 값이 높다고 해서 실제 정답 확률과 항상 잘 맞는 것은 아니다.<br> 확률 신뢰도가 중요한 경우에는 validation 데이터에서 calibration을 확인해야 합니다.

## 7. target shape와 dtype 확인하기

**다중 분류 오류는 shape, dtype, 값 범위 세 가지로 나누어 확인**

```
logits shape: (B, C)
target shape: (B,)
target dtype: torch.long
target 값 범위: 0 ~ C-1
```

label smoothing이나 soft label을 사용할 때는 logits와 같은 shape의 float target을 넣을 수 있다.<br> 
각 행은 class별 확률을 나타내며 보통 0~1 범위이고 합이 1이어야 한다 <br> PyTorch가 값의 유효성을 자동 검증해 주는 것은 아니므로 직접 확인해야한다.
