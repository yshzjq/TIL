## 1. 이번에 배울것

Dataset을 train, valid, test로 나누고 각각 DataLoader를 구성한다

실전 학습에서는 세 데이터의 역할을 분리한다

```
train set: 모델 파라미터를 학습하는 데이터
valid set: 학습 중 설정을 비교하고 best 모델을 고르는 데이터
test set : 모든 선택이 끝난 뒤 최종 성능을 한 번 확인하는 데이터
```

loader 설정

```
train loader: shuffle=True
valid loader: shuffle=False
test loader : shuffle=False
```

test 결과를 보고 모델이나 hyperparameter를 다시 고르면 test가 사실상 validation 역할을 하게 된다<br>
따라서 test set은 최종 선택이 끝날 때까지 보지 않는 경계를 지켜야 합니다.

train 70%는 parameter 학습에 사용하므로 shuffle=True,<br>
valid 15%는 설정과 best 모델 선택에 사용하므로 shuffle=False,<br>
test 15%는 모든 선택이 끝난 뒤 한 번 평가하므로 shuffle=False<br>
test를 확인한 뒤 다시 설정을 바꾸면 test가 또 하나의 validation set이 된다

## 2. batch size란 무엇인가요?

`batch_size`는 한 번의 forward/backward에서 모델에 넣는 샘플 수다.

예를 들어 샘플이 100개 있고 `batch_size=20`이면 한 epoch은 5개의 batch로 나뉩니다.

```python
import torch
from torch.utils.data import TensorDataset, DataLoader

X = torch.randn(100, 6)
y = torch.randint(0, 3, size=(100,), dtype=torch.long)

dataset = TensorDataset(X, y)
loader = DataLoader(dataset, batch_size=20, shuffle=False)

print("number of batches:", len(loader))

for batch_x, batch_y in loader:
    print(batch_x.shape, batch_y.shape)
    break
```

batch_size가 커지면 한 번에 더 많은 샘플을 처리하지만, 메모리 사용량도 커진다

## 3. shuffle은 왜 필요한가요?

학습 데이터가 특정 순서로 정렬되어 있으면 모델이 그 순서에 영향을 받을 수 있다

예를 들어 class 0 데이터가 앞에 몰려 있고 class 1 데이터가 뒤에 몰려 있다면, shuffle 없이 학습할 때 batch마다 class 분포가 심하게 달라질 수 있다

```python
# 앞쪽은 0, 뒤쪽은 1로 정렬된 label입니다.
y_sorted = torch.tensor([0] * 50 + [1] * 50, dtype=torch.long)
X = torch.randn(100, 4)

dataset = TensorDataset(X, y_sorted)

loader_no_shuffle = DataLoader(dataset, batch_size=10, shuffle=False)
loader_shuffle = DataLoader(dataset, batch_size=10, shuffle=True)

batch_x, batch_y = next(iter(loader_no_shuffle))
print("no shuffle first labels:", batch_y)

batch_x, batch_y = next(iter(loader_shuffle))
print("shuffle first labels:", batch_y)
```

valid loader에서는 성능 측정이 목적이므로 보통 shuffle=False를 사용

## 4. train/valid/test split이 필요한 이유

모델이 train 데이터에만 잘 맞는지, 설정을 고르는 동안 일반화되는지,<br>
최종 선택 뒤에도 성능이 유지되는지를 서로 다른 데이터로 확인한다

| 데이터 | 사용 목적 |
| --- | --- |
| train set | 모델 파라미터를 업데이트한다 |
| valid set | 학습 중 성능을 확인하고 모델·설정을 선택한다 
| test set | 모든 선택이 끝난 뒤 최종 성능을 한 번 평가한다. |

train loss만 낮아지고 valid loss가 높아진다면 과적합을 의심할 수 있다. <br>
test 결과를 보고 설정을 반복해서 바꾸면 test 정보가 모델 선택에 새어 들어가는 **data leakage**가 생길 수 있다.

## 5. `random_split` 사용하기

PyTorch의 `random_split`을 사용하면 Dataset을 여러 부분으로 나눌 수 있다.

```python
import torch
from torch.utils.data import TensorDataset, random_split

X = torch.randn(100, 6)
y = torch.randint(0, 3, size=(100,), dtype=torch.long)

dataset = TensorDataset(X, y)



train_size = 70
valid_size = 15
test_size = 15

# 1. random_split()으로 Dataset의 인덱스 분할
train_dataset, valid_dataset, test_dataset = random_split(
    dataset,
    [train_size, valid_size, test_size]
)

print("train length:", len(train_dataset))
print("valid length:", len(valid_dataset))
print("test length :", len(test_dataset))
```

출력

```
train length: 70
valid length: 15
test length : 15
```

## 6. train, valid, test loader 만들기

DataLoader를 만든다.

```python
from torch.utils.data import DataLoader

# 2. DataLoader 객체 생성
train_loader = DataLoader(train_dataset, batch_size=16, shuffle=True)
valid_loader = DataLoader(valid_dataset, batch_size=16, shuffle=False)
test_loader = DataLoader(test_dataset, batch_size=16, shuffle=False)



# 반복자(iterator)는 여러 데이터에서 다음 값을 하나씩 꺼내면서, 현재 어디까지 꺼냈는지 기억하는 객체
# → DataLoader 반복자 생성

# next(반복자)
# → sampler에서 인덱스 16개 가져오기
# → train_dataset[idx]를 16번 호출
# → 각 __getitem__()에서 데이터와 transform 처리
# → 16개의 샘플을 batch로 묶기
# → (batch_x, batch_y) 반환

# 3. iter(train_loader)로 batch 반복자 생성 
# rain batch를 하나씩 가져오기 위한 반복자 객체를 생성

# 4. next()로 batch 하나 가져오기

train_batch_x, train_batch_y = next(iter(train_loader))
valid_batch_x, valid_batch_y = next(iter(valid_loader))
test_batch_x, test_batch_y = next(iter(test_loader))

print("train batch:", train_batch_x.shape, train_batch_y.shape)
print("valid batch:", valid_batch_x.shape, valid_batch_y.shape)
print("test batch :", test_batch_x.shape, test_batch_y.shape)
```

마지막 batch는 batch_size보다 작을 수 있다. valid/test에서는 모든 샘플을 평가하기 위해 보통 drop_last=False를 유지한다

## 7. 재현 가능한 split과 split별 transform 만들기

매번 실행할 때 split 결과가 달라지면 실험 비교가 어려울 수 있다. <br>이때 `torch.Generator().manual_seed()`를 사용한다

`random_split`의 결과들은 같은 원본 Dataset을 공유한다.<br>
따라서 원본의 `transform` 속성을 나중에 바꾸는 방식으로는 train과 valid의 transform을 분리할 수 없다. <br>
다음처럼 **transform이 없는 원본을 먼저 분할하고**, 각 split의 인덱스를 별도 래퍼에 넣는다.

```python 
import torch
from torch.utils.data import Dataset, TensorDataset, random_split

class SubsetWithTransform(Dataset):
    def __init__(self, base_dataset, indices, transform=None):
        self.base_dataset = base_dataset
        self.indices = list(indices)
        self.transform = transform

    def __len__(self):
        return len(self.indices)

    def __getitem__(self, idx):
        x, y = self.base_dataset[self.indices[idx]]
        if self.transform is not None:
            x = self.transform(x)
        return x, y

# 실제 이미지 프로젝트에서는 transform=None인 원본 Dataset을 준비

# tensor([
#    [ 0.,  1.,  2.,  3.,  4.,  5.],  # 첫 번째 데이터
#    [ 6.,  7.,  8.,  9., 10., 11.],  # 두 번째 데이터
#    ...
# ])
X = torch.arange(100 * 6, dtype=torch.float32).reshape(100, 6)

# tensor([0, 1, 2, 0, 1, 2...])
y = torch.arange(100) % 3

# TensorDataset은 Tensor들을 묶어서 PyTorch가 사용할 수 있는 Dataset 객체로 만들어 주는 클래스
raw_dataset = TensorDataset(X, y)

# torch.Generator().manual_seed(42)는 random_split()이 
# 매번 동일한 train·valid·test 인덱스를 생성하도록 난수의 시작점을 고정
split_generator = torch.Generator().manual_seed(42)



train_part, valid_part, test_part = random_split(
    raw_dataset,                # 나누고자 하는 Dataset
    [70, 15, 15],               # 나누는 비율[70% : train_part, 15% : valid_part, 15% : test_part]
    generator=split_generator,  # 난수 생성기 지정
)

# 예시용 transform입니다. 실제 이미지라면 train_transform과 valid_transform을 넣습니다.
train_transform = lambda x: x + torch.rand_like(x) * 0.01
valid_transform = lambda x: x
test_transform = lambda x: x


# 우선 원본 Dataset, train 인덱스, train transform이 속성으로 저장된 객체가 생성된 상태입니다.
train_dataset = SubsetWithTransform(raw_dataset, train_part.indices, train_transform)
valid_dataset = SubsetWithTransform(raw_dataset, valid_part.indices, valid_transform)
test_dataset = SubsetWithTransform(raw_dataset, test_part.indices, test_transform)



print(len(train_dataset), len(valid_dataset), len(test_dataset))
print("valid sample is stable:", torch.equal(valid_dataset[0][0], valid_dataset[0][0]))
```
