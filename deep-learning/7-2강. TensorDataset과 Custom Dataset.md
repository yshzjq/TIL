## 1. 이번에 배울 것

Custom Dataset을 직접 만들어 본다

TensorDataset은 이미 Tensor 형태로 준비된 데이터에 매우 편리합니다. <br>
하지만 실제 프로젝트에서는 데이터가 파일 경로, 이미지, 텍스트, CSV row, JSON object 형태로 있을 수 있다.<br>
이때는 Dataset 클래스를 상속해 직접 데이터 접근 방식을 정의

Custom Dataset

TensorDataset은 이미 준비된 Tensor를 묶고, Custom Dataset은 `__len__`과 `__getitem__`으로 데이터 접근 방식을 직접 정의한다

## 2. TensorDataset 다시 보기

먼저 TensorDataset을 다시 확인합니다.

```python
import torch
from torch.utils.data import TensorDataset

X = torch.randn(10, 4)
y = torch.randint(0, 2, size=(10,), dtype=torch.long)

dataset = TensorDataset(X, y)

print("dataset length:", len(dataset))
print("first sample:", dataset[0])
```

`TensorDataset(X, y)`는 내부적으로 첫 번째 차원을 기준으로 데이터를 묶습니다.

```
X[0]과 y[0]이 하나의 샘플
X[1]과 y[1]이 하나의 샘플
...
```

TensorDataset은 간단하지만, 데이터 로딩 로직을 세밀하게 제어하기는 어렵다

## 3. Custom Dataset은 언제 필요한가

| 상황 | 예시 |
| --- | --- |
| 파일에서 데이터를 읽어야 함 | 이미지 파일 경로를 읽고 PIL image로 로드 |
| 샘플마다 전처리가 필요함 | 텍스트 tokenization, 이미지 transform |
| label을 별도 규칙으로 만들어야 함 | 파일명에서 label 추출 |
| 데이터가 Tensor로 미리 올라와 있지 않음 | CSV row, JSON line, audio file |

## 4. Dataset 클래스 기본 구조

```python
from torch.utils.data import Dataset

class MyDataset(Dataset):
    def __init__(self):
        # 데이터 목록, 파일 경로, label 등을 준비합니다.
        pass

    def __len__(self):
        # 전체 샘플 개수를 반환합니다.
        pass

    def __getitem__(self, idx):
        # idx번째 샘플과 label을 반환합니다.
        pass
```

반드시 기억할 메서드

| 메서드 | 반드시 해야 하는 일 |
| --- | --- |
| `__len__` | `len(dataset)` 호출 시 반환할 전체 샘플 수를 정의합니다. |
| `__getitem__` | `dataset[idx]` 호출 시 반환할 샘플을 정의합니다. |

## 5. 표 데이터 Custom Dataset 만들기

```python
import torch
from torch.utils.data import Dataset

class TabularDataset(Dataset):
    """
    feature Tensor와 label Tensor를 받아
    idx번째 샘플을 반환하는 간단한 표 데이터 Dataset입니다.
    """
    def __init__(self, features, labels):
        """
        features:
            shape가 (num_samples, num_features)인 Tensor입니다.

        labels:
            shape가 (num_samples,)인 class label Tensor입니다.
        """
        # 샘플 개수가 같은지 확인합니다.
        assert len(features) == len(labels), "features와 labels의 샘플 수가 다릅니다."

        self.features = features
        self.labels = labels

    def __len__(self):
        """
        Dataset 전체 샘플 수를 반환합니다.
        """
        return len(self.features)

    def __getitem__(self, idx):
        """
        idx번째 feature와 label을 반환합니다.
        """
        x = self.features[idx]
        y = self.labels[idx]
        return x, y
```
```python
X = torch.randn(12, 5)
y = torch.randint(0, 3, size=(12,), dtype=torch.long)

dataset = TabularDataset(X, y)

print("dataset length:", len(dataset))

sample_x, sample_y = dataset[0]
print("sample_x shape:", sample_x.shape)
print("sample_y:", sample_y)
```

## 6. Dataset과 DataLoader 연결하기

Custom Dataset도 DataLoader와 같은 방식으로 연결합니다.

```python
from torch.utils.data import DataLoader

loader = DataLoader(
    dataset,
    batch_size=4,
    shuffle=True
)

batch_x, batch_y = next(iter(loader))

print("batch_x shape:", batch_x.shape)
print("batch_y shape:", batch_y.shape)
print("batch_y dtype:", batch_y.dtype)
```

출력

```
batch_x shape: torch.Size([4, 5])
batch_y shape: torch.Size([4])
batch_y dtype: torch.int64
```

`__getitem__`이 샘플 하나를 반환하면 DataLoader가 여러 샘플을 묶어 batch로 만들어준다


## 7. Dataset 반환 구조 디버깅하기

Dataset을 만들면 가장 먼저 다음을 확인한다

```python
def inspect_dataset(dataset):
    """
    Dataset의 첫 번째 샘플 구조를 확인합니다.
    """
    print("dataset length:", len(dataset))

    sample = dataset[0]
    print("sample type:", type(sample))

    if isinstance(sample, tuple):
        for i, item in enumerate(sample):
            if torch.is_tensor(item):
                print(f"sample[{i}] shape:", item.shape)
                print(f"sample[{i}] dtype:", item.dtype)
            else:
                print(f"sample[{i}] type:", type(item))
    else:
        print("sample:", sample)

inspect_dataset(dataset)
```

이런 디버깅 함수를 만들어두면 Custom Dataset을 만들 때 오류를 빨리 찾을 수 있다.

Dataset이 반환하는 구조가 모델과 loss 함수가 기대하는 구조와 맞아야 한다

실제 프로젝트에서는 파일 경로를 보관하고, `__getitem__`에서 이미지 한 장을 읽은 뒤 transform을 적용한다

```python
from PIL import Image
from torch.utils.data import Dataset

class ImagePathDataset(Dataset):
    def __init__(self, image_paths, labels, transform=None):
        assert len(image_paths) == len(labels)
        self.image_paths = image_paths
        self.labels = labels
        self.transform = transform

    def __len__(self):
        return len(self.image_paths)

    def __getitem__(self, idx):
        image = Image.open(self.image_paths[idx]).convert("RGB")
        label = int(self.labels[idx])

        if self.transform is not None:
            image = self.transform(image)

        return image, label
```
학습 전에 `image, label = dataset[0]`을 실행해 이미지 shape·dtype·값 범위와 label을 먼저 확인해야한다<br>
파일 손상이나 채널 수 문제를 학습 루프 전에 발견할 수 있다.

## 8. 자주 하는 실수

### 실수 1. `__len__`에서 feature 수를 반환하기

```python
# 잘못된 예시입니다.
def __len__(self):
    return self.features.shape[1]  # feature 수를 반환하고 있습니다.
```

올바른 코드는 샘플 수를 반환해야 한다

```python
def __len__(self):
    return self.features.shape[0]
```

### 실수 2. `__getitem__`에서 label을 빼먹기

```python
# 잘못된 예시입니다.
def __getitem__(self, idx):
    return self.features[idx]
```

지도학습에서는 보통 `(x, y)`를 반환한다

```python
def __getitem__(self, idx):
    return self.features[idx], self.labels[idx]
```

### 실수 3. label dtype을 float로 둔 채 CrossEntropyLoss에 사용하기

분류 label은 보통 `torch.long`이어야 합니다.

```python
y = y.long()
```

### 예시

```python
class MyClassificationDataset(Dataset):
    def __init__(self, features, labels):
        assert len(features) == len(labels)
        self.features = features.float()
        self.labels = labels.long()

    def __len__(self):
        return len(self.features)

    def __getitem__(self, idx):
        return self.features[idx], self.labels[idx]

X = torch.randn(40, 6)
y = torch.randint(0, 3, size=(40,))

dataset = MyClassificationDataset(X, y)
loader = DataLoader(dataset, batch_size=8, shuffle=True)

batch_x, batch_y = next(iter(loader))
print(batch_x.shape)
print(batch_y.shape)
print(batch_y.dtype)
```
