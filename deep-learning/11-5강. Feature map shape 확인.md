## 1. 이번에 배울것

CNN을 만들 때 가장 많이 나는 오류는 <br>
마지막 `nn.Linear`의 `in_features`가 실제 flatten feature 수와 맞지 않는 오류다.

 feature map shape를 직접 확인하고, flatten feature 수를 안전하게 계산하는 방법을 배운다

 ## 2. shape 흐름을 눈으로 확인하기

```python
import torch
import torch.nn as nn

class DebugCNN(nn.Module):
    """
    forward 과정에서 중간 shape를 출력하는 디버깅용 CNN입니다.
    학습용 최종 모델이라기보다 shape 확인용 모델입니다.
    """
    def __init__(self):
        super().__init__()

        # 첫 번째 Conv block
        self.conv1 = nn.Conv2d(3, 16, kernel_size=3, padding=1)
        self.relu1 = nn.ReLU()
        self.pool1 = nn.MaxPool2d(2)

        # 두 번째 Conv block
        self.conv2 = nn.Conv2d(16, 32, kernel_size=3, padding=1)
        self.relu2 = nn.ReLU()
        self.pool2 = nn.MaxPool2d(2)

    def forward(self, x):
        print("input :", x.shape)

        x = self.conv1(x)
        print("conv1 :", x.shape)

        x = self.relu1(x)
        print("relu1 :", x.shape)

        x = self.pool1(x)
        print("pool1 :", x.shape)

        x = self.conv2(x)
        print("conv2 :", x.shape)

        x = self.relu2(x)
        print("relu2 :", x.shape)

        x = self.pool2(x)
        print("pool2 :", x.shape)

        return x

model = DebugCNN()
images = torch.randn(8, 3, 32, 32)
features = model(images)
```

출력

```
input : torch.Size([8, 3, 32, 32])
conv1 : torch.Size([8, 16, 32, 32])
relu1 : torch.Size([8, 16, 32, 32])
pool1 : torch.Size([8, 16, 16, 16])
conv2 : torch.Size([8, 32, 16, 16])
relu2 : torch.Size([8, 32, 16, 16])
pool2 : torch.Size([8, 32, 8, 8])
```

## 3. flatten feature 수 계산

마지막 feature map이 `(8, 32, 8, 8)`이라면 샘플 하나의 feature 수는 다음과 같다.

```
32 * 8 * 8 = 2048
```

코드로 확인하면 다음과 같다.

```python
flat = torch.flatten(features, start_dim=1)

print("features shape:", features.shape)
print("flat shape    :", flat.shape)
print("flatten_dim   :", flat.shape[1])
```

## 4. 더미 입력으로 flatten_dim 자동 계산하기

직접 계산해도 되지만, 더 안전한 방법은 더미 입력을 한 번 통과시키는 것이다

```python
import torch
import torch.nn as nn

class FeatureExtractor(nn.Module):
    def __init__(self):
        super().__init__()
        self.features = nn.Sequential(
            nn.Conv2d(3, 16, kernel_size=3, padding=1),
            nn.ReLU(),
            nn.MaxPool2d(2),
            nn.Conv2d(16, 32, kernel_size=3, padding=1),
            nn.ReLU(),
            nn.MaxPool2d(2),
        )

    def forward(self, x):
        return self.features(x)

feature_extractor = FeatureExtractor()

# 실제 학습 데이터와 같은 shape의 더미 입력을 만듭니다.
# batch size는 1이어도 됩니다. 중요한 것은 C,H,W입니다.
dummy = torch.randn(1, 3, 32, 32)

# feature extractor를 통과시킵니다.
with torch.no_grad():
    dummy_features = feature_extractor(dummy)

# flatten 후 feature 수를 확인합니다.
flatten_dim = torch.flatten(dummy_features, start_dim=1).shape[1]

print("dummy_features shape:", dummy_features.shape)
print("flatten_dim:", flatten_dim)
assert flatten_dim == dummy_features[0].numel()
```

`flatten_dim`은 CNN 구조가 바뀌면 같이 바뀐다 <br>
Conv/Pooling 구조를 수정했다면 `flatten_dim`도 다시 확인해야 한다

더미 입력은 실제 데이터와 같은 C,H,W뿐 아니라 모델과 같은 device와 dtype을 사용해야 한다.

BatchNorm이나 Dropout이 있는 모델에서 출력 shape만 확인할 때는, <br> 
임시 입력이 학습 상태에 영향을 주지 않도록 잠시 model.eval()과 torch.no_grad()를 사용한다. <br>
확인이 끝나면 모델을 원래의 train/eval 모드로 되돌린다.

## 5. 자주 하는 실수

### 실수 1. flatten_dim을 예전 값으로 유지하기

```python
# 구조 변경 후에는 반드시 다시 확인합니다.
dummy = torch.randn(1, 3, 32, 32)
with torch.no_grad():
    out = feature_extractor(dummy)
flatten_dim = torch.flatten(out, start_dim=1).shape[1]
print(flatten_dim)
```
