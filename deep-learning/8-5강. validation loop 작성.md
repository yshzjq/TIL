## 1. 이번에 배울것

```
train loop      : 학습 데이터로 parameter 업데이트
validation loop : 학습 중 성능 확인과 모델·설정 선택
test loop       : 모든 선택이 끝난 뒤 최종 성능을 한 번 평가
```

validation 결과는 epoch마다 확인할 수 있지만, test set은 최종 선택이 끝날 때까지 보지 않는다<br>
코드 구조는 비슷해도 데이터의 역할은 다르다.

validation loop 흐름

validation loop에서는 `model.eval()`과 `torch.no_grad()`를 사용하고, optimizer step을 수행하지 않는다

## 2. validation loop의 목적

검증 데이터는 학습에 직접 사용하지 않는 데이터입니다. 모델이 학습 데이터만 외우고 있는지, 새로운 데이터에도 어느 정도 잘 맞는지 확인하기 위해 사용된다

validation loop에서는 다음을 하지 않는다
```
loss.backward()
optimizer.step()
```

대신 아래 코드를 수행한다

```
model.eval()
with torch.no_grad():
    logits = model(inputs)
    loss = criterion(logits, labels)
```

## 3. train loop와 validation loop 비교

| 항목 | train loop | validation loop |
| --- | --- | --- |
| 모드 | `model.train()` | `model.eval()` |
| gradient 계산 | 사용 | 사용하지 않음 |
| `loss.backward()` | 호출 | 호출하지 않음 |
| `optimizer.step()` | 호출 | 호출하지 않음 |
| 목적 | parameter 업데이트 | 성능 확인 |

validation loop에서 optimizer.step()이 들어가면 검증 데이터로 모델이 학습되어 버려서 검증의 의미가 사라진다

## 4. 검증 데이터셋 준비

```python
import torch
import torch.nn as nn
from torch.utils.data import TensorDataset, DataLoader

X_valid = torch.randn(64, 1, 28, 28)
y_valid = torch.randint(0, 10, (64,), dtype=torch.long)

valid_dataset = TensorDataset(X_valid, y_valid)
valid_loader = DataLoader(valid_dataset, batch_size=32, shuffle=False)

device = torch.device("cuda" if torch.cuda.is_available() else "cpu")
model = nn.Sequential(
    nn.Flatten(),
    nn.Linear(784, 64),
    nn.ReLU(),
    nn.Linear(64, 10),
).to(device)
criterion = nn.CrossEntropyLoss()
```

## 5. validation 함수 만들기

```python
def validate(model, valid_loader, criterion, device):
    """
    valid_loader 전체를 순회하며 평균 validation loss를 계산합니다.
    """
    # 모델을 평가 모드로 전환합니다.
    model.eval()

    total_loss = 0.0
    total_samples = 0

    # 검증에서는 gradient를 계산하지 않습니다.
    with torch.no_grad():
        for inputs, labels in valid_loader:
            inputs = inputs.to(device)
            labels = labels.to(device)

            logits = model(inputs)
            loss = criterion(logits, labels)

            batch_size = inputs.size(0)
            total_loss += loss.item() * batch_size
            total_samples += batch_size

    if total_samples == 0:
        raise ValueError("valid_loader가 비어 있습니다.")

    return total_loss / total_samples
```

## 6. train/valid loss 함께 확인
```python
valid_loss = validate(model, valid_loader, criterion, device)
print(f"valid_loss={valid_loss:.4f}")
```

처음에는 loss가 크게 흔들릴 수 있다. <br>
중요한 것은 한 epoch 결과만 보는 것이 아니라 여러 epoch 동안의 변화 흐름을 보는 것이다

## 7. 자주 하는 실수

### 실수 1. validation에서 `model.eval()`을 빼먹기

```
# 잘못된 예시입니다. eval mode 전환이 빠졌습니다.
with torch.no_grad():
    logits = model(inputs)
```

수정
```
model.eval()
with torch.no_grad():
    logits = model(inputs)
```


### 실수 2. validation에서 backward와 step을 호출하기

```
# 잘못된 예시입니다.
loss.backward()
optimizer.step()
```

validation에서는 호출하지 않습니다.
