## 1. 이번에 배울것

 MLP와 CNN을 같은 조건에서 학습하고 비교, 그 결과를 **리포트 형태**로 정리

리포트는 단순히 다음처럼 끝나면 안 된다

```
CNN accuracy가 더 높았습니다.
```

좋은 리포트는 다음 질문에 답해야 한다

 ```
1. 어떤 데이터로 실험했나요?
2. 어떤 모델 구조를 사용했나요?
3. CNN은 Conv2d와 Pooling을 통해 shape가 어떻게 바뀌었나요?
4. MLP와 CNN의 metric은 어떻게 달랐나요?
5. 그 결과를 어떻게 해석할 수 있나요?
6. 다음 실험에서는 무엇을 바꿔볼 수 있나요?
```


## 2. 왜 accuracy만으로는 부족한가

accuracy는 직관적인 지표다.

하지만 accuracy 하나만 보면 모델이 왜 잘했는지, 왜 못했는지 설명하기 어렵다

예를 들어 CNN이 MLP보다 accuracy가 높게 나왔다면, 다음 이유를 함께 설명해야 한다

- CNN은 `Conv2d`로 지역 패턴을 추출했습니다.
- `MaxPool2d`로 공간 크기를 줄이면서 중요한 feature를 남겼습니다.
- 마지막에 `Flatten`과 `Linear`로 class별 logits를 만들었습니다.
- 반면 MLP는 이미지를 처음부터 한 줄로 펼쳤습니다.

리포트는 “성능이 몇 % 나왔습니다”로 끝나는 글이 아니다

**모델 구조 → 학습 기록 → 결과 해석 → 다음 실험**까지 이어지는 짧은 실험 문서다.

## 3. 실험 리포트에 반드시 포함할 항목

| 항목 | 포함해야 하는 내용 |
| --- | --- |
| 실험 설정 | dataset, 전처리, split/loader seed, batch size, epoch, learning rate, optimizer |
| 모델 구조 | MLP 구조, CNN 구조, Conv2d/Pooling/Flatten 흐름 |
| 출력 shape | logits shape, CNN feature map shape |
| 학습 결과 | train/valid loss, train/valid accuracy |
| 그래프 | loss curve, accuracy curve |
| 비교 결과 | 같은 선택 epoch의 valid accuracy/loss와 parameter 수 |
| 해석 | 결과 범위·parameter budget·무작위성 한계를 포함한 해석 |
| 다음 실험 | filter 수, kernel size, augmentation, epoch 변경 등 |

`SmallCNN(num_classes=10)`만 쓰고 내부 구조를 설명하지 않으면, CNN 실험 리포트로는 부족하다

## 4. CNN 구조와 shape 흐름 기록하기

CNN이 이미지를 어떤 shape로 바꾸는지 기록하는 함수

```python
import torch
import torch.nn as nn

class SmallCNN(nn.Module):
    def __init__(self, num_classes=10):
        super().__init__()
        self.features = nn.Sequential(
            nn.Conv2d(3, 16, kernel_size=3, padding=1),
            nn.ReLU(),
            nn.MaxPool2d(2),
            nn.Conv2d(16, 32, kernel_size=3, padding=1),
            nn.ReLU(),
            nn.MaxPool2d(2),
        )
        self.flatten = nn.Flatten()
        self.classifier = nn.Linear(32 * 8 * 8, num_classes)

    def forward(self, x):
        x = self.features(x)
        x = self.flatten(x)
        logits = self.classifier(x)
        return logits
```

### shape 흐름 확인 함수

shape 확인 때문에 학습 중인 모델의 device나 train/eval 상태가 바뀌지 않도록 원래 상태를 복원한다

```python
def trace_cnn_shapes(model, input_shape=(1, 3, 32, 32), device="cpu"):
    original_device = next(model.parameters()).device
    original_training = model.training
    target_device = torch.device(device)
    records = []

    try:
        model.to(target_device)
        model.eval()
        dtype = next(model.parameters()).dtype
        x = torch.zeros(*input_shape, device=target_device, dtype=dtype)

        with torch.no_grad():
            records.append({"layer": "input", "shape": tuple(x.shape)})
            for idx, layer in enumerate(model.features):
                x = layer(x)
                records.append({
                    "layer": f"features[{idx}] {layer.__class__.__name__}",
                    "shape": tuple(x.shape)
                })

            x = model.flatten(x)
            records.append({"layer": "flatten", "shape": tuple(x.shape)})
            logits = model.classifier(x)
            records.append({"layer": "classifier", "shape": tuple(logits.shape)})
    finally:
        model.to(original_device)
        model.train(original_training)

    return records
```

사용 예시

```python
cnn = SmallCNN(num_classes=10)
shape_records = trace_cnn_shapes(cnn)

for record in shape_records:
    print(record)
```

결과

```

{'layer': 'features[0] Conv2d', 'shape': (1, 16, 32, 32)}
{'layer': 'features[1] ReLU', 'shape': (1, 16, 32, 32)}
{'layer': 'features[2] MaxPool2d', 'shape': (1, 16, 16, 16)}
{'layer': 'features[3] Conv2d', 'shape': (1, 32, 16, 16)}
{'layer': 'features[4] ReLU', 'shape': (1, 32, 16, 16)}
{'layer': 'features[5] MaxPool2d', 'shape': (1, 32, 8, 8)}
{'layer': 'flatten', 'shape': (1, 2048)}
{'layer': 'classifier', 'shape': (1, 10)}
```

이 값을 CSV와 그래프로 저장하면 리포트에 바로 사용할 수 있습니다.

```python
from pathlib import Path
import csv
import matplotlib.pyplot as plt

def save_history_csv(history, path):
    """
    epoch별 train/valid loss와 accuracy를 CSV로 저장합니다.
    CSV는 Excel이나 Google Sheets에서 열기 쉽습니다.
    """

    path = Path(path)
    path.parent.mkdir(parents=True, exist_ok=True)

    num_epochs = len(history["train_loss"])

    with open(path, "w", newline="", encoding="utf-8") as f:
        writer = csv.writer(f)
        writer.writerow(["epoch", "train_loss", "train_acc", "valid_loss", "valid_acc"])

        for i in range(num_epochs):
            writer.writerow([
                i + 1,
                history["train_loss"][i],
                history["train_acc"][i],
                history["valid_loss"][i],
                history["valid_acc"][i]
            ])
```

### MLP와 CNN curve를 함께 저장

각 파일에 train과 validation을 함께 그린다.<br>
실선은 validation, 점선은 train으로 읽습니다.

```python
def save_compare_curves(mlp_history, cnn_history, plot_dir):
    plot_dir = Path(plot_dir)
    plot_dir.mkdir(parents=True, exist_ok=True)
    epochs = range(1, len(mlp_history["train_loss"]) + 1)

    plt.figure(figsize=(8, 5))
    plt.plot(epochs, mlp_history["train_loss"], "--", label="MLP train")
    plt.plot(epochs, mlp_history["valid_loss"], label="MLP valid")
    plt.plot(epochs, cnn_history["train_loss"], "--", label="CNN train")
    plt.plot(epochs, cnn_history["valid_loss"], label="CNN valid")
    plt.title("MLP vs CNN Loss")
    plt.xlabel("Epoch")
    plt.ylabel("Loss")
    plt.legend()
    plt.grid(True)
    plt.savefig(plot_dir / "mlp_vs_cnn_valid_loss.png", dpi=150, bbox_inches="tight")
    plt.close()

    plt.figure(figsize=(8, 5))
    plt.plot(epochs, mlp_history["train_acc"], "--", label="MLP train")
    plt.plot(epochs, mlp_history["valid_acc"], label="MLP valid")
    plt.plot(epochs, cnn_history["train_acc"], "--", label="CNN train")
    plt.plot(epochs, cnn_history["valid_acc"], label="CNN valid")
    plt.title("MLP vs CNN Accuracy")
    plt.xlabel("Epoch")
    plt.ylabel("Accuracy")
    plt.legend()
    plt.grid(True)
    plt.savefig(plot_dir / "mlp_vs_cnn_valid_acc.png", dpi=150, bbox_inches="tight")
    plt.close()
```

그래프는 다음 순서로 읽는다

1. x축 epoch와 y축 metric을 확인
2. validation loss가 가장 낮은 epoch를 선택 지점으로 표시
3. train은 좋아지는데 validation이 나빠지면 overfitting 가능성을 기록.
4. 같은 epoch·learning rate가 두 모델 모두에 최적인 것은 아니라는 한계를 함께 적는다

## 6. MLP vs CNN 비교표 만들기

한 모델 안에서도 loss와 accuracy는 **같은 선택 epoch**의 값을 사용한다

```python
def count_parameters(model):
    return sum(p.numel() for p in model.parameters() if p.requires_grad)

def selected_metrics(history):
    index = min(
        range(len(history["valid_loss"])),
        key=lambda i: history["valid_loss"][i]
    )
    return {
        "selected_epoch": index + 1,
        "valid_loss": history["valid_loss"][index],
        "valid_acc": history["valid_acc"][index]
    }

def summarize_comparison(mlp, cnn, mlp_history, cnn_history):
    return {
        "MLP": {
            **selected_metrics(mlp_history),
            "params": count_parameters(mlp)
        },
        "CNN": {
            **selected_metrics(cnn_history),
            "params": count_parameters(cnn)
        }
    }
```

이 기초 실습은 한 고정 seed의 결과를 기록한다.<br>
test metric은 모델 선택에 쓰지 않고 최종 보고서의 별도 행에 한 번만 기록하며, 한 번의 결과를 일반화하지 않는다

## 7. 결과 해석 문장 작성

리포트에는 숫자뿐 아니라 해석 문장이 있어야 한다

결과 해석 포인트 예시

```
CNN은 Conv2d와 MaxPool2d를 통해 이미지의 지역 패턴을 단계적으로 추출했습니다.
반면 MLP는 이미지를 처음부터 Flatten하여 픽셀 벡터로 사용했습니다.
이번 실험에서 CNN의 validation accuracy가 더 높았다면,
이는 CNN이 이미지의 공간 구조를 더 잘 활용했기 때문이라고 해석할 수 있습니다.
다만 epoch 수, 모델 크기, augmentation 여부에 따라 결과는 달라질 수 있습니다.
```

“CNN이 무조건 좋다”라고 쓰면 안 된다

좋은 리포트는 실험 조건 안에서만 조심스럽게 결론을 낸다

### 실수 1. accuracy 숫자만 리포트에 적기

### 실수 2. train accuracy만 보고 결론 내리기

### 실수 3. parameter 수를 비교하지 않기

두 모델의 parameter 수가 크게 다르면 성능 차이가 구조 때문인지 모델 크기 때문인지 해석하기 어렵다.

따라서 `count_parameters()`로 parameter 수를 함께 기록하는 것이 좋다.
