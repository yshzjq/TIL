## 0. RNN(순환 신경망, Recurrent Neural Network)

**이전 단계의 정보가 현재 단계의 연산에 영향을 미치는 순환 구조의 인공신경망**이다.

데이터의 앞뒤 문맥과 순서가 중요한 **자연어 처리, 음성 인식, 시계열 데이터(주가, 날씨 등) 예측**에 특화되어 있다

## 1. 이번에 배울것

실제 데이터 중에는 **순서가 중요한 데이터**가 많다

| 데이터 | 순서가 중요한 이유 |
| --- | --- |
| 문장 | 앞 단어가 뒤 단어의 의미에 영향을 줍니다. |
| 주가/매출 | 과거 흐름이 현재 값 해석에 필요합니다. |
| 센서 데이터 | 시간에 따른 변화 패턴이 중요합니다. |
| 사용자 행동 로그 | 이전 행동이 다음 행동 예측에 영향을 줍니다. |

이런 데이터를 **시퀀스 데이터(sequence data)** 라고 부른다

## 2. Sequence Data란 무엇인가

시퀀스 데이터는 여러 시점의 값이 순서대로 나열된 데이터다

예를 들어 하루 단위 매출 데이터는 다음처럼 볼 수 있다.

```
월요일 -> 화요일 -> 수요일 -> 목요일 -> 금요일
```

딥러닝에서는 이 데이터를 Tensor로 바꿔 모델에 넣는다.<br>
보통 PyTorch에서 `batch_first=True`를 사용하면 시퀀스 입력 shape는 다음과 같다.

```
(batch_size, sequence_length, input_size)
```

각 차원의 의미

| 차원 | 의미 | 예시 |
| --- | --- | --- |
| `batch_size` | 한 번에 처리하는 샘플 수 | 문장 32개 |
| `sequence_length` | 각 샘플 안의 시점/토큰 수 | 문장당 단어 10개 |
| `input_size` | 각 시점이 가진 feature 수 | 단어 embedding 64차원 |

시퀀스 데이터에서는 첫 번째 차원만 보는 것이 아니라, **샘플 안에 시간축이 하나 더 있다**는 점을 기억해야 한다.

## 3. Hidden State 직관

RNN은 시퀀스를 한 번에 전부 보는 대신, 시점별로 순서대로 처리한다

```
x1 -> x2 -> x3 -> x4
```

각 시점에서 RNN은 두 가지를 사용한다

1. 현재 입력 `x_t`
2. 이전 시점에서 넘어온 hidden state `h_{t-1}`

그리고 새로운 hidden state `h_t`를 만든다

$$
h_t =\tanh\left(\underbrace{x_t W_{ih}^{\top} + b_{ih}}_{\text{현재 입력 정보}}+\underbrace{h_{t-1} W_{hh}^{\top} + b_{hh}}_{\text{이전 hidden state 정보}}\right)
$$

`x_t`는 현재 입력, `h_(t-1)`은 이전 hidden state입니다. 같은 가중치 `W_ih`, `W_hh`를 모든 시점에 반복해서 사용한다

```
현재 입력 + 이전 기억 -> 새로운 기억
```

Hidden state는 현재 시점까지 들어온 시퀀스 정보를 요약해서 다음 시점으로 전달하는 RNN의 내부 기억값이다.

중요한 건 hidden state가 과거 입력을 전부 그대로 저장하는 것이 아니라, 필요한 정보를 압축해서 전달한다



## 4. PyTorch RNN 입력 shape

PyTorch의 `nn.RNN`은 기본적으로 `(seq_len, batch, input_size)` 형식도 지원하지만,<br> 처음 배우는 단계에서는 `batch_first=True`를 사용하는 편이 직관적이다

```python
import torch
import torch.nn as nn

# batch_size=4
# sequence_length=6
# input_size=3
# 즉, 샘플 4개가 있고 각 샘플은 6개 시점으로 구성되며,
# 각 시점마다 feature 3개가 들어 있다고 가정합니다.
x = torch.randn(4, 6, 3)

# input_size=3: 각 시점의 입력 feature 수
# hidden_size=8: RNN이 각 시점에서 만들어낼 hidden feature 수
# batch_first=True: 입력 shape를 (batch, seq, feature)로 사용합니다.
rnn = nn.RNN(
    input_size=3,
    hidden_size=8,
    batch_first=True
)

# output: 모든 시점의 hidden state가 들어 있습니다.
# h_n: 각 layer와 방향의 최종 hidden state가 들어 있습니다.
output, h_n = rnn(x)

print("x shape     :", x.shape)
print("output shape:", output.shape)
print("h_n shape   :", h_n.shape)
```

예상 출력

```
x shape     : torch.Size([4, 6, 3])
output shape: torch.Size([4, 6, 8])
h_n shape   : torch.Size([1, 4, 8])
```

## 5. output과 h_n의 차이

output
→ 모든 시점의 hidden state를 저장

h_n
→ 마지막 시점의 hidden state를 따로 저장

| 값 | 의미 | shape 예시 |
| --- | --- | --- |
| `output` | 모든 시점의 hidden state | `(4, 6, 8)` |
| `h_n` | 각 layer·방향의 최종 hidden state | `(1, 4, 8)` |

현재처럼 **고정 길이·무패딩·1-layer·단방향**이면 `output[:, -1, :]`는 각 샘플의 마지막 시점 hidden state이고 `h_n[-1]`과 같은 값을 가진다

일반적인 `h_n` shape는 `(D × num_layers, batch, hidden_size)`입니다. 단방향이면 `D=1`, 양방향이면 `D=2`입니다. `batch_first=True`는 input과 output의 차원 순서만 바꾸며 `h_n`의 차원 순서는 바꾸지 않는다.

```python
# output shape: (batch, seq_len, hidden_size)
# 마지막 시점만 꺼내면 (batch, hidden_size)가 된다
last_output = output[:, -1, :]

print(last_output.shape)
assert torch.allclose(last_output, h_n[-1])
```

출력

```
torch.Size([4, 8])
```

## 6. 자주 하는 실수

### 실수 1. sequence_length와 input_size를 반대로 이해하기

`(batch, seq_len, input_size)`에서 `seq_len`은 시점 개수이고, `input_size`는 각 시점의 feature 수다.

이 둘을 반대로 이해하면 `nn.RNN(input_size=...)`에 잘못된 값을 넣게 된다<br> 그러면 모델이 기대하는 마지막 차원과 실제 입력 Tensor의 마지막 차원이 달라져 shape 오류가 발생

### 실수 2. `batch_first=True`가 h_n에도 적용된다고 생각

`batch_first=True`여도 `h_n`은 `(D × num_layers, batch, hidden_size)`다. 첫 번째 차원을 batch로 읽지 않습니다.

### 실수 3. `batch_first=True`를 빼먹기

```python
rnn = nn.RNN(input_size=3, hidden_size=8)
```

위처럼 작성하면 PyTorch는 기본적으로 입력을 `(seq_len, batch, input_size)`로 해석한다

보통 `(batch, seq_len, input_size)` 형태로 데이터를 만들기 때문에, <br>`batch_first=True`를 빼먹으면 batch 차원과 sequence 차원을 잘못 해석할 수 있다.
