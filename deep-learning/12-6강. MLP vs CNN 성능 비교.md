## 1. 이번에 배울것

**MLP와 CNN을 같은 조건에서 학습하고 비교**한다

## 2. MLP와 CNN 비교에서 반드시 봐야 하는 것

MLP와 CNN은 둘 다 최종적으로 과정을 다르지만`(batch_size, num_classes)` 형태의 logits를 출력한다.



### MLP는 이미지를 먼저 펼친다
MLP는 이미지를 보통 다음처럼 처리한다.

```
이미지: (batch_size, 3, 32, 32)
Flatten: (batch_size, 3 * 32 * 32)
Linear layers
logits: (batch_size, 10)
```

즉, MLP는 이미지를 긴 벡터로 펼친 뒤 학습한다

이 방식은 단순하고 빠르지만, 가까운 픽셀끼리의 위치 관계나 지역 패턴을 직접 보존하기 어렵습니다.

### CNN은 Conv2d로 feature map을 만든다

CNN은 이미지를 바로 펼치지 않는다

```
이미지: (batch_size, 3, 32, 32)
Conv2d/ReLU/MaxPool2d
feature map: (batch_size, channels, height, width)
Flatten
Linear classifier
logits: (batch_size, 10)
```

CNN은 `Conv2d`를 통해 작은 영역의 패턴을 찾고, `MaxPool2d`로 공간 크기를 줄이면서 중요한 특징을 남긴다

그래서 이미지 분류에서는 MLP보다 CNN이 더 유리한 경우가 많다.


## 3. 비교 실험에서 맞춰야 할 조건

1. 같은 train/valid split과 전처리
2. 같은 epoch, batch size, loss, optimizer, learning rate, metric
3. 같은 고정 seed에서 각 모델의 초기화와 train shuffle을 다시 시작
4. parameter 수를 함께 기록

ImageMLP(hidden_dim=8)과 SmallCNN처럼 parameter 수가 비슷한 모델을 사용

그러나 parameter 수와 학습 조건이 같아도 실제 계산량과 각 모델에 가장 좋은 hyperparameter는 다를 수 있다

한 seed의 결과는 이 실험 조건의 관찰이며, “CNN이 항상 더 좋다”는 결론이 아니다.

## 4. 비교에 사용할 MLP와 CNN 정의

- `ImageMLP`: 이미지를 먼저 Flatten한 뒤 Linear layer로 분류
- `SmallCNN`: `Conv2d`, `ReLU`, `MaxPool2d`로 feature map을 만든 뒤 Flatten과 Linear로 분류

### MLP 모델 정의

```python
import torch
import torch.nn as nn

class ImageMLP(nn.Module):
    """
    3채널 32x32 이미지를 입력받는 MLP baseline입니다.

    입력 shape:
        (batch_size, 3, 32, 32)

    출력 shape:
        (batch_size, num_classes)
    """

    def __init__(self, hidden_dim=8, num_classes=10):
        super().__init__()

        # MLP는 픽셀 값과 고정 index를 보존해 벡터로 펼치지만,
        # 지역성이나 가중치 공유를 구조적으로 사용하지 않습니다.
        # (batch_size, 3, 32, 32) -> (batch_size, 3072)
        self.flatten = nn.Flatten()

        # 3 * 32 * 32 = 3072개의 픽셀 값을 입력 feature로 사용합니다.
        self.classifier = nn.Sequential(
            nn.Linear(3 * 32 * 32, hidden_dim),
            nn.ReLU(),
            nn.Linear(hidden_dim, num_classes)
        )

    def forward(self, x):
        # x shape: (batch_size, 3, 32, 32)
        x = self.flatten(x)

        # x shape: (batch_size, 3072)
        logits = self.classifier(x)

        # logits shape: (batch_size, num_classes)
        return logits
```

### CNN 모델 정의

```python
class SmallCNN(nn.Module):
    """
    3채널 32x32 이미지를 입력받는 간단한 CNN 모델입니다.

    입력 shape:
        (batch_size, 3, 32, 32)

    출력 shape:
        (batch_size, num_classes)
    """

    def __init__(self, num_classes=10):
        super().__init__()

        # features는 이미지에서 공간적 특징을 추출하는 부분입니다.
        self.features = nn.Sequential(
            # Conv2d 1번
            # 입력:  (batch_size, 3, 32, 32)
            # 출력:  (batch_size, 16, 32, 32)
            # padding=1이므로 3x3 kernel을 사용해도 높이와 너비가 유지됩니다.
            nn.Conv2d(
                in_channels=3,
                out_channels=16,
                kernel_size=3,
                padding=1
            ),
            nn.ReLU(),

            # MaxPool2d는 높이와 너비를 절반으로 줄입니다.
            # 출력: (batch_size, 16, 16, 16)
            nn.MaxPool2d(kernel_size=2),

            # Conv2d 2번
            # 입력:  (batch_size, 16, 16, 16)
            # 출력:  (batch_size, 32, 16, 16)
            nn.Conv2d(
                in_channels=16,
                out_channels=32,
                kernel_size=3,
                padding=1
            ),
            nn.ReLU(),

            # 출력: (batch_size, 32, 8, 8)
            nn.MaxPool2d(kernel_size=2)
        )

        # CNN feature map을 classifier에 넣기 위해 펼칩니다.
        # (batch_size, 32, 8, 8) -> (batch_size, 32 * 8 * 8)
        self.flatten = nn.Flatten()

        # 32 * 8 * 8 = 2048
        self.classifier = nn.Linear(32 * 8 * 8, num_classes)

    def forward(self, x):
        # x shape: (batch_size, 3, 32, 32)
        x = self.features(x)

        # x shape: (batch_size, 32, 8, 8)
        x = self.flatten(x)

        # x shape: (batch_size, 2048)
        logits = self.classifier(x)

        # logits shape: (batch_size, num_classes)
        return logits
```

## 5. 모델 출력과 shape 확인하기

두 모델 모두 최종 출력은 logits다.

logits는 softmax 확률이 아니라, class별 원시 점수입니다.

```python
# 샘플 이미지 8장을 만든다고 가정합니다.
# 실제 CIFAR-10 batch도 같은 형태입니다.
images = torch.randn(8, 3, 32, 32)

mlp = ImageMLP(hidden_dim=8, num_classes=10)
cnn = SmallCNN(num_classes=10)

mlp_logits = mlp(images)
cnn_logits = cnn(images)

print("MLP logits shape:", mlp_logits.shape)
print("CNN logits shape:", cnn_logits.shape)
```

출력

```
MLP logits shape: torch.Size([8, 10])
CNN logits shape: torch.Size([8, 10])
```

여기서 `(8, 10)`은 다음 뜻입니다.

```
8  = 이미지 8장
10 = 각 이미지에 대해 class 10개의 점수
```

두 모델의 최종 출력 shape가 같다고 해서 내부 구조가 같다는 뜻은 아니다

MLP는 이미지를 먼저 펼치고, CNN은 Conv2d로 feature map을 만든 뒤 펼친다.

## 6. 같은 train/valid 함수로 학습

MLP와 CNN은 내부 구조가 다르지만, 학습 함수는 거의 동일하게 사용할 수 있다.

이유는 두 모델 모두 다음 형태로 동작하기 때문이다

```python
logits = model(images)
loss = criterion(logits, labels)
```

### 학습 함수

```python
def train_one_epoch(model, train_loader, criterion, optimizer, device):
    """
    train_loader 전체를 한 번 학습하는 함수입니다.

    반환값:
        avg_loss: 전체 샘플 기준 평균 loss
        accuracy: 전체 샘플 기준 accuracy
    """

    # Dropout, BatchNorm 등이 학습 모드로 동작하도록 설정합니다.
    model.train()

    total_loss = 0.0
    correct = 0
    total = 0

    for images, labels in train_loader:
        # images shape: (batch_size, 3, 32, 32)
        # labels shape: (batch_size,)
        images = images.to(device)
        labels = labels.to(device)

        # 이전 batch에서 계산된 gradient를 초기화합니다.
        optimizer.zero_grad()

        # 모델 forward를 실행해 class별 원시 점수 logits를 얻습니다.
        logits = model(images)

        # CrossEntropyLoss는 logits와 정수 class label을 입력받습니다.
        loss = criterion(logits, labels)

        # loss를 기준으로 gradient를 계산합니다.
        loss.backward()

        # optimizer가 parameter를 업데이트합니다.
        optimizer.step()

        # loss.item()은 현재 batch 평균 loss입니다.
        # 전체 샘플 평균을 구하기 위해 batch_size를 곱해 누적합니다.
        batch_size = images.size(0)
        total_loss += loss.item() * batch_size

        # logits에서 가장 큰 점수를 가진 class를 예측값으로 사용합니다.
        preds = logits.argmax(dim=1)
        correct += (preds == labels).sum().item()
        total += batch_size

    avg_loss = total_loss / total
    accuracy = correct / total

    return avg_loss, accuracy
```

### 검증 함수

```python
def validate(model, valid_loader, criterion, device):
    """
    validation dataset에 대한 평균 loss와 accuracy를 계산합니다.
    validation에서는 parameter를 업데이트하지 않습니다.
    """

    # 평가 모드로 전환합니다.
    model.eval()

    total_loss = 0.0
    correct = 0
    total = 0

    # validation에서는 gradient가 필요 없습니다.
    # no_grad를 사용하면 불필요한 계산 그래프 생성을 막을 수 있습니다.
    with torch.no_grad():
        for images, labels in valid_loader:
            images = images.to(device)
            labels = labels.to(device)

            logits = model(images)
            loss = criterion(logits, labels)

            batch_size = images.size(0)
            total_loss += loss.item() * batch_size

            preds = logits.argmax(dim=1)
            correct += (preds == labels).sum().item()
            total += batch_size

    avg_loss = total_loss / total
    accuracy = correct / total

    return avg_loss, accuracy
```

## 7. MLP와 CNN 학습 실행

이 페이지를 새 런타임에서도 실행할 수 있도록 CIFAR-10 준비와 학습 helper를 함께 정의한다

ToTensor()는 이미지를 PyTorch가 계산할 수 있는 Tensor로 바꾸고,<br> CIFAR-10 같은 일반 이미지의 픽셀 값을 0~1 범위로 바꿔준다.

```python
import random
import numpy as np
from torch.utils.data import DataLoader, random_split
from torchvision import datasets, transforms

SEED = 42
BATCH_SIZE = 64
NUM_EPOCHS = 3

def set_seed(seed):
    random.seed(seed)
    np.random.seed(seed)
    torch.manual_seed(seed)
    if torch.cuda.is_available():
        torch.cuda.manual_seed_all(seed)

transform = transforms.Compose([

    # CIFAR-10 이미지를 PyTorch Tensor로 변환합니다.
    #
    # 원래 이미지 형태:
    # (Height, Width, Channel)
    #
    # ToTensor() 적용 후:
    # (Channel, Height, Width)
    #
    # CIFAR-10은 RGB 이미지이므로:
    # (32, 32, 3)
    #      ↓
    # (3, 32, 32)
    #
    # 픽셀 값도 0~255 범위에서
    # 0~1 범위의 실수값으로 변환된다
    transforms.ToTensor(),

    # 이미지의 각 RGB 채널을 정규화합니다.
    #
    # 계산식:
    # (x - mean) / std
    #
    # 여기서는 RGB 세 채널 모두
    # mean = 0.5
    # std  = 0.5
    #
    # 따라서 기존 0~1 범위의 값이
    # 대략 -1~1 범위로 변환됩니다.
    #
    # 예:
    # x = 0   → -1
    # x = 0.5 →  0
    # x = 1   →  1
    transforms.Normalize((0.5, 0.5, 0.5), (0.5, 0.5, 0.5))
])
full_train_dataset = datasets.CIFAR10(

    # 데이터를 저장하거나 불러올 폴더
    root="./data",
    
    # train=True 이므로
    # CIFAR-10의 train 데이터 50,000장을 가져옵니다.
    train=True,


     # 데이터가 없다면 자동으로 다운로드합니다.
    download=True,

    # 데이터를 꺼낼 때마다
    # 위에서 만든 transform을 적용합니다.
    #
    # 즉:
    # 이미지
    # → Tensor 변환
    # → Normalize
    transform=transform
)

# random_split은 데이터를 무작위로 나누기 때문에
# 실행할 때마다 train/validation 구성이 달라질 수 있다.
#
# 그래서 Generator에 SEED를 고정해서
# 항상 같은 방식으로 데이터가 나뉘도록 만든다
split_generator = torch.Generator().manual_seed(SEED)


# full_train_dataset 50,000장을
#
# train_dataset : 45,000장
# valid_dataset :  5,000장
#
# 으로 무작위 분할
train_dataset, valid_dataset = random_split(
    full_train_dataset, [45000, 5000], generator=split_generator
)

# validation 데이터를 batch 단위로 꺼내기 위한 DataLoader
valid_loader = DataLoader(
     # validation 데이터 5,000장
    valid_dataset, 
    
    # 한 번에 64장씩 모델에 전달합니다.
    batch_size=BATCH_SIZE, 
    
    # validation은 학습이 아니라 성능 평가 목적이므로
    # 굳이 데이터 순서를 섞지 않습니다.
    shuffle=False)



def make_train_loader(seed):

    # 학습 데이터의 shuffle 순서를 재현하기 위해
    # 난수 generator를 만들고 seed를 고정
    generator = torch.Generator().manual_seed(seed)

    # train_dataset을 batch 단위로 꺼내는 DataLoader를 반환
    return DataLoader(

        train_dataset, 
        # 한 번에 모델에 넣을 데이터 개수
        batch_size=BATCH_SIZE,

        # 학습 데이터는 epoch마다 순서를 섞는다
        shuffle=True, 
        
        # shuffle에 사용할 난수 generator
        generator=generator
    )

def fit_model(model, train_loader, valid_loader, criterion, optimizer, device, num_epochs):
    history = {
        # epoch마다 train/validation 성능을 저장할 공간
        "train_loss": [], "train_acc": [],
        "valid_loss": [], "valid_acc": []
    }

    # num_epochs만큼 반복해서 모델을 학습
    for epoch in range(num_epochs):
        train_loss, train_acc = train_one_epoch(
            model, train_loader, criterion, optimizer, device
        )
        valid_loss, valid_acc = validate(
            model, valid_loader, criterion, device
        )
        history["train_loss"].append(train_loss)
        history["train_acc"].append(train_acc)
        history["valid_loss"].append(valid_loss)
        history["valid_acc"].append(valid_acc)
        print(
            f"Epoch [{epoch + 1}/{num_epochs}] "
            f"train_acc={train_acc:.4f}, valid_acc={valid_acc:.4f}"
        )
    return history

def selected_metrics(history):

    # validation loss가 가장 작은 epoch의 index를 찾는다
    #
    # 예를 들어:
    #
    # valid_loss = [1.2, 0.9, 1.0]
    #
    # 가장 작은 값은 0.9이고
    # index는 1입니다.
    index = min(
        range(len(history["valid_loss"])),

        # 각 index i에 대해
        # history["valid_loss"][i] 값을 비교한다.
        key=lambda i: history["valid_loss"][i]
    )

    # validation loss가 가장 좋았던 epoch의
    # 정보만 골라서 반환한다
    return {

        # index는 0부터 시작하지만
        # epoch는 보통 1부터 표시하므로 +1 한다
        "selected_epoch": index + 1,

        # 선택된 epoch의 validation loss
        "valid_loss": history["valid_loss"][index],

        # 선택된 epoch의 validation accuracy
        "valid_acc": history["valid_acc"][index]
    }
```

두 모델은 같은 seed에서 초기화하고, 같은 seed의 shuffle loader를 각각 새로 만든다

```python
device = torch.device("cuda" if torch.cuda.is_available() else "cpu")
criterion = nn.CrossEntropyLoss()

set_seed(SEED)
mlp_train_loader = make_train_loader(SEED)
mlp = ImageMLP(hidden_dim=8, num_classes=10).to(device)
mlp_optimizer = torch.optim.Adam(mlp.parameters(), lr=0.001)
mlp_history = fit_model(
    mlp, mlp_train_loader, valid_loader,
    criterion, mlp_optimizer, device, NUM_EPOCHS
)

set_seed(SEED)
cnn_train_loader = make_train_loader(SEED)
cnn = SmallCNN(num_classes=10).to(device)
cnn_optimizer = torch.optim.Adam(cnn.parameters(), lr=0.001)
cnn_history = fit_model(
    cnn, cnn_train_loader, valid_loader,
    criterion, cnn_optimizer, device, NUM_EPOCHS
)

comparison = {
    "MLP": selected_metrics(mlp_history),
    "CNN": selected_metrics(cnn_history)
}
```

## 8. 결과 비교하기

각 모델에서 validation loss가 가장 낮은 epoch 하나를 선택하고,<br> 그 epoch의 loss와 accuracy를 함께 본다
```python
def count_parameters(model):
    return sum(p.numel() for p in model.parameters() if p.requires_grad)

comparison["MLP"]["params"] = count_parameters(mlp)
comparison["CNN"]["params"] = count_parameters(cnn)
print(comparison)
```

서로 다른 epoch의 `best accuracy`와 `last loss`를 한 행에 섞지 않는다

## 9. 결과 해석하기

CNN의 validation 성능이 더 좋았다면 다음처럼 제한해서 쓴다

> 비슷한 parameter 수와 같은 데이터 split·학습 조건을 사용한 이번 한 seed 실험에서 CNN의 validation 성능이 더 높았습니다. 지역성·가중치 공유가 기여했을 가능성이 있지만, 계산량과 모델별 최적 설정은 다를 수 있어 원인을 확정할 수 없습니다.
> 

결과를 읽을 때는 같은 선택 epoch의 loss/accuracy, parameter 수, train-valid 곡선을<br> 함께 보고 한 seed·계산량·최적 설정 차이를 한계로 적는다.
