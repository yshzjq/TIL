## 1. 이번에 우리가 배울 것

| 지표 | 의미 |
| --- | --- |
| loss | 모델의 예측이 정답과 얼마나 다른지 나타내는 값 |
| accuracy | 전체 샘플 중 몇 개를 맞혔는지 나타내는 비율 |

validation loss는 조금 내려갔는데 accuracy가 그대로라면, 모델이 확신도는 조금 달라졌지만 실제 예측 class는 크게 바뀌지 않았을 수 있다

반대로 accuracy는 높아졌는데 loss가 불안정하다면, 일부 샘플에 대해 매우 틀린 예측을 하고 있을 수 있다

분류 모델을 학습할 때는 **loss와 accuracy를 함께 기록**해야 모델이 실제로 좋아지고 있는지 판단하기 쉽다.<br>
다만 class 불균형이 크면 다수 class만 예측해도 accuracy가 높을 수 있으므로, 문제에 따라 class별 precision·recall·F1과 confusion matrix도 함께 확인한다

## 2. accuracy

accuracy는 전체 샘플 중 모델이 정답 class를 맞힌 비율
```
accuracy = 맞힌 샘플 수 / 전체 샘플 수
```


```python
import torch

# 샘플 3개, class 4개에 대한 logits 예시입니다.
logits = torch.tensor([
    [2.1, 0.3, 0.1, -1.2],
    [0.2, 1.5, 3.0, 0.1],
    [-0.4, 2.2, 0.7, 1.0]
])

# 정답 class index입니다.
labels = torch.tensor([0, 2, 3])

# dim=1은 class 차원을 의미합니다.
# 각 샘플에서 가장 큰 logit을 가진 class index를 예측값으로 선택합니다.
preds = logits.argmax(dim=1)

print("preds :", preds)
print("labels:", labels)
print("correct:", preds == labels)
```

출력

```
preds : tensor([0, 2, 1])
labels: tensor([0, 2, 3])
correct: tensor([ True,  True, False])
```

3개 중 2개를 맞혔으므로 accuracy는 `2 / 3 = 0.666...`

## 3. batch accuracy와 epoch accuracy의 차이

batch accuracy는 batch 하나에서 계산한 accuracy
epoch accuracy는 epoch 전체 샘플에 대해 계산한 accuracy

둘은 비슷해 보이지만, 마지막 batch 크기가 다를 때 단순 평균을 내면 값이 왜곡될 수 있다.

batch accuracy만 평균 값

```
(0.50 + 0.50 + 1.00) / 3 = 0.666...
```

하지만 전체 샘플 기준으로 계산

```
전체 맞힌 개수 = 16 + 16 + 4 = 36
전체 샘플 수 = 32 + 32 + 4 = 68
accuracy = 36 / 68 = 0.529...
```

차이가 크다

epoch 단위 accuracy는 batch accuracy의 단순 평균이 아니라, **전체 맞힌 개수 / 전체 샘플 수**로 계산해야한다.

## 4. 전체 샘플 기준으로 metric 누적하기

아래 함수는 logits와 labels를 받아 맞힌 개수와 전체 샘플 수를 반환한다.

```python
def count_correct(logits, labels):
    """
    logits와 labels를 비교하여 맞힌 개수를 계산합니다.

    logits:
        모델 출력값입니다.
        shape는 보통 (batch_size, num_classes)입니다.

    labels:
        정답 class index입니다.
        shape는 보통 (batch_size,)입니다.
    """

    # class 차원(dim=1)에서 가장 큰 값을 가진 index를 예측 class로 선택합니다.
    # 예: logits shape가 (32, 10)이면 preds shape는 (32,)입니다.
    preds = logits.argmax(dim=1)

    # 예측 class와 정답 class가 같은지 비교합니다.
    # 결과는 True/False 값을 가진 bool Tensor입니다.
    correct_tensor = preds == labels

    # True는 1, False는 0처럼 합산됩니다.
    # .item()을 사용해 Python 숫자로 바꿉니다.
    correct = correct_tensor.sum().item()

    # labels의 첫 번째 차원은 batch 안의 샘플 수입니다.
    total = labels.size(0)

    return correct, total
```

```python
logits = torch.tensor([
    [2.1, 0.3, 0.1],
    [0.2, 3.0, 1.0],
    [0.1, 0.3, 2.7]
])
labels = torch.tensor([0, 1, 1])

correct, total = count_correct(logits, labels)
accuracy = correct / total

print("correct:", correct)
print("total  :", total)
print("acc    :", accuracy)
```

출력

```
correct: 2
total  : 3
acc    : 0.6666666666666666
```

## 5. train loop에 accuracy 추가하기

이제 train loop가 loss뿐 아니라 accuracy도 반환하도록 바꿔보겠습니다.

```python
def train_one_epoch(model, train_loader, criterion, optimizer, device):
    """
    train 데이터셋을 한 epoch 동안 학습하고 평균 loss와 accuracy를 반환합니다.
    """

    # 학습 단계에서는 반드시 train mode로 전환합니다.
    # Dropout, BatchNorm 같은 layer가 학습 모드로 동작합니다.
    model.train()

    # 전체 샘플 기준 평균 loss를 계산하기 위한 누적 변수입니다.
    total_loss = 0.0

    # accuracy 계산을 위한 누적 변수입니다.
    total_correct = 0
    total_samples = 0

    for inputs, labels in train_loader:
        # 데이터와 정답을 모델이 있는 device로 이동합니다.
        inputs = inputs.to(device)
        labels = labels.to(device)

        # 이전 batch에서 계산된 gradient가 남아 있지 않도록 초기화합니다.
        optimizer.zero_grad()

        # forward: 모델 예측값(logits)을 계산합니다.
        outputs = model(inputs)

        # loss 계산: outputs와 labels를 비교합니다.
        loss = criterion(outputs, labels)

        # backward: loss를 기준으로 gradient를 계산합니다.
        loss.backward()

        # step: 계산된 gradient를 이용해 parameter를 업데이트합니다.
        optimizer.step()

        # 현재 batch 크기입니다.
        batch_size = inputs.size(0)

        # criterion이 반환하는 loss는 보통 batch 평균입니다.
        # 전체 샘플 기준 평균을 구하려면 batch_size를 곱해서 누적합니다.
        total_loss += loss.item() * batch_size

        # 현재 batch에서 맞힌 개수를 계산합니다.
        correct, total = count_correct(outputs, labels)
        total_correct += correct
        total_samples += total

    if total_samples == 0:
        raise ValueError("train_loader가 비어 있습니다.")

    # 전체 샘플 기준 평균 loss입니다.
    avg_loss = total_loss / total_samples

    # 전체 샘플 기준 accuracy입니다.
    avg_acc = total_correct / total_samples

    return avg_loss, avg_acc
```

`loss.item()`만 계속 더한 뒤 batch 개수로 나누는 방식도 자주 보인다<br>
하지만 batch 크기가 항상 같지 않을 수 있으므로, 처음에는 `loss.item() * batch_size`로 누적하고 전체 샘플 수로 나누는 방식을 습관화하는 것이 좋다.

## 6. validation loop에 accuracy 추가하기


validation에서는 parameter를 업데이트하지 않습니다.
따라서 `optimizer.zero_grad()`, `loss.backward()`, `optimizer.step()`을 사용하지 않는다


```python
def validate(model, valid_loader, criterion, device):
    """
    validation 데이터셋에 대한 평균 loss와 accuracy를 계산합니다.
    """

    # 평가 단계에서는 eval mode로 전환합니다.
    # Dropout은 비활성화되고, BatchNorm은 저장된 running statistics를 사용합니다.
    model.eval()

    total_loss = 0.0
    total_correct = 0
    total_samples = 0

    # validation에서는 gradient 계산이 필요하지 않습니다.
    # torch.no_grad()를 사용하면 메모리 사용량을 줄이고 계산도 더 가볍게 만들 수 있습니다.
    with torch.no_grad():
        for inputs, labels in valid_loader:
            inputs = inputs.to(device)
            labels = labels.to(device)

            # forward만 수행합니다.
            outputs = model(inputs)

            # validation loss를 계산합니다.
            loss = criterion(outputs, labels)

            batch_size = inputs.size(0)
            total_loss += loss.item() * batch_size

            correct, total = count_correct(outputs, labels)
            total_correct += correct
            total_samples += total

    if total_samples == 0:
        raise ValueError("valid_loader가 비어 있습니다.")

    avg_loss = total_loss / total_samples
    avg_acc = total_correct / total_samples

    return avg_loss, avg_acc
```

inputs.size(0) → 0번째 차원의 크기를 숫자로 조회
inputs.sum(dim=0) → 0번째 차원을 따라 합쳐서 실제 차원을 축소

validation loop 안에서 `loss.backward()`를 호출하면 안 된다.<br>
validation은 현재 모델의 성능을 확인하는 단계이지, 모델을 학습시키는 단계가 아니다

## 7. 자주 하는 실수

### 실수 1. `argmax(dim=0)`을 사용하는 경우

```
# 잘못된 예시입니다.
# dim=0은 batch 방향입니다.
preds = outputs.argmax(dim=0)
```

다중 분류 logits의 shape가 `(batch_size, num_classes)`라면 class 차원은 `dim=1`입니다.

```
# 올바른 예시입니다.
preds = outputs.argmax(dim=1)
```


다중 분류인 경우의 argmax

| 코드 | 비교하는 방향 | 반환하는 값 | 결과 shape |
| --- | --- | --- | --- |
| `argmax(dim=0)` | batch 방향 | 각 class에서 점수가 가장 높은 샘플 번호 | `(num_classes,)` |
| `argmax(dim=1)` | class 방향 | 각 샘플에서 점수가 가장 높은 class 번호 | `(batch_size,)` |


### 실수 2. batch accuracy를 단순 평균하는 경우

```
# 마지막 batch 크기가 다르면 왜곡될 수 있다.
acc_sum += batch_acc
avg_acc = acc_sum / num_batches
```

대신 맞힌 개수와 전체 샘플 수를 누적

```
total_correct += correct
total_samples += labels.size(0)
avg_acc = total_correct / total_samples
```

### 실수 3. validation에서 gradient를 계산하는 경우

```
# validation에서는 필요하지 않은 코드입니다.
loss.backward()
optimizer.step()
```

validation에서는 다음 구조를 사용
```
model.eval()
with torch.no_grad():
    outputs = model(inputs)
```
