## 1. 이번에 배울것

지금까지 MLP에서는 입력을 보통 `(batch_size, features)` 형태로 다뤘다. 

이미지에서는 feature를 한 줄로 펼치기 전에, 먼저 이미지가 가진 **공간 구조**를 읽어야 한다

이미지 Tensor는 보통 다음 순서로 다룬다

```
(batch_size, channels, height, width)
```

이 순서를 줄여서 **NCHW**라고 부릅니다. 일반 이미지 배열은 `(H, W, C)`로 보일 수 있지만,<br> PyTorch `Conv2d`에 넣는 batch는 `(N, C, H, W)`여야 한다

| 기호 | 의미 | 예시 |
| --- | --- | --- |
| `N` | batch 안의 이미지 개수 | 32장 |
| `C` | channel 수 | 흑백 1, RGB 3 |
| `H` | 이미지 높이 | 32, 224 |
| `W` | 이미지 너비 | 32, 224 |

## 2. 왜 channel을 먼저 알아야 하나

CNN은 이미지의 작은 영역을 보면서 특징을 찾는다.<br> 
그런데 RGB 이미지는 한 픽셀 안에 빨강, 초록, 파랑 값이 같이 들어 있다. <br>
그래서 CNN의 첫 번째 Conv layer는 입력 channel 수를 정확히 알아야 한다

예를 들어 CIFAR-10 이미지는 `3x32x32` 형태다.

```
CIFAR-10 image shape: (3, 32, 32)
DataLoader batch shape: (batch_size, 3, 32, 32)
```

`nn.Conv2d(in_channels=3, ...)`에서 `in_channels=3`은 RGB 이미지의 channel 수와 맞아야 합니다.

## 3. 더미 이미지 Tensor 만들기

```python
import torch

# 이미지 batch를 직접 만들어봅니다.
# 8장의 RGB 이미지가 있고, 각 이미지는 32x32 크기라고 가정합니다.
# shape는 (batch_size, channels, height, width) 순서입니다.
images = torch.randn(8, 3, 32, 32)

# Tensor의 전체 shape를 확인합니다.
print("images shape:", images.shape)

# 각 차원을 변수로 풀어서 읽으면 shape 의미가 더 명확해집니다.
batch_size, channels, height, width = images.shape

print("batch_size:", batch_size)  # 이미지 개수
print("channels  :", channels)    # RGB이므로 3
print("height    :", height)      # 이미지 높이
print("width     :", width)       # 이미지 너비
```

출력

```
images shape: torch.Size([8, 3, 32, 32])
batch_size: 8
channels  : 3
height    : 32
width     : 32
```

## 4. HWC와 CHW 순서 헷갈리지 않기

일부 이미지 라이브러리는 이미지를 `(height, width, channels)` 순서로 다룬다. 
<br>
이를 **HWC**라고 합니다. 반면 PyTorch CNN은 보통 `(channels, height, width)` 순서인 **CHW**를 사용한다

```python
import torch

# HWC 형태의 이미지 한 장이라고 가정합니다.
# 예: 일반 이미지 처리 라이브러리에서 자주 볼 수 있는 순서입니다.
hwc_image = torch.randn(32, 32, 3)

print("HWC shape:", hwc_image.shape)

# PyTorch CNN에 넣으려면 CHW 형태가 필요합니다.
# permute(2, 0, 1)은 차원 순서를 바꿉니다.
# 기존 0번 차원 H, 1번 차원 W, 2번 차원 C를
# 새 순서 C, H, W로 바꿉니다.
chw_image = hwc_image.permute(2, 0, 1)

print("CHW shape:", chw_image.shape)

# permute 결과는 메모리에서 연속적이지 않을 수 있습니다.
# 이후 view가 필요하면 chw_image = chw_image.contiguous()로 정리합니다.
```

예상 출력은 다음과 같습니다.

```
HWC shape: torch.Size([32, 32, 3])
CHW shape: torch.Size([3, 32, 32])
```

`permute`는 차원의 순서를 바꾸는 함수다. 값 자체를 정규화하거나 크기를 바꾸는 함수가 아니다

## 5. DataLoader에서 batch shape 확인

```python
import torch
from torch.utils.data import TensorDataset, DataLoader

# 예제용 이미지 100장과 label 100개를 만듭니다.
# 실제 수업에서는 torchvision.datasets.CIFAR10 같은 Dataset을 사용합니다.
images = torch.randn(100, 3, 32, 32)
labels = torch.randint(0, 10, size=(100,))

# TensorDataset은 Tensor 여러 개를 같은 index 기준으로 묶어줍니다.
dataset = TensorDataset(images, labels)

# DataLoader는 Dataset에서 batch를 만들어줍니다.
loader = DataLoader(dataset, batch_size=16, shuffle=True)

# 첫 번째 batch만 꺼내 shape를 확인합니다.
batch_images, batch_labels = next(iter(loader))

print("batch_images shape:", batch_images.shape)
print("batch_labels shape:", batch_labels.shape)
```

출력

```
batch_images shape: torch.Size([16, 3, 32, 32])
batch_labels shape: torch.Size([16])
```

## 6. 자주 하는 실수

### 실수 1. `(N, H, W, C)`를 CNN에 넣기

```python
wrong_images = torch.randn(16, 32, 32, 3)
```

이 Tensor는 PyTorch CNN 기준으로 channel 수가 32인 것처럼 해석될 수 있습니다.

수정

```python
# (N, H, W, C) -> (N, C, H, W)
correct_images = wrong_images.permute(0, 3, 1, 2)
print(correct_images.shape)
```

### 실수 2. 흑백 이미지 channel 차원 빼먹기

```python
# 잘못된 예: (N, H, W)
gray_images = torch.randn(16, 28, 28)

# 수정: channel 차원 추가 -> (N, 1, H, W)
gray_images = gray_images.unsqueeze(1)
print(gray_images.shape)
```
