## 1. 이번에 배울것

RNN의 forward 결과를 실제 분류 모델로 연결한다<br>
핵심은 output 전체를 그대로 쓰는 것이 아니라,<br> 문제에 맞는 시점의 hidden state를 선택하는 것이다


```
문장 전체 -> 긍정/부정 분류
시계열 전체 -> 다음 상태 분류
사용자 행동 sequence -> 이탈 여부 분류
```

## 2. RNN forward 결과 다시 보기

```python
import torch
import torch.nn as nn

x = torch.randn(4, 6, 3)
rnn = nn.RNN(input_size=3, hidden_size=8, batch_first=True)

output, h_n = rnn(x)

print(output.shape)
print(h_n.shape)
```

출력

```
torch.Size([4, 6, 8])
torch.Size([1, 4, 8])
```

`output`에는 6개 시점 각각의 hidden state가 들어 있다.

```
output[:, 0, :] -> 첫 번째 시점 hidden
output[:, 1, :] -> 두 번째 시점 hidden
...
output[:, -1, :] -> 마지막 시점 hidden
```

## 3. 마지막 유효 시점 출력으로 분류

분류 문제에서는 각 샘플의 마지막 **유효한** hidden state를 `nn.Linear`에 넣어 class별 logits를 만든다

모든 샘플이 같은 길이이고 padding이 없다면 

```python
last_hidden = output[:, -1, :]  # (batch, hidden_size)
classifier = nn.Linear(8, 3)
logits = classifier(last_hidden)  # (batch, num_classes)
```

길이가 다른 문장을 오른쪽에 PAD로 채웠다면 `-1` 위치는 PAD일 수 있다.

```
샘플 A: 실제 실제 실제 실제 실제 실제   length=6
샘플 B: 실제 실제 실제 실제 PAD  PAD    length=4
샘플 C: 실제 실제 PAD  PAD  PAD  PAD    length=2
```

`lengths - 1` 위치를 샘플마다 골라야 합니다.

```python
# batch_size = 3
# seq_len = 6
# input_size = 3
#
# 즉:
# 샘플 3개가 있고
# 각 샘플은 최대 6개 시점까지 가지며
# 각 시점마다 feature가 3개 있습니다.
padded_x = torch.randn(3, 6, 3)

# 두 번째 샘플(index 1)은 실제 길이가 4라고 가정합니다.
#
# index:
# 0   1   2   3   4   5
#
# x1  x2  x3  x4  0   0
#
# 뒤쪽 2개 시점을 0으로 padding합니다.
padded_x[1, 4:] = 0.0

# 세 번째 샘플(index 2)은 실제 길이가 2라고 가정합니다.
#
# index:
# 0   1   2   3   4   5
#
# x1  x2  0   0   0   0
#
# 뒤쪽 4개 시점을 0으로 padding합니다.
padded_x[2, 2:] = 0.0

# rnn의 hidden_size가 8이라면
#
# 입력 shape:
# (3, 6, 3)
#
# output shape:
# (3, 6, 8)
#
# output에는 각 샘플의 모든 시점 hidden state가 들어 있습니다.
#
# 예:
# sample 0 -> [h1, h2, h3, h4, h5, h6]
# sample 1 -> [h1, h2, h3, h4, h5, h6]
# sample 2 -> [h1, h2, h3, h4, h5, h6]
#
# 여기서 _ 는 h_n을 사용하지 않겠다는 뜻입니다.
output, _ = rnn(padded_x)

# sample 0의 실제 길이 = 6
# sample 1의 실제 길이 = 4
# sample 2의 실제 길이 = 2
lengths = torch.tensor([6, 4, 2], dtype=torch.long)

# 4. lengths가 올바른 형태인지 검사
# lengths는 각 샘플마다 길이 하나씩 있어야 하므로
# shape가 반드시 (batch,)여야 합니다.
#
# 현재 batch_size는 3이므로
#
# lengths.shape == (3,)
#
# 이어야 합니다.
if lengths.ndim != 1 or lengths.size(0) != output.size(0):
    raise ValueError("lengths shape는 (batch,)여야 합니다.")

# 각 sequence 길이는 최소 1 이상이어야 하고
# 최대 seq_len을 넘을 수 없습니다.
#
# 현재 seq_len = 6이므로
#
# 가능한 길이:
# 1 ~ 6
if torch.any(lengths < 1) or torch.any(lengths > output.size(1)):
    raise ValueError("각 length는 1 이상 seq_len 이하여야 합니다.")

# output이 GPU에 있다면 lengths도 GPU에 있어야
# 같은 연산에서 함께 사용할 수 있습니다.
lengths = lengths.to(output.device)

# batch_size가 3이므로
#
# [0, 1, 2]
#
# 를 만듭니다.
#
# 각 숫자는 sample 번호를 의미합니다.
batch_index = torch.arange(output.size(0), device=output.device)

# 실제 길이가:
#
# [6, 4, 2]
#
# 라면 실제 마지막 index는:
#
# [5, 3, 1]
#
# 입니다.
#
# 그래서 length - 1을 합니다.
last_index = lengths - 1

# batch_index = [0, 1, 2]
# last_index  = [5, 3, 1]
#
# 따라서 실제로는:
#
# output[0, 5]  -> sample 0의 마지막 hidden state
# output[1, 3]  -> sample 1의 마지막 hidden state
# output[2, 1]  -> sample 2의 마지막 hidden state
#
# 를 한 번에 가져온다
last_hidden = output[batch_index, last_index]  # (3, hidden_size)
```



`lengths`는 PAD를 제외한 실제 시점 수이며 1 이상이어야 한다


## 4. RNNClassifier 구현

`lengths=None`이면 고정 길이·무패딩 batch, `lengths`가 있으면 오른쪽 padding batch로 처리한다

```python
import torch
import torch.nn as nn
class RNNClassifier(nn.Module):
    def __init__(self, input_size, hidden_size, num_classes):
        super().__init__()
        self.rnn = nn.RNN(
            input_size=input_size,
            hidden_size=hidden_size,
            batch_first=True
        )
        self.fc = nn.Linear(hidden_size, num_classes)
    def forward(self, x, lengths=None):
        output, h_n = self.rnn(x)
        if lengths is None:
            # 고정 길이·무패딩인 경우입니다.
            last_hidden = output[:, -1, :]
        else:
            if lengths.dtype not in (
                torch.uint8, torch.int8, torch.int16, torch.int32, torch.int64
            ):
                raise TypeError("lengths는 정수 dtype이어야 합니다.")
            if lengths.ndim != 1 or lengths.size(0) != x.size(0):
                raise ValueError("lengths shape는 (batch,)여야 합니다.")
            lengths = lengths.to(x.device, dtype=torch.long)
            if torch.any(lengths < 1) or torch.any(lengths > x.size(1)):
                raise ValueError("각 length는 1 이상 seq_len 이하여야 합니다.")
            batch_index = torch.arange(x.size(0), device=x.device)
            last_index = lengths - 1
            last_hidden = output[batch_index, last_index]
        return self.fc(last_hidden)
# 고정 길이·무패딩 예시
x = torch.randn(4, 6, 3)
model = RNNClassifier(input_size=3, hidden_size=8, num_classes=3)
logits = model(x)
print(logits.shape)  # torch.Size([4, 3])
# 오른쪽 padding 예시
padded_x = torch.randn(3, 6, 3)
lengths = torch.tensor([6, 4, 2])
padded_x[1, 4:] = 0.0
padded_x[2, 2:] = 0.0
logits = model(padded_x, lengths=lengths)
print(logits.shape)  # torch.Size([3, 3])
```

## 5. 중간 shape를 출력하는 디버깅 forward

초반에는 shape를 눈으로 확인하는 것이 가장 빠른 디버깅 방법<br> 아래 디버깅 예시는 고정 길이·무패딩 batch용입이다.

```python
class DebugRNNClassifier(nn.Module):
    def __init__(self, input_size, hidden_size, num_classes):
        super().__init__()
        self.rnn = nn.RNN(input_size, hidden_size, batch_first=True)
        self.fc = nn.Linear(hidden_size, num_classes)
    def forward(self, x):
        print("input       :", x.shape)
        output, h_n = self.rnn(x)
        print("rnn output  :", output.shape)
        print("h_n         :", h_n.shape)
        last_hidden = output[:, -1, :]
        print("last_hidden :", last_hidden.shape)
        logits = self.fc(last_hidden)
        print("logits      :", logits.shape)
        return logits
```

## 6. 자주 하는 실수

### 실수 1. `output` 전체를 바로 `Linear`에 넣고 결과 shape를 헷갈리기

```python
logits = self.fc(output)
```

`output` shape가 `(batch, seq_len, hidden_size)`이면 `Linear`는 마지막 차원만 바꿔서<br> `(batch, seq_len, num_classes)`를 만든다.

문장 전체에 대해 label 하나를 예측하려는 문제라면 출력은 `(batch, num_classes)`가 되어야 하므로 마지막 시점만 선택해야 한다



### 실수 2. `h_n`의 첫 번째 차원을 batch로 착각하기

`h_n` shape는 `(D × num_layers, batch, hidden_size)`입니다. 단방향은 `D=1`, 양방향은 `D=2`다.<br> 
첫 번째 차원은 layer와 direction이 합쳐진 차원이며 batch가 아니다. `batch_first=True`도 이 shape를 바꾸지 않습니다.<br> 현재 1-layer 단방향 예제에서 마지막 layer의 값은 `h_n[-1]`입니다.
