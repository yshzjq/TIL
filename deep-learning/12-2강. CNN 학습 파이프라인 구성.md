## 1. 이번에 배울것

```
이미지 Dataset
-> DataLoader
-> CNN model
-> logits
-> loss
-> backward
-> optimizer.step
-> validation
-> epoch별 metric 기록
```

PyTorch의 CIFAR-10 이미지 분류를 위해 다음 순서로 진행

```
1. CIFAR-10 데이터 로드 및 정규화
2. CNN 정의
3. loss 함수와 optimizer 정의
4. 학습
5. 테스트
```

CNN 학습 파이프라인은 **이미지 데이터, CNN 모델, loss, optimizer, train/valid loop가 하나의 흐름으로 연결되는 것**을 의미

## 2. CNN 학습 파이프라인

CNN 학습 파이프라인(표 위에서 아래까지 순서대로 진행)

| 단계 | 역할 | 확인할 것 |
| --- | --- | --- |
| Dataset / Transform | 이미지와 label을 준비합니다. | 이미지가 Tensor인지, channel 순서가 맞는지 |
| DataLoader | 여러 이미지를 batch로 묶습니다. | `images.shape`, `labels.shape` |
| CNN model | 이미지에서 특징을 추출하고 logits를 만듭니다. | `Conv2d`, `Flatten`, `Linear` 연결 |
| Logits | class별 점수입니다. | shape가 `(batch_size, num_classes)`인지 |
| Loss / Optimizer | 예측과 정답을 비교하고 parameter를 업데이트합니다. | `CrossEntropyLoss`, `Adam` |
| Train / Valid loop | 학습과 검증을 반복합니다. | `model.train()`, `model.eval()`, `torch.no_grad()` |



학습을 시작하기 전에 반드시 **batch shape와 logits shape를 먼저 확인**해야 한다.

## 3. 데이터 준비 흐름

이번 강에서는 CIFAR-10 형태의 이미지 분류 데이터를 사용한다.<br>
CIFAR-10 이미지 한 장의 shape는 `(3, 32, 32)`이고, DataLoader가 만든 batch는 `(batch_size, 3, 32, 32)`다.

train split 안에서 다시 train/validation을 나누고,<br>
원래 test split은 모든 모델 선택이 끝난 뒤 마지막 평가에만 사용한다

```python
import random
import numpy as np
import torch

# Dataset을 batch 단위로 꺼내기 위한 DataLoader와
# 하나의 Dataset을 여러 부분으로 나누기 위한 random_split을 가져온다.
from torch.utils.data import DataLoader, random_split

# CIFAR-10 데이터셋과 이미지 전처리 기능을 사용하기 위해 import한다
from torchvision import datasets, transforms


# 난수 고정
SEED = 42

# 페이지를 위에서부터 다시 실행하면 데이터 분할, 모델 초기화, shuffle이 같은 출발점에서 시작합니다.

# Python 기본 random 모듈의 난수 고정
random.seed(SEED)

# NumPy의 난수 고정
np.random.seed(SEED)

# PyTorch CPU 연산의 난수 고정
torch.manual_seed(SEED)

# CUDA(GPU)를 사용하는 경우 GPU 난수도 고정합니다.
if torch.cuda.is_available():
    torch.cuda.manual_seed_all(SEED)



transform = transforms.Compose([

    # CIFAR-10 이미지를 PyTorch Tensor로 변환한다.
    #
    # 원래 이미지는 보통
    # [Height, Width, Channel]
    # 형태이고 픽셀 값은 0~255입니다.
    #
    # ToTensor()를 적용하면
    # [Channel, Height, Width]
    # 형태의 float Tensor가 되고
    # 픽셀 값도 0~1 범위로 변환된다
    #
    # CIFAR-10 이미지:
    # (32, 32, 3)
    #      ↓
    # (3, 32, 32)

    transforms.ToTensor(),

    # 각 RGB 채널의 값을 정규화합니다.
    #
    # 계산식:
    #
    # normalized = (x - mean) / std
    #
    # 현재 mean=0.5, std=0.5이므로
    #
    # x=0   → (0 - 0.5) / 0.5 = -1
    # x=0.5 → (0.5 - 0.5) / 0.5 = 0
    # x=1   → (1 - 0.5) / 0.5 = 1
    #
    # 따라서 기존의 0~1 범위를
    # 대략 -1~1 범위로 변환합니다.
    #
    # CIFAR-10은 RGB 이미지이므로
    # R, G, B 세 채널 각각에 mean과 std를 지정합니다.
    transforms.Normalize(
        mean=(0.5, 0.5, 0.5),
        std=(0.5, 0.5, 0.5)
    )
])

# CIFAR-10에서 원래 제공하는 train 데이터 전체를 가져옵니다.
#
# CIFAR-10 train 데이터:
# 총 50,000장
#
# 이 50,000장을 이후에
# train / validation으로 다시 나눌 것입니다.
full_train_dataset = datasets.CIFAR10(
    root="./data",
    train=True,
    download=True,
    transform=transform
)

# CIFAR-10이 원래 제공하는 test 데이터입니다.
#
# CIFAR-10 test 데이터:
# 총 10,000장
#
# test 데이터는 모델 학습이나
# hyperparameter 선택에 사용하지 않습니다.
#
# train과 validation을 이용해 모델 선택이 모두 끝난 뒤
# 최종 성능을 확인할 때 한 번 사용하는 것이 좋습니다.
test_dataset = datasets.CIFAR10(
    root="./data",
    train=False,
    download=True,
    transform=transform
)

# validation에 사용할 이미지 개수를 5,000장으로 정한다
valid_size = 5000

# 전체 train 데이터 50,000장에서
# validation 5,000장을 제외한 나머지를 실제 학습에 사용합니다.
#
# 50,000 - 5,000 = 45,000
train_size = len(full_train_dataset) - valid_size

# random_split은 데이터를 무작위로 나누기 때문에
# 실행할 때마다 다른 데이터가 train/valid에 들어갈 수 있습니다.
#
# Generator에 seed를 고정하여
# 항상 같은 방식으로 나뉘도록 만듭니다.
split_generator = torch.Generator().manual_seed(SEED)

train_dataset, valid_dataset = random_split(
     
    # 나눌 원본 Dataset
    full_train_dataset,

    # train 45,000장 / validation 5,000장
    [train_size, valid_size],

    # 데이터 분할에 사용할 난수 generator
    generator=split_generator
)

# 결과적으로 데이터는 다음과 같이 나뉜다
#
# full_train_dataset : 50,000
#
# ├── train_dataset : 45,000
# └── valid_dataset : 5,000
#
# test_dataset       : 10,000


# train_loader는 epoch마다 데이터를 섞어서 사용합니다.
#
# shuffle 과정에서도 난수가 사용되므로
# 별도의 Generator를 만들어 seed를 고정합니다.
#
# split_generator와 train_generator를 따로 만든 이유는
# "데이터를 나누는 난수"와
# "학습 데이터를 섞는 난수"를 서로 독립적으로 관리하기 위해서다.
train_generator = torch.Generator().manual_seed(SEED)


train_loader = DataLoader(

    # 학습 Dataset
    train_dataset,

    # 한 번에 모델에게 전달할 이미지 개수
    batch_size=64,

    # 학습 데이터는 epoch마다 순서를 섞습니다.
    #
    # 이렇게 하면 모델이 항상 같은 데이터 순서에
    # 지나치게 의존하는 것을 줄일 수 있습니다.
    shuffle=True,

    # shuffle에 사용할 난수 Generator
    generator=train_generator
)

# validation은 학습하지 않으므로
# 데이터 순서를 섞을 필요가 없다.
valid_loader = DataLoader(valid_dataset, batch_size=64, shuffle=False)

# test도 학습하지 않으므로 shuffle하지 않습니다.
test_loader = DataLoader(test_dataset, batch_size=64, shuffle=False)



# 학습을 시작하기 전에
#
# images.shape
# labels.shape
#
# 등을 확인하기 위한 별도의 DataLoader입니다.
#
# train_loader에서 직접 한 batch를 꺼내 shape를 확인하면
# shuffle=True에 사용되는 train_generator의 난수 상태가
# 한 번 소비될 수 있습니다.
#
# 그러면 실제 학습 시작 시 데이터 순서가
# 예상했던 것과 달라질 수 있습니다.
#
# 따라서 shape 확인만을 위한
# shuffle=False DataLoader를 별도로 만듭니다.
inspection_loader = DataLoader(
    train_dataset, 
    batch_size=64, 

    # validation은 학습하지 않으므로
    # 데이터 순서를 섞을 필요가 없습니다.
    shuffle=False
)
```

train set: parameter 학습

validation set: 모델과 hyperparameter 선택

test set: 선택을 끝낸 최종 모델을 마지막에 한 번 평가

test 결과를 보고 모델을 다시 바꾸면 test set도 사실상 validation처럼 사용하게 된다.

## 4. 데이터 batch shape 확인

```python
# inspection_loader에서 첫 batch 하나만 꺼냅니다.
images, labels = next(iter(inspection_loader))

print("images shape:", images.shape)
print("labels shape:", labels.shape)
print("images dtype:", images.dtype)
print("labels dtype:", labels.dtype)
```

출력

```
images shape: torch.Size([64, 3, 32, 32])
labels shape: torch.Size([64])
images dtype: torch.float32
labels dtype: torch.int64
```

| Tensor | shape | 의미 |
| --- | --- | --- |
| `images` | `(64, 3, 32, 32)` | 이미지 64장, RGB 3채널, 32x32 |
| `labels` | `(64,)` | 이미지 64장에 대한 class index |

`labels.dtype`이 `torch.int64`인 것도 중요하다

`nn.CrossEntropyLoss`는 class index target을 사용할 때 target dtype이 `torch.long`, 즉 보통 `torch.int64`여야 한다

CNN 입력은 보통 `(N, C, H, W)` 형태다.

```
N: batch size
C: channel 수
H: height
W: width
```

CIFAR-10 batch라면 보통 `(batch_size, 3, 32, 32)`다.

## 5. 이번 강에서 사용할 CNN 모델 정의

SmallCNN shape 흐름

```python
import torch
import torch.nn as nn

class SmallCNN(nn.Module):
    """
    CIFAR-10처럼 3채널 32x32 이미지를 입력받아
    class 10개에 대한 logits를 출력하는 간단한 CNN 모델입니다.

    입력 shape:
        (batch_size, 3, 32, 32)

    출력 shape:
        (batch_size, num_classes)
    """

    def __init__(self, num_classes=10):
        super().__init__()

        # features는 이미지에서 공간적 특징을 추출하는 부분입니다.
        # Conv2d -> ReLU -> MaxPool2d 구조를 2번 반복합니다.
        self.features = nn.Sequential(
            # 첫 번째 Conv block
            # 입력 shape : (batch_size, 3, 32, 32)
            # 출력 shape : (batch_size, 16, 32, 32)
            # in_channels=3  : RGB 이미지의 channel 수입니다.
            # out_channels=16: 16개의 filter로 16장의 feature map을 만듭니다.
            # kernel_size=3  : 3x3 필터를 사용합니다.
            # padding=1      : 가장자리에 1칸 padding을 넣어 높이/너비를 유지합니다.
            nn.Conv2d(
                in_channels=3,
                out_channels=16,
                kernel_size=3,
                padding=1
            ),

            # ReLU는 음수 값을 0으로 바꾸어 비선형성을 추가합니다.
            nn.ReLU(),

            # MaxPool2d(2)는 2x2 영역에서 가장 큰 값만 남깁니다.
            # 높이와 너비가 절반으로 줄어듭니다.
            # 출력 shape: (batch_size, 16, 16, 16)
            nn.MaxPool2d(kernel_size=2),

            # 두 번째 Conv block
            # 입력 shape : (batch_size, 16, 16, 16)
            # 출력 shape : (batch_size, 32, 16, 16)
            nn.Conv2d(
                in_channels=16,
                out_channels=32,
                kernel_size=3,
                padding=1
            ),
            nn.ReLU(),

            # 다시 높이와 너비가 절반으로 줄어듭니다.
            # 출력 shape: (batch_size, 32, 8, 8)
            nn.MaxPool2d(kernel_size=2),
        )

        # Flatten은 4차원 feature map을 2차원 Tensor로 펼칩니다.
        # (batch_size, 32, 8, 8) -> (batch_size, 32 * 8 * 8)
        self.flatten = nn.Flatten()

        # classifier는 펼쳐진 feature를 class별 점수로 바꿉니다.
        # 32 * 8 * 8 = 2048
        # 출력 shape: (batch_size, num_classes)
        self.classifier = nn.Linear(
            in_features=32 * 8 * 8,
            out_features=num_classes
        )

    def forward(self, x):
        # x shape: (batch_size, 3, 32, 32)
        x = self.features(x)

        # x shape: (batch_size, 32, 8, 8)
        x = self.flatten(x)

        # x shape: (batch_size, 2048)
        logits = self.classifier(x)

        # logits shape: (batch_size, num_classes)
        return logits
```


`logits`는 softmax를 적용한 확률이 아니라, 모델이 class별로 출력한 **원시 점수**다.

`nn.CrossEntropyLoss`는 이 logits를 그대로 입력으로 받는다.

## 6. CNN forward shape 확인

모델을 정의했으면 바로 학습을 시작하지 말고, 먼저 더미 batch 또는 실제 batch 하나로 forward를 실행해본다

```python
# GPU가 가능하면 GPU를 사용하고, 아니면 CPU를 사용합니다.
device = torch.device("cuda" if torch.cuda.is_available() else "cpu")

# CNN 모델을 생성한 뒤 device로 이동합니다.
model = SmallCNN(num_classes=10).to(device)

# 실제 train_loader에서 batch 하나를 꺼냅니다.
images, labels = next(iter(train_loader))

# CIFAR-10은 class가 10개이므로 logits의 마지막 차원은 10이어야 합니다.

```


## 7. loss와 optimizer 연결

```python
import torch.nn as nn

# 모델 생성 및 device 이동
model = SmallCNN(num_classes=10).to(device)

# 다중 분류 문제에서는 CrossEntropyLoss를 사용합니다.
# CrossEntropyLoss : Softmax를 직접 붙이지 않아도 loss 계산 안에서 필요한 처리가 이미 들어가 있습니다.
# 입력: logits shape (batch_size, num_classes)
# 정답: labels shape (batch_size,), dtype torch.long
criterion = nn.CrossEntropyLoss()

# optimizer는 model.parameters()를 업데이트합니다.
# Adam은 학습 초반에 안정적으로 많이 쓰는 optimizer입니다.
optimizer = torch.optim.Adam(
    model.parameters(),
    lr=0.001
)
```
`CrossEntropyLoss`에 들어가는 값

| 항목 | shape | 설명 |
| --- | --- | --- |
| `logits` | `(batch_size, 10)` | class별 원시 점수 |
| `labels` | `(batch_size,)` | 정답 class 번호 |

## 8. train 함수 작성

train 함수는 `train_loader` 전체를 한 번 순회하면서 모델을 업데이트한다

한 epoch의 학습 흐름

```
model.train()
-> batch 꺼내기
-> device 이동
-> optimizer.zero_grad()
-> forward
-> loss 계산
-> loss.backward()
-> optimizer.step()
-> loss/accuracy 누적
```

```python
def train_one_epoch(model, train_loader, criterion, optimizer, device):
    """
    train_loader 전체를 한 번 학습하는 함수입니다.

    반환값:
        avg_loss: 전체 샘플 기준 평균 train loss
        accuracy: 전체 샘플 기준 train accuracy
    """

    # 모델을 학습 모드로 바꿉니다.
    # Dropout, BatchNorm 같은 layer는 train/eval 모드에 따라 다르게 동작합니다.
    model.train()

    # 전체 loss 합계를 저장합니다.
    total_loss = 0.0

    # 맞힌 샘플 수를 저장합니다.
    correct = 0

    # 전체 샘플 수를 저장합니다.
    total = 0

    for images, labels in train_loader:
        # 이미지는 shape (batch_size, 3, 32, 32)입니다.
        # labels는 shape (batch_size,)입니다.
        images = images.to(device)
        labels = labels.to(device)

        # 이전 batch에서 계산된 gradient를 제거합니다.
        # 이 줄을 빼먹으면 gradient가 누적되어 의도하지 않은 업데이트가 발생할 수 있습니다.
        optimizer.zero_grad()

        # CNN forward를 실행합니다.
        # logits shape: (batch_size, num_classes)
        logits = model(images)

        # 예측 logits와 정답 labels를 비교해 loss를 계산합니다.
        loss = criterion(logits, labels)

        # loss를 기준으로 gradient를 계산합니다.
        loss.backward()

        # 계산된 gradient를 사용해 model parameter를 업데이트합니다.
        optimizer.step()

        # 현재 batch 크기입니다.
        batch_size = images.size(0)

        # loss.item()은 현재 batch의 평균 loss입니다.
        # 전체 샘플 기준 평균을 구하려면 batch_size를 곱해 누적합니다.
        total_loss += loss.item() * batch_size

        # logits에서 가장 점수가 큰 class index를 예측값으로 사용합니다.
        preds = logits.argmax(dim=1)

        # 맞힌 개수를 누적합니다.
        correct += (preds == labels).sum().item()

        # 전체 샘플 수를 누적합니다.
        total += batch_size

    # 전체 샘플 기준 평균 loss와 accuracy를 계산합니다.
    avg_loss = total_loss / total
    accuracy = correct / total

    return avg_loss, accuracy
```

`loss.item()`은 출력용 숫자다.

gradient 계산은 반드시 Tensor인 `loss`에 대해 `loss.backward()`로 수행해야 합니다.

## 9. validation 함수 작성

validation 함수는 모델 성능을 확인하는 함수

train 함수와 가장 큰 차이는 **parameter를 업데이트하지 않는다**

validation 흐름

```
model.eval()
-> torch.no_grad()
-> forward
-> loss 계산
-> accuracy 계산
```

```python
def validate(model, valid_loader, criterion, device):
    """
    validation dataset에 대한 평균 loss와 accuracy를 계산합니다.

    validation에서는 parameter를 업데이트하지 않습니다.
    따라서 backward와 optimizer.step을 사용하지 않습니다.
    """

    # 모델을 평가 모드로 바꿉니다.
    # Dropout은 꺼지고, BatchNorm은 저장된 running statistics를 사용합니다.
    model.eval()

    total_loss = 0.0
    correct = 0
    total = 0

    # validation에서는 gradient 계산이 필요 없습니다.
    # torch.no_grad()를 사용하면 불필요한 계산 그래프 생성을 막아 메모리를 줄일 수 있습니다.
    with torch.no_grad():
        for images, labels in valid_loader:
            images = images.to(device)
            labels = labels.to(device)

            # forward만 수행합니다.
            logits = model(images)

            # validation loss를 계산합니다.
            loss = criterion(logits, labels)

            batch_size = images.size(0)
            total_loss += loss.item() * batch_size

            preds = logits.argmax(dim=1)
            correct += (preds == labels).sum().item()
            total += batch_size

    avg_loss = total_loss / total
    accuracy = correct / total

    return avg_loss, accuracy
```

validation 함수 안에서는 아래 세 줄을 사용하지 않는다.

```python
optimizer.zero_grad()
loss.backward()
optimizer.step()
```

validation은 모델을 바꾸는 단계가 아니라, 현재 모델이 얼마나 잘하는지 확인하는 단계다.

## 10. epoch loop 실행

이제 train 함수와 validation 함수를 epoch 단위로 반복

```python
num_epochs = 3

# epoch별 metric을 기록할 dictionary입니다.
history = {
    "train_loss": [],
    "train_acc": [],
    "valid_loss": [],
    "valid_acc": []
}

for epoch in range(num_epochs):
    # 한 epoch 학습을 수행합니다.
    train_loss, train_acc = train_one_epoch(
        model=model,
        train_loader=train_loader,
        criterion=criterion,
        optimizer=optimizer,
        device=device
    )

    # validation 성능을 계산합니다.
    valid_loss, valid_acc = validate(
        model=model,
        valid_loader=valid_loader,
        criterion=criterion,
        device=device
    )

    # history에 epoch 결과를 저장합니다.
    history["train_loss"].append(train_loss)
    history["train_acc"].append(train_acc)
    history["valid_loss"].append(valid_loss)
    history["valid_acc"].append(valid_acc)

    # 현재 epoch 결과를 출력합니다.
    print(
        f"Epoch [{epoch + 1}/{num_epochs}] "
        f"train_loss={train_loss:.4f}, train_acc={train_acc:.4f}, "
        f"valid_loss={valid_loss:.4f}, valid_acc={valid_acc:.4f}"
    )
```

## 11. 자주 하는 실수

### 실수 1. `SmallCNN`을 정의하지 않고 학습 코드만 실행

### 실수 2. classifier 입력 크기를 잘못 계산

```python
# 잘못된 예시입니다.
# 실제 flatten 크기는 32 * 8 * 8인데, 다른 값을 넣으면 오류가 발생합니다.
self.classifier = nn.Linear(32 * 16 * 16, num_classes)
```

CNN의 마지막 feature map이 `(batch_size, 32, 8, 8)`이면 flatten 후 길이는 `32 * 8 * 8 = 2048`입니다.

그런데 classifier가 다른 입력 크기를 기대하면 `mat1 and mat2 shapes cannot be multiplied` 오류가 발생할 수 있다.


확인코드

```python
images, labels = next(iter(inspection_loader))
images = images.to(device)

with torch.no_grad():
    feature = model.features(images)
    flat = model.flatten(feature)

print("feature shape:", feature.shape)
print("flat shape:", flat.shape)
print("classifier in_features:", model.classifier.in_features)
```

### 실수 3. validation에서 `optimizer.step()` 호출

validation은 성능 확인 단계이므로 parameter를 바꾸면 안 된다.

validation에서 `optimizer.step()`을 호출하면 검증 데이터로 모델 parameter가 업데이트된다

그러면 validation이 더 이상 “공정한 성능 확인”이 아니게 되고, 데이터 누수와 비슷한 문제가 생길 수 있다.

validation에서는 아래 코드가 없어야 한다

```python
loss.backward()
optimizer.step()
```

### 실수 4. labels dtype이 float인 경우

`CrossEntropyLoss`에서 class index target은 `torch.long`이어야 한다.

```python
print(labels.dtype)  # torch.int64이면 정상입니다.
```

`nn.CrossEntropyLoss`는 정답을 one-hot vector가 아니라 class 번호로 받는 경우가 많다.

이때 label은 `0`, `1`, `2` 같은 정수 class index여야 한다

`labels`가 `float32`이면 loss 계산에서 dtype 오류가 발생할 수 있다.

수정

```python
labels = labels.long()
```

### 실수 5. validation에서 `torch.no_grad()`를 빼먹기

validation에서는 gradient가 필요 없다.

그런데 `torch.no_grad()`를 사용하지 않으면 PyTorch가 불필요하게 계산 그래프를 추적할 수 있다.

그 결과 메모리를 더 사용하고 검증 속도도 느려질 수 있다.

수정 코드

```python
model.eval()
with torch.no_grad():
    logits = model(images)
```
