## 1. 이번에 우리가 배울 것


모델 학습 전에 반드시 정리해야 하는 모델 클래스 구조를 다시 확인
```
DataLoader -> batch -> model(x) -> logits -> loss -> backward -> step
```

이 흐름에서 `model(x)` 부분을 담당하는 것이 `nn.Module` 기반 모델이다

`__init__`에서 layer를 준비하고, `forward`에서 입력 Tensor가 layer를 통과하는 순서를 작성

## 2. nn.Module

`nn.Module`을 사용하면 다음 장점이 있다.

| 기능 | 설명 |
| --- | --- |
| parameter 자동 추적 | `self.fc1`, `self.fc2`의 weight/bias를 자동으로 관리합니다. |
| `.to(device)` 사용 | 모델 전체를 CPU/GPU로 이동할 수 있습니다. |
| `train()` / `eval()` 사용 | 학습 모드와 평가 모드를 전환할 수 있습니다. |
| `state_dict()` 사용 | 9장에서 모델 저장/불러오기에 사용할 수 있습니다. |

8모델을 예측 함수로만 보지 말고, 학습 루프 안에서 업데이트되는 객체로 봐야 한다.<BR>
그래서 `nn.Module`, `optimizer`, `state_dict`가 자연스럽게 연결된다

## 3. `__init__`

`__init__`에는 모델이 사용할 layer를 정의

```python
import torch
import torch.nn as nn

class SimpleMLP(nn.Module):
    def __init__(self, input_dim=784, hidden_dim=128, num_classes=10):
        super().__init__()

        # 이미지 입력을 1차원 feature 벡터로 펼치는 layer입니다.
        self.flatten = nn.Flatten()

        # 첫 번째 선형층입니다.
        # input_dim개의 feature를 hidden_dim개의 feature로 바꿉니다.
        self.fc1 = nn.Linear(input_dim, hidden_dim)

        # 은닉층 뒤에 들어가는 활성화 함수입니다.
        self.relu = nn.ReLU()

        # 마지막 출력층입니다.
        # hidden_dim개의 feature를 num_classes개의 class 점수로 바꿉니다.
        self.fc2 = nn.Linear(hidden_dim, num_classes)
```
`__init__`은 실제 데이터를 계산하는 곳이 아니다

__init__은 모델에서 사용할 Flatten, Linear, ReLU 등의 layer를 생성하고 등록하는 공간이다


## 4. `forward`는 데이터 흐름이다

`forward`에는 입력 Tensor가 어떤 순서로 layer를 통과할지 작성한다

```python
class SimpleMLP(nn.Module):
    def __init__(self, input_dim=784, hidden_dim=128, num_classes=10):
        super().__init__()
        self.flatten = nn.Flatten()
        self.fc1 = nn.Linear(input_dim, hidden_dim)
        self.relu = nn.ReLU()
        self.fc2 = nn.Linear(hidden_dim, num_classes)

    def forward(self, x):
        # x shape: (batch_size, 1, 28, 28)
        x = self.flatten(x)

        # x shape: (batch_size, 784)
        x = self.fc1(x)

        # x shape: (batch_size, hidden_dim)
        x = self.relu(x)

        # logits shape: (batch_size, num_classes)
        logits = self.fc2(x)

        return logits
```

## 5. `model(x)`와 `forward(x)`의 관계

이 코드는 `nn.Module.__call__`을 거쳐 내부적으로 `forward(images)`를 호출한다.<br>
`__call__`은 hook과 학습/평가 모드 등 모듈 동작을 함께 처리하므로,<br>
일반적인 학습 코드에서는 `model.forward(images)`를 직접 호출하지 않고 `model(images)`를 사용한다

```python
images = torch.randn(8, 1, 28, 28)
model = SimpleMLP()

logits = model(images)

print("images shape:", images.shape)
print("logits shape:", logits.shape)
```

출력
```
images shape: torch.Size([8, 1, 28, 28])
logits shape: torch.Size([8, 10])
```

### hook
Hook은 모델의 코드를 직접 수정하지 않고도, 특정 layer의 실행 전후에 자동으로 호출되도록 걸어 두는 관찰·처리 함수다.

1. model.fc1이 계산을 수행
2. fc1의 출력이 만들어짐
3. 등록된 check_output()이 자동 실행
4. 출력 shape을 표시
5. 모델의 나머지 계산 진행

hook 흐름<br>
입력<br>
→ forward pre-hook<br>
→ layer의 forward 계산<br>
→ forward hook<br>
→ 출력<br>

forward pre-hook
→ forward 실행 직전에 자동 호출
→ 입력값 확인

forward hook
→ forward 실행 직후에 자동 호출
→ 출력값 확인

backward hook
→ 역전파할 때 자동 호출
→ gradient 확인


## 6. 더미 입력으로 forward 확인

학습을 시작하기 전에 더미 입력으로 forward를 한 번 확인하는 습관이 중요하다

```python
import torch

# 학습 데이터와 같은 shape의 더미 입력을 만듭니다.
dummy_images = torch.randn(4, 1, 28, 28)

# 모델을 생성합니다.
model = SimpleMLP(input_dim=784, hidden_dim=64, num_classes=10)

# forward를 실행합니다.
logits = model(dummy_images)

print("dummy_images:", dummy_images.shape)
print("logits      :", logits.shape)

# 기대한 출력 shape인지 확인합니다.
assert logits.shape == torch.Size([4, 10])
```

## 8. 자주 하는 실수

### 실수 1. `forward`에서 `return`을 빼먹기

```python
class WrongMLP(nn.Module):
    def __init__(self):
        super().__init__()
        self.fc = nn.Linear(4, 2)

    def forward(self, x):
        logits = self.fc(x)
        # return logits를 빼먹었습니다.
```

수정

```python
class CorrectMLP(nn.Module):
    def __init__(self):
        super().__init__()
        self.fc = nn.Linear(4, 2)

    def forward(self, x):
        logits = self.fc(x)
        return logits
```


### 실수 2. batch 차원을 제거하기

```
[읽기용 코드 조각]
# 잘못된 예시입니다.
# flatten 결과에서 batch 차원이 사라질 수 있습니다.

```

MLP 입력은 보통 `(batch_size, features)` 형태여야 한다

```

# 올바른 예시입니다.
```
