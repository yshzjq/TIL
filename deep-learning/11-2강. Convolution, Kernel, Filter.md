## 0. CNN(Convolutional Neural Network)

CNN(Convolutional Neural Network)은 이미지와 영상처럼 **공간적 구조를 가진 데이터**를 처리하는 데 널리 사용되는 신경망이다<br>
이미지를 처음부터 한 줄로 펼치지 않고, 작은 영역을 살펴보는 filter를 이미지 전체에 반복 적용하여 선, 경계, 질감 같은 지역 패턴을 찾는다.

CNN의 핵심 아이디어는 다음 두 가지

- **국소 연결(local connectivity)**: 한 번에 이미지 전체가 아니라 작은 영역을 살펴본다
- **가중치 공유(weight sharing)**: 같은 filter를 여러 위치에서 반복 사용하여, 비슷한 패턴을 같은 방식으로 찾는다

filter의 값은 사람이 직접 정하는 것이 아니라 학습 과정에서 역전파를 통해 조정된다

하나의 filter가 만든 결과를 feature map이라고 하며, <br>여러 filter를 사용하면 서로 다른 패턴에 반응하는 여러 feature map을 얻을 수 있다.

### CNN의 전체 흐름

```
입력 이미지
-> Convolution: 지역 패턴을 찾아 feature map 생성
-> ReLU: 비선형성 추가
-> Pooling: feature map의 공간 크기 축소
-> Conv/ReLU/Pooling 반복: 더 복잡한 특징 추출
-> Flatten: feature map을 벡터로 변환
-> Linear: class별 logits 출력
```

앞쪽 layer는 주로 선이나 질감처럼 단순한 특징에 반응하고, layer가 깊어질수록 이를 조합하여 형태나 객체의 일부처럼 더 복잡한 특징을 표현한다

그림은 `특징 추출(feature learning)`과 `분류(classification)`의 두 부분으로 나뉜다.<br> 

Convolution과 Pooling이 이미지의 특징을 추출하고, Flatten과 Linear layer가 추출된 특징을 class별 점수로 변환한다


```
이미지 Tensor 구조
-> Convolution, Kernel, Filter
-> Padding과 Stride
-> Pooling
-> Feature map shape
-> CNN classifier
```

지역 연결(local receptive field)과 가중치 공유는 시각 정보 처리 방식에서 아이디어를 얻었지만,<br> 사람의 시신경을 그대로 복제한 모델은 아니다. 이미지 분류, 객체 탐지, 자율주행 등 비전 분야에서 널리 활용된다

## 1. 이번에 배울것

Convolution은 이미지 위를 작은 창으로 훑으면서 특정 패턴이 있는지 계산하는 연산이다.<br>
이 작은 창을 보통 **kernel** 또는 **filter**라고 부른다.

```
kernel/filter = 이미지에서 찾고 싶은 작은 패턴 검사 도구
feature map = 그 패턴이 어디에서 강하게 나타났는지 표시한 결과
```

### 한 칸을 직접 계산해보기

입력의 한 영역과 kernel

```
입력 영역          kernel
1  2  0           1  0 -1
0  1  3           1  0 -1
2  2  1           1  0 -1
```

같은 위치의 값끼리 곱한 뒤 모두 더한다

```
(1×1)+(2×0)+(0×-1)
+(0×1)+(1×0)+(3×-1)
+(2×1)+(2×0)+(1×-1)
= 1+0+0+0+0-3+2+0-1
= -1
```

따라서 이 kernel이 현재 위치에서 만든 feature map의 한 칸은 -1입니다.<br>
실제 nn.Conv2d에는 여기에 bias가 더해질 수 있다

RGB 입력이라면 한 filter가 R, G, B 세 channel의 영역을 각각 계산한 뒤 모두 더해 출력 channel 한 칸을 만든다

PyTorch의 nn.Conv2d는 엄밀히는 kernel을 뒤집지 않는 cross-correlation을 계산하지만,<br> 딥러닝에서는 kernel 자체를 학습하므로 관례적으로 convolution이라고 부른다.

## 2. `nn.Conv2d`의 핵심 인자

PyTorch의 `nn.Conv2d`는 2D 이미지 feature map에 convolution을 적용하는 layer다. 

`stride`는 kernel이 이동하는 간격, `padding`은 입력 주변에 추가되는 padding 양을 제어합니다.

| 인자 | 의미 | 예시 |
| --- | --- | --- |
| `in_channels` | 입력 이미지 또는 feature map의 channel 수 | RGB 이미지면 3 |
| `out_channels` | 만들어낼 feature map 수 | 8, 16, 32 등 |
| `kernel_size` | filter의 공간 크기 | 3이면 3x3 |
| `padding` | 가장자리 주변에 추가할 값의 두께 | 1 |
| `stride` | kernel이 이동하는 간격 | 1 또는 2 |

## 3. Conv2d로 shape 확인하기

```python
import torch
import torch.nn as nn

# 입력 이미지 batch입니다.
# 4장의 RGB 이미지이고, 크기는 32x32입니다.
x = torch.randn(4, 3, 32, 32)

# Conv2d layer를 만듭니다.
# in_channels=3  : 입력이 RGB 이미지이므로 channel 수 3
# out_channels=8 : 서로 다른 filter 8개를 사용해 feature map 8개를 만듭니다.
# kernel_size=3  : 3x3 크기의 filter를 사용합니다.
# padding=1      : 가장자리에 1칸 padding을 추가해 H,W 크기를 유지하기 쉽게 합니다.
conv = nn.Conv2d(
    in_channels=3,
    out_channels=8,
    kernel_size=3,
    padding=1
)

# convolution을 적용합니다.
y = conv(x)

print("input shape :", x.shape)
print("output shape:", y.shape)
```

출력

```
input shape : torch.Size([4, 3, 32, 32])
output shape: torch.Size([4, 8, 32, 32])
```

여기서 batch size 4는 유지됩니다. 입력 channel 3은 출력 channel 8로 바뀐다

Conv2d는 보통 `(N, C, H, W)` 중에서 `C`, `H`, `W`를 바꿉니다. `N`, 즉 batch size는 그대로 유지된다

## 4. weight shape 확인하기

```python
print("weight shape:", conv.weight.shape)
print("bias shape  :", conv.bias.shape)
```

출력

```
weight shape: torch.Size([8, 3, 3, 3])
bias shape  : torch.Size([8])
```

Conv2d의 weight shape는 순서

```
(out_channels, in_channels, kernel_height, kernel_width)
```

즉, `nn.Conv2d(3, 8, kernel_size=3)`은 다음 parameter를 가진다.

```
weight shape = (8, 3, 3, 3)
bias shape   = (8,)
```

## 5. out_channels는 feature map 개수

`out_channels=8`은 filter가 8개라는 뜻이다<br>
 각 filter는 입력 이미지에서 다른 패턴을 찾으려고 학습

```python
for out_channels in [4, 8, 16]:
    conv = nn.Conv2d(3, out_channels, kernel_size=3, padding=1)
    y = conv(x)
    print(f"out_channels={out_channels:2d} -> output shape={y.shape}")
```

출력

```
out_channels= 4 -> output shape=torch.Size([4, 4, 32, 32])
out_channels= 8 -> output shape=torch.Size([4, 8, 32, 32])
out_channels=16 -> output shape=torch.Size([4, 16, 32, 32])
```

## 6. 자주 하는 실수

### 실수 1. `in_channels`를 잘못 넣기

```python
# 입력은 RGB 이미지이므로 channel 수가 3입니다.
x = torch.randn(4, 3, 32, 32)

# 잘못된 예시입니다. in_channels=1은 흑백 이미지를 기대합니다.
wrong_conv = nn.Conv2d(1, 8, kernel_size=3, padding=1)

try:
    y = wrong_conv(x)
except RuntimeError as e:
    print("오류 발생!")
    print(e)
```

수정

```python
correct_conv = nn.Conv2d(3, 8, kernel_size=3, padding=1)
y = correct_conv(x)
print(y.shape)
```

### 실수 2. `out_channels`를 class 수로 오해하기

CNN 중간 layer의 `out_channels`는 class 수가 아니다. 중간 feature map 수입니다. class 수는 보통 마지막 `nn.Linear`의 `out_features`에 들어갑니다.
