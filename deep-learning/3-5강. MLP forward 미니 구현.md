## 1. 이번에 우리가 배울 것

```plain
model = nn.Sequential(
    nn.Flatten(),
    nn.Linear(784, 128),
    nn.ReLU(),
    nn.Linear(128, 10)
)
```

이번 강에서는 같은 구조를 직접 클래스 형태로 작성

```plain
class SimpleMLP(nn.Module):
    ...
```

이 방식은 앞으로 학습 루프, 중간 출력 확인, 조건부 분기, 복잡한 모델 구조를 만들 때 훨씬 유용하다.

## 2. 왜 `nn.Module`을 사용하나요?

PyTorch에서 대부분의 모델과 layer는 `nn.Module`을 기반으로 만들어진다. `nn.Module`을 상속하면 다음 장점이 있다.

| 장점 | 설명 |
| --- | --- |
| parameter 자동 추적 | `self.fc1`, `self.fc2`에 들어 있는 weight/bias를 자동으로 관리한다 |
| `.to(device)` 사용 가능 | 모델 전체를 CPU/GPU로 이동할 수 있다 |
| `train()` / `eval()` 사용 가능 | 학습 모드와 평가 모드를 전환할 수 있다. |
| 구조 확장 가능 | Sequential보다 복잡한 forward 흐름을 직접 정의할 수 있다. |

PyTorch 모델을 직접 만들 때는 보통 nn.Module을 상속하고, __init__에 layer를 정의하고, forward에 데이터 흐름을 작성한다

## 3. `__init__`과 `forward` 역할

`nn.Module` 클래스에서 가장 중요한 부분은 두 가지

| 메서드 | 역할 |
| --- | --- |
| `__init__` | 모델에 필요한 layer를 미리 준비한다. |
| `forward` | 입력 Tensor가 layer를 어떤 순서로 통과할지 정의한다. |

```plain
__init__  : 부품 준비
forward   : 부품을 어떤 순서로 사용할지 정의
```

## 4. SimpleMLP 구현하기

아래 블록은 import와 클래스 정의를 포함한 **독립 실행 셀**입니다. 이후 `SimpleMLP`을 사용하는 짧은 셀은 \*\*[앞 셀 실행]\*\*을 전제로 한다

입력은 `(batch_size, 1, 28, 28)` 형태라고 가정합니다. 최종 출력은 class 10개에 대한 logits입니다.

```python
import torch
import torch.nn as nn

class SimpleMLP(nn.Module):
    """
    28x28 흑백 이미지를 입력으로 받아
    class별 logits를 출력하는 간단한 MLP 모델입니다.
    """

    def __init__(self, input_dim=1 * 28 * 28, hidden_dim=128, num_classes=10):
        """
        모델에 필요한 layer를 정의합니다.

        input_dim:
            flatten 이후 샘플 하나가 가지는 feature 수
            1x28x28 이미지는 784개 feature를 가집니다.

        hidden_dim:
            은닉층의 출력 feature 수
            이 값이 커질수록 모델 parameter 수가 늘어난다

        num_classes:
            분류할 class 수
            출력 logits의 마지막 차원이 된다.
        """
        super().__init__()

        # 이미지 입력을 (batch_size, features) 형태로 펼친다
        self.flatten = nn.Flatten()

        # 첫 번째 선형층
        # input_dim개의 feature를 hidden_dim개의 feature로 변환한다
        self.fc1 = nn.Linear(input_dim, hidden_dim)

        # 은닉층 뒤에 사용할 활성화 함수입니다.
        self.relu = nn.ReLU()

        # 마지막 출력층
        # hidden_dim개의 feature를 num_classes개의 logits로 변환한다
        self.fc2 = nn.Linear(hidden_dim, num_classes)

    def forward(self, x):
        """
        입력 Tensor x가 모델을 통과하는 순서를 정의합니다.
        """
        # x shape: (batch_size, 1, 28, 28)
        x = self.flatten(x)

        # x shape: (batch_size, 784)
        x = self.fc1(x)

        # x shape: (batch_size, hidden_dim)
        x = self.relu(x)

        # logits shape: (batch_size, num_classes)
        logits = self.fc2(x)

        return logits
```

SimpleMLP는 nn.Module을 상속받은 신경망 클래스,<br> 객체를 만들 때 __init__()이 실행되며 그 안에서 super().__init__()으로 부모의 PyTorch 기능을 초기화한다.<br> 이후 model(x)를 호출하면 정의해둔 forward()의 순서대로 계산된다.

## 5. forward shape 흐름 확인하기

모델을 만들었으면 가장 먼저 입력과 출력 shape를 확인해야 한다.

```python
import torch

# 샘플 8개, 흑백 28x28 이미지
images = torch.randn(8, 1, 28, 28)

model = SimpleMLP(input_dim=1 * 28 * 28, hidden_dim=128, num_classes=10)

logits = model(images)

print("images shape:", images.shape)
print("logits shape:", logits.shape)

assert logits.shape == torch.Size([8, 10])
```

출력은 다음과 같습니다.

```plain
images shape: torch.Size([8, 1, 28, 28])
logits shape: torch.Size([8, 10])
```

여기서 `model(images)`를 호출하면 `nn.Module`의 호출 로직이 hook과 여러 내부 처리를 거쳐 `forward(images)`를 실행<br>
`model.forward(images)`를 직접 호출하지 않고 `model(images)` 형태를 사용

## 6. 중간 shape를 출력하는 디버깅용 forward

초반에는 forward 중간 shape를 출력하는 방식이 도움이 된다

```python
import torch
import torch.nn as nn

class DebugMLP(nn.Module):
    """
    forward 과정에서 중간 shape를 출력하는 디버깅용 MLP입니다.
    """

    def __init__(self, input_dim=784, hidden_dim=128, num_classes=10):
        super().__init__()
        self.flatten = nn.Flatten()
        self.fc1 = nn.Linear(input_dim, hidden_dim)
        self.relu = nn.ReLU()
        self.fc2 = nn.Linear(hidden_dim, num_classes)

    def forward(self, x):
        print("input  :", x.shape)

        x = self.flatten(x)
        print("flatten:", x.shape)

        x = self.fc1(x)
        print("fc1    :", x.shape)

        x = self.relu(x)
        print("relu   :", x.shape)

        logits = self.fc2(x)
        print("fc2    :", logits.shape)

        return logits

images = torch.randn(8, 1, 28, 28)
model = DebugMLP()
logits = model(images)
```

출력

```plain
input  : torch.Size([8, 1, 28, 28])
flatten: torch.Size([8, 784])
fc1    : torch.Size([8, 128])
relu   : torch.Size([8, 128])
fc2    : torch.Size([8, 10])
```

`hidden_dim`을 바꾸어도 마지막 출력 class 수가 5개라면 logits shape는 `(batch_size, 5)`입니다.

## 8. parameter 수와 출력 shape 검증

모델을 만들면 parameter 수와 입출력 shape를 함께 확인하는 함수를 만들어두면 좋다.

```python
import torch

def count_parameters(model):
    """
    학습 가능한 parameter 수를 계산합니다.
    """
    
    # 모델이 가지고 있는 **모든 parameter(weight, bias)**를 하나씩 가져옵니다.
    # p.requires_grad는 해당 parameter가 gradient(기울기)를 계산할 대상인지 확인하는 값
    # numel()은 Tensor 안에 들어있는 숫자의 총개수를 반환합니다.
    return sum(p.numel() for p in model.parameters() if p.requires_grad)

def check_model_output(model, x, expected_shape):
    """
    모델 출력 shape가 기대한 shape와 같은지 확인합니다.
    """
    logits = model(x)

    print("input shape :", x.shape)
    print("output shape:", logits.shape)
    print("parameters  :", count_parameters(model))

    assert logits.shape == expected_shape, (
        f"출력 shape가 다릅니다. expected={expected_shape}, actual={logits.shape}"
    )

    return logits

images = torch.randn(8, 1, 28, 28)
model = SimpleMLP(input_dim=784, hidden_dim=64, num_classes=10)

logits = check_model_output(
    model=model,
    x=images,
    expected_shape=torch.Size([8, 10])
)

```

출력

```plain
input shape : torch.Size([8, 1, 28, 28])
output shape: torch.Size([8, 10])
parameters  : 50890
```

## 9. 실전 디버깅 패턴

### 깨진 코드

```python
import torch
import torch.nn as nn

images = torch.randn(8, 1, 28, 28)

# 잘못된 모델입니다.
# flatten 후 feature 수는 784인데 input_dim을 28로 넣었습니다.
model = SimpleMLP(input_dim=28, hidden_dim=64, num_classes=10)

try:
    logits = model(images)
except RuntimeError as e:
    print("오류 발생!")
    print(e)
```

### 확인 코드

```python
flat = torch.flatten(images, start_dim=1)

print("images shape:", images.shape)
print("flat shape  :", flat.shape)
print("flat feature:", flat.shape[-1])
print("model fc1 in_features:", model.fc1.in_features)
```

### 수정 코드

```python
model = SimpleMLP(input_dim=1 * 28 * 28, hidden_dim=64, num_classes=10)
logits = model(images)

print(logits.shape)
```
