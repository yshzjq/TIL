## 2. 손실 함수 선택은 출력층 설계와 한 세트입니다

### 2-1. 네 가지 질문을 순서대로 답합니다

```
1. 무엇을 예측하나요?
2. 샘플 하나당 정답은 몇 개인가요?
3. 모델은 샘플 하나당 몇 개의 값을 출력해야 하나요?
4. target은 어떤 shape와 dtype으로 표현하나요?
```

이 네 질문에 답하면 loss가 자연스럽게 정해진다.

| 문제 예시 | 샘플당 정답 | 출력 | 대표 loss |
| --- | --- | --- | --- |
| 집값 예측 | 실수값 1개 | 실수 1개 | MSELoss |
| 스팸 여부 | 0/1 하나 | logit 1개 | BCEWithLogitsLoss |
| 문서 종류 5개 중 하나 | class index 1개 | logits 5개 | CrossEntropyLoss |
| 금융·긴급·개인정보 label | label 여러 개 가능 | label별 logit | BCEWithLogitsLoss |


### 2-2. 출력층과 target은 서로 같은 정보를 다른 방식으로 표현합니다

다중 분류에서 모델은 모든 후보 class의 점수 `C`개를 출력하지만 target은 정답 후보 하나의 index만 저장합니다.

```
모델 출력: [class 0 점수, class 1 점수, ..., class C-1 점수]
target: 정답 위치 하나
```

이진 분류에서는 class 1의 확률이 정해지면 class 0의 확률은 1 - class 1의 확률로 자동 결정됩니다.<br> 따라서 모델은 보통 class 1에 대한 logit 하나만 출력하며, logit이 클수록 class 1, 작을수록 class 0으로 판단한다

문제 정의 -> 출력 의미와 shape -> target 표현 -> loss 순서로 결정하세요.

---

아래 표를 먼저 기억하세요.

| 문제 유형 | 모델 출력 | target | 대표 loss |
| --- | --- | --- | --- |
| 회귀 | 실수값 | 실수값 `float` | `nn.MSELoss()` |
| 이진 분류 | logit 1개 | 0/1 `float` | `nn.BCEWithLogitsLoss()` |
| 다중 분류 | class별 logits | class index `long` | `nn.CrossEntropyLoss()` |

loss 함수만 바꾸면 되는 것이 아니라. 출력층의 마지막 차원, target의 shape, target dtype도 함께 맞아야 한다

## 3. 회귀 문제: `MSELoss`

회귀는 연속적인 숫자를 예측하는 문제이다

예시

| 문제 | 예측값 |
| --- | --- |
| 집값 예측 | 3.5억 |
| 수요량 예측 | 1200개 |
| 온도 예측 | 23.4도 |

회귀에서는 모델 출력과 target이 보통 같은 shape를 가진다

```python
import torch
import torch.nn as nn

# 샘플 4개, feature 3개입니다.
x = torch.randn(4, 3)

# 회귀 모델은 샘플마다 실수값 1개를 예측합니다.
model = nn.Linear(3, 1)

# target도 실수값입니다.
target = torch.tensor([[2.5], [3.0], [1.2], [4.1]], dtype=torch.float32)

pred = model(x)
criterion = nn.MSELoss()
loss = criterion(pred, target)

print("pred shape  :", pred.shape)
print("target shape:", target.shape)
print("loss:", loss)
```

출력

```
pred shape  : torch.Size([4, 1])
target shape: torch.Size([4, 1])
```

## 4. 이진 분류 문제: `BCEWithLogitsLoss`

**BCE는 각 출력 원소를 독립적인 0/1 질문으로 본다**

예를 들어 샘플 하나의 logit이 `2.0`, target이 `1.0`이라면 “이 샘플이 class 1인가?”라는 하나의 질문입니다.

```
logit 1개 -> Sigmoid로 class 1 방향 점수
0/1 float target -> 그 질문의 정답
```

### 4-1. 왜 target이 float인가요?

BCE는 target을 수식에 직접 넣어 계산하므로, target을 0.0과 1.0 같은 실수 Tensor로 입력해야 한다

```
0.0 -> 음성 class
1.0 -> 양성 class
0~1 사이 값 -> soft target도 표현 가능
```

### 4-2. 이진 분류와 다중 레이블은 같은 loss를 쓸 수 있습니다

다중 레이블은 label마다 독립적인 이진 질문을 여러 개 동시에 수행한다

```
출력 (B, L): label L개에 대한 logits
target (B, L): 각 label의 0/1 float
loss: BCEWithLogitsLoss
```
예를 들어 문서 한 개에 금융, 개인정보, 긴급 label이 동시에 참일 수 있으므로 class끼리 하나만 선택하는 Softmax 경쟁이 아니다

### 4-3. `pos_weight`는 언제 등장하나요?

양성 샘플이 매우 적은 불균형 문제에서는 양성 오류의 가중치를 높이는 `pos_weight`를 사용할 수 있다<br>
다만 먼저 데이터 분포와 metric을 확인하고 적용해야 하며, 기본 구조는 변하지 않는다

이진 분류는 class가 두 개인 문제입니다. 모델은 보통 샘플마다 logit 1개를 출력합니다.

```python
import torch
import torch.nn as nn

x = torch.randn(4, 3)

# 이진 분류 모델: logit 1개 출력
model = nn.Linear(3, 1)

# target은 0 또는 1이고 float dtype을 사용합니다.
target = torch.tensor([[0.0], [1.0], [0.0], [1.0]], dtype=torch.float32)

logits = model(x)
criterion = nn.BCEWithLogitsLoss()
loss = criterion(logits, target)

print("logits shape:", logits.shape)
print("target shape:", target.shape)
print("target dtype:", target.dtype)
print("loss:", loss)
```

`BCEWithLogitsLoss`를 사용할 때는 모델 마지막에 `Sigmoid`를 넣지 않는다. 예측을 해석할 때만 `torch.sigmoid(logits)`를 사용한다

## 5. 다중 분류 문제: `CrossEntropyLoss`

CrossEntropyLoss의 target 숫자는 수치 크기가 아니라 정답 위치다.

### 5-1. class index를 주소처럼 읽으세요

```
logits = [0.2, 1.7, -0.4, 0.9]
target = 1
```

여기서 target `1`은 두 번째 위치가 정답이라는 뜻이다. 숫자 1을 예측하는 회귀 문제가 아니다

`CrossEntropyLoss`는 target index를 사용해 정답 class의 log probability를 선택하므로 `torch.long`을 사용한다

### 5-2. class가 두 개여도 CrossEntropyLoss를 사용할 수 있나요?

가능, 이 경우 모델은 `(B, 2)` logits를 출력하고 target은 `(B,)` long입니다.

```
이진 분류 기본 패턴 A: (B, 1) + BCEWithLogitsLoss

데이터 4개 → 출력 shape (4, 1)

logits = [
    [-2.1],  # class 0 쪽
    [ 1.5],  # class 1 쪽
    [ 0.7],  # class 1 쪽
    [-0.4]   # class 0 쪽
]

이진 분류 대안 패턴 B: (B, 2) + CrossEntropyLoss

데이터 4개 → 출력 shape (4, 2)

logits = [
    [ 2.1, -1.0],  # class 0 점수가 큼
    [-0.5,  1.8],  # class 1 점수가 큼
    [ 0.2,  0.9],  # class 1 점수가 큼
    [ 1.2, -0.3]   # class 0 점수가 큼
]
```

두 설계를 섞으면 안 된다. 초반에는 logit 하나와 BCE 패턴을 기본으로 사용

### 5-3. one-hot target을 왜 기본으로 쓰지 않는지

class index 하나면 정답 위치를 충분히 표현할 수 있고 메모리와 코드가 단순하다<br>
soft label이나 label smoothing을 의도하지 않는다면 `(B,)` long target이 기본입니다.


One-hot target: 모든 class 자리를 만들고 정답만 1로 표시 → (B, C)

Soft label은 정답을 하나로 확정하지 않고, 각 class일 가능성을 확률처럼 나누어 표현하는 방법

Label smoothing은 확실한 정답인 1을 조금 낮추고, 나머지 class에도 아주 작은 값을 나누어 주는 방법

다중 분류는 class가 3개 이상이고, 각 샘플이 하나의 class에 속하는 문제입니다.

```python
import torch
import torch.nn as nn

x = torch.randn(4, 3)

# 다중 분류 모델: class 5개에 대한 logits 출력
model = nn.Linear(3, 5)

# target은 one-hot이 아니라 class index입니다.
target = torch.tensor([0, 2, 4, 1], dtype=torch.long)

logits = model(x)
criterion = nn.CrossEntropyLoss()
loss = criterion(logits, target)

print("logits shape:", logits.shape)
print("target shape:", target.shape)
print("target dtype:", target.dtype)
print("loss:", loss)
```

출력

```
logits shape: torch.Size([4, 5])
target shape: torch.Size([4])
target dtype: torch.int64
```

`CrossEntropyLoss`의 target은 보통 `(batch_size,)` shape의 class index이고, dtype은 `torch.long`이다

## 6. 손실 함수 선택 체크리스트


다음 결정 트리를 순서대로 따라가면 대부분의 기본 문제를 분류할 수 있다.


```
예측값이 연속적인 숫자인가?
├─ 예 -> 회귀 -> MSELoss 등
└─ 아니오
   └─ 샘플 하나에 정답 label이 여러 개 동시에 붙을 수 있는가?
      ├─ 예 -> 다중 레이블 -> BCEWithLogitsLoss
      └─ 아니오
         └─ class가 두 개인가?
            ├─ 예 -> logit 1개 + BCEWithLogitsLoss
            └─ 아니오 -> class별 logits + CrossEntropyLoss
```

손실 함수 선택 체크리스트

1. 예측하려는 값이 연속적인 숫자인가요?
    - 예: 집값, 온도, 점수
    - 출력: `(batch_size, 1)` 또는 필요한 회귀 차원
    - target: `float`
    - loss: `MSELoss`
2. class가 두 개이고, 샘플마다 0/1을 예측하나요?
    - 예: 스팸/정상, 포함/미포함
    - 출력: `(batch_size, 1)` logits
    - target: `(batch_size, 1)` float
    - loss: `BCEWithLogitsLoss`
3. 여러 class 중 샘플마다 하나의 class를 고르나요?
    - 예: 문서 카테고리 5개 중 하나
    - 출력: `(batch_size, num_classes)` logits
    - target: `(batch_size,)` long
    - loss: `CrossEntropyLoss`
4. 한 샘플에 여러 label이 동시에 참일 수 있나요?
    - 예: 문서에 ‘금융’, ‘개인정보’, ‘긴급’ label이 동시에 붙음
    - 출력: `(batch_size, num_labels)` logits
    - target: 같은 shape의 0/1 float
    - loss: `BCEWithLogitsLoss`
