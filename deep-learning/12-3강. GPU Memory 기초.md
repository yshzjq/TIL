## 1. 이번에 배울것

CNN은 MLP보다 중간 feature map이 많이 생긴다. <br>
그래서 GPU memory 사용량을 더 신경 써야 한다.

GPU Memory 흐름

GPU memory를 차지하는 대표 요소

- 입력 batch
- 모델 parameter
- forward 중간 activation
- gradient
- optimizer state

## 2. GPU 사용 가능 여부 확인

```python
import torch

device = torch.device("cuda" if torch.cuda.is_available() else "cpu")
print("device:", device)
```

## 3-1. 기준 CNN 모델 만들기

```python
import torch
import torch.nn as nn

class SmallCNN(nn.Module):
    """
    작은 CNN baseline입니다.
    입력:  (N, 3, 32, 32)
    출력:  (N, num_classes)
    """
    def __init__(self, num_classes=10):
        super().__init__()

        self.features = nn.Sequential(
            # 첫 번째 block: RGB 3채널을 16채널 feature map으로 변환합니다.
            nn.Conv2d(3, 16, kernel_size=3, padding=1),
            nn.ReLU(),
            nn.MaxPool2d(2),  # 32x32 -> 16x16

            # 두 번째 block: 16채널을 32채널 feature map으로 변환합니다.
            nn.Conv2d(16, 32, kernel_size=3, padding=1),
            nn.ReLU(),
            nn.MaxPool2d(2),  # 16x16 -> 8x8
        )

        self.flatten = nn.Flatten()
        self.classifier = nn.Linear(32 * 8 * 8, num_classes)

    def forward(self, x):
        x = self.features(x)
        x = self.flatten(x)
        logits = self.classifier(x)
        return logits
``` 

## 3-2. 모델과 batch를 GPU로 이동

```python
model = SmallCNN(num_classes=10).to(device)

images = torch.randn(64, 3, 32, 32).to(device)
labels = torch.randint(0, 10, size=(64,)).to(device)

logits = model(images)
print(logits.shape)
print(logits.device)
```
모델과 입력 Tensor는 같은 device에 있어야 한다.


## 4. GPU memory 확인

기초 단계에서는 상세한 메모리 수치보다 **모델과 입력이 같은 device에 있는지**, 입력 shape와 batch size가 의도한 값인지 먼저 확인

```python
print("model device :", next(model.parameters()).device)
print("images device:", images.device)
print("images shape :", images.shape)
assert next(model.parameters()).device == images.device
```

## 5. batch size가 memory에 미치는 영향

batch size가 커지면 한 번에 보관하는 입력과 중간 feature map이 늘어난다 <br>
CUDA OOM이 나면 먼저 batch size를 64→32→16처럼 줄이고, 한 번의 forward·backward·optimizer step이 끝까지 되는지 확인

CUDA OOM = GPU에 올려야 할 모델, 데이터, 중간 계산값이 GPU 메모리 용량을 초과한 상태

같은 batch size라도 모델 구조, 입력 크기, dtype에 따라 필요한 메모리는 다르다.<br>
따라서 “최대 batch size”를 일반 규칙처럼 외우지 않습니다.

## 6. `torch.cuda.empty_cache()`으론는 보통 해결되지 않는다

`empty_cache()`는 사용 중인 Tensor를 지우지 않는다.<br> 
먼저 불필요한 Tensor 참조를 없애고, validation/inference에서는 `torch.no_grad()`를 사용하며,<br> 
batch size를 줄이는 것이 기본 대응이다
