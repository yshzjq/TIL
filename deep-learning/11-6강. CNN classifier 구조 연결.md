## 1. 이번에 배울것

CNN classifier는 보통 두 부분으로 나눌 수 있다.

| 부분 | 역할 |
| --- | --- |
| feature extractor | 이미지에서 공간적 특징을 추출한다 |
| classifier | 추출된 특징을 class별 logits로 변환한다 |


## 2. CNN classifier 코드 구조

```python
import torch
import torch.nn as nn

class SimpleCNN(nn.Module):
    """
    CIFAR-10처럼 3x32x32 이미지를 입력으로 받아
    class별 logits를 출력하는 간단한 CNN 모델입니다.
    """
    def __init__(self, num_classes=10):
        super().__init__()

        # feature extractor는 이미지의 공간적 패턴을 feature map으로 바꿉니다.
        self.features = nn.Sequential(
            # 입력: (N, 3, 32, 32)
            nn.Conv2d(3, 16, kernel_size=3, padding=1),
            nn.ReLU(),
            nn.MaxPool2d(2),  # (N, 16, 16, 16)

            nn.Conv2d(16, 32, kernel_size=3, padding=1),
            nn.ReLU(),
            nn.MaxPool2d(2),  # (N, 32, 8, 8)
        )

        # feature map을 한 줄 feature로 펼칩니다.
        self.flatten = nn.Flatten()

        # classifier는 펼쳐진 feature를 class별 logits로 바꿉니다.
        # 마지막 feature map이 (32, 8, 8)이므로 flatten_dim은 32*8*8입니다.
        self.classifier = nn.Linear(32 * 8 * 8, num_classes)

    def forward(self, x):
        # x shape: (batch_size, 3, 32, 32)
        x = self.features(x)

        # x shape: (batch_size, 32, 8, 8)
        x = self.flatten(x)

        # logits shape: (batch_size, num_classes)
        logits = self.classifier(x)
        return logits
```

## 3. 더미 입력으로 출력 shape 확인하기

```python
import torch

model = SimpleCNN(num_classes=10)

# CIFAR-10과 같은 입력 shape입니다.
images = torch.randn(8, 3, 32, 32)

# forward를 실행합니다.
logits = model(images)

print("images shape:", images.shape)
print("logits shape:", logits.shape)
assert logits.shape == (images.size(0), 10)
```

출력

```
images shape: torch.Size([8, 3, 32, 32])
logits shape: torch.Size([8, 10])
```

분류 모델의 최종 출력은 보통 `(batch_size, num_classes)` 형태의 logits다.<br>
`CrossEntropyLoss`를 사용할 때는 여기에 softmax를 미리 적용하지 않는다

## 4. classifier 입력 크기를 자동으로 계산하는 버전

직접 `32 * 8 * 8`을 쓰면 구조 변경 시 오류가 날 수 있다<br>
다음처럼 더미 입력으로 flatten_dim을 계산할 수 있다.

```python
import torch
import torch.nn as nn

class SaferCNN(nn.Module):
    def __init__(self, num_classes=10, input_shape=(3, 32, 32)):
        super().__init__()

        self.features = nn.Sequential(
            nn.Conv2d(input_shape[0], 16, kernel_size=3, padding=1),
            nn.ReLU(),
            nn.MaxPool2d(2),
            nn.Conv2d(16, 32, kernel_size=3, padding=1),
            nn.ReLU(),
            nn.MaxPool2d(2),
        )
        self.flatten = nn.Flatten()

        # 현재 features에는 BatchNorm/Dropout이 없지만,
        # 일반적인 shape 확인 패턴에 맞춰 상태를 복원합니다.
        original_training = self.features.training
        self.features.eval()
        parameter = next(self.features.parameters())
        dummy = torch.zeros(
            1, *input_shape,
            device=parameter.device,
            dtype=parameter.dtype
        )
        with torch.no_grad():
            dummy_out = self.features(dummy)
            flatten_dim = self.flatten(dummy_out).shape[1]
        self.features.train(original_training)

        self.classifier = nn.Linear(flatten_dim, num_classes)

    def forward(self, x):
        x = self.features(x)
        x = self.flatten(x)
        return self.classifier(x)
```

```
입력
(1, 3, 32, 32)

Conv2d(3 -> 16, kernel=3, padding=1)
(1, 16, 32, 32)

MaxPool2d(2)
(1, 16, 16, 16)

Conv2d(16 -> 32, kernel=3, padding=1)
(1, 32, 16, 16)

MaxPool2d(2)
(1, 32, 8, 8)

Flatten
(1, 2048)

Linear(2048 -> 10)
(1, 10)
```

## 5. 자주 하는 실수

### 실수 1. 마지막 Linear의 in_features를 잘못 넣기

```python
# 잘못된 예시
# 실제 flatten_dim은 2048인데 1024를 넣음
wrong_classifier = nn.Linear(1024, 10)
```

해결 방법은 feature map shape를 먼저 확인하는 것입니다.

```python
dummy = torch.randn(1, 3, 32, 32)
with torch.no_grad():
    out = model.features(dummy)
print(out.shape)
print(torch.flatten(out, start_dim=1).shape)
```
