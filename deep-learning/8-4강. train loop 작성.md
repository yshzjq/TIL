## 1. 이번에 배울것

이번 강에서는 `DataLoader`에서 batch를 꺼내 모델을 학습시키는 train loop를 작성합니다.

train loop는 다음 일을 반복합니다.

```
batch 가져오기 -> device 이동 -> forward -> loss 계산 -> backward -> step -> loss 누적
```

## 2. train loop의 목적

train loop의 목적은 모델 parameter를 업데이트하는 것이다

```
optimizer.zero_grad()
loss.backward()
optimizer.step()
```

- `zero_grad()`는 현재 batch를 학습하기 전에, 직전에 처리했던 batch에서 parameter의 .grad에 남아 있는 gradient를 초기화한다.
- `backward()`는 현재 batch에서 계산된 loss를 각 parameter(weight, bias)에 대해 미분하고, 그 gradient를 각 parameter의 .grad에 저장한다
- `step()`은 계산된 gradient를 사용해 parameter를 업데이트합니다.
- `.grad` 예측값과 정답으로 계산한 loss를 각 parameter에 대해 편미분한 값

PyTorch recipe에서도 `.backward()`를 호출하면 gradient가 누적되므로, 학습 loop에서 gradient를 초기화하는 것이 중요하다

## 3. 실습용 데이터셋 준비

```python
import torch
from torch.utils.data import TensorDataset, DataLoader

# 샘플 256개, 흑백 28x28 이미지라고 가정합니다.
X = torch.randn(256, 1, 28, 28)

# 0~9 사이 class label입니다.
y = torch.randint(0, 10, (256,), dtype=torch.long)

train_dataset = TensorDataset(X, y)
train_loader = DataLoader(train_dataset, batch_size=32, shuffle=True)
```

## 4. 한 epoch 학습 함수 만들기

```python
def train_one_epoch(model, train_loader, criterion, optimizer, device):
    """
    train_loader 전체를 한 번 순회하며 모델을 학습합니다.
    """
    # 모델을 학습 모드로 전환합니다.
    model.train()

    # epoch 전체 loss를 누적할 변수입니다.
    total_loss = 0.0

    # 전체 샘플 수를 누적합니다.
    total_samples = 0

    for inputs, labels in train_loader:
        # 입력과 정답을 같은 device로 이동합니다.
        inputs = inputs.to(device)
        labels = labels.to(device)

        # 이전 batch에서 계산된 gradient를 초기화합니다.
        # 0이 아닌 none 으로 초기화
        # 0을 써 넣는 작업을 하지 않아도 되서 메모리를 덜 쓴다!!
        optimizer.zero_grad(set_to_none=True)

        # forward: 모델 예측값을 계산합니다.
        logits = model(inputs)

        # loss 계산: logits와 labels를 비교합니다.
        loss = criterion(logits, labels)

        # backward: loss 기준으로 gradient를 계산합니다.
        loss.backward()

        # step: gradient를 사용해 parameter를 업데이트합니다.
        optimizer.step()

        # batch loss에 batch size를 곱해 누적합니다.
        batch_size = inputs.size(0)
        total_loss += loss.item() * batch_size
        total_samples += batch_size

    # 비어 있는 loader라면 0으로 나누지 않도록 즉시 알립니다.
    if total_samples == 0:
        raise ValueError("train_loader가 비어 있습니다.")

    # 전체 샘플 기준 평균 loss를 반환합니다.
    avg_loss = total_loss / total_samples
    return avg_loss
```

## 5. loss 평균 계산하기

batch별 loss를 단순 평균하면 마지막 batch 크기가 다를 때 약간 부정확할 수 있다.<br> 
아래 방식은 criterion의 기본값인 `reduction="mean"`처럼 batch 평균 loss를 반환할 때, batch size를 곱해 합으로 되돌린 뒤 전체 샘플 수로 나누는 계산

```
total_loss += loss.item() * batch_size
total_samples += batch_size
avg_loss = total_loss / total_samples
```

loss 총합 / loss 총 개수

`loss.item()`은 scalar Tensor를 Python 숫자로 꺼내는 코드<br> 
loss는 학습용, loss.item()은 기록·출력용


항상 loss.item() × batch_size를 하면 정확한 전체 평균이 되는 것은 아니다.

왜냐하면 어떤 loss는 batch 안의 모든 데이터 개수로 평균을 내는 게 아니라, 실제로 loss 계산에 참여한 원소 개수나 가중치 합으로 평균을 내기 때문

loss 함수가 실제로 평균을 낸 기준에 맞춰 분자와 분모를 따로 누적해야 한다

일반적인 경우
loss = loss 합 / 샘플 수
→ 샘플 수를 기준으로 누적

ignore_index / mask
loss = 유효 loss 합 / 유효 원소 수
→ 유효 원소 수를 기준으로 누적

class weight
loss = 가중 loss 합 / 가중치 합
→ 가중치 합을 기준으로 누적

그래서 loss × batch_size는 "loss가 정말 batch의 샘플 수로 평균된 경우"에만 딱 맞는 방법

평균 loss를 전체 데이터 기준으로 정확히 합치려면, 그 loss가 무엇을 분모로 평균했는지를 알아야 한다.

## 6. device를 포함한 train loop 실행

```python
import torch
import torch.nn as nn
import torch.optim as optim

# device 선택
device = torch.device("cuda" if torch.cuda.is_available() else "cpu")

# 모델, loss, optimizer 준비
model = nn.Sequential(
    nn.Flatten(),
    nn.Linear(784, 64),
    nn.ReLU(),
    nn.Linear(64, 10),
).to(device)
criterion = nn.CrossEntropyLoss()
optimizer = optim.Adam(model.parameters(), lr=0.001)

# 한 epoch 학습
train_loss = train_one_epoch(model, train_loader, criterion, optimizer, device)

print("train_loss:", train_loss)
```

## 7. 자주 하는 실수

### 실수 1. `optimizer.zero_grad()`를 빼먹기

### 실수 2. labels를 device로 이동하는 것을 빼먹기

### 실수 3. `loss.item()`으로 backward 하기

```
# 잘못된 예시입니다.
loss.item().backward()
```

`loss.item()`은 Python 숫자이므로 backward를 할 수 없습니다.
