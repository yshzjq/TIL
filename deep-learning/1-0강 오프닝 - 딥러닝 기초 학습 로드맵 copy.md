# 1. 이번에 우리가 배울 것

데이터를 준비하고, 모델을 만들고, 학습시키고, 검증하고, 저장하고, 다시 추론하는 전체 흐름을 직접 이해하는 것아 중요하다
 
딥러닝 학습은 보통 아래 흐름으로 진행됩니다.

```
문제 정의
-> 데이터 준비
-> 입력과 정답 구성
-> 모델 설계
-> 손실 함수 선택
-> 옵티마이저 선택
-> 학습 loop 실행
-> 검증 loop 실행
-> 성능 기록
-> 모델 저장
-> 추론
```

딥러닝 코드는 길어 보이지만, 대부분은 같은 구조를 반복합니다.

앞으로의 핵심은 코드를 외우는 것이 아니라 **데이터 -> 모델 -> 손실 -> 최적화 -> 평가** 흐름을 읽는 힘을 기른다.

---

## 2. 규칙 기반, 머신러닝, 딥러닝 접근 비교

큰 범위에서 보면 AI 안에 머신러닝이 있고, 머신러닝 안에 딥러닝이 있다

<img src="{{ '/assets/images/uploads/deep-learning/AI, 머신러닝, 딥러닝의 관계.png' | relative_url }}" alt="AI, 머신러닝, 딥러닝의 관계" loading="lazy">

이미지에서 볼 수 있듯이 딥러닝은 머신러닝의 한 방법이다

딥러닝은 기존 머신러닝보다 복잡한 데이터에서 표현을 직접 학습하는 능력이 강하기 때문에 이미지, 텍스트, 음성, 시계열 같은 문제에서 널리 사용된다

LLM도 결국 딥러닝 모델이다. 
Transformer, BERT, GPT, Fine-tuning, LoRA, RAG 평가 모델 같은 내용을 이해하려면 먼저 아래 질문에 답할 수 있어야 합니다.

```
모델은 어떻게 입력을 받아 예측값을 만드나요?
예측값이 틀렸다는 것을 어떻게 숫자로 표현하나요?
손실이 작아지는 방향으로 파라미터는 어떻게 바뀌나요?
학습 데이터와 검증 데이터는 왜 나누나요?
모델 저장, 실험 기록, 재현성은 왜 중요할까요?
```

💬 **튜터 한마디**

LLM을 다룰 때도 “모델이 답을 생성한다”는 결과만 보면 디버깅이 어렵습니다. 반대로 딥러닝 학습 흐름을 알고 있으면 Fine-tuning, 평가, 서빙 파이프라인을 훨씬 빠르게 이해할 수 있다.

### 2-1. 규칙 기반 접근


```python
text = "상품을 반품하고 환불받고 싶어요."

if "환불" in text or "반품" in text:
    label = "환불 문의"
else:
    label = "기타 문의"

print(label)
```

출력은 다음과 같습니다.

```
환불 문의
```

문장에 `환불`과 `반품`이 모두 들어 있지만 `or` 조건은 하나만 참이어도 전체가 참이므로 `환불 문의`가 출력된다.

규칙 기반 접근은 사람이 직접 조건을 작성.

장점은 단순하고 빠르지만 표현이 조금만 바뀌면 놓치기 쉽습니다.


### 2-2. 머신러닝 접근

머신러닝에서는 사람이 특징을 설계합니다.

| 특징 | 예시 |
| --- | --- |
| 특정 단어 포함 여부 | 환불, 취소, 반품 포함 여부 |
| 문장 길이 | 글자 수, 단어 수 |
| 문의 카테고리 | 배송, 결제, 상품, 계정 |
| 이전 문의 횟수 | 고객의 과거 문의 수 |

모델은 이 특징들을 보고 분류 규칙을 학습


### 2-3. 딥러닝 접근

딥러닝에서는 모델이 데이터 안에서 유용한 특징 표현을 스스로 학습합니다.

```
입력 데이터
-> 신경망 모델
-> 내부 표현 학습
-> 예측 결과
```

텍스트 분류를 예로 들면, 딥러닝 모델은 단어 하나만 보는 것이 아니라 문장 전체의 패턴, 단어 순서, 문맥을 활용할 수 있습니다.


최종적으로는 아래 흐름을 설명하고 구현할 수 있어야 합니다.

```
데이터 로딩
-> Dataset / DataLoader 구성
-> 모델 정의
-> loss_fn / optimizer 설정
-> train loop 작성
-> validation loop 작성
-> metric 기록
-> checkpoint 저장
-> inference 실행
-> 실험 결과 리포트 작성
```
