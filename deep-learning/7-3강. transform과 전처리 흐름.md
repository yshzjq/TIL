## 1. 이번에 배울것

실제 데이터는 모델이 바로 학습하기 좋은 형태로 준비되어 있지 않은 경우가 많다

예를 들어 이미지는 파일로 저장되어 있고, 크기도 제각각일 수 있다.<br>
픽셀 값의 범위도 모델 학습에 맞게 조정해야 할 수 있다.

이런 전처리 과정을 PyTorch에서는 보통 **transform**으로 구성한다

```
원본 데이터 -> transform -> 모델 입력 Tensor
```

TorchVision의 transform은 이미지나 Tensor에 적용하는 전처리/증강 도구다<br> 
여러 transform을 `Compose`로 연결해 파이프라인처럼 사용할 수 있습니다.

## 2. transform이란 무엇인가요?

transform은 데이터 하나를 모델이 학습하기 좋은 형태로 바꾸는 함수 또는 함수들의 묶음

| transform 예시 | 역할 |
| --- | --- |
| `Resize` | 이미지 크기를 맞춘다. |
| `ToTensor` | 이미지를 PyTorch Tensor로 바꾼다. |
| `Normalize` | 채널별 평균과 표준편차로 값의 분포를 조정한다. |
| `RandomHorizontalFlip` | 학습 데이터 증강을 위해 이미지를 랜덤하게 뒤집는다 |

처음에는 다음 흐름을 가장 많이 사용합니다.

```python
from torchvision import transforms

transform = transforms.Compose([
    transforms.Resize((64, 64)),
    transforms.ToTensor(),
    # RGB 이미지이므로 채널마다 mean과 std를 하나씩 지정합니다.
    transforms.Normalize(
        mean=(0.5, 0.5, 0.5),
        std=(0.5, 0.5, 0.5)
    )
])
```

## 3. 이미지 전처리의 기본 흐름

이미지 모델에 데이터를 넣으려면 보통 다음 순서를 거칩니다.

```
1. 이미지 파일을 읽습니다.
2. 이미지 크기를 모델 입력 크기에 맞춥니다.
3. 이미지를 Tensor로 변환합니다.
4. 픽셀 값 분포를 정규화합니다.
5. batch로 묶어 모델에 넣습니다.
```

이 흐름을 Dataset과 DataLoader로 연결하면 다음과 같다.

```
Dataset.__getitem__
    이미지 읽기
    transform 적용
    image, label 반환

DataLoader
    여러 image, label을 batch로 묶음
```

## 4. `ToTensor`와 shape 변화

이미지 데이터에서 매우 중요한 변화는 shape 순서다.

일반적인 이미지 배열은 보통 다음 형태입니다.

```
(height, width, channels)
```

PyTorch 이미지 Tensor는 보통 다음 형태를 사용합니다.

```
(channels, height, width)
```

즉, 이미지 한 장은 `(C, H, W)`이고, batch가 되면 `(N, C, H, W)`가 된다

```python
import torch

# 이미 Tensor 이미지가 있다고 가정합니다.
# batch size 8, RGB 3채널, 64x64 이미지입니다.
images = torch.randn(8, 3, 64, 64)

print(images.shape)
```

PyTorch CNN 모델은 일반적으로 이미지 batch를 `(batch_size, channels, height, width)` 형태로 기대한다

## 5. `Normalize`의 의미

`Normalize(mean, std)`는 각 채널의 값을 정규화 된 값으로 바꾼다
```
정규화된 값 = (원래 값 - mean) / std
```

예를 들어 흑백 이미지 Tensor 값이 `[0, 1]` 범위에 있고, `mean=0.5`, `std=0.5`를 적용하면 값의 범위가 대략 `[-1, 1]`로 바뀝니다.

```python
import torch

x = torch.tensor([0.0, 0.5, 1.0])
mean = 0.5
std = 0.5

x_norm = (x - mean) / std
print(x_norm)
```

출력

```
tensor([-1.,  0.,  1.])
```

정규화는 모델이 특정 스케일에 과하게 민감해지는 것을 줄이고,<br> 학습을 안정적으로 만드는 데 도움을 줄 수 있다

## 6. train transform과 valid transform 구분

학습 데이터에는 augmentation을 적용할 수 있습니다. 예를 들어 이미지를 랜덤하게 뒤집거나, 약간 회전하거나, 잘라낼 수 있습니다.

하지만 검증 데이터에는 보통 랜덤 augmentation을 적용하지 않습니다. 검증은 모델 성능을 일관되게 측정해야 하기 때문입니다.

```python
from torchvision import transforms

train_transform = transforms.Compose([
    transforms.Resize((64, 64)),
    transforms.RandomHorizontalFlip(p=0.5),
    transforms.ToTensor(),
    
    # 예시
    transforms.Normalize(mean=(0.5, 0.5, 0.5), std=(0.5, 0.5, 0.5))
])

valid_transform = transforms.Compose([
    transforms.Resize((64, 64)),
    transforms.ToTensor(),

    # 예시
    transforms.Normalize(mean=(0.5, 0.5, 0.5), std=(0.5, 0.5, 0.5))
])
```

valid transform에 랜덤 augmentation을 넣으면 평가 결과가 실행할 때마다 흔들릴 수 있다.

`random_split`이 만든 `Subset`들은 같은 원본 Dataset을 공유한다. 

random_split으로 생성된 train과 valid Subset은 같은 원본 Dataset을 공유한다. <br>
원본 Dataset의 transform을 변경하면 두 Subset 모두 마지막으로 설정된 동일한 transform을 사용하게 되므로, <br>
서로 다른 transform을 독립적으로 적용할 수 없다.

## 7. Custom Dataset에 transform 연결하기

```python
import torch
from torch.utils.data import Dataset

class DummyImageDataset(Dataset):
    """
    이미지 Dataset의 구조를 연습하기 위한 더미 Dataset입니다.
    실제 프로젝트에서는 image_paths를 받아 파일을 읽는 방식으로 바뀝니다.
    """
    def __init__(self, images, labels, transform=None):
        assert len(images) == len(labels)
        self.images = images
        self.labels = labels
        self.transform = transform

    def __len__(self):
        return len(self.images)

    def __getitem__(self, idx):
        image = self.images[idx]
        label = self.labels[idx]

        # transform이 있으면 image에 적용합니다.
        if self.transform is not None:
            image = self.transform(image)

        return image, label
```



```python
# Tensor 입력을 받아 값을 간단히 스케일링하는 예시 transform입니다.
# 아래 코드는 한 샘플의 전체 원소로 평균과 표준편차를 계산합니다.
# 채널별 고정 통계를 사용하는 torchvision.transforms.Normalize와는 다릅니다.
class SimpleNormalize:
    def __call__(self, x):
        return (x - x.mean()) / (x.std() + 1e-6)

images = torch.randn(10, 3, 32, 32)
labels = torch.randint(0, 2, size=(10,), dtype=torch.long)

dataset = DummyImageDataset(images, labels, transform=SimpleNormalize())

image, label = dataset[0]
print("image shape:", image.shape)
print("image mean:", image.mean().item())
print("image std :", image.std().item())
print("label:", label)
```
결과
```
image shape: torch.Size([3, 32, 32])
image mean: -1.412505934439423e-08
image std : 0.9999990463256836
label: tensor(0)
```
