## 1. 이번에 배울것

```
zero_grad -> forward -> loss 계산 -> backward -> optimizer.step
```

이 과정 에서 **backward가 무엇을 계산하는지**를 배운다

딥러닝 학습은 모델이 예측을 틀렸을 때 loss를 줄이는 방향으로 weight와 bias를 조금씩 수정하는 과정이다<br>
이때 필요한 값이 **gradient**다

gradient는 현재 위치에서 파라미터가 조금 변할 때 loss가 얼마나, 어느 방향으로 변하는지를 나타내는 **변화율**이다.<br> 
실제로 파라미터를 얼마나 움직일지는 optimizer와 learning rate가 함께 결정한다.

PyTorch에는 `torch.autograd`라는 자동미분 엔진이 있고, 이 엔진은 계산 그래프에 대한 gradient를 자동으로 계산한다

계산 그래프와 Chain Rule 흐름

forward는 왼쪽에서 오른쪽으로 값을 계산하고, backward는 loss에서 시작해 오른쪽에서 왼쪽으로 gradient를 전달

여기서 `loss.backward()`는 단순히 loss를 출력하는 함수가 아니다<br>
loss가 만들어지기까지 사용된 연산들을 거꾸로 따라가며,<br>
각 파라미터가 loss에 얼마나 영향을 주는지 계산

`loss.backward()`는 loss에서 시작해 모델 파라미터까지 거꾸로 이동하며 gradient를 계산합니다.

## 2. 계산 그래프

계산 그래프는 값이 어떤 연산을 거쳐 만들어졌는지 표현한 그림

예시

```
x = 2
w = 3
b = 1
z = x * w + b
loss = z ** 2
```

이 계산은 다음 흐름으로 볼 수 있다.

```
x, w, b -> z = x * w + b -> loss = z ** 2
```

이 전체 흐름을 계산 그래프로 생각할 수 있다.

## 3. 아주 작은 계산 그래프 직접 따라가기

간단한 계산을 PyTorch로 작성해보겠습니다.

```python
import torch

# w는 우리가 학습시키고 싶은 값이라고 가정합니다.
# requires_grad=True를 주면 PyTorch가 w와 관련된 연산을 추적합니다.
w = torch.tensor(3.0, requires_grad=True)

# 입력 x와 bias b는 여기서는 고정값으로 둡니다.
x = torch.tensor(2.0)
b = torch.tensor(1.0)

# forward 계산입니다.
z = x * w + b

# loss는 z가 0에 가까워지기를 바란다고 가정한 간단한 예시입니다.
loss = z ** 2


print("z:", z)


print("loss:", loss)


print("loss grad_fn:", loss.grad_fn)
```

출력은 다음과 비슷합니다.

```
# z를 만든 마지막 연산은 + b, 즉 덧셈이었다.
z: tensor(7., grad_fn=<AddBackward0>)       

# loss를 만든 마지막 연산은 ** 2, 즉 제곱이었다.
loss: tensor(49., grad_fn=<PowBackward0>) 

# loss.grad_fn을 따로 출력한 것. 위와 동일한 역전파 객체다.
loss grad_fn: <PowBackward0 object at ...>
```

`grad_fn`은 이 Tensor가 어떤 연산으로 만들어졌는지 알려주는 단서다. <br>
`loss`는 `z ** 2`로 만들어졌기 때문에 `PowBackward0` 같은 정보가 붙어 있다.

## 4. Chain Rule을 직관적으로 이해

Chain Rule은 합성된 계산의 영향을 단계별로 곱해서 전달하는 규칙이다.

```
loss가 z에 얼마나 민감한가?
z가 w에 얼마나 민감한가?
그러면 loss가 w에 얼마나 민감한지 계산할 수 있다.
```

앞의 예시에서 계산

```
z = x * w + b
loss = z ** 2
```
`w`가 바뀌면 `z`가 바뀌고, `z`가 바뀌면 `loss`가 바뀝니다. 즉, `w`는 `z`를 거쳐 loss에 영향을 줍니다.

```
w -> z -> loss
```

Chain Rule은 이 연결된 영향을 거꾸로 계산한다

```
loss -> z -> w
```

## 5. PyTorch에서 계산 그래프 확인하기

이제 `backward()`를 호출해보겠습니다.

```python
import torch

w = torch.tensor(3.0, requires_grad=True)
x = torch.tensor(2.0)
b = torch.tensor(1.0)

z = x * w + b
loss = z ** 2

# loss를 기준으로 w의 gradient를 계산합니다.
loss.backward()

# w.grad에는 loss가 w에 대해 얼마나 민감한지 저장됩니다.
print("w:", w)
print("w.grad:", w.grad)
```
출력

```
w: tensor(3., requires_grad=True)
w.grad: tensor(28.)
```
여기서 `w.grad`가 28이라는 것은 지금 위치에서 w가 조금 변하면 loss가 그만큼 민감하게 변한다는 뜻이다

직접 계산

```
z = x * w + b = 2 * 3 + 1 = 7
loss = z ** 2

loss의 z에 대한 변화율 = 2 * z = 14
z의 w에 대한 변화율 = x = 2

loss의 w에 대한 변화율 = 14 * 2 = 28
```

## 6. scalar loss가 중요한 이유

딥러닝 학습에서는 보통 loss가 숫자 하나, 즉 scalar가 되어야 한다

예를 들어 MSE loss를 직접 계산하면 샘플별 loss가 먼저 만들어질 수 있다

```python
import torch

pred = torch.tensor([1.0, 2.0, 3.0], requires_grad=True)
target = torch.tensor([1.5, 1.5, 2.5])

# 샘플별 제곱 오차입니다.
loss_each = (pred - target) ** 2
print("loss_each:", loss_each)
print("loss_each shape:", loss_each.shape)

# 전체 loss를 scalar로 만듭니다.
loss = loss_each.mean()
print("loss:", loss)
print("loss shape:", loss.shape)
```

출력

```
loss_each: tensor([0.2500, 0.2500, 0.2500], grad_fn=<PowBackward0>)
loss_each shape: torch.Size([3])
loss: tensor(0.2500, grad_fn=<MeanBackward0>)
loss shape: torch.Size([])
```

`loss_each`는 shape가 `(3,)`인 Tensor입니다. 학습에서는 보통 이 값을 평균이나 합으로 줄여 scalar loss를 만든 뒤 `backward()`를 호출한다

```python
# scalar loss이므로 backward를 호출
loss.backward()
print(pred.grad)
```

처음에는 loss가 scalar인지 꼭 확인. 

```py
loss_each.backward(
    gradient=torch.tensor([1.0, 1.0, 1.0])
)
```

여러 값을 가진 Tensor도 외부 gradient를 명시하면 backward할 수 있지만, 

기초 학습 루프에서는 평균이나 합으로 scalar loss를 만든 뒤 `backward()`를 호출하는 것이 가장 안전하다

## 7. 자주 하는 실수

### `requires_grad=True`를 주지 않은 Tensor의 gradient를 기대하기

```python
w = torch.tensor(3.0)  # requires_grad=True가 없습니다.
x = torch.tensor(2.0)

loss = (x * w) ** 2

try:
    loss.backward()
except RuntimeError as e:
    print("오류 발생!")
    print(e)
```

학습할 값이라면 `requires_grad=True`가 필요하다. 

실제 모델 파라미터는 `nn.Linear` 같은 모듈 안에서 자동으로 `requires_grad=True`로 생성된다

### 실수 2. loss가 만들어진 뒤 값을 `.item()`으로 바꿔버리기

```python
# loss.item()은 Python 숫자를 꺼낸다
# 로깅에는 좋지만, 이 값으로 backward를 할 수 없다
loss_value = loss.item()
print(type(loss_value))
```

`loss.item()`은 출력이나 기록용으로 사용하세요. backward는 Tensor인 `loss`에 호출해야 한다
