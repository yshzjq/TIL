## 1. 이번에 배울것

CNN 성능을 제대로 해석하려면 비교 기준이 필요하다. 이 비교 기준을 **baseline**이라고 한다.


### MLP baseline: CNN과 비교할 기준선

이미지 입력
→ Flatten
→ Linear + ReLU
→ Linear
→ logits
→ 성능 측정


## 2. 왜 MLP baseline이 필요한가

CNN은 이미지의 공간 구조를 활용한다 반면 MLP는 이미지를 한 줄로 펼친 뒤 처리한다

| 모델 | 이미지 처리 방식 |
| --- | --- |
| MLP | 픽셀 값과 고정된 index 순서는 보존하지만, 가까운 픽셀을 함께 보는 지역성·가중치 공유를 구조적으로 사용하지 않는다 |
| CNN | 작은 영역을 보며 지역 패턴과 공간 구조를 활용한다 |

MLP baseline은 단순한 비교 기준을 제공한다. <br>
다만 성능 차이를 CNN의 구조만으로 설명하려면 모델 크기와 무작위성도 함께 통제해야 한다

## 3. CIFAR-10용 MLP 만들기

```python
import torch
import torch.nn as nn

class ImageMLP(nn.Module):
    """
    CIFAR-10 이미지를 flatten한 뒤 분류하는 MLP baseline입니다.
    입력: (N, 3, 32, 32)
    출력: (N, 10)
    """
    def __init__(self, hidden_dim=256, num_classes=10):
        super().__init__()

        self.model = nn.Sequential(
            # 이미지를 한 줄로 펼칩니다.
            nn.Flatten(),

            # 3*32*32 = 3072개의 입력 feature를 hidden_dim으로 변환합니다.
            nn.Linear(3 * 32 * 32, hidden_dim),
            nn.ReLU(),

            # hidden feature를 class별 logits로 변환합니다.
            nn.Linear(hidden_dim, num_classes)
        )

    def forward(self, x):
        logits = self.model(x)
        return logits
```

## 4. 출력 shape 확인하기

```python
images = torch.randn(8, 3, 32, 32)
model = ImageMLP(hidden_dim=256, num_classes=10)
logits = model(images)

print("images:", images.shape)
print("logits:", logits.shape)
```

출력

```
images: torch.Size([8, 3, 32, 32])
logits: torch.Size([8, 10])
```

## 5. CNN과 parameter 수 비교

```python
class SmallCNN(nn.Module):
    def __init__(self, num_classes=10):
        super().__init__()
        self.features = nn.Sequential(
            nn.Conv2d(3, 16, 3, padding=1), nn.ReLU(), nn.MaxPool2d(2),
            nn.Conv2d(16, 32, 3, padding=1), nn.ReLU(), nn.MaxPool2d(2)
        )
        self.classifier = nn.Linear(32 * 8 * 8, num_classes)

    def forward(self, x):
        return self.classifier(torch.flatten(self.features(x), start_dim=1))

def count_parameters(model):
    return sum(p.numel() for p in model.parameters() if p.requires_grad)

mlp = ImageMLP(hidden_dim=256, num_classes=10)
cnn = SmallCNN(num_classes=10)

print("MLP parameters:", count_parameters(mlp))
print("CNN parameters:", count_parameters(cnn))
```

예상 parameter 수는 `ImageMLP(hidden_dim=256)`이 789,258개, `SmallCNN`이 25,578개입니다.<br>

1. 같은 train/valid split과 전처리를 사용한다
2. 같은 고정 seed에서 모델 초기화와 train shuffle을 다시 시작한다
3. epoch, batch size, optimizer, learning rate, metric을 맞춘다
4. parameter 수를 함께 기록한다

parameter 수를 비슷하게 맞춘 뒤에도 MLP와 CNN의 연산량과 최적 학습 설정은 다를 수 있다.<br> 
따라서 결과는 “이 데이터·seed·학습 조건에서”로 제한해 해석하고 절대적인 우열로 일반화하지 않는다

## 6. 동일한 train/valid 함수 재사용하기

MLP와 CNN은 둘 다 입력 batch를 받아 logits를 반환합니다. 따라서 같은 학습 함수를 재사용할 수 있다.

```python
# MLP도 model(images) -> logits 구조입니다.
mlp_logits = mlp(images)

# CNN도 model(images) -> logits 구조입니다.
cnn_logits = cnn(images)

print(mlp_logits.shape)
print(cnn_logits.shape)
```

모델 내부 구조는 달라도, 출력이 `(batch_size, num_classes)` logits라면<br> 같은 `CrossEntropyLoss`, 같은 training loop를 사용할 수 있다.

## 7. 자주 하는 실수

### 실수 1. MLP input_dim 계산 실수

CIFAR-10 이미지는 `3*32*32=3072` feature입니다. `32*32=1024`로 계산하면 RGB channel을 빠뜨린 것이다

### 실수 2. CNN과 MLP를 다른 조건으로 학습하기

비교하려면 데이터 split, 전처리, epoch, batch size, optimizer, learning rate, metric과 고정 seed의 shuffle 순서를 맞춰야 한다.<br>
그래도 계산량과 각 모델에 최적인 설정은 다를 수 있다는 한계를 적는다.
