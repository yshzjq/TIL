## 1. 이번에 우리가 배울 것

이번 강에서는 **이진 분류(binary classification)** 출력층을 설계합니다. 이진 분류는 정답 class가 두 개인 문제

<img src="{{'/assets/images/uploads/deep-learning/이진 분류 출력 흐름 그림.png' | relative_url }}" alt="이진 분류 출력 흐름 그림.png" loading="lazy">

모델의 raw logits를 Sigmoid로 0~1 사이 점수로 바꾸고, 예시 threshold 0.5 기준으로 label을 만드는 흐름

## 2. 이진 분류 출력층의 핵심 흐름

### 2-1. class가 두 개인데 왜 logit은 하나만 출력하나요?

이진 분류에서는 보통 class 1 방향의 근거 점수 하나만 출력한다<br>
class 0과 class 1은 서로 반대 선택지이므로, <br>
하나의 점수가 어느 쪽으로 기울었는지만 알면 두 class를 구분할 수 있다.

```
logit < 0  -> class 0 쪽 근거가 더 큼
logit = 0  -> 두 class의 경계
logit > 0  -> class 1 쪽 근거가 더 큼
```

예를 들어 logit이 `-2`, `0`, `2`라면 Sigmoid 결과는 `0.119`, `0.5`, `0.881`

| raw logit | Sigmoid 결과 | 기본 해석 |
| --- | --- | --- |
| -2 | 약 0.119 | class 0 쪽 |
| 0 | 0.5 | 결정 경계 |
| 2 | 약 0.881 | class 1 쪽 |

### 2-2. logit의 부호와 크기를 따로 읽으세요

부호는 어느 class 쪽인지, 절댓값은 경계에서 얼마나 멀리 있는지를 나타내는 근거로 볼 수 있다.

```
-0.1 -> class 0 쪽이지만 경계에 가까움
-5.0 -> class 0 쪽으로 강한 근거
 0.1 -> class 1 쪽이지만 경계에 가까움
 5.0 -> class 1 쪽으로 강한 근거
```

단, logit 자체는 확률이 아니며 모델 간 절대값을 그대로 비교해서도 안 됩니다. 확률처럼 해석하려면 Sigmoid를 적용한다.

### 2-3. 확률 0.5 기준과 logit 0 기준은 같은 경계입니다

Sigmoid는 단조 증가 함수이므로 다음 두 코드는 같은 기본 예측을 만든다.

```python
preds_from_prob = (torch.sigmoid(logits) >= 0.5).long()
preds_from_logit = (logits >= 0).long()
```

확률 threshold를 0.7처럼 바꾸면 대응하는 logit threshold도 0이 아니게 됩니다. <br>
초반에는 확률로 변환한 뒤 threshold를 적용하는 방식이 가장 직관적이다

이진 분류의 logit 하나는 class 1 방향의 근거 점수이며, Sigmoid가 이를 0과 1 사이 값으로 바꾸고 threshold가 최종 label을 결정


이진 분류의 전체 흐름

```
입력 Tensor
-> MLP
-> logits
-> sigmoid(logits)
-> probability
-> threshold 적용
-> 예측 label
```

하지만 학습할 때는 이 흐름을 그대로 모델 안에 모두 넣지 않는 경우가 많다

특히 PyTorch에서 `nn.BCEWithLogitsLoss`를 사용할 때는 모델이 **Sigmoid를 적용하지 않은 raw logits**를 출력하도록 두는 것이 일반적이다.

`BCEWithLogitsLoss`를 사용할 때는 모델 마지막에 `nn.Sigmoid()`를 넣지 않고, loss 함수에 raw logits를 넣습니다. 예측 결과를 해석할 때만 `torch.sigmoid(logits)`를 적용

## 3. Sigmoid는 어떤 함수인가요?

Sigmoid는 입력값을 0과 1 사이로 바꾼다

```
Sigmoid(x) = 1 / (1 + exp(-x))
```

입력값이 매우 작으면 0에 가까워지고, 매우 크면 1에 가까워진다

| logit | sigmoid(logit) | 해석 |
| --- | --- | --- |
| -5 | 약 0.01 | class 1일 가능성이 낮음 |
| 0 | 0.50 | 애매함 |
| 5 | 약 0.99 | class 1일 가능성이 높음 |


코드로 확인해보겠습니다.

```python
import torch

logits = torch.tensor([-5.0, 0.0, 5.0])
probs = torch.sigmoid(logits)

print("logits:", logits)
print("probs :", probs)
```

출력

```
logits: tensor([-5.,  0.,  5.])
probs : tensor([0.0067, 0.5000, 0.9933])
```


## 4. 이진 분류 모델의 출력 shape

이진 분류 모델은 보통 샘플마다 logit 하나를 출력

```python
import torch
import torch.nn as nn

class BinaryMLP(nn.Module):
    """
    feature 4개를 입력받아 이진 분류 logit 1개를 출력하는 모델입니다.
    """
    def __init__(self, input_dim=4, hidden_dim=16):
        super().__init__()
        self.net = nn.Sequential(
            nn.Linear(input_dim, hidden_dim),
            nn.ReLU(),
            nn.Linear(hidden_dim, 1)  # 이진 분류에서는 logit 1개를 출력합니다.
        )

    def forward(self, x):
        logits = self.net(x)
        return logits

x = torch.randn(8, 4)
model = BinaryMLP()
logits = model(x)

print("x shape     :", x.shape)
print("logits shape:", logits.shape)
```

출력

```
x shape     : torch.Size([8, 4])
logits shape: torch.Size([8, 1])
```

여기서 `8`은 batch size이고, 마지막 차원 `1`은 샘플마다 logit 하나를 출력

## 5. `BCEWithLogitsLoss`를 사용할 때의 원칙

### 5-1. 이름의 `WithLogits`를 그대로 읽으세요

`BCEWithLogitsLoss`는 확률이 아니라 **raw logits**를 입력으로 받습니다. 내부에서 Sigmoid와 BCE를 수치적으로 안정적인 하나의 계산으로 결합

```
권장: raw logits -> BCEWithLogitsLoss
예측 해석: raw logits -> Sigmoid -> probability
```

모델 안에 `nn.Sigmoid()`를 넣고 그 결과를 다시 `BCEWithLogitsLoss`에 전달하면 안된다,<br>
이미 0~1로 압축된 값을 loss가 logit으로 오해하여 Sigmoid 연산을 두번 한다

### 5-2. 왜 내부 결합이 더 안정적인가요?

매우 큰 양수나 음수 logit에서는 Sigmoid 결과가 1 또는 0에 매우 가까워진다.<br> 확률을 먼저 만든 뒤 `log`를 계산하면 컴퓨터의 제한된 정밀도 때문에 값이 0으로 잘리거나 불안정해질 수 있다

`BCEWithLogitsLoss`는 logits 단계에서 식을 정리해 이 문제를 줄입니다. 초반에는 복잡한 공식을 외우기보다 다음 원칙을 기억하면 충분합니다.

```
학습용 loss에는 raw logits
사람이 볼 확률에는 Sigmoid
```

### 5-3. target은 왜 float인가요?

BCE는 각 출력 원소를 0과 1 사이의 수치로 비교하고 곱셈·로그 계산을 수행<br>
따라서 target도 계산 가능한 실수 Tensor를 사용

```
logits shape: (B, 1)      target shape: (B, 1)
logits dtype: float       target dtype: float
```

기본 이진 분류에서는 target 값이 `0.0` 또는 `1.0`이다,<br> 필요하면 label smoothing이나 soft target처럼 그 사이의 실수도 표현할 수 있다.

`long`은 숫자를 저장할 수 없는 타입이라서가 아니라, `BCEWithLogitsLoss`가 기대하는 계산 계약이 float target이기 때문에 사용하지 않는 것

이진 분류에서 자주 사용하는 loss는 `nn.BCEWithLogitsLoss`입니다.

이 loss는 이름 그대로 **logits를 입력으로 받는 BCE loss**다.<br>내부적으로 Sigmoid와 Binary Cross Entropy 계산을 함께 처리

```python
import torch
import torch.nn as nn

model = BinaryMLP()
criterion = nn.BCEWithLogitsLoss()

# 샘플 8개, feature 4개입니다.
x = torch.randn(8, 4)

# target도 logits와 같은 shape로 맞춥니다.
# 이진 분류 target은 보통 float 타입을 사용합니다.
target = torch.tensor([
    [0.0],
    [1.0],
    [0.0],
    [1.0],
    [1.0],
    [0.0],
    [1.0],
    [0.0]
])

logits = model(x)
loss = criterion(logits, target)

print("logits shape:", logits.shape)
print("target shape:", target.shape)
print("loss:", loss)
```

출력
```
logits shape: torch.Size([8, 1])
target shape: torch.Size([8, 1])
loss: tensor(..., grad_fn=<BinaryCrossEntropyWithLogitsBackward0>)
```

`BCEWithLogitsLoss`에 넣을 때는 `torch.sigmoid(logits)`를 미리 적용하지 않는다. 이미 Sigmoid가 내부에 포함되어 있기 때문이다

## 6. logits에서 확률과 label 만들기

학습이 끝났거나 예측을 확인할 때는 logits를 확률로 바꾸고 threshold를 적용

```python
import torch

# 모델이 출력한 raw logits라고 가정합니다.
logits = torch.tensor([
    [-2.0],
    [0.2],
    [1.7],
    [4.0]
])

# Sigmoid를 적용해 0~1 사이 확률처럼 해석합니다.
probs = torch.sigmoid(logits)

# 예시 threshold 0.5 이상이면 class 1, 아니면 class 0으로 예측합니다.
preds = (probs >= 0.5).long()

print("logits:")
print(logits)
print("probs:")
print(probs)
print("preds:")
print(preds)
```

출력은 다음과 비슷합니다.

```
probs:
tensor([[0.1192],
        [0.5498],
        [0.8455],
        [0.9820]])
preds:
tensor([[0],
        [1],
        [1],
        [1]])
```

`0.5`는 기본 예시이지 모든 문제의 정답은 아니다. <br>실제 threshold는 validation 데이터에서 오분류 비용, class 불균형, precision과 recall 중 무엇을 더 중시하는지를 기준으로 정한다.

학습 단계와 예측 단계의 코드를 구분

```
학습 단계: logits -> BCEWithLogitsLoss
예측 단계: logits -> sigmoid -> threshold -> label
```

## 7. target shape와 dtype 확인하기

이진 분류에서 자주 발생하는 오류는 `logits`와 `target`의 shape가 다른 경우

```python
import torch
import torch.nn as nn

criterion = nn.BCEWithLogitsLoss()

logits = torch.randn(8, 1)

# 잘못된 target shape입니다.
# logits는 (8, 1)인데 target은 (8,)입니다.
target_wrong = torch.tensor([0, 1, 0, 1, 1, 0, 1, 0], dtype=torch.float32)

print("logits shape      :", logits.shape)
print("target_wrong shape:", target_wrong.shape)
```

출력은 다음과 같습니다.

```
logits shape      : torch.Size([8, 1])
target_wrong shape: torch.Size([8])
```
수정하려면 `unsqueeze(1)`로 target을 `(8, 1)`로 바꾼다.

```python
target = target_wrong.unsqueeze(1)

loss = criterion(logits, target)

print("target shape:", target.shape)
print("loss:", loss)
```

또는 처음부터 target을 2차원으로 만들 수 있다.

```python
target = torch.tensor([
    [0.0],
    [1.0],
    [0.0],
    [1.0],
    [1.0],
    [0.0],
    [1.0],
    [0.0]
])
```

한 샘플에 여러 label이 동시에 참일 수 있는 다중 레이블 분류에서는 class마다 logit 하나를 출력.<br> 
예를 들어 class가 5개라면 logits와 target shape는 보통 `(batch_size, 5)`이고, 각 원소에 `BCEWithLogitsLoss`를 적용.

또한 Sigmoid 결과는 0~1 범위이지만 언제나 잘 보정된 실제 확률을 뜻하지는 않는다 <br>확률값 자체가 중요한 업무라면 validation 데이터에서 calibration을 별도로 확인해야 한다.

📃 **이진 분류 체크리스트**

| 항목 | 권장 형태 |
| --- | --- |
| logits shape | `(batch_size, 1)` |
| target shape | `(batch_size, 1)` |
| target dtype | `torch.float32` |
| loss | `nn.BCEWithLogitsLoss()` |
| 예측 확률 | `torch.sigmoid(logits)` |
| 예측 label | `(probs >= 0.5).long()` |
