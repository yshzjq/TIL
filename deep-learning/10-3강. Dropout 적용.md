MLP는 parameter 수가 많아질수록 학습 데이터의 세부 패턴을 쉽게 외울 수 있다.

데이터가 충분하지 않거나 모델이 너무 크면 train accuracy는 높지만 validation accuracy가 낮아지는 일이 생긴다

Dropout은 학습 중 일부 뉴런을 잠시 꺼서 다음 효과를 기대한다

| 효과 | 설명 |
| --- | --- |
| 특정 뉴런 의존 감소 | 매번 일부 뉴런이 꺼지므로 한 뉴런에만 의존하기 어렵다. |
| 앙상블과 비슷한 효과 | 매번 조금 다른 네트워크로 학습하는 것처럼 동작한다. |
| 과적합 완화 | train 데이터 외우기를 줄이고 일반화 성능을 높이는 데 도움을 준다. |

## 3. Dropout의 직관

```
특정 뉴런만 강하게 의존하는 모델
-> Dropout으로 일부 뉴런을 랜덤하게 끔
-> 다른 뉴런들도 역할을 나눠 갖도록 학습
-> 더 견고한 표현 학습 가능
```

## 4. `nn.Dropout` 동작 확인

```python
import torch
import torch.nn as nn

# 결과를 어느 정도 재현하기 위해 seed를 고정합니다.
# Dropout은 무작위로 값을 끄기 때문에 seed 없이 실행하면 결과가 달라질 수 있습니다.
torch.manual_seed(0)

# p=0.5는 학습 시 각 입력 원소를 50% 확률로 0으로 만든다는 뜻입니다.
dropout = nn.Dropout(p=0.5)

# 모든 값이 1인 Tensor를 만듭니다.
# 어떤 값이 0으로 바뀌는지 보기 쉽도록 1만 사용합니다.
x = torch.ones(10)

# Dropout은 학습 모드에서 무작위로 일부 값을 0으로 만듭니다.
dropout.train()
y_train = dropout(x)

# 평가 모드에서는 Dropout이 비활성화되어 입력이 그대로 통과합니다.
dropout.eval()
y_eval = dropout(x)

print("input       :", x)
print("train output:", y_train)
print("eval output :", y_eval)
```

`train output`에서는 일부 값이 0이 됩니다. 반면 `eval output`에서는 입력값이 그대로 유지된다

PyTorch의 `nn.Dropout`은 학습 중 일부 원소를 0으로 만들고, 남은 값은 보정 계수로 스케일링한다<br>
그래서 출력 평균이 크게 무너지지 않도록 설계되어 있다.

## 5. MLP에 Dropout 추가하기

Dropout은 보통 은닉층의 활성화 함수 뒤에 넣는다.

```
Linear -> ReLU -> Dropout -> Linear
```

```python
import torch
import torch.nn as nn

class DropoutMLP(nn.Module):
    """
    Dropout을 적용한 간단한 MLP 모델입니다.
    """

    def __init__(self, input_dim=784, hidden_dim=128, num_classes=10, dropout_p=0.3):
        super().__init__()

        # 이미지 입력을 2차원 Tensor로 펼칩니다.
        # 입력 shape: (batch_size, 1, 28, 28)
        # 출력 shape: (batch_size, 784)
        self.flatten = nn.Flatten()

        # 첫 번째 선형층입니다.
        # 784개의 feature를 hidden_dim개 feature로 변환합니다.
        self.fc1 = nn.Linear(input_dim, hidden_dim)

        # 비선형성을 추가하는 ReLU입니다.
        self.relu = nn.ReLU()

        # Dropout layer입니다.
        # 학습 중 hidden representation의 일부를 무작위로 0으로 만듭니다.
        self.dropout = nn.Dropout(p=dropout_p)

        # 출력층입니다.
        # hidden_dim개 feature를 class 수만큼의 logits로 변환합니다.
        self.fc2 = nn.Linear(hidden_dim, num_classes)

    def forward(self, x):
        # 이미지 batch를 flatten합니다.
        x = self.flatten(x)

        # 첫 번째 선형 변환을 수행합니다.
        x = self.fc1(x)

        # ReLU로 비선형성을 추가합니다.
        x = self.relu(x)

        # 학습 모드에서는 일부 값을 0으로 만들고,
        # 평가 모드에서는 그대로 통과합니다.
        x = self.dropout(x)

        # 마지막 logits를 계산합니다.
        logits = self.fc2(x)

        return logits
```

## 6. train mode와 eval mode 차이

Dropout은 `model.train()`과 `model.eval()`에 따라 다르게 동작

| 모드 | Dropout 동작 | 사용 시점 |
| --- | --- | --- |
| `model.train()` | 일부 값을 무작위로 0으로 만듭니다. | 학습 단계 |
| `model.eval()` | Dropout을 비활성화합니다. | 검증/추론 단계 |

```python
model = DropoutMLP(dropout_p=0.5)
images = torch.randn(4, 1, 28, 28)

# 학습 모드입니다.
# Dropout이 켜져 있으므로 같은 입력을 넣어도 출력이 달라질 수 있습니다.
model.train()
out_train_1 = model(images)
out_train_2 = model(images)

# 평가 모드입니다.
# Dropout이 꺼져 있으므로 같은 입력에 대해 출력이 안정적입니다.
model.eval()
out_eval_1 = model(images)
out_eval_2 = model(images)

print("train outputs same?", torch.allclose(out_train_1, out_train_2))
print("eval outputs same? ", torch.allclose(out_eval_1, out_eval_2))
```

validation이나 inference에서 `model.eval()`을 호출하지 않으면 Dropout이 계속 켜져 있어서 예측 결과가 흔들릴 수 있다.

## 7. Dropout 비율 선택하기

`p`는 0으로 만들 확률입니다.

| `p` 값 | 의미 | 주의점 |
| --- | --- | --- |
| `0.1` | 약한 Dropout | 과적합 완화 효과가 작을 수 있다. |
| `0.3` | 중간 정도 Dropout | MLP에서 자주 시도해볼 수 있다. |
| `0.5` | 강한 Dropout | 모델이 충분히 배우지 못할 수 있다. |

처음에는 `0.2` 또는 `0.3` 정도부터 시도하고, validation 성능을 보면서 조정하는 것이 좋다.<br>
Dropout이 항상 성능을 높이는 것은 아니다. 

효과를 비교할 때는 같은 train/valid split과 seed를 사용하고, baseline에서 Dropout 하나만 바꿔 여러 run의 경향을 확인

## 8. 자주 하는 실수

### 실수 1. Dropout을 출력층 뒤에 넣습니다

분류 logits 뒤에 Dropout을 넣으면 loss 계산이 불안정해질 수 있습니다. 보통 은닉층 뒤에 넣는다.

### 실수 2. validation에서 `model.eval()`을 빼먹습니다

Dropout은 train/eval 모드에 따라 다르게 동작한다<br>
validation 함수에는 반드시 `model.eval()`이 있어야 한다
