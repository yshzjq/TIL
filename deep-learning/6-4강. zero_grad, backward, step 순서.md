한 번의 학습 step 순서

backward 전에 gradient를 초기화하고, backward 후 optimizer가 파라미터를 업데이트하는 순서를 보여준다

## 2. 한 번의 학습 step 전체 흐름

```python
import torch
import torch.nn as nn
import torch.optim as optim

# 간단한 선형 모델
model = nn.Linear(2, 1)

# 손실 함수와 옵티마이저
criterion = nn.MSELoss()
optimizer = optim.SGD(model.parameters(), lr=0.01)

# 더미 데이터
x = torch.randn(4, 2)
y = torch.randn(4, 1)

# 1. 이전 step의 gradient를 초기화
optimizer.zero_grad()

# 2. forward로 예측값을 계산
pred = model(x)

# 3. loss를 계산
loss = criterion(pred, y)

# 4. backward로 gradient를 계산
loss.backward()

# 5. optimizer가 파라미터를 업데이트
optimizer.step()

print("loss:", loss.item())
```

`backward()`는 gradient를 계산하고, `step()`은 그 gradient를 사용해 parameter를 업데이트합니다.

## 3. gradient는 기본적으로 누적된다

PyTorch에서는 `backward()`를 호출할 때 gradient가 기존 `.grad`에 더해진다. 즉, 자동으로 0으로 초기화되지 않는다

다음 예시를 보겠습니다.

```python
import torch

w = torch.tensor(2.0, requires_grad=True)

loss1 = w ** 2
loss1.backward()
print("first grad:", w.grad)

loss2 = w ** 2
loss2.backward()
print("second grad:", w.grad)
```

출력

```
first grad: tensor(4.)
second grad: tensor(8.)
```

두 번째 backward 이후 gradient가 4가 아니라 8이 되었다<br>
이전 gradient에 새 gradient가 더해졌기 때문이다

## 4. `optimizer.zero_grad()`의 역할

`optimizer.zero_grad()`는 optimizer가 관리하는 파라미터들의 gradient를 초기화한다

```python
import torch
import torch.nn as nn
import torch.optim as optim

model = nn.Linear(2, 1)
criterion = nn.MSELoss()
optimizer = optim.SGD(model.parameters(), lr=0.01)

x = torch.randn(4, 2)
y = torch.randn(4, 1)

# forward, loss, backward
pred = model(x)
loss = criterion(pred, y)
loss.backward()

print("before zero_grad:")
print(model.weight.grad)

# gradient를 None으로 비웁니다.
optimizer.zero_grad(set_to_none=True)

print("after zero_grad:")
print(model.weight.grad)
```
출력
```
before zero_grad:
tensor([[1.3219, 3.0148]])
after zero_grad:
None
```

## 5. `loss.backward()`의 역할

`loss.backward()`는 현재 forward 계산 그래프를 기준으로 gradient를 계산한다

```python
optimizer.zero_grad()

pred = model(x)
loss = criterion(pred, y)

# backward 전에는 grad가 비어 있습니다.
print("before backward:", model.weight.grad)

loss.backward()

# backward 후에는 grad가 채워집니다.
print("after backward:", model.weight.grad)
```

`backward()`만으로는 파라미터 값이 바뀌지 않습니다. 이 점이 중요하다

## 6. `optimizer.step()`의 역할

`optimizer.step()`은 `.grad`에 저장된 gradient를 사용해 실제 파라미터를 업데이트합니다.

```python
import torch
import torch.nn as nn
import torch.optim as optim

torch.manual_seed(0)

model = nn.Linear(2, 1)
criterion = nn.MSELoss()
optimizer = optim.SGD(model.parameters(), lr=0.1)

x = torch.randn(4, 2)
y = torch.randn(4, 1)

# 업데이트 전 weight를 복사해 둡니다.
weight_before = model.weight.detach().clone()

optimizer.zero_grad()
pred = model(x)
loss = criterion(pred, y)
loss.backward()
optimizer.step()

weight_after = model.weight.detach().clone()

print("weight before:", weight_before)
print("weight after :", weight_after)
print("changed?", not torch.allclose(weight_before, weight_after))
```

## 7. parameter가 실제로 바뀌는지 확인하기

학습이 잘 되지 않을 때는 한 step만 실행해 파라미터가 바뀌는지 확인하면 좋습니다.

```python
def check_one_step_update(model, optimizer, criterion, x, y):
    """
    한 번의 학습 step에서 파라미터가 실제로 바뀌는지 확인합니다.
    """
    # 첫 번째 파라미터를 복사합니다.
    first_param_before = next(model.parameters()).detach().clone()

    optimizer.zero_grad()
    pred = model(x)
    loss = criterion(pred, y)
    loss.backward()
    optimizer.step()

    first_param_after = next(model.parameters()).detach().clone()

    print("loss:", loss.item())
    print("parameter changed?:", not torch.allclose(first_param_before, first_param_after))

check_one_step_update(model, optimizer, criterion, x, y)
```

## 8. 자주 하는 실수

### 실수 1. `zero_grad()`를 빼먹기

```python
# 잘못된 패턴입니다.
# gradient가 계속 누적될 수 있습니다.
pred = model(x)
loss = criterion(pred, y)
loss.backward()
optimizer.step()
```

`loss.backward()`를 호출하면 각 parameter의 `.grad`에 gradient가 저장된다

그래서 zero_grad()를 빼먹으면 이전 batch의 gradient와 현재 batch의 gradient가 섞여,<br>
의도한 방향보다 parameter가 더 크게 또는 이상한 방향으로 업데이트될 수 있다.
