## 1. 이번에 배울것

```
model -> logits
logits + labels -> loss
loss.backward() -> gradient
optimizer.step() -> parameter update
```


모델 출력, Loss, Optimizer 연결

모델 출력은 loss로 연결되고, loss는 backward와 optimizer step을 통해 parameter update로 연결된다


## 2. 모델 출력과 loss 연결

다중 분류에서는 모델이 class별 점수인 logits를 출력

```python
import torch
import torch.nn as nn
import torch.optim as optim

class MLPClassifier(nn.Module):
    """이 페이지를 단독 실행하기 위한 최소 MLP 정의입니다."""

    def __init__(self, input_dim=784, hidden_dim=64, num_classes=10):
        super().__init__()
        self.network = nn.Sequential(
            nn.Flatten(),
            nn.Linear(input_dim, hidden_dim),
            nn.ReLU(),
            nn.Linear(hidden_dim, num_classes),
        )

    def forward(self, x):
        return self.network(x)

images = torch.randn(8, 1, 28, 28)
labels = torch.tensor([0, 1, 2, 3, 4, 5, 6, 7], dtype=torch.long)

model = MLPClassifier(input_dim=784, hidden_dim=64, num_classes=10)
logits = model(images)

print("logits shape:", logits.shape)
print("labels shape:", labels.shape)
```

출력

```
logits shape: torch.Size([8, 10])
labels shape: torch.Size([8])
```

`logits`는 class별 점수이고,<br>
`labels`는 각 샘플의 정답 class 번호입니다. <br>
class 수가 `num_classes`라면 모든 label은 `0 <= label < num_classes` 범위여야 한다.


## 3. `CrossEntropyLoss` 입력 조건

`CrossEntropyLoss`는 다중 분류에서 자주 사용하는 손실 함수다

```python
criterion = nn.CrossEntropyLoss()
loss = criterion(logits, labels)

print("loss:", loss)
print("loss shape:", loss.shape)
```

loss는 보통 scalar Tensor 다

```
loss shape: torch.Size([])
```


`CrossEntropyLoss`를 사용할 때는 다음 조건을 자주 확인해야 한다

| 항목 | 조건 |
| --- | --- |
| logits shape | `(batch_size, num_classes)` |
| labels shape | `(batch_size,)` |
| labels dtype | `torch.long` |
| logits 값 | softmax 적용 전 raw logits |


## 4. optimizer는 무엇을 업데이트해야하나?

optimizer는 모델의 parameter를 업데이트한다<br>
따라서 optimizer를 만들 때는 `model.parameters()`를 넘깁니다.

```python
optimizer = optim.Adam(model.parameters(), lr=0.001)
```

여기서 `lr`은 learning rate입니다. learning rate는 한 번의 업데이트에서 parameter를 얼마나 크게 움직일지 정하는 값이다

optimizer는 loss에서 계산된 gradient를 보고 weight와 bias를 조금씩 바꾸는 역할을 한다

## 5. 학습에 필요한 세 가지 객체 준비
```python
model = MLPClassifier(input_dim=784, hidden_dim=64, num_classes=10)
criterion = nn.CrossEntropyLoss()
optimizer = optim.Adam(model.parameters(), lr=0.001)
```

각 객체의 역할

| 객체 | 역할 |
| --- | --- |
| `model` | 입력을 받아 logits를 만듭니다. |
| `criterion` | logits와 label을 비교해 loss를 계산 |
| `optimizer` | gradient를 사용해 parameter를 업데이트 |

## 6. 한 batch로 학습 step 실행하기

```python
# 1. 더미 batch를 만듭니다.
images = torch.randn(8, 1, 28, 28)
labels = torch.tensor([0, 1, 2, 3, 4, 5, 6, 7], dtype=torch.long)

# 2. 모델, 손실 함수, optimizer를 준비합니다.
model = MLPClassifier(input_dim=784, hidden_dim=64, num_classes=10)
criterion = nn.CrossEntropyLoss()
optimizer = optim.Adam(model.parameters(), lr=0.001)

# 3. 이전 gradient를 초기화합니다.
optimizer.zero_grad()

# 4. forward를 실행합니다.
logits = model(images)

# 5. loss를 계산합니다.
loss = criterion(logits, labels)

# 6. gradient를 계산합니다.
loss.backward()

# 7. parameter를 업데이트합니다.
optimizer.step()

print("logits shape:", logits.shape)
print("loss        :", loss.item())
```

## 7. 자주 하는 실수

### 실수 1. labels dtype을 float로 만들기

`CrossEntropyLoss`의 class index target은 `long` dtype이어야 한다.


### 실수 2. logits에 softmax를 먼저 적용하기

### 실수 3. optimizer에 `model.parameters()`를 넘기지 않기

```
[읽기용 코드 조각]

```
