## 1. 이번에 배울것

CNN에서 shape가 어려운 이유는 Convolution이 height와 width를 바꿀 수 있기 때문이다

이때 출력 크기를 조절하는 대표적인 인자가 **padding**과 **stride**다.

그림에서는 입력 가장자리에 칸을 덧붙이는 것이 padding, kernel이 한 번에 이동하는 칸 수가 stride다.<br>
padding은 가장자리 정보를 계산할 기회를 늘리고, stride가 커지면 kernel이 방문하는 위치 수가 줄어 출력 H,W가 작아진다

## 2. Padding이란?



<img src="{{ '/assets/images/uploads/deep-learning/CNN.png' | relative_url }}" alt="CNN.png" loading="lazy">

Padding은 입력 이미지의 가장자리 주변에 값을 추가하는 것이다.
보통 0을 추가하므로 zero padding이라고도 한다

padding이 필요한 이유

- 가장자리 정보가 너무 빨리 사라지는 것을 줄인다
- 여러 Conv layer를 쌓아도 feature map 크기를 어느 정도 유지할 수 있다.
- `kernel_size=3`, `stride=1`, `padding=1` 조합은 H,W를 유지하는 데 자주 사용됩니다.

```python
import torch
import torch.nn as nn

x = torch.randn(1, 3, 32, 32)

# padding이 없는 convolution입니다.
conv_no_padding = nn.Conv2d(3, 8, kernel_size=3, padding=0)

# padding=1을 사용한 convolution입니다.
conv_with_padding = nn.Conv2d(3, 8, kernel_size=3, padding=1)

y1 = conv_no_padding(x)
y2 = conv_with_padding(x)

print("no padding :", y1.shape)
print("padding=1  :", y2.shape)
```

출력

```
no padding : torch.Size([1, 8, 30, 30])
padding=1  : torch.Size([1, 8, 32, 32])
```

## 3. Stride란?

Stride는 kernel이 한 번에 몇 칸씩 이동할지를 뜻한다

```
stride=1: 한 칸씩 촘촘하게 이동
stride=2: 두 칸씩 건너뛰며 이동
```

stride가 커지면 출력 feature map의 H,W가 줄어든다.

```python
import torch
import torch.nn as nn

x = torch.randn(1, 3, 32, 32)

conv_stride1 = nn.Conv2d(3, 8, kernel_size=3, padding=1, stride=1)
conv_stride2 = nn.Conv2d(3, 8, kernel_size=3, padding=1, stride=2)

y1 = conv_stride1(x)
y2 = conv_stride2(x)

print("stride=1:", y1.shape)
print("stride=2:", y2.shape)
```

출력

```
stride=1: torch.Size([1, 8, 32, 32])
stride=2: torch.Size([1, 8, 16, 16])
```

## 4. 출력 크기 공식

Convolution의 출력 height는 다음 공식으로 계산할 수 있다

```
H_out = floor((H_in + 2 * padding - dilation * (kernel_size - 1) - 1) / stride + 1)
```

초반에는 dilation을 1로 두고 보면 된다
```

H_out = floor((H_in + 2P - K) / S + 1)
```

| 기호 | 의미 |
| --- | --- |
| `H_in` | 입력 height |
| `P` | padding |
| `K` | kernel size |
| `S` | stride |

너비 `W_out`도 같은 방식으로 계산한다

공식은 중요하지만, 처음에는 공식을 외우는 것보다 `print(y.shape)`로 확인하는 습관이 더 중요하다

## 5. 공식과 코드 결과 비교하기

```python
import math
import torch
import torch.nn as nn

def conv_output_size(input_size, kernel_size, padding=0, stride=1, dilation=1):
    """
    Conv2d의 한쪽 공간 크기 출력값을 계산합니다.
    input_size는 height 또는 width 하나의 크기입니다.
    """
    return math.floor(
        (input_size + 2 * padding - dilation * (kernel_size - 1) - 1) / stride + 1
    )

# 입력 이미지 크기입니다.
H = 32
W = 32

# Conv2d 조건입니다.
kernel_size = 3
padding = 1
stride = 2

# 공식으로 출력 크기를 계산합니다.
H_out = conv_output_size(H, kernel_size, padding, stride)
W_out = conv_output_size(W, kernel_size, padding, stride)

print("formula output:", H_out, W_out)

# 실제 Conv2d 결과와 비교합니다.
x = torch.randn(1, 3, H, W)
conv = nn.Conv2d(3, 8, kernel_size=kernel_size, padding=padding, stride=stride)
y = conv(x)

print("torch output:", y.shape)
assert tuple(y.shape[-2:]) == (H_out, W_out)
```

```
formula output: 16 16
torch output: torch.Size([1, 8, 16, 16])
```

## 6. 자주 하는 실수

### 실수 1. padding을 넣으면 무조건 크기가 유지된다고 생각하기

padding을 넣어도 stride가 2이면 크기가 줄어들 수 있다.

```python
x = torch.randn(1, 3, 32, 32)
conv = nn.Conv2d(3, 8, kernel_size=3, padding=1, stride=2)
y = conv(x)
print(y.shape)  # (1, 8, 16, 16)
```

### 실수 2. height와 width를 따로 확인하지 않기

이미지가 정사각형이 아니면 H와 W가 다르게 변할 수 있다.

```python
x = torch.randn(1, 3, 64, 32)
conv = nn.Conv2d(3, 8, kernel_size=3, padding=1, stride=2)
y = conv(x)
print(y.shape)
```
