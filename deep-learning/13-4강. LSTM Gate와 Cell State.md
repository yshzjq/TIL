RNN은 시퀀스 데이터를 처리할 수 있지만, 긴 시퀀스에서는 앞쪽 정보가 뒤쪽까지 잘 유지되지 않을 수 있다.<br>
LSTM은 이 문제를 완화하기 위해 등장한 구조입니다.

LSTM은 hidden state 외에 **cell state**라는 기억 경로를 추가로 사용한다

## 2. LSTM은 왜 필요한가

RNN은 hidden state 하나에 모든 정보를 담으려고 한다

```
이전 hidden + 현재 입력 → 새로운 hidden
```

반면 LSTM은 다음 두 가지 상태를 사용

| 상태 | 역할 |
| --- | --- |
| hidden state `h_t` | 현재 시점의 출력에 가까운 요약 정보 |
| cell state `c_t` | 오래 유지할 기억을 담는 경로 |

cell state 덕분에 LSTM은 어떤 정보를 오래 유지하고,<br>
어떤 정보를 버릴지 더 세밀하게 조절할 수 있다.

## 3. Gate와 Cell State 직관

LSTM의 gate는 0~1 범위의 비율로 정보를 얼마나 통과시킬지 조절

| 구성 | 직관 |
| --- | --- |
| Forget gate `f_t` | 이전 cell state 중 얼마나 유지할지 정한다. |
| Input gate `i_t` | 새 후보 기억을 얼마나 저장할지 정한다. |
| Candidate `g_t` | 현재 입력과 이전 hidden으로 새 기억 후보를 만든다. |
| Output gate `o_t` | 갱신된 cell state를 hidden으로 얼마나 내보낼지 정한다 |

gate와 후보의 활성화 함수를 먼저 구분

```
i_t = sigmoid(...)   # input gate, 0~1
f_t = sigmoid(...)   # forget gate, 0~1
o_t = sigmoid(...)   # output gate, 0~1
g_t = tanh(...)      # 새 기억 후보, -1~1
```

`i_t`, `f_t`, `o_t`는 0~1 비율을 만드는 gate이고, `g_t`는 gate가 아니라 tanh로 만든 후보 내용이다.<br>
다음 두 줄은 이 값으로 cell과 hidden을 갱신한다
```
c_t = f_t × c_(t-1) + i_t × g_t
h_t = o_t × tanh(c_t)
```

첫 항은 이전 기억 유지, 둘째 항은 새 기억 저장이다.<br> 
`c_t`에서 두 정보를 합친 뒤 output gate가 `h_t`를 만든다

## 4. PyTorch LSTM shape 확인

```python
import torch
import torch.nn as nn

# batch_size=4, sequence_length=6, input_size=3
x = torch.randn(4, 6, 3)

# LSTM layer를 만듭니다.
# RNN과 마찬가지로 batch_first=True를 사용하면 입력 shape는 (batch, seq, feature)입니다.
lstm = nn.LSTM(
    input_size=3,
    hidden_size=8,
    batch_first=True
)

# LSTM은 output과 함께 (h_n, c_n)을 반환합니다.
output, (h_n, c_n) = lstm(x)

print("output:", output.shape)
print("h_n   :", h_n.shape)
print("c_n   :", c_n.shape)
```

출력

```
output: torch.Size([4, 6, 8])
h_n   : torch.Size([1, 4, 8])
c_n   : torch.Size([1, 4, 8])
```

h_n
→ 현재 시점에서 밖으로 드러나는 요약된 정보
→ 다음 layer나 출력 계산에 주로 사용

c_n
→ LSTM 내부에서 오래 기억하려고 유지하는 정보
→ 장기 기억에 더 가까운 역할

`nn.LSTM`은 `batch_first=True`일 때 input과 output을 `(batch, seq, feature)` 순서로 받는다.<br>
그러나 `h_n`, `c_n`의 일반 shape는 모두 `(D × num_layers, batch, hidden_size)`이며 batch_first의 영향을 받지 않는다

## 5. LSTMClassifier 구현하기

기본 예제는 단방향 LSTM입니다. 고정 길이·무패딩이면 마지막 index를 쓰고, 오른쪽 padding이 있으면 `lengths - 1` 위치를 선택한다

```python
import torch
import torch.nn as nn

class LSTMClassifier(nn.Module):
    def __init__(self, input_size, hidden_size, num_classes):
        super().__init__()
        self.lstm = nn.LSTM(
            input_size=input_size,
            hidden_size=hidden_size,
            batch_first=True
        )
        self.fc = nn.Linear(hidden_size, num_classes)

    def forward(self, x, lengths=None):
        output, (h_n, c_n) = self.lstm(x)

        if lengths is None:
            last_hidden = output[:, -1, :]
        else:
            if lengths.dtype not in (
                torch.uint8, torch.int8, torch.int16, torch.int32, torch.int64
            ):
                raise TypeError("lengths는 정수 dtype이어야 합니다.")
            if lengths.ndim != 1 or lengths.size(0) != x.size(0):
                raise ValueError("lengths shape는 (batch,)여야 합니다.")

            lengths = lengths.to(x.device, dtype=torch.long)
            if torch.any(lengths < 1) or torch.any(lengths > x.size(1)):
                raise ValueError("각 length는 1 이상 seq_len 이하여야 합니다.")
            batch_index = torch.arange(x.size(0), device=x.device)
            last_index = lengths - 1
            last_hidden = output[batch_index, last_index]

        return self.fc(last_hidden)

x = torch.randn(4, 6, 3)
model = LSTMClassifier(input_size=3, hidden_size=8, num_classes=2)
logits = model(x)
print(logits.shape)  # torch.Size([4, 2])
```

이 기초 예제는 단방향 LSTM과 오른쪽 padding을 다룬다<br> padding batch에서는 정수 `lengths`로 마지막 유효 시점을 선택한다

## 6. 자주 하는 실수

### 실수 1. LSTM 반환값을 RNN처럼만 받기

LSTM은 `output`과 함께 `(h_n, c_n)`을 반환한다.<br>
즉, 두 번째 반환값 자체가 tuple입니다. 따라서 `output, (h_n, c_n) = lstm(x)`처럼 받아야 hidden state와 cell state를 명확히 확인할 수 있다.
