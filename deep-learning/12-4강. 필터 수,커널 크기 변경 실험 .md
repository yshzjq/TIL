## 1. 이번에 우리가 배울 것

CNN 실험 매트릭스 = CNN의 구조나 하이퍼파라미터를 여러 조건으로 바꿔 실험하고,<br> 그 결과를 비교하기 위해 정리한 표입니다.

기준 모델
→ filter 수 변경
→ kernel 크기 변경
→ 학습 로그 저장
→ 결과 비교

## 2. 실험 가능한 조건

| 조건 | 바꾸면 생기는 변화 |
| --- | --- |
| filter 수 | feature map channel 수와 parameter 수가 변한다. |
| kernel 크기 | 한 번에 보는 주변 영역 크기가 변한다. |
| pooling 횟수 | feature map의 공간 크기가 변한다. |
| learning rate | 학습 속도와 안정성이 변한다. |

## 3. 설정값으로 CNN 만들기

```python
import torch
import torch.nn as nn

class ConfigurableCNN(nn.Module):
    """
    filter 수와 kernel 크기를 설정할 수 있는 CNN입니다.
    실험마다 모델 구조를 조금씩 바꿔 비교할 때 사용합니다.
    """
    def __init__(self, channels1=16, channels2=32, kernel_size=3, num_classes=10):
        super().__init__()

        if kernel_size <= 0 or kernel_size % 2 == 0:
            raise ValueError("공간 크기를 유지하려면 양의 홀수 kernel_size를 사용하세요.")

        # kernel_size가 3이면 padding=1, 5이면 padding=2로 두어 H,W를 유지합니다.
        padding = kernel_size // 2

        self.features = nn.Sequential(
            nn.Conv2d(3, channels1, kernel_size=kernel_size, padding=padding),
            nn.ReLU(),
            nn.MaxPool2d(2),
            nn.Conv2d(channels1, channels2, kernel_size=kernel_size, padding=padding),
            nn.ReLU(),
            nn.MaxPool2d(2),
        )

        self.flatten = nn.Flatten()

        # 입력이 32x32이고 pooling을 두 번 적용하므로 8x8이 됩니다.
        self.classifier = nn.Linear(channels2 * 8 * 8, num_classes)

    def forward(self, x):
        x = self.features(x)
        x = self.flatten(x)
        logits = self.classifier(x)
        return logits
```

## 5. 파라미터 수와 출력 shape 비교하기

```python
def count_parameters(model):
    return sum(p.numel() for p in model.parameters() if p.requires_grad)

images = torch.randn(8, 3, 32, 32)

for cfg in experiment_configs:
    model = ConfigurableCNN(
        channels1=cfg["channels1"],
        channels2=cfg["channels2"],
        kernel_size=cfg["kernel_size"],
        num_classes=10
    )

    logits = model(images)


    # 모델 이름
    print("experiment:", cfg["name"])
    #logits shpae
    print("  logits shape:", logits.shape)
    # 파라미터 개수
    print("  parameters  :", count_parameters(model))
    assert logits.shape == (images.size(0), 10)
```
 logits shape와 parameter 수만 비교

 어느 구조의 분류 성능이 더 좋은지는 아직 알 수 없다

## 6. 실험 결과를 기록할 때 필요한 항목

| 기록 항목 | 이유 |
| --- | --- |
| 실험 이름 | 어떤 조건인지 구분합니다. |
| filter 수 | 모델 폭을 기록합니다. |
| kernel size | local pattern을 보는 범위를 기록합니다. |
| parameter 수 | 모델 크기를 비교합니다. |
| best valid accuracy | 성능을 비교합니다. |
| best valid loss | 안정성을 비교합니다. |

## 7. 자주 하는 실수

### 실수 1. 구조를 여러 개 동시에 바꾸기

filter 수, kernel 크기, learning rate를 동시에 바꾸면 무엇 때문에 성능이 바뀌었는지 알기 어렵다.

### 실수 2. parameter 수를 비교하지 않기

더 좋은 성능이 단순히 모델이 훨씬 커졌기 때문일 수 있다.
