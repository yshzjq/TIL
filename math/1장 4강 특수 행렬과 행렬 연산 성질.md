# 특수 행렬과 행렬 연산 성질

> **행렬의 구조를 알면 계산을 단순하게 만들 수 있다.**<br>
> 행렬곱에서는 **곱하는 순서**, 역행렬에서는 **원래 입력을 유일하게 복원할 수 있는지**가 중요하다.

## 1. 단위행렬과 역행렬

**단위행렬(identity matrix)**은 **주대각선의 원소가 모두 1이고 나머지는 0인 정사각행렬**이다.<br>
**주대각선**은 왼쪽 위에서 오른쪽 아래로 이어지는 대각선을 뜻한다.

<img src="{{ '/assets/images/uploads/math/단위행렬(identity matrix).png' | relative_url }}" alt="대각선 원소가 1이고 나머지가 0인 단위행렬" loading="lazy">

단위행렬은 행렬곱에서 **숫자 1과 같은 역할**을 한다. $A$와 $I$가 같은 크기의 정사각행렬이면:

$$
AI=IA=A
$$

**역행렬 $A^{-1}$**은 $A$와 곱했을 때 단위행렬이 되는 행렬이다.

$$
AA^{-1}=A^{-1}A=I
$$

```python
import numpy as np

I = np.eye(3)  # 3×3 단위행렬
A = np.array([[2, 0, 1], [0, 3, 0], [1, 0, 2]])

check = A @ I  # A와 같은 값
```

**코드의 목적:** `np.eye(3)`으로 단위행렬을 만들고, 곱해도 원래 행렬의 값이 유지되는지 확인한다.<br>
역행렬은 모든 행렬에 존재하지 않으며, 존재 조건은 5절에서 살펴본다.

<br>

## 2. 대각행렬·삼각행렬·대칭행렬

여기서는 **실수로 이루어진 정사각행렬**을 기준으로 설명한다.

| 종류 | 정의 | 예시 |
| --- | --- | --- |
| **대각행렬** | 주대각선 이외의 원소가 모두 0 | `[[1, 0], [0, 2]]` |
| **상삼각행렬** | 주대각선 **아래**의 원소가 모두 0 | `[[1, 2], [0, 3]]` |
| **하삼각행렬** | 주대각선 **위**의 원소가 모두 0 | `[[1, 0], [2, 3]]` |
| **대칭행렬** | 전치해도 같은 행렬: $A=A^T$ | `[[1, 2], [2, 3]]` |

**대각행렬의 대각선 원소는 0이어도 된다.** 단위행렬은 대각선 원소가 모두 1인 특별한 대각행렬이다.<br>
또한 **대각행렬은 상삼각·하삼각·대칭행렬의 조건을 모두 만족**한다.

```python
import numpy as np

diag = np.diag([1, 2, 3])                 # 대각선이 1, 2, 3인 3×3 행렬
upper = np.array([[1, 2], [0, 3]])        # 상삼각행렬
lower = np.array([[1, 0], [2, 3]])        # 하삼각행렬
symmetric = np.array([[1, 2], [2, 3]])    # 대칭행렬

is_symmetric = np.array_equal(symmetric, symmetric.T)  # True
```

**코드의 목적:** 특수 행렬을 만들고, `A.T`로 전치하여 대칭 여부를 확인한다.

- **대각행렬**은 벡터와 곱할 때 각 성분을 해당 대각선 값만큼 곱하므로 계산이 간단하다.
- **삼각행렬**은 0인 부분을 활용해 연립방정식을 순서대로 풀기 좋다.
- **대칭행렬**은 **공분산행렬(여러 특성이 함께 변하는 정도를 담은 행렬)** 등에서 나타난다.

<br>

## 3. 행렬곱은 순서가 중요하다

**비교환성**은 곱하는 순서를 바꾸면 결과가 달라질 수 있다는 성질이다.<br>
숫자 곱셈과 달리 행렬곱은 **일반적으로 $AB=BA$가 성립하지 않는다.** 순서가 바뀌면 내적에 쓰이는 행과 열이 달라지기 때문이다.

```python
import numpy as np

A = np.array([[1, 2], [0, 1]])
B = np.array([[1, 0], [3, 1]])

AB = A @ B  # [[7, 2], [3, 1]]
BA = B @ A  # [[1, 2], [3, 7]]

is_equal = np.array_equal(AB, BA)  # False
```

**코드의 목적:** 같은 두 행렬도 곱하는 순서에 따라 결과가 달라질 수 있음을 확인한다.

> **항상 $AB\ne BA$인 것은 아니다.** 단위행렬처럼 순서를 바꿔도 같은 경우가 있다.<br>
> 행렬 크기에 따라서는 **반대 순서의 곱셈 자체가 불가능**할 수도 있다.

신경망의 층도 순서대로 계산을 적용한다. 따라서 **레이어 순서를 바꾸면 결과가 달라지거나, 입력·출력 크기가 맞지 않아 연결할 수 없게 될 수 있다.**

<br>

## 4. 곱의 전치: 순서를 뒤집는다

행렬곱을 전치하려면 **각 행렬을 전치하고, 곱하는 순서를 뒤집는다.**

$$
(AB)^T=B^T A^T
$$

크기로 확인하면 $A$가 $(m,k)$, $B$가 $(k,n)$일 때 $(AB)^T$는 $(n,m)$이다.<br>
오른쪽도 $B^T$의 $(n,k)$와 $A^T$의 $(k,m)$을 곱하므로 결과가 $(n,m)$으로 맞는다.

```python
import numpy as np

A = np.array([[1, 2], [3, 4]])
B = np.array([[5, 6], [7, 8]])

left = (A @ B).T
right = B.T @ A.T

is_equal = np.array_equal(left, right)  # True
```

**코드의 목적:** 곱을 먼저 전치한 결과와, 순서를 뒤집어 각각의 전치를 곱한 결과가 같은지 확인한다.<br>
**$A^T B^T$로 순서를 유지하면 일반적으로 같은 결과가 아니며**, 크기에 따라 곱셈이 불가능할 수도 있다.

<br>

## 5. 행렬식과 역행렬의 존재 조건

### 행렬식의 계산과 의미

**행렬식(determinant)**은 정사각행렬에서 계산하는 하나의 수이며, $\det(A)$로 쓴다.<br>
**$2\times2$ 행렬**의 행렬식은 다음과 같다.

$$
A=\begin{bmatrix}a&b\\c&d\end{bmatrix}
\quad\Rightarrow\quad
\det(A)=ad-bc
$$

행렬을 공간을 변환하는 규칙으로 보면, **행렬식의 절댓값**은 면적(2차원)이나 부피(3차원)가 **몇 배로 변하는지**를 나타낸다.

- **$\det(A)\ne0$:** 공간의 차원을 유지하므로 **역행렬이 존재**한다.
- **$\det(A)=0$:** 공간이 더 낮은 차원으로 눌려 **역행렬이 존재하지 않는다.** 예를 들어 2차원 평면이 직선이나 한 점으로 압축된다.

행렬식이 0일 때는 행 또는 열벡터들이 **선형 종속(일부 벡터를 다른 벡터들의 조합으로 나타낼 수 있는 상태)**이다.<br>
이를 단순히 “모든 벡터의 방향이 같다”는 뜻으로 해석하면 안 된다.

```python
import numpy as np

A = np.array([[1, 2], [3, 4]])
det_A = np.linalg.det(A)  # 약 -2.0 → 역행렬 존재

singular = np.array([[1, 2], [2, 4]])
det_singular = np.linalg.det(singular)  # 0.0 → 역행렬 없음
```

**코드의 목적:** `np.linalg.det()`로 행렬식을 계산한다. 역행렬이 없는 정사각행렬을 **특이행렬(singular matrix)**이라고 부른다.

### 행렬식이 0이면 왜 되돌릴 수 없을까?

다음 행렬 $A$는 **두 번째 행이 첫 번째 행의 2배**이며, 행렬식은 $1\times4-2\times2=0$이다.

$$
A=\begin{bmatrix}1&2\\2&4\end{bmatrix},\qquad
B=\begin{bmatrix}a&b\\c&d\end{bmatrix}
$$

어떤 행렬 $B$를 오른쪽에 곱해도 결과는 다음과 같다.

$$
AB=\begin{bmatrix}
a+2c&b+2d\\
2(a+2c)&2(b+2d)
\end{bmatrix}
$$

**결과의 두 번째 행도 항상 첫 번째 행의 2배**이다.<br>
하지만 단위행렬 $I$의 두 행 $[1,0]$과 $[0,1]$은 이런 관계가 아니다. 따라서 **어떤 $B$를 곱해도 $AB=I$가 될 수 없다.**

기하학적으로는 **서로 다른 입력이 같은 출력으로 겹쳐져, 출력만 보고 원래 입력을 하나로 결정할 수 없기 때문**이다.

> **수학적 성질과 컴퓨터의 수치 비교를 구분한다.**<br>
> 위 정수 예제의 `np.array_equal()`은 원소가 정확히 같은지 비교한다. 역행렬처럼 실수 연산을 거친 값에는 **부동소수점 오차(수를 근사해 저장·계산하면서 생기는 작은 오차)**가 있을 수 있으므로, 허용 오차 안에서 비교하는 `np.allclose()`를 사용한다.

<br>

## 6. 복습 체크

- **단위행렬의 역할은?** 행렬곱에서 숫자 1처럼 작용하며, $AI=IA=A$이다.
- **대칭행렬의 조건은?** $A=A^T$이다.
- **행렬곱의 순서를 바꿔도 되는가?** 일반적으로 안 된다. 결과가 달라지거나 곱셈이 불가능할 수 있다.
- **곱을 전치하면?** $(AB)^T=B^T A^T$처럼 순서를 뒤집는다.
- **역행렬이 존재하는 조건은?** 정사각행렬에서 $\det(A)\ne0$이어야 한다.
