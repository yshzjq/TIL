# 1. 단위행렬과 역행렬의 관계

### 단위행렬(identity matrix)

<img src="{{ '/assets/images/uploads/math/단위행렬(identity matrix).png' | relative_url }}" alt="대각선 원소가 1이고 나머지가 0인 단위행렬" loading="lazy">

단위행렬 I는 대각선 원소가 모두 1이고 나머지는 0인 정사각행렬


```python
import numpy as np

I = np.eye(3)
A = np.array([[2, 0, 1], [0, 3, 0], [1, 0, 2]])

check = A @ I   # A와 동일
```

# 2. 대각행렬, 삼각행렬, 대칭행렬의 정의와 성질

### 대각행렬

대각행렬(diagonal matrix)은 대각선 이외의 모든 원소가 0인 행렬.<br> 
계산이 간단해서 연산량을 줄이는 데 좋다.

### 대칭행렬

대칭행렬(symmetric matrix)은 자기 자신의 전치와 같은 행렬(A = A^T).<br> 
공분산행렬이 대표적인 대칭행렬의 예

```python
identity = np.eye(3)
diag = np.diag([1, 2, 3])
symmetric = np.array([[1, 2], [2, 3]])

is_symmetric = np.array_equal(symmetric, symmetric.T)  # True
```

# 3. 행렬 곱의 비교환성 AB ≠ BA

숫자의 곱셈과 달리 행렬의 곱셈은 순서를 바꾸면 결과가 달라질 수 있다.<br> 
이를 비교환성(AB ≠ BA)한다

결과가 달라지는 이유는 행렬 곱이 각 행과 열의 내적으로 계산되기 때문에<br> 
곱하는 순서가 바뀌면 서로 다른 행과 열이 곱해지기 때문이다.

```python
A = np.array([[1, 2], [0, 1]])
B = np.array([[1, 0], [3, 1]])

AB = A @ B
BA = B @ A

is_equal = np.array_equal(AB, BA)  # False
```

신경망은 층마다 행렬을 차례로 곱해나가는 구조라서, 층의 순서를 바꾸면<br>
아예 다른 모델이 되기 때문에, 모델 코드에서 레이어를 쌓는 순서가 중요한 이유다


# 4. 전치의 성질: (AB)^T = B^T A^T

두 행렬의 곱을 전치는 각각 전치한 뒤 순서를 바꿔서 곱으로 계산

(AB)^T = B^T A^T

순서를 그대로 유지한 A^T B^T와는 값이 다르다

```python
A = np.array([[1, 2], [3, 4]])
B = np.array([[5, 6], [7, 8]])

left = (A @ B).T
right = B.T @ A.T

is_equal = np.array_equal(left, right)  # True
```

# 5. 역행렬 존재 조건과 행렬식의 직관

행렬식(determinant)은 정사각행렬 하나를 하나의 숫자로 요약한 값

2x2 행렬 A = [[a, b], [c, d]]의 행렬식은 ad - bc로 계산

행렬식이 0이면 방향이 같다는걸 의미 즉 차원이 줄어든다 -> 역행렬을 만들 수 없다.

행렬식이 0이면 그 행렬은 역행렬을 가지지 않는다, 직관적으로는 행렬이 공간을 대표하는 방향이 사라져서(차원이 줄어들어서) 역방향 변환을 만들 수 없다는 뜻이다


```python
A = np.array([[1, 2], [3, 4]])
det_A = np.linalg.det(A)   # -2.0, 0이 아니므로 역행렬 존재

singular = np.array([[1, 2], [2, 4]])
det_singular = np.linalg.det(singular)  # 0.0, 역행렬 없음
```

## 보충 설명

### det(A) = 0일 때 역행렬이 존재하지 않는 이유
<br>

$$
A =
\begin{bmatrix}
1 & 2 \\
2 & 4
\end{bmatrix}
$$

역행렬 $A^{-1}$이 존재하려면 어떤 행렬 $B$가 있어서 다음 식을 만족해야 한다.

$$
AB = I
$$

행렬 $B$를 다음과 같이 둔다

$$
B =
\begin{bmatrix}
a & b \\
c & d
\end{bmatrix}
$$

그러면 $A$와 $B$를 곱하면

$$
\begin{bmatrix}
a+2c & b+2d \\
2a+4c & 2b+4d
\end{bmatrix}
$$

가 된다.

여기서 두 번째 행은 항상 첫 번째 행의 2배이다.

즉, 결과는 항상 다음과 같은 형태가 된다. (x = a + 2a, y = b + 2d)

$$
AB =
\begin{bmatrix}
x & y \\
2x & 2y
\end{bmatrix}
$$

하지만 단위행렬 $I$는

$$
I =
\begin{bmatrix}
1 & 0 \\
0 & 1
\end{bmatrix}
$$

이다.

단위행렬의 두 번째 행 $[0, 1]$은 첫 번째 행 $[1, 0]$의 2배가 아니다.

따라서 어떤 행렬 $B$를 곱하더라도

$$
AB = I
$$

가 될 수 없다.

즉, $AB = I$를 만족하는 행렬 $B$가 존재하지 않으므로 $A$의 역행렬 $A^{-1}$도 존재하지 않는다.

핵심 정리

$$
\boxed{\det(A)=0 \Rightarrow A^{-1}\text{ 없음} \Rightarrow AA^{-1}=I\text{ 불가능}}
$$

det(A) = 0이면 행렬의 행 또는 열이 서로 독립적이지 않아 역행렬을 만들 수 없다.
