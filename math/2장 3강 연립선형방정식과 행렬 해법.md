# 1. 연립방정식의 행렬 표현 $Ax=b$

**방정식 묶음을 행렬로**

여러 개의 선형방정식(연립선형방정식)을 동시에 만족시켜야 할 때,<br> 
각 방정식의 **계수를 행으로 모아** 행렬 $A$를 만들고, 미지수들을 벡터 $x$로, 상수항을 벡터 $b$로 묶으면 $Ax=b$ 형태가 된다

이렇게 표현하면 여러 개의 방정식을 하나의 행렬 연산으로 다룰 수 있어요.

예를 들어 "$2x + y = 5$", "$x - y = 1$"은 $A = [[2,1],[1,-1]]$, $b=[5,1]$로 표현된다


미지수가 3개인데 방정식이 2개밖에 없으면<br>
$A$가 정사각행렬이 아니게 되고, 변수 수가 방정식 수보다 많아져요. 이런 경우 해가 무한히 많거나 아예 없을 수 있어요.

## 2. 가우스 소거법과 역행렬 해법 개요

가우스 소거법은 행렬의 행을 더하거나 빼서 계단 형태로 정리한 다음, 뒤에서부터 차례로 변수를 구하는 방법

역행렬 해법은 $A$가 정사각행렬이고 역행렬 $A^{-1}$이 존재할 때, $x = A^{-1}b$로 해를 바로 구하는 방법

실제 코딩에서는 역행렬을 직접 계산하기보다 np.linalg.solve처럼 더 안정적인 함수를 쓰는 것을 권장

solve는 정사각행렬이고 유일해가 있을 때 사용, 방정식 수가 더 많은 회귀형 문제는 np.linalg.lstsq를 사용하기도 한다


```py
import numpy as np

A = np.array([[2, 1], [1, -1]])
b = np.array([5, 1])

x = np.linalg.solve(A, b)
```

위 코드를 실행하면 $x = [2, 1]$이 나오며, 두 직선의 교점이다

## 3. 해의 3가지 경우: 유일해, 무한해, 해 없음

연립방정식은 $A$와 $b$의 관계에 따라 해가 정확히 하나인 유일해, 해가 무한히 많은 무한해, 해가 전혀 없는 불능의 세 가지 경우 중 하나가 된다

$A$의 rank와 확대행렬 $[A, b]$의 rank를 비교하면 어느 경우인지 판단할 수 있다<br>
둘이 같고 변수 수와도 같으면 유일해, 같지만 변수 수보다 작으면 무한해, 서로 다르면 불능이다

정사각행렬의 경우에는 행렬식(det)이 0이 아니면 유일해가 보장된다(역행렬이 있다)

| 경우 | 조건 | 예시 |
| --- | --- | --- |
| 유일해 | rank(A) = rank([A, b]) = 변수 수 | 두 직선이 한 점에서 만남 |
| 무한해 | rank(A) = rank([A, b]) < 변수 수 | 두 직선이 완전히 겹침 |
| 불능 | rank(A) < rank([A, b]) | 두 직선이 평행하고 만나지 않음 |

det(A)를 계산하지 못하는 직사각행렬이 아닌 경우, <br>
$A$와 확대행렬 $[A, b]$의 rank를 각각 구해서 위 표의 세 가지 조건 중 어느 것에 해당하는지 확인하면 된다


# 4. 선형회귀와 정규방정식


먼저 선형회귀를 이렇게 생각해보자.
$[
A\beta \approx b
]$여기서
- $A$: 데이터
- $\beta$: 우리가 찾고 싶은 회귀계수
- $b$: 실제 정답
- $A\beta$: 모델의 예측값


예를 들어 데이터가 7개인데 직선 하나를 찾는다고 해본다 <BR>
직선은 보통 <BR>


$[
y=\beta_0+\beta_1x
]$

처럼 계수 2개만 있지.
그런데 데이터 점은 7개니까 사실상 7개의 조건을 계수 2개로 맞춰야 하는 상황

미지수는 적은데 방정식은 많음

이런 상황을 **과잉결정(overdetermined)**이라고 한다.

실제 데이터가 완벽하게 한 직선 위에 있지 않다면, 7개 점을 전부 정확하게 통과하는 직선은 거의 없다.

$[
A\beta=b
]$

를 정확히 만족하는 $\beta$가 존재하지 않을 수 있다

그러면 선형회귀에서는
<BR>
전부 정확하게 맞추는 건 불가능하여 전체적으로 가장 덜 틀리는 직선을 찾는다

각 데이터에서

$[
\text{실제값}-\text{예측값}
]$

을 **잔차(residual)**라고 한다

벡터로 쓰면

$[
r=b-A\beta
]$


선형회귀는 이 잔차들의 제곱을 모두 더한 값


$[
\|b-A\beta\|^2
]$

을 가장 작게 만드는 $\beta$를 찾는 거야.


이것이 **최소제곱법**

<BR>

정규방정식은

그 “잔차 제곱합이 가장 작아지는 $\beta$”가 만족하는 식이

$[
A^TA\beta=A^Tb
]$


이걸 **정규방정식(normal equation)**이라고 한다.


그러니까 정규방정식은 새로운 종류의 회귀가 아니라,
최소제곱으로 가장 좋은 $\beta$를 찾기 위해 생기는 방정식


### 왜 $A^TA$를 쓰는 이유

예를 들어 $A$가

$[
7\times2
]$

행렬이 있으면

7개의 데이터, 2개의 변수라는 뜻

그러면

$[
A^T:2\times7
]$

이고,

$[
A^TA
]$

는

$[
(2\times7)(7\times2)=2\times2
]$

가 돼.

즉 $A^TA$는 정사각행렬이 돼.
그래서 조건이 맞으면 역행렬을 이용해


$[
\beta=(A^TA)^{-1}A^Tb
]$

위 식으로 $\beta$를 구한다

단 $A$의 열들이 선형독립이어야 한다

최소제곱법이 목표이고, 정규방정식은 그 목표를 푸는 방법 중 하나이다

“잔차가 위아래로 골고루 남는다”는 건 무슨 말이냐
이 부분도 조금 더 정확히 보면 좋아.
정규방정식을 정리하면
\[
A^T(A\beta-b)=0
\]또는
\[
A^T(b-A\beta)=0
\]이 돼.
잔차를
\[
r=b-A\beta
\]라고 하면
\[
A^Tr=0
\]이야.
이 뜻은:
잔차 벡터가 $A$의 열공간과 직교한다

는 뜻이야.
쉽게 말하면, 우리가 찾은 직선을 더 이쪽저쪽 움직여도 전체 제곱오차를 더 줄일 수 없는 가장 균형 잡힌 위치에 있다는 뜻이야.
다만 “위쪽 잔차와 아래쪽 잔차가 항상 똑같다”는 뜻은 아니야.
특히 절편이 포함된 일반적인 선형회귀에서는 잔차의 합이 0이 되는 성질이 있어서 위아래가 어느 정도 균형을 이루지만, 정규방정식의 더 본질적인 의미는 잔차가 열공간과 직교한다는 거야.
