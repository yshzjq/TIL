# 1. 벡터공간과 선형결합, span

**선형결합(Linear Combination)**<br>
여러 벡터에 각각 스칼라 값을 곱한 뒤 모두 더하는 것.

[
a_1v_1 + a_2v_2 + \cdots + a_nv_n
]

(v_1, v_2, \dots, v_n): 벡터

(a_1, a_2, \dots, a_n): 스칼라 값


집합 안의 두 벡터를 더하거나 스칼라배를 해도 결과가 여전히 그 집합 안에 있어야 한다.


**벡터공간(Vector Space)**<br>
벡터끼리 더하거나 스칼라를 곱해도 그 결과가 계속 그 집합 안에 남아 있는 벡터들의 집합

***span***<br>
주어진 벡터들을 선형결합해서 만들 수 있는 모든 벡터의 집합(span은 2차원 평면 전체)

2차원에서 서로 평행하지 않은 두 벡터라면, 그 두 벡터의 선형결합으로 평면 위의 어떤 점이든 만들 수 있다

```py
import numpy as np

v1 = np.array([1, 0])
v2 = np.array([0, 1])
target = np.array([3, 5])

coeffs, *_ = np.linalg.lstsq(np.array([v1, v2]).T, target, rcond=None)
```

# 2. 선형 독립과 선형 종속

벡터 집합이 선형독립이면 그 중 어떤 벡터도 나머지 벡터들의 선형결합으로 표현할 수 없다는 뜻

반대로 선형종속은 하나 이상의 벡터가 나머지의 선형결합으로 표현되는 경우로, 이는 데이터에 중복된 정보가 있다는 의미한다

```py
import numpy as np

vectors = np.array([[1, 2], [2, 4]])  # 두 번째 벡터가 첫 번째의 2배
rank = np.linalg.matrix_rank(vectors)
```

# 3. 기저와 차원

벡터공간을 생성하는 선형독립인 벡터 집합을 기저라고 한다

기저를 이루는 벡터의 개수를 그 벡터공간의 차원

2차원 평면은 서로 평행하지 않은 두 벡터를 기저로 가질 수 있다.

```py
import numpy as np

basis = np.array([[1, 0], [0, 1]]).T  # 2차원 평면의 표준 기저
dimension = np.linalg.matrix_rank(basis)  # 기저 벡터 개수 = 차원
```

# 4. 열공간, 영공간, rank의 직관

**열공간, 영공간, rank**

행렬의 열벡터들이 만드는 span을 열공간이라고 하고, $Ax=0$을 만족하는 $x$들의 집합을 영공간이라고 해요.<br>
A → 여러 열벡터를 모아놓은 행렬<br>


rank는 열공간의 차원으로, 독립적인 열(특성)의 개수를 의미

데이터 관점에서는, rank가 전체 컬럼 수보다 낮다면 중복되거나 종속적인 특성이 있다는 뜻이다

데이터 행렬의 rank가 낮다는 것은 일부 특성이 다른 특성의 선형결합으로 설명된다는 뜻이다

이런 경우 선형회귀에서는 다중공선성 문제가 발생해 계수 추정이 불안정해질 수 있다

다중공산성 : 여러 특성(feature)들이 서로 너무 비슷한 정보를 가지고 있는 상태 <br>또는 회귀에 사용하는 특성들끼리 서로 너무 강하게 연관되어 있는 상태
