# 연립선형방정식과 행렬 해법

> **$Ax=b$는 여러 방정식을 하나의 행렬 방정식으로 묶은 표현이다.**<br>
> 정확한 해의 존재 여부는 **rank**로 판단하고, 정확히 맞출 수 없는 경우에는 **최소제곱법**으로 오차를 줄인다.

## 1. 연립선형방정식을 $Ax=b$로 표현하기

**선형방정식**은 미지수에 계수를 곱해 더한 값이 상수와 같다는 방정식이다. **연립선형방정식**은 여러 선형방정식을 동시에 만족하는 미지수 값을 찾는 문제이다.

예를 들어 $2x_1+x_2=5$, $x_1-x_2=1$은 다음과 같이 쓸 수 있다.

$$
\underbrace{\begin{bmatrix}2&1\\1&-1\end{bmatrix}}_{A}
\underbrace{\begin{bmatrix}x_1\\x_2\end{bmatrix}}_{x}
=
\underbrace{\begin{bmatrix}5\\1\end{bmatrix}}_{b}
$$

- **$A$:** 각 방정식의 계수를 **행으로 모은 행렬**이다.
- **$x$:** 미지수를 모은 벡터이다.
- **$b$:** 각 방정식의 상수항을 모은 벡터이다.

방정식이 $m$개이고 미지수가 $n$개이면 **$A$의 크기는 $(m,n)$**이다.<br>
2강의 **열공간(열벡터들의 선형결합으로 만들 수 있는 공간)**과 연결하면, **$b$가 $A$의 열공간에 속할 때 정확한 해가 존재**한다.

<br>

## 2. 가우스 소거법과 역행렬 해법

### 가우스 소거법: 해를 유지하며 식 정리하기

**가우스 소거법**은 **확대행렬 $[A\mid b]$**에 기본 행 연산을 적용해 계단 모양으로 정리하는 방법이다.<br>
확대행렬은 $A$의 오른쪽에 상수항 $b$를 열로 붙인 것이다. 다음 연산은 **방정식의 해집합을 바꾸지 않는다.**

1. 두 행을 서로 바꾼다.
2. 한 행에 **0이 아닌 수**를 곱한다.
3. 한 행에 다른 행의 배수를 더한다.

앞의 예시에서 두 번째 행에서 첫 번째 행의 $\frac12$배를 빼면:

$$
\left[\begin{array}{cc|c}2&1&5\\1&-1&1\end{array}\right]
\longrightarrow
\left[\begin{array}{cc|c}2&1&5\\0&-\frac32&-\frac32\end{array}\right]
$$

아래 행에서 $x_2=1$을 구하고, 이를 위 행에 대입하면 $x_1=2$이다.<br>
이렇게 **아래 식부터 위로 올라가며 미지수를 구하는 과정**을 **후진 대입**이라고 한다.

### 역행렬 공식과 실제 코드

$A$가 정사각행렬이고 역행렬이 존재하면 **유일한 해**를 다음과 같이 나타낼 수 있다.

$$
x=A^{-1}b
$$

실제 계산에서는 역행렬을 따로 구하기보다 **`np.linalg.solve(A, b)`로 방정식을 직접 푼다.** 이 함수는 **정사각행렬이면서 역행렬이 존재하는 경우**에 사용한다. [NumPy 공식 문서](https://numpy.org/doc/stable/reference/generated/numpy.linalg.solve.html)

```python
import numpy as np

A = np.array([[2, 1], [1, -1]])
b = np.array([5, 1])

x = np.linalg.solve(A, b)
print(x)                         # [2. 1.]
print(np.allclose(A @ x, b))      # True
```

**코드의 목적:** 미지수 $x_1,x_2$를 구한 뒤 원래 방정식을 만족하는지 확인한다.<br>
`np.allclose()`는 실수 계산에서 생기는 작은 오차를 허용해 비교한다. 이 해는 두 방정식을 나타내는 **두 직선의 교점**이다.

<br>

## 3. 해의 세 가지 경우: rank로 판단하기

**rank(랭크)**는 행렬에 포함된 **선형독립인 열벡터의 최대 개수**이다.<br>
미지수 개수를 $n$이라 할 때, $A$와 확대행렬 $[A\mid b]$의 rank를 비교하면 해의 개수를 알 수 있다.

| 경우 | 조건 | 두 직선으로 보는 예시 |
| --- | --- | --- |
| **유일해** | $\operatorname{rank}(A)=\operatorname{rank}([A\mid b])=n$ | 한 점에서 만남 |
| **무한히 많은 해** | $\operatorname{rank}(A)=\operatorname{rank}([A\mid b])<n$ | 두 직선이 겹침 |
| **해 없음(불능)** | $\operatorname{rank}(A)<\operatorname{rank}([A\mid b])$ | 서로 다른 평행선 |

**$b$를 붙였을 때 rank가 커진다면**, $b$가 기존 열벡터들의 선형결합으로 만들어지지 않는다는 뜻이므로 해가 없다.

> **이 조건은 정사각행렬과 직사각행렬 모두에 적용된다.**<br>
> 정사각행렬에서는 $\det(A)\ne0$이면 유일해가 보장되지만, 직사각행렬에는 행렬식을 적용할 수 없다.

미지수가 3개인데 방정식이 2개라면 $\operatorname{rank}(A)\le2<3$이다.<br>
따라서 **해가 존재하면 무한히 많고, 조건이 서로 모순되면 해가 없다.**

<br>

## 4. 선형회귀와 최소제곱법

### 정확한 해가 없을 때

선형회귀에서는 **$A\beta\approx b$**로 생각할 수 있다.<br>
$A$는 입력 데이터를 정리한 행렬, $\beta$는 찾으려는 **회귀계수**, $b$는 실제 관측값, $A\beta$는 예측값이다.

예를 들어 데이터 7개에 직선 $y=\beta_0+\beta_1x$를 맞추면, **조건은 7개이고 미지수는 절편 $\beta_0$와 기울기 $\beta_1$ 두 개**이다.<br>
이처럼 **방정식 수가 미지수 수보다 많은 경우**를 **과잉결정(overdetermined)**이라고 한다.

**과잉결정이라고 항상 해가 없는 것은 아니다.** 모든 점이 한 직선 위에 있으면 정확히 맞출 수 있다.<br>
하지만 실제 데이터가 한 직선 위에 있지 않다면, 모든 조건을 만족하는 대신 **전체 오차가 가장 작은 직선**을 찾는다.

### 잔차의 제곱합 최소화

**잔차(residual)**는 **실제값에서 예측값을 뺀 값**이다.

$$
r=b-A\beta
$$

**최소제곱법**은 다음 **잔차 제곱합**을 가장 작게 만드는 $\beta$를 찾는 방법이다.

$$
\|b-A\beta\|_2^2=\sum_{i=1}^{m}\bigl(b_i-(A\beta)_i\bigr)^2
$$

각 오차를 제곱하므로 양수와 음수 오차가 서로 상쇄되지 않는다.

### NumPy로 직선 맞추기

```python
import numpy as np

feature_x = np.arange(7, dtype=float)  # 입력값: 0, 1, ..., 6
b = np.array([2, 2, 5, 7, 9, 10, 14])

# 첫 번째 열은 절편용 1, 두 번째 열은 입력값
A = np.column_stack([np.ones_like(feature_x), feature_x])  # (7, 2)
beta = np.linalg.lstsq(A, b, rcond=None)[0]

prediction = A @ beta
residual = b - prediction
print(np.round(beta, 3))  # [1. 2.] → 예측 직선: y = 1 + 2x
```

**코드의 목적:** 7개 데이터의 잔차 제곱합을 최소화하는 절편과 기울기를 구한다.<br>
`np.column_stack()`은 배열을 열로 나란히 모으고, `lstsq(...)[0]`은 반환값 중 회귀계수만 꺼낸다.

**`np.linalg.lstsq()`는 최소제곱해를 구하며, 최소제곱해가 여러 개이면 그중 계수 벡터의 길이가 가장 작은 해를 반환한다.** 정확한 해가 존재하면 잔차를 0으로 만드는 해를 구할 수 있다. [NumPy 공식 문서](https://numpy.org/doc/stable/reference/generated/numpy.linalg.lstsq.html)

<br>

## 5. 정규방정식: 최소제곱해가 만족하는 조건

최소제곱해에서는 **잔차 벡터가 $A$의 열공간과 직교(수직)**한다.<br>
즉, $A$의 각 열벡터와 잔차의 내적이 0이다. 잔차 $r=b-A\beta$를 대입하면:

$$
A^Tr=0
\quad\Longleftrightarrow\quad
A^T(b-A\beta)=0
\quad\Longleftrightarrow\quad
A^TA\beta=A^Tb
$$

마지막 식이 **정규방정식(normal equation)**이다.<br>
핵심은 **제곱오차를 최소화하는 조건**이며, 단순히 행렬을 정사각형으로 만들기 위해 생긴 식이 아니다.

### 역행렬 공식의 조건

앞의 예시에서 $A$가 $(7,2)$이면 $A^TA$는 $(2,2)$이다.<br>
하지만 **정사각행렬이 되었다고 역행렬이 반드시 존재하는 것은 아니다.** $A$의 열들이 선형독립일 때에만 $A^TA$의 역행렬이 존재하며, 다음 공식으로 **유일한 최소제곱해**를 나타낼 수 있다.

$$
\beta=(A^TA)^{-1}A^Tb
$$

열들이 선형종속이면 최소제곱해는 여러 개이며, 위 역행렬 공식을 사용할 수 없다.<br>
실제 코드에서는 $A^TA$와 역행렬을 직접 계산하기보다 **앞의 `np.linalg.lstsq()`를 사용**한다.

### 잔차의 합이 0이라는 뜻

**절편에 해당하는, 모든 원소가 1인 열이 $A$에 포함되어 있으면** $A^Tr=0$에서 다음을 얻는다.

$$
\sum_{i=1}^{m}r_i=0
$$

이는 **양수 잔차와 음수 잔차가 합으로 상쇄된다**는 뜻이다. 양수·음수 잔차의 개수가 같거나 하나씩 같은 크기로 짝을 이룬다는 뜻은 아니다.<br>
절편이 없으면 잔차 합이 0이라는 성질은 일반적으로 보장되지 않는다.

<br>

## 6. 복습 체크

- **$Ax=b$에서 한 행은?** 방정식 하나의 계수이며, $b$에는 해당 상수항이 들어간다.
- **정확한 해가 존재하는 조건은?** $b$가 $A$의 열공간에 속해야 한다.
- **`solve`와 `lstsq`는 언제 쓰는가?** 정사각·가역 행렬의 방정식은 `solve`, 최소제곱 문제는 `lstsq`로 푼다.
- **정규방정식은 무엇인가?** 최소제곱해가 만족하는 $A^TA\beta=A^Tb$이다.
- **정규방정식의 기하학적 의미는?** 잔차가 $A$의 열공간과 직교한다.
