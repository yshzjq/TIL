# 선형 변환의 기하학적 해석

> **행렬곱은 벡터를 회전하거나 늘리고, 뒤집거나 투영하는 변환으로 해석할 수 있다.**<br>
> 신경망에서는 가중치 행렬에 편향과 비선형 활성화가 더해져 복잡한 관계를 표현한다.

## 1. 선형 변환의 정의

**선형 변환(linear transformation)**은 다음 **두 조건을 모든 벡터 $u,v$와 스칼라 $c$에 대해 만족하는 함수** $T$이다.

| 조건 | 수식 | 쉬운 의미 |
| --- | --- | --- |
| **가산성** | $T(u+v)=T(u)+T(v)$ | 먼저 더하고 변환하나, 각각 변환한 뒤 더하나 같다. |
| **동차성** | $T(cu)=cT(u)$ | 먼저 $c$배하고 변환하나, 변환한 뒤 $c$배하나 같다. |

즉, **벡터에 계수를 곱해 더하는 관계를 유지한다.**

$$
T(au+bv)=aT(u)+bT(v)
$$

**선형 변환은 반드시 원점을 원점으로 보낸다:** $T(0)=0$.<br>
하지만 이것만으로 선형이라고 할 수는 없다. 예를 들어 $T(x)=x^2$는 원점을 유지하지만, 일반적으로 $T(2x)=4x^2\ne2T(x)$여서 동차성을 만족하지 않는다.

### 행렬로 표현하기

**유한차원 벡터 공간에서는 입력·출력 공간의 기저를 정하면 모든 선형 변환을 행렬로 표현할 수 있다.**<br>
**기저**는 좌표를 나타내는 기준 벡터들의 집합이다. 평면에서는 보통 $(1,0)$과 $(0,1)$을 사용한다.

이 노트는 **열벡터 표기**를 사용한다. $n$차원 입력을 $m$차원 출력으로 보내는 변환은 다음과 같다.

$$
T(x)=Ax,\qquad A\text{의 크기}:m\times n
$$

**행렬의 각 열은 해당 기저 벡터가 변환된 결과**이다.

```python
import numpy as np

def check_linearity_sample(T, u, v, c):
    additive = np.allclose(T(u + v), T(u) + T(v))
    homogeneous = np.allclose(T(c * u), c * T(u))
    return additive and homogeneous

A = np.array([[2, 0], [0, 1]])
u = np.array([1.0, 2.0])
v = np.array([3.0, -1.0])
print(check_linearity_sample(lambda x: A @ x, u, v, 3.0))  # True
```

**코드의 목적:** 표본에서 가산성과 동차성을 **모두** 확인한다. `@`는 행렬곱이고, `np.allclose`는 계산 오차를 허용해 두 값이 거의 같은지 비교한다.<br>
**몇 개의 표본이 통과했다고 선형성이 증명되는 것은 아니다.** 정의상 모든 입력과 스칼라에서 성립해야 한다.

## 2. 평면에서의 대표적인 선형 변환

다음 변환들은 모두 $2\times2$ 행렬로 표현된다.<br>
**행렬식 $\det(A)$**는 정사각행렬에서 계산하는 수로, 평면에서는 **넓이를 $|\det(A)|$배로 바꾸는 정도**를 나타낸다. 부호가 음수이면 도형의 시계·반시계 방향 배치가 뒤집힌다.

### ① 회전: 원점 중심으로 돌리기

$$
R(\theta)=\begin{bmatrix}
\cos\theta&-\sin\theta\\
\sin\theta&\cos\theta
\end{bmatrix}
$$

양의 $\theta$는 **반시계 방향 회전**이다. $\det(R)=1$이며 길이와 넓이를 유지한다.<br>
예를 들어 $(1,0)$을 $45^\circ$ 회전하면 $(\cos45^\circ,\sin45^\circ)\approx(0.707,0.707)$이다.

### ② 스케일링: 좌표축 방향으로 늘이거나 줄이기

$$
S=\begin{bmatrix}s_x&0\\0&s_y\end{bmatrix},\qquad
\begin{bmatrix}x\\y\end{bmatrix}\longmapsto
\begin{bmatrix}s_xx\\s_yy\end{bmatrix}
$$

$x$성분은 $s_x$배, $y$성분은 $s_y$배가 되어 **넓이는 $|s_xs_y|$배**가 된다.<br>
계수가 음수이면 해당 축 방향이 뒤집히고, 0이면 해당 좌표의 정보가 사라진다.

### ③ 반사: 원점을 지나는 직선을 기준으로 뒤집기

$x$축에 대한 반사는 $y$성분의 부호를 바꾼다.

$$
F=\begin{bmatrix}1&0\\0&-1\end{bmatrix},\qquad
\begin{bmatrix}x\\y\end{bmatrix}\longmapsto
\begin{bmatrix}x\\-y\end{bmatrix}
$$

$\det(F)=-1$이므로 **넓이의 크기는 유지하지만 방향 배치는 뒤집힌다.**<br>
직선에 대한 반사가 선형이려면 **기준 직선이 원점을 지나야 한다.**

### ④ 투영: 낮은 차원의 공간으로 보내기

**투영(projection)**은 벡터를 특정 부분공간 위로 보내는 변환이다. **부분공간**은 원점을 포함하고, 덧셈·스칼라 곱을 해도 그 안에 머무는 공간이다.<br>
$x$축으로의 **직교투영**은 수직으로 내려 $y$성분을 없앤다.

$$
P=\begin{bmatrix}1&0\\0&0\end{bmatrix},\qquad
\begin{bmatrix}x\\y\end{bmatrix}\longmapsto
\begin{bmatrix}x\\0\end{bmatrix}
$$

**낮은 차원의 부분공간으로 투영하면 정보가 사라져 $\det(P)=0$이며, 역행렬이 없다.**<br>
다만 전체 공간에 그대로 투영하는 $P=I$는 항등변환이므로 $\det(I)=1$이다.

## 3. 합성 변환과 행렬곱의 순서

**합성 변환**은 한 변환의 결과에 다른 변환을 이어서 적용하는 것이다.<br>
열벡터 $x$에 **$A$를 먼저, $B$를 나중에 적용하면 전체 행렬은 $BA$**이다.

$$
x\xrightarrow{A}Ax\xrightarrow{B}B(Ax)=(BA)x
$$

**벡터에 가까운 오른쪽 행렬부터 적용한다.** 일반적으로 $AB\ne BA$이므로 순서에 따라 결과가 달라진다.

```python
import numpy as np

theta = np.pi / 4  # 45도: 삼각함수에는 라디안 단위 사용
R = np.array([[np.cos(theta), -np.sin(theta)],
              [np.sin(theta),  np.cos(theta)]])
S = np.array([[2, 0], [0, 1]])  # x축 방향만 2배
x = np.array([1.0, 0.0])

print(np.round(R @ S @ x, 3))  # [1.414 1.414]: 확대 후 회전
print(np.round(S @ R @ x, 3))  # [1.414 0.707]: 회전 후 확대
```

**코드의 목적:** 같은 회전과 확대라도 **순서에 따라 결과가 달라짐**을 확인한다.<br>
앞 강의의 배치 표기 $XW$는 **샘플을 행으로 배치한 방식**이다. 같은 변환을 행벡터로 쓰면 $(Ax)^T=x^TA^T$이므로 곱하는 위치가 달라진다.

## 4. 신경망 레이어와 선형·아핀 변환

완전연결층은 보통 다음처럼 계산한다.

$$
z=Wx+b,\qquad h=\sigma(z)
$$

- **$Wx$:** 입력에 가중치 행렬을 곱하는 **선형 변환**이다.
- **$Wx+b$:** 편향을 더한 **아핀 변환(선형 변환에 평행이동을 더한 변환)**이다. $b\ne0$이면 원점이 $b$로 옮겨져 선형이 아니다.
- **$\sigma$:** 활성화 함수이다. 예를 들어 **ReLU**는 각 성분에 $\max(0,z)$를 적용해 음수를 0으로 만든다.

**비선형 활성화 없이 선형 변환만 쌓으면 하나의 선형 변환과 같다.** 편향을 포함해도 여러 아핀 변환은 하나의 아핀 변환으로 합쳐진다.<br>
따라서 여러 층으로 복잡한 비선형 관계를 표현하려면 **층 사이에 비선형 활성화 함수**가 필요하다.

<br>

## 5. 복습 체크

- **선형 변환의 두 조건은?** 가산성과 동차성이 모든 입력에서 성립해야 한다.
- **$T(0)=0$이면 반드시 선형인가?** 아니다. 원점 보존은 필요조건일 뿐이다.
- **$A$ 다음 $B$를 적용한 행렬은?** 열벡터 표기에서는 $BA$이다.
- **낮은 차원으로 투영하면 왜 되돌릴 수 없는가?** 일부 방향의 정보가 사라지기 때문이다.
- **편향과 비선형 활성화의 역할은?** 편향은 출력의 기준을 옮기고, 비선형 활성화는 비선형 관계를 표현하게 한다.
