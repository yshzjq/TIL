# 벡터의 수학적 정의와 기하학적 해석

## 1. 스칼라, 벡터, 행렬의 정의 및 표기법

스칼라(scalar) : 크기만 가지는 하나의 숫자<br>
벡터(vector) :  벡터는 크기와 방향을 모두 갖는 값<br>
행렬(matrix) : 행렬은 숫자로 이루어진 직사각형 배열

정리하면 스칼라는 0차원, 벡터는 1차원, 행렬은 2차원 형태로 숫자를 담는 그릇

## 2. 벡터의 덧셈과 스칼라 곱

### 벡터의 덧셈

벡터의 덧셈은 같은 위치에 있는 성분끼리 더하는 연산

두 벡터 a = (a1, a2)와 b = (b1, b2)가 있으면 a + b = (a1+b1, a2+b2)로 계산

기하학적으로 벡터 a의 끝에 벡터 b를 이어 붙이면 <br>
도착하는 지점이 a + b, 이를 평행사변형 법칙이라고 한다.

### 스칼라 곱

스칼라 곱은 벡터의 모든 성분에 같은 숫자(스칼라)를 곱하는 연산

c가 스칼라이고 v = (v1, v2)일 때 cv = (cv1, c\*v2)로 계산

기하학적으로 스칼라 곱은 벡터의 길이가 늘어나거나 줄어든다<br>
c가 음수면 방향이 반대로 된다

## 3. 벡터의 크기(노름), 방향, 단위벡터

### 노름(norm)

노름은 벡터의 크기, 길이를 나타낸다

2차원 벡터 v = (v1, v2)의 노름은 피타고라스 정리를 이용해서 계산

```text
||v|| = sqrt(v1^2 + v2^2)
```

일반적인 n차원 벡터에서도 각 성분을 제곱해 더한 뒤 제곱근을 취한다<br>
이를 유클리드 노름(L2 norm)이라고 부른다.

### 단위벡터와 정규화

단위벡터는 노름이 1인 벡터

어떤 벡터든 자기 자신의 노름으로 나누면 방향은 그대로 유지한 채 크기만 1로 만들어 진다, 이 과정을 정규화(normalization)라고 한다

```text
unit_v = v / ||v||
```

#### \* 노름의 종류

일 때

벡터가

$$
x = [-2, 5, -1]
$$

일 때,

### L1 Norm

$$
\|x\|_1 = |-2| + |5| + |-1| = 8
$$

### L2 Norm

$$
\|x\|_2
= \sqrt{(-2)^2 + 5^2 + (-1)^2}
= \sqrt{30}
\approx 5.48
$$

### L∞ Norm

$$
\|x\|_\infty
= \max(2, 5, 1)
= 5
$$

L2 노름 외에도 성분의 절댓값을 그대로 더하는 L1 노름, 가장 큰 성분의 절댓값만 <br>취하는 L∞ 노름 등이 있다

머신러닝에서는 규제(regularization) 기법에 따라 L1, L2 노름을 다르게 사용하기도 한다

## 4. 정규화와 ML 특성 벡터의 의미

머신러닝에서는 하나의 데이터를 여러 특성(feature)으로 이루어진 벡터로 표현

예를 들어 한 사람의 데이터를<br><br>
[나이, 키, 연봉]<br><br>
과 같은 하나의 특성 벡터로 나타낼 수 있다.<br>

나이: 0 \~ 100<br>
키: 100 \~ 200<br>
연봉: 0 \~ 100,000,000

이 상태에서 거리나 크기를 계산하면 값의 범위가 큰 특성(연봉)이 결과에 더 큰 영향을 줄 수 있다.

그래서 정규화나 표준화와 같은 특성 스케일링(feature scaling)​을 사용해 각 특성의 크기 차이를 조정한다.

이렇게 하면 특정 특성의 단위나 숫자 크기 때문에 결과가 지나치게 좌우되는 것을 줄일수 있고, 모델이 여러 특성을 보다 균형 있게 활용할 수 있습니다.
