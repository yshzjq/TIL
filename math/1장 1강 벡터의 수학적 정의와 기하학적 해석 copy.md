# 스칼라, 벡터, 행렬과 노름·정규화

## 1. 스칼라, 벡터, 행렬

### 1-1. 스칼라(Scalar)

스칼라는 **하나의 숫자로 표현되는 값**이다.

예를 들어 다음과 같은 값들이 스칼라이다.

```plain
나이 = 25
온도 = 20
학습률 = 0.001
```

수학에서는 보통 소문자로 표현한다.

[
a = 3
]




### 1-2. 벡터(Vector)

벡터는 **여러 개의 숫자를 한 줄로 모아 표현한 값**이다.

기하학적으로는 **크기와 방향을 가지는 값**으로 생각할 수 있다.

예를 들어,

[
\mathbf{v} =
\begin{bmatrix}
3 \
4
\end{bmatrix}
]

는 2개의 성분을 가진 2차원 벡터이다.

머신러닝에서는 하나의 데이터를 여러 개의 특성으로 표현할 때 벡터를 많이 사용한다.

```plain
[나이, 키, 몸무게]
[25, 175, 70]
```




### 1-3. 행렬(Matrix)

행렬은 **숫자를 행(row)과 열(column)의 직사각형 형태로 배열한 것**이다.

예를 들어,

[
A =
\begin{bmatrix}
1 & 2 \
3 & 4 \
5 & 6
\end{bmatrix}
]

는

- 행(row): 3개
- 열(column): 2개

를 가진 `3 × 2` 행렬이다.

머신러닝에서는 여러 개의 데이터를 한 번에 표현할 때 행렬을 자주 사용한다.

```plain
[
    [25, 175, 70],
    [30, 180, 80],
    [22, 165, 55]
]
```

각 행을 하나의 데이터라고 생각할 수 있다.




### 정리

| 종류 | 형태 | 예 |
| --- | --- | --- |
| 스칼라 | 하나의 숫자 | `3` |
| 벡터 | 숫자의 1차원 배열 | `[1, 2, 3]` |
| 행렬 | 숫자의 2차원 배열 | `[[1, 2], [3, 4]]` |

NumPy와 같은 배열 관점에서 단순하게 생각하면 다음과 같다.

```plain
스칼라 → 0차원
벡터   → 1차원
행렬   → 2차원
```

> 단, 수학적인 벡터와 행렬의 개념은 단순히 배열의 차원만을 의미하는 것은 아니다.
> 처음 배울 때는 위와 같이 이해하면 편하다.




# 2. 벡터의 덧셈과 스칼라 곱

## 2-1. 벡터의 덧셈

벡터의 덧셈은 **같은 위치에 있는 성분끼리 더하는 연산**이다.

두 벡터

[
\mathbf{a} = (a_1, a_2)
]

[
\mathbf{b} = (b_1, b_2)
]

가 있다면,

(a_1+b_1,;a_2+b_2)
]

로 계산한다.

### 예시

[
\mathbf{a}=(2,3)
]

[
\mathbf{b}=(4,1)
]

이라면,

# (2+4,;3+1)

(6,4)
]

이다.




### 기하학적 의미

벡터 `a`의 끝에 벡터 `b`의 시작점을 이어 붙이면, 처음 위치에서 최종 위치까지의 벡터가 `a + b`가 된다.

이를 \*\*삼각형 법칙(Triangle Rule)\*\*이라고 한다.

또한 두 벡터를 같은 시작점에서 그린 뒤 평행사변형을 만들면, 그 평행사변형의 대각선이 `a + b`가 된다.

이를 \*\*평행사변형 법칙(Parallelogram Rule)\*\*이라고 한다.




## 2-2. 스칼라 곱

스칼라 곱은 **벡터의 모든 성분에 같은 숫자를 곱하는 연산**이다.

스칼라 `c`와 벡터

[
\mathbf{v}=(v_1,v_2)
]

가 있다면,

(cv_1,;cv_2)
]

로 계산한다.

### 예시

[
\mathbf{v}=(2,3)
]

이고

[
c=2
]

라면,

(4,6)
]

이 된다.




### 기하학적 의미

스칼라 곱을 하면 벡터의 **길이와 경우에 따라 방향이 변한다.**

- `|c| > 1` → 벡터가 길어진다.
- `0 < |c| < 1` → 벡터가 짧아진다.
- `c < 0` → 벡터의 방향이 반대로 바뀐다.
- `c = 0` → 영벡터가 된다.

예를 들어,

[
\mathbf{v}=(2,1)
]

이라면,

[
2\mathbf{v}=(4,2)
]

는 같은 방향으로 길이가 2배가 되고,

[
-\mathbf{v}=(-2,-1)
]

은 크기는 같지만 방향이 반대가 된다.




# 3. 벡터의 크기, 노름, 단위벡터

## 3-1. 노름(Norm)

노름은 **벡터의 크기 또는 길이를 수치로 나타내는 방법**이다.

2차원 벡터

[
\mathbf{v}=(v_1,v_2)
]

의 일반적인 길이는 피타고라스 정리를 이용하여 계산한다.

\sqrt{v_1^2+v_2^2}
]

예를 들어,

[
\mathbf{v}=(3,4)
]

라면,

# \sqrt{3^2+4^2}

# \sqrt{25}

5
]

이다.

일반적인 `n`차원 벡터에서도 각 성분을 제곱하여 더한 후 제곱근을 구한다.

\sqrt{x_1^2+x_2^2+\cdots+x_n^2}
]

이를 \*\*L2 Norm 또는 유클리드 노름(Euclidean Norm)\*\*이라고 한다.




## 3-2. 단위벡터(Unit Vector)

단위벡터는 **노름이 1인 벡터**이다.

[
|\mathbf{u}|=1
]

예를 들어,

[
\mathbf{v}=(3,4)
]

의 크기는

[
|\mathbf{v}|=5
]

이므로 벡터를 자신의 노름으로 나누면

\left(
\frac{3}{5},
\frac{4}{5}
\right)
]

가 된다.

새로운 벡터의 노름은

[
\sqrt{
\left(\frac{3}{5}\right)^2
+
\left(\frac{4}{5}\right)^2
}
=1
]

이다.

즉, 원래 벡터의 **방향은 유지하면서 길이만 1로 만든 것**이다.




## 3-3. 정규화(Normalization)

벡터를 자신의 노름으로 나누어 길이를 1로 만드는 과정을 \*\*정규화(normalization)\*\*라고 한다.

\frac{\mathbf{v}}{|\mathbf{v}|}
]

정규화 전:

```plain
v = [3, 4]
길이 = 5
```

정규화 후:

```plain
unit_v = [0.6, 0.8]
길이 = 1
```

따라서 정규화의 핵심은

> **벡터의 방향은 유지하고 크기만 1로 만드는 것**

이라고 이해할 수 있다.




# 4. 노름의 종류

벡터

[
\mathbf{x}=[-2,5,-1]
]

이 있다고 하자.

## 4-1. L1 Norm

각 성분의 **절댓값을 모두 더한다.**

|-2|+|5|+|-1|
]

[
=2+5+1=8
]

따라서,

[
\boxed{|\mathbf{x}|_1=8}
]




## 4-2. L2 Norm

각 성분을 **제곱하여 더한 후 제곱근을 구한다.**

\sqrt{(-2)^2+5^2+(-1)^2}
]

# [

# \sqrt{4+25+1}

\sqrt{30}
\approx5.48
]

따라서,

[
\boxed{|\mathbf{x}|_2\approx5.48}
]

L2 Norm은 우리가 일반적으로 생각하는 **직선거리 또는 벡터의 길이**와 대응한다.




## 4-3. L∞ Norm

각 성분의 절댓값 중 **가장 큰 값**을 선택한다.

\max(2,5,1)
]

따라서,

[
\boxed{|\mathbf{x}|_{\infty}=5}
]




### 노름 비교

| Norm | 계산 방법 | 결과 |
| --- | --- | --- |
| L1 | 절댓값을 모두 더함 | `8` |
| L2 | 제곱합의 제곱근 | `≈ 5.48` |
| L∞ | 가장 큰 절댓값 | `5` |

머신러닝에서는 손실 함수나 **규제(regularization)** 등에 따라 L1과 L2 Norm이 사용될 수 있다.

대표적으로,

- **L1 규제**: 일부 가중치를 0에 가깝게 만드는 경향
- **L2 규제**: 큰 가중치가 지나치게 커지는 것을 억제하는 경향

이 있다.




# 5. 머신러닝에서 특성 벡터의 의미

머신러닝에서는 하나의 데이터를 여러 개의 \*\*특성(feature)\*\*으로 표현한다.

예를 들어 한 사람의 데이터를 다음과 같이 나타낼 수 있다.

```plain
[나이, 키, 연봉]
```

실제 값이

```plain
[25, 175, 40,000,000]
```

이라면 하나의 데이터가 3개의 특성을 가진 벡터로 표현된 것이다.

이를 \*\*특성 벡터(feature vector)\*\*라고 한다.




# 6. 특성의 크기가 서로 다른 경우

각 특성의 값 범위를 생각해 보면 다음과 같이 큰 차이가 있을 수 있다.

| 특성 | 대략적인 범위 |
| --- | --- |
| 나이 | 0 \~ 100 |
| 키 | 100 \~ 200 |
| 연봉 | 0 \~ 100,000,000 |

예를 들어,

```plain
사람 A = [25, 170, 30,000,000]
사람 B = [26, 171, 50,000,000]
```

와 같은 데이터가 있다고 하자.

숫자의 크기를 보면 연봉 값이 나이와 키보다 압도적으로 크다.

따라서 거리 기반 계산이나 일부 머신러닝 알고리즘에서는 **연봉이라는 특성이 결과에 지나치게 큰 영향을 줄 수 있다.**




# 7. 특성 스케일링(Feature Scaling)

이러한 문제를 줄이기 위해 각 특성의 숫자 범위를 조정하는 과정을 \*\*특성 스케일링(feature scaling)\*\*이라고 한다.

대표적인 방법으로 다음이 있다.

### Min-Max Scaling

값을 일정한 범위로 변환한다.

일반적으로 다음과 같이 `0 ~ 1` 범위로 맞춘다.

```plain
나이 → 0 ~ 1
키   → 0 ~ 1
연봉 → 0 ~ 1
```




### Standardization

각 특성의 평균과 표준편차를 이용하여 값을 변환한다.

변환 후 데이터가 대략

```plain
평균 ≈ 0
표준편차 ≈ 1
```

이 되도록 만든다.




## 벡터 정규화와 특성 스케일링의 차이

`Normalization`이라는 표현이 여러 의미로 사용되기 때문에 구분할 필요가 있다.

### 벡터 정규화

하나의 벡터 전체를 자신의 노름으로 나눈다.

[
\frac{\mathbf{x}}{|\mathbf{x}|}
]

목적:

> **벡터의 방향은 유지하고 길이를 1로 만든다.**




### 특성 스케일링

데이터셋의 각 특성(column)의 값 범위를 조정한다.

```plain
           나이       키       연봉
사람 A      25       170     3000만
사람 B      35       180     5000만
사람 C      45       175     7000만
           ↓         ↓         ↓
       각 특성별로 크기를 조정
```

목적:

> **특성마다 숫자의 범위가 다른 문제를 줄여 모델이 여러 특성을 균형 있게 활용할 수 있도록 한다.**

따라서 **벡터의 길이를 1로 만드는 정규화**와 **각 특성의 값 범위를 조정하는 특성 스케일링**은 서로 관련은 있지만 같은 개념은 아니다.




# 8. 전체 흐름 정리

```plain
스칼라
↓
하나의 숫자

벡터
↓
여러 숫자를 한 줄로 표현
↓
벡터 덧셈 / 스칼라 곱
↓
벡터의 크기 = Norm
↓
L1 / L2 / L∞
↓
벡터를 Norm으로 나누기
↓
단위벡터
↓
벡터 정규화
```

머신러닝에서는 다음과 같이 연결된다.

```plain
하나의 데이터
↓
여러 Feature로 표현
↓
Feature Vector
↓
Feature마다 숫자 범위가 크게 다를 수 있음
↓
거리나 학습 결과가 특정 Feature에 지나치게 영향받을 수 있음
↓
Feature Scaling 사용
↓
여러 Feature의 크기 차이를 조정
```




## 핵심 요약

> **스칼라**는 하나의 숫자이고, **벡터**는 여러 숫자를 모은 값이며, **행렬**은 벡터 여러 개를 행과 열 형태로 모은 구조라고 볼 수 있다.

> \*\*노름(Norm)\*\*은 벡터의 크기를 측정하는 방법이며, 대표적으로 L1, L2, L∞ Norm이 있다.

> 벡터를 자신의 노름으로 나누면 방향은 유지하면서 길이가 1인 **단위벡터**를 만들 수 있으며, 이를 벡터 **정규화**라고 한다.

> 머신러닝에서는 하나의 데이터를 여러 특성으로 구성된 **특성 벡터**로 표현하며, 특성마다 값의 범위가 크게 다르면 특정 특성이 계산에 지나치게 큰 영향을 줄 수 있다.

> 이러한 문제를 줄이기 위해 **Min-Max Scaling, Standardization 등의 Feature Scaling**을 사용하여 특성들의 숫자 크기를 조정한다.
