# 벡터의 수학적 정의와 기하학적 해석

## 1. 내적(dot product)의 정의와 계산법

**내적이란**

내적(dot product)은 두 벡터의 같은 위치 성분끼리 곱한 뒤 모두 더하는 연산

```
a · b = a1*b1 + a2*b2 + ... + an*bn
```

내적의 결과는 벡터가 아니라 하나의 스칼라 값

import numpy as np

```
a = np.array([1, 2, 3])
b = np.array([4, 5, 6])

dot = np.dot(a, b)   # 32
dot2 = a @ b          # 32, 동일한 결과
```

## 2. 내적과 각도: cosθ = a·b / (|a||b|)

두 벡터 a, b 사이의 각도를 θ라고 하면

```
a · b = |a| * |b| * cos(θ)
```

이 식을 각도에 대해 정리하면 코사인 값을 구할 수 있다

```
cos(θ) = (a · b) / (|a| * |b|)
```

내적은 두 벡터 크기의 곱으로 나누면 두 벡터가 이루는 각도의 코사인 값(코사인 유사도)이다.


## 3. 코사인 유사도의 값 해석

코사인 유사도는 항상 -1과 1 사이의 값을 가진다

값이 클수록 두 벡터의 방향이 비슷하다는 의미

## 4. 임베딩 공간에서 유사도 검색이 동작하는 방식

텍스트나 이미지를 숫자 벡터로 변환한 것을 임베딩(embedding)

임베딩 공간에서는 의미가 비슷한 대상일수록 벡터의 방향이 비슷하게 학습된다

어떤 질문으로 인해 벡터와 코사인 유사도가 가장 높은 문서 벡터들을 찾으면,<br> 그것이 곧 질문과 가장 관련 있는 문서가 된다 <br>
이 원리가 검색 엔진과 추천 시스템의 핵심이다

## 5. 딥러닝에서 내적이 가중합·유사도 계산으로 쓰이는 맥락

완전연결층에서 입력과 가중치의 곱을 모두 더하는 가중합 계산도 내적이다


트랜스포머의 어텐션 메커니즘에서도 쿼리(query)와 키(key) 벡터의 내적으로 두 위치가 얼마나 관련 있는지를 계산

내적은 딥러닝 전반에서 두 벡터의 관계를 수치화하는 핵심 연산으로 반복해서 등장한다

### - 코사인 유사도와 유클리드 거리 차이

코사인 유사도는 두 벡터의 방향이 얼마나 비슷한지만 보고, 벡터의 크기는 신경 쓰지 않는다.

유클리드 거리는 두 벡터 사이의 실제 위치 차이를 측정하기 때문에 크기 차이에도 영향을 받는다

만약 문서 길이처럼 크기가 들쭉날쭉한 데이터를 비교할 때는 코사인 유사도가 더 안정적으로 쓰인다

## 추가

완전연결층(Fully Connected Layer)은 신경망에서 앞쪽의 모든 입력값이 뒤쪽의 모든 뉴런과 연결되어 있는 층, Dense Layer라고도 부른다

```
x1 ─────┬──→ 뉴런 1
        └──→ 뉴런 2

x2 ─────┬──→ 뉴런 1
        └──→ 뉴런 2

x3 ─────┬──→ 뉴런 1
        └──→ 뉴런 2 
```

모든 입력 x1, x2, x3가 모든 뉴런에 연결되어 있기 때문에 완전연결(Fully Connected)라고 한다.
