# 내적과 코사인 유사도

> **내적은 두 벡터의 크기와 방향을 함께 반영하고, 코사인 유사도는 방향의 유사성을 비교한다.**

## 1. 내적의 정의와 계산

**내적(dot product)**은 두 벡터의 **같은 위치 성분끼리 곱한 뒤 모두 더하는 연산**이다.<br>
이 노트에서는 **성분 수가 같은 실수 벡터**를 다루며, 내적의 결과는 벡터가 아닌 **스칼라(하나의 수)**이다.

$$
\mathbf{a}\cdot\mathbf{b} = \sum_{i=1}^{n} a_i b_i = a_1b_1 + a_2b_2 + \cdots + a_nb_n
$$

$n$은 성분의 개수이며, $\sum$는 각 항을 모두 더한다는 기호이다.

```python
import numpy as np

a = np.array([1, 2, 3])
b = np.array([4, 5, 6])

dot = np.dot(a, b)  # 1*4 + 2*5 + 3*6 = 32
dot2 = a @ b       # 32
```

**코드의 목적:** 두 벡터의 내적을 계산한다. **1차원 배열**에서는 `np.dot(a, b)`와 `a @ b`가 같은 내적을 구한다.

<br>

## 2. 내적에서 코사인 유사도로

### 벡터의 길이와 각도

벡터의 **길이(크기)**는 $\|\mathbf{a}\|$로 쓰며, 다음과 같이 계산한다.

$$
\|\mathbf{a}\| = \sqrt{a_1^2 + a_2^2 + \cdots + a_n^2}
$$

두 벡터가 모두 **영벡터(모든 성분이 0인 벡터)가 아닐 때**, 두 벡터 사이의 각도 $\theta$와 내적은 다음 관계를 갖는다.

$$
\mathbf{a}\cdot\mathbf{b} = \|\mathbf{a}\|\|\mathbf{b}\|\cos\theta
$$

**내적이 크다고 방향이 더 비슷하다고 단정할 수 없다.** 벡터의 길이가 커져도 내적이 커질 수 있기 때문이다.<br>
내적을 두 벡터 길이의 곱으로 나누어 크기의 영향을 제거한 값이 **코사인 유사도(cosine similarity)**이다.

$$
\operatorname{cos\_sim}(\mathbf{a},\mathbf{b}) = \frac{\mathbf{a}\cdot\mathbf{b}}{\|\mathbf{a}\|\|\mathbf{b}\|} = \cos\theta
$$

> **영벡터가 포함되면 코사인 유사도는 정의되지 않는다.** 분모가 0이 되고, 영벡터의 방향도 정해지지 않기 때문이다.

### 계산 예시

$\mathbf{a}=[1,2]$, $\mathbf{b}=[3,4]$일 때:

$$
\mathbf{a}\cdot\mathbf{b}=1\times3+2\times4=11,\qquad
\|\mathbf{a}\|=\sqrt{5},\quad \|\mathbf{b}\|=5
$$

$$
\operatorname{cos\_sim}(\mathbf{a},\mathbf{b}) = \frac{11}{5\sqrt{5}} \approx 0.984
$$

**1에 가까우므로 두 벡터의 방향이 비슷하다.** 내적 $11$과 코사인 유사도 $0.984$는 서로 다른 값이다.

### 값 해석

코사인 유사도의 범위는 **$-1$ 이상 $1$ 이하**이다. 값이 클수록 두 벡터 사이의 각도가 작다.

| 코사인 유사도 | 각도 | 기하학적 의미 |
| --- | --- | --- |
| $1$ | $0^\circ$ | 같은 방향 |
| $0$ | $90^\circ$ | 직교(서로 수직) |
| $-1$ | $180^\circ$ | 반대 방향 |

### NumPy로 계산하기

```python
import numpy as np

a = np.array([1, 2])
b = np.array([3, 4])
norm_a = np.linalg.norm(a)
norm_b = np.linalg.norm(b)

if norm_a == 0 or norm_b == 0:
    raise ValueError("영벡터의 코사인 유사도는 정의되지 않습니다.")

cos_sim = (a @ b) / (norm_a * norm_b)
print(round(cos_sim, 3))  # 0.984
```

**코드의 목적:** 내적을 두 벡터 길이의 곱으로 나누어 코사인 유사도를 구한다.<br>
`np.linalg.norm()`은 여기서 벡터의 길이를 계산하며, `if`문은 영벡터로 인해 0으로 나누는 것을 막는다.

<br>

## 3. 코사인 유사도와 유클리드 거리

**유클리드 거리**는 같은 시작점에서 그린 두 벡터의 끝점 사이의 **직선 거리**이다.

$$
d(\mathbf{a},\mathbf{b}) = \|\mathbf{a}-\mathbf{b}\| = \sqrt{\sum_{i=1}^{n}(a_i-b_i)^2}
$$

| 구분 | 코사인 유사도 | 유클리드 거리 |
| --- | --- | --- |
| 비교 기준 | 방향이 얼마나 비슷한가 | 두 점이 얼마나 가까운가 |
| 크기의 영향 | 길이가 달라도 방향이 같으면 같은 값 | 크기 차이에도 영향을 받음 |
| 더 유사하거나 가까운 쪽 | 값이 클수록 | 값이 작을수록 |

예를 들어 $[1,2]$와 $[2,4]$는 같은 방향이므로 **코사인 유사도는 1**이다.<br>
하지만 끝점은 다르므로 **유클리드 거리는 $\sqrt{5}$**이다.

문서의 단어 출현 횟수처럼 **크기 차이를 제외하고 구성 비율을 비교하고 싶을 때** 코사인 유사도가 유용하다. 다만 **벡터 크기 자체가 중요한 정보라면** 다른 척도가 더 적합할 수 있다.

<br>

## 4. 임베딩을 이용한 유사도 검색

**임베딩(embedding)**은 텍스트나 이미지의 특징을 숫자 벡터로 표현한 것이다.<br>
유사도 검색용 모델은 의미가 비슷한 대상이 벡터 공간에서 가깝거나 비슷한 방향을 갖도록 학습한다.

코사인 유사도를 사용하는 검색은 다음 순서로 진행된다.

1. 질문과 문서를 **같은 임베딩 공간**의 벡터로 변환한다.
2. 질문 벡터와 각 문서 벡터의 **코사인 유사도**를 계산한다.
3. 유사도가 높은 문서를 **관련 문서의 후보**로 가져온다.

예를 들어 “비밀번호를 잊었어요”라는 질문에 “계정 비밀번호 재설정 방법” 문서가 높은 유사도를 보일 수 있다. 이런 방식은 **의미 기반 검색과 추천 시스템**에 활용된다.

> **유사도가 높다고 정답 문서임이 보장되지는 않는다.** 검색 결과는 모델과 데이터에 따라 달라진다.<br>
> 또한 코사인 유사도 $0$은 **직교**, $-1$은 **반대 방향**이라는 뜻이며, 이를 곧바로 “의미가 무관함”이나 “반대말”로 해석하면 안 된다.

<br>

## 5. 딥러닝에서 내적이 쓰이는 곳

### 완전연결층: 입력의 가중합

**완전연결층(Fully Connected Layer, Dense Layer)**은 모든 입력이 해당 층의 모든 뉴런에 연결된 층이다.<br>
각 **뉴런(입력을 받아 계산하는 단위)**은 자신의 **가중치(각 입력에 곱하는 계수)**를 사용해 다음 값을 구한다.

$$
z = \mathbf{w}\cdot\mathbf{x}+b = w_1x_1+w_2x_2+\cdots+w_nx_n+b
$$

$\mathbf{x}$는 입력, $\mathbf{w}$는 가중치 벡터이며, $b$는 **편향(가중합에 더하는 값)**이다.<br>
즉, **입력의 가중합을 계산하는 부분이 내적**이다. 예를 들어 입력 3개와 뉴런 2개가 있다면, 두 뉴런 모두 입력 3개를 각각의 가중치로 계산한다.

### 어텐션: 어떤 정보에 주목할지 계산

트랜스포머의 **어텐션(attention)**은 입력의 여러 위치 중 어디에 얼마나 주목할지 정하는 계산이다.<br>
**쿼리(query)**는 찾으려는 정보를, **키(key)**는 비교할 대상의 특징을 나타내는 벡터로 이해할 수 있다.

일반적인 어텐션에서는 쿼리 $\mathbf{q}$와 키 $\mathbf{k}$의 내적을 다음과 같이 조정해 관련성 점수로 사용한다.

$$
\text{점수} = \frac{\mathbf{q}\cdot\mathbf{k}}{\sqrt{d_k}}
$$

$d_k$는 키 벡터의 성분 수이다. $\sqrt{d_k}$로 나누어 차원이 커질 때 점수의 크기를 조절하고, 여러 점수에 **소프트맥스(합이 1인 양수 가중치로 바꾸는 함수)**를 적용해 정보를 섞을 비중을 구한다.

**이 점수는 코사인 유사도와 다르다.** 두 벡터의 길이의 곱으로 나누는 계산이 아니기 때문이다.

<br>

## 6. 복습 체크

- **내적의 결과는?** 하나의 스칼라이며, 벡터의 크기와 방향을 함께 반영한다.
- **코사인 유사도는?** 내적을 두 벡터 길이의 곱으로 나눈 값이다. 영벡터에는 정의되지 않는다.
- **유사도 1이면 같은 벡터인가?** 같은 방향이라는 뜻이다. 길이는 다를 수 있다.
- **딥러닝에서 어디에 쓰이는가?** 완전연결층의 가중합과 어텐션의 관련성 점수 계산에 내적이 쓰인다.
