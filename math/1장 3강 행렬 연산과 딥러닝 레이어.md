# 행렬 연산과 딥러닝 레이어

> **행렬곱은 여러 내적을 한 번에 계산하는 연산이다.**<br>
> 딥러닝에서는 여러 입력을 행렬로 묶고, **가중치와의 행렬곱에 편향을 더해** 출력을 계산한다.

## 1. 행렬의 정의와 기본 연산

**행렬(matrix)**은 수를 **행(가로)과 열(세로)**로 배치한 것이다.<br>
행이 $m$개, 열이 $n$개이면 **$m\times n$ 행렬**이며, NumPy에서는 `shape`가 `(m, n)`이다.

- **행렬의 덧셈:** 같은 위치의 원소끼리 더한다. 기본적으로 두 행렬의 **행과 열의 개수가 각각 같아야 한다.**
- **스칼라 곱:** 행렬의 **모든 원소에 같은 수(스칼라)를 곱한다.**

```python
import numpy as np

A = np.array([[1, 2], [3, 4]])
B = np.array([[5, 6], [7, 8]])

add_result = A + B      # [[6, 8], [10, 12]]
scalar_result = 2 * A   # [[2, 4], [6, 8]]
```

**코드의 목적:** 행렬의 덧셈과 스칼라 곱을 계산한다. 두 연산 모두 결과의 `shape`는 원래 행렬과 같은 `(2, 2)`이다.<br>
NumPy에서는 **브로드캐스팅** 규칙에 따라 모양이 다른 배열도 더할 수 있다. 이 규칙은 뒤에서 편향을 더할 때 살펴본다.

<br>

## 2. 행렬곱: 행과 열의 내적

### 곱셈이 가능한 조건

$A$의 크기가 $(m,k)$, $B$의 크기가 $(k,n)$이면 결과 $AB$의 크기는 $(m,n)$이다.

$$
\underbrace{A}_{m\times k}\underbrace{B}_{k\times n}
= \underbrace{AB}_{m\times n}
$$

**앞 행렬의 열 개수와 뒤 행렬의 행 개수가 같아야 한다.**<br>
결과의 $(i,j)$ 원소는 **$A$의 $i$번째 행과 $B$의 $j$번째 열의 내적**이다.

$$
(AB)_{ij}=\sum_{t=1}^{k} A_{it}B_{tj}
$$

$\sum$는 각 항을 모두 더한다는 뜻이다. 공통 차원 $k$에 해당하는 성분을 곱해 더하므로, 결과의 크기에는 $m$과 $n$만 남는다.<br>
여기서 내적에 필요한 조건은 두 벡터의 **성분 수가 같다는 것**이며, 벡터의 크기까지 같을 필요는 없다.

### 계산 예시

```python
import numpy as np

A = np.array([[1, 2, 3], [4, 5, 6]])    # shape: (2, 3)
W = np.array([[1, 0], [0, 1], [1, 1]])  # shape: (3, 2)

result = A @ W                          # shape: (2, 2)
print(result)
# [[ 4  5]
#  [10 11]]
```

**코드의 목적:** `@`로 행렬곱을 계산한다.<br>
첫 번째 결과 원소 $4$는 $A$의 첫 번째 행 $[1,2,3]$과 $W$의 첫 번째 열 $[1,0,1]$의 내적이다.

$$
1\times1+2\times0+3\times1=4
$$

> **NumPy에서 `A @ B`는 행렬곱, `A * B`는 원소별 곱이다.**<br>
> 원소별 곱은 대응하는 원소끼리 곱하며, 두 배열의 모양이 같거나 브로드캐스팅이 가능해야 한다.<br>
> 또한 **행렬곱은 순서가 중요하다.** 일반적으로 $AB\ne BA$이며, 순서를 바꾸면 곱셈 자체가 불가능할 수도 있다.

<br>

## 3. 전치행렬과 역행렬

### 전치행렬: 행과 열 바꾸기

**전치행렬(transpose)**은 행과 열을 서로 바꾼 행렬이며, $A^T$로 쓴다.<br>
$A$가 $(m,n)$이면 $A^T$는 $(n,m)$이다. NumPy에서는 `A.T`로 구한다.

### 역행렬: 행렬의 작용 되돌리기

정사각행렬 $A$에 대해 다음 관계를 만족하는 행렬 $A^{-1}$을 **역행렬(inverse matrix)**이라고 한다.

$$
AA^{-1}=A^{-1}A=I
$$

**정사각행렬**은 행과 열의 개수가 같은 행렬이다.<br>
**단위행렬 $I$**는 왼쪽 위에서 오른쪽 아래로 이어지는 대각선의 원소가 1이고, 나머지는 0인 행렬로, 곱셈에서 숫자 $1$과 같은 역할을 한다.

**정사각행렬이어도 역행렬이 항상 존재하지는 않는다.**<br>
역행렬은 **행렬식(determinant)이 0이 아닐 때** 존재한다. 행렬식은 정사각행렬에서 계산하는 하나의 수이며, 여기서는 역행렬의 존재 여부를 판단하는 데 사용한다.

```python
import numpy as np

A = np.array([[1, 2], [3, 4]])

A_T = A.T
# [[1, 3],
#  [2, 4]]

A_inv = np.linalg.inv(A)
# [[-2.0,  1.0],
#  [ 1.5, -0.5]]
```

**코드의 목적:** 같은 행렬의 전치와 역행렬을 구한다.<br>
이 예시의 행렬식은 $1\times4-2\times3=-2$이므로 역행렬이 존재한다. **역행렬은 각 원소의 역수 `1 / A`와 다르다.**

<br>

## 4. 배치 처리와 데이터 행렬

**배치(batch)**는 한 번에 처리하는 여러 데이터의 묶음이다.<br>
이 노트에서는 **한 행에 샘플 하나, 한 열에 특성 하나**를 배치한다. **샘플**은 고객 한 명처럼 데이터 한 건을, **특성**은 나이처럼 그 데이터의 속성을 뜻한다.

고객 3명에게 나이·연봉·근속연수·구매횟수라는 특성 4개가 있다면 다음과 같이 묶을 수 있다.

```python
import numpy as np

# 열 순서: 나이, 연봉, 근속연수, 구매횟수
X = np.array([
    [25, 3200, 1,  4],
    [41, 6800, 9, 12],
    [33, 5100, 5,  7],
])

print(X.shape)  # (3, 4): 샘플 3개, 특성 4개
```

**코드의 목적:** 고객별 벡터를 위아래로 쌓아 **데이터 행렬 $X$**를 만든다.<br>
이렇게 하면 **행렬곱 한 번으로 여러 샘플에 같은 가중치 계산을 적용**할 수 있다.

<br>

## 5. 완전연결층의 계산: $Y=XW+b$

**완전연결층(Fully Connected Layer, Dense Layer)**은 모든 입력 특성이 모든 출력 뉴런과 연결된 층이다.<br>
**뉴런**은 입력을 받아 계산하는 단위이며, 각 뉴런은 자신의 **가중치(입력에 곱하는 계수)**로 가중합을 구하고 **편향(추가로 더하는 값)**을 더한다.

$$
Y=XW+b
$$

배치 전체의 출력을 행렬로 나타내므로 여기서는 대문자 $Y$를 사용한다.

### 행렬 크기 확인

샘플이 **100개**, 샘플마다 입력 특성이 **4개**, 출력 뉴런이 **2개**인 경우:

| 기호 | 의미 | NumPy의 `shape` |
| --- | --- | --- |
| $X$ | 입력 데이터 | `(100, 4)` |
| $W$ | 가중치: 각 열이 출력 뉴런 하나의 가중치 | `(4, 2)` |
| $XW$ | 샘플별 가중합 | `(100, 2)` |
| $b$ | 출력 뉴런별 편향 | `(2,)` |
| $Y$ | 편향까지 더한 결과 | `(100, 2)` |

$$
(100,4)\times(4,2)\longrightarrow(100,2)
$$

**출력의 행 개수는 샘플 수, 열 개수는 출력 뉴런 수**이다.<br>
이 표기에서는 `X @ W + b`로 계산하며, **편향을 더한 뒤에도 결과의 모양은 `(100, 2)`로 유지된다.**

### 편향과 브로드캐스팅

`b.shape = (2,)`는 원소가 2개인 **1차원 배열**이라는 뜻이다.<br>
NumPy는 이 편향을 **모든 행에 동일하게 더한다.** 이렇게 모양이 다른 배열을 호환되는 모양으로 맞추어 연산하는 규칙을 **브로드캐스팅(broadcasting)**이라고 한다.

예를 들어 $b=[1,-1]$이면, 모든 샘플의 **첫 번째 출력에는 1을 더하고 두 번째 출력에는 1을 뺀다.**

**편향은 입력이 모두 0이어도 출력이 0으로 고정되지 않도록 기준값을 조절한다.**<br>
다만 $XW+b$만으로는 비선형 관계를 표현할 수 없다. 딥러닝에서는 필요에 따라 **활성화 함수(계산 결과를 다음 출력으로 바꾸는 함수)**를 적용하며, **비선형 활성화 함수**가 층 사이에 있어야 여러 층을 쌓아 더 복잡한 관계를 표현할 수 있다.

<br>

## 6. 복습 체크

- **행렬곱이 가능한 조건은?** 앞 행렬의 열 수와 뒤 행렬의 행 수가 같아야 한다.
- **결과의 크기는?** $(m,k)\times(k,n)\rightarrow(m,n)$이다.
- **전치와 역행렬의 차이는?** 전치는 행과 열을 바꾸고, 역행렬은 곱했을 때 단위행렬이 되게 한다.
- **완전연결층은 어떻게 계산하는가?** $XW$로 모든 샘플의 가중합을 구한 뒤, 같은 편향 $b$를 각 행에 더한다.
