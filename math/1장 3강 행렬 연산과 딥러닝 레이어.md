# 1. 행렬의 정의, 행렬 덧셈과 스칼라 곱

### 행렬의 덧셈

행렬의 덧셈은 벡터의 덧셈과 마찬가지로 **같은 위치에 있는 원소끼리 더하는 연산**이다.

따라서 두 행렬을 더하려면 **행과 열의 개수, 즉 shape가 서로 같아야 한다.**

### 행렬의 스칼라 곱

행렬의 스칼라 곱은 **행렬의 모든 원소에 동일한 숫자(스칼라)를 곱하는 연산**이다.

벡터의 스칼라 곱과 마찬가지로 각 원소에 같은 값이 곱해진다.

```python
import numpy as np

A = np.array([[1, 2], [3, 4]])
B = np.array([[5, 6], [7, 8]])

add_result = A + B
scalar_result = 2 * A
```

# 2. 행렬 곱셈의 정의와 계산 규칙

### 행렬의 곱셈

크기가 (m, k)인 행렬 A와 (k, n)인 행렬 B를 곱하면 (m, n) 크기의 행렬 나온다.

결과 행렬의 (i, j) 원소는 A의 i번째 행과 B의 j번째 열을 내적한 값이다
즉 A의 열 개수와 B의 행 개수(k)가 일치해야 곱셈이 가능


```python
A = np.array([[1, 2, 3], [4, 5, 6]])   # shape (2, 3)
W = np.array([[1, 0], [0, 1], [1, 1]]) # shape (3, 2)

result = A @ W   # shape (2, 2)
```

결과의 `(i, j)` 칸 하나는 **A의 i번째 행과 B의 j번째 열의 내적**. 


내적을 하려면 두 벡터 길이가 같아야 하므로<br> A의 열 개수와 B의 행 개수(`k`)가 반드시 일치해야 한다<br>
마지막으로 `k`는 계산이 끝나면 사라진다

```python
 print(result)
 # [[ 4,  5],
 #  [10, 11]]
 ```


# 3. 전치행렬과 역행렬의 기본 성질

**전치행렬**

전치행렬(transpose)은 행과 열을 서로 바꿔 놓은 행렬, A의 전치는 A^T로 표기.


**역행렬**

정사각행렬 A에 대해 A * A_inv = I(단위행렬)를 만족하는 A_inv를 A의 역행렬이라고 한다.

행렬식(determinant)이 0이 아닌 경우 역행렬이 존재.


```python
A = np.array([[1, 2], 
              [3, 4]])

# 전치 행렬

A_T = A.T

#array([[1, 3],
#       [2, 4]])


# 역행렬

A_inv = np.linalg.inv(A)

# array([[-2. ,  1. ],
#       [ 1.5, -0.5]])
```

# 4. 배치 처리에서 X가 데이터 행렬인 이유

여러 사람의 데이터를 한꺼번에 행렬로 묶어놓은 게 데이터 행렬 X

예를 들면 고객 3명이 있고, 각 고객마다 특성이 4개가 있다.

* 나이
* 연봉
* 근속연수
* 구매횟수

그러면 고객 1명은 하나의 벡터로 표현할 수 있다

[25, 3200, 1, 4]

나머지 2명

[41, 6800, 9, 12]<br>
[33, 5100, 5, 7]

위 데이터를 여러개 모아서 위아래로 쌓으면 데이터 행렬 X가 된다

한 행(row) = 고객 한 명
한 열(column) = 하나의 특성


머신러닝에서는 사람 한 명의 데이터를 벡터로 만들고, 여러 사람의 벡터를 위아래로 쌓아서 행렬 X로 만든다.<br>
 그러면 행렬 곱 한 번으로 모든 사람의 계산을 동시에 할 수 있다.

# 5. 완전연결층 y = XW + b의 행렬 연산 구조

완전연결층(Fully Connected Layer)은 입력값들을 가중치와 곱해서 새로운 출력값을 만드는 층.

기본 계산식

y=XW+b

X: 입력 데이터<br>
W: 가중치<br>
b: 편향(bias)<br>
y: 계산된 출력

### 예시
데이터가 100개이고, 각 샘플마다 특성이 4개

X.shape=(100,4)

출력 뉴런이 2개

W.shape=(4,2)

XW 를 하면

(100,4)(4,2)→(100,2)

여기에 편향을 더하면

WX.shape = (100,2)<br>
b.shape =  (2,) <br>
y.shape = WX.shape + b

편향 b는 출력값의 기본 위치를 조정해서 모델이 더 다양한 관계를 표현할 수 있도록 해주는 값	​



## 추가

편향은 모델이 반드시 0에서 시작하지 않아도 되도록 해주는 값(기본 위치를 조정)
편향은 0을 피하려고 넣는 값이 아니라, 모델이 더 자유롭게 데이터를 표현하도록 해주는 값이다.
