# 1. 선형 변환의 정의

선형 변환은 벡터를 다른 벡터로 옮기는 함수 중, 두 가지 조건을 만족하는 특별한 함수

첫째는 가산성으로, $T(u+v) = T(u) + T(v)$가 성립해야 한다.

둘째는 동차성으로, $T(cu) = cT(u)$가 성립해야 한다.

이 두 조건을 만족하면, 그 변환은 항상 하나의 행렬 곱으로 표현할 수 있다.



```python
import numpy as np

def is_linear_like(T, u, v, c):
    left = T(u + v)
    right = T(u) + T(v)
    return np.allclose(left, right)
```

# 2. 회전, 스케일링, 반사, 투영 행렬

평면 위의 점을 움직이는 대표적인 선형 변환은 네 가지

* 회전은 원점을 중심으로 벡터를 일정한 각도만큼 돌리는 변환이다, det = 1이므로 넓이는 그대로 유지된다.
* 스케일링은 좌표축 방향으로 크기를 늘리거나 줄이는 변환이다, det = sx · sy이고, 넓이는 |det|배만큼 변한다.
* 반사는 특정 축이나 직선을 기준으로 벡터를 뒤집는 변환이다. |det| = 1이므로 넓이의 크기는 그대로지만 방향이 뒤집힌다.<br>
45도 회전 행렬을 벡터 $(1, 0)$에 곱하면 $(\cos45° ,\sin45°) \approx (0.71, 0.71)$
* 투영은 벡터를 특정 축이나 부분공간 위로 눌러 보내는 변환이다. 이 과정에서 일부 방향의 정보가 사라지며, 투영 행렬은 det = 0이므로 역행렬이 존재하지 않는다.

네 변환 모두 2×2 행렬 하나로 표현할 수 있다.

# 3. 합성 변환과 행렬 곱

**변환을 두 번 적용하면?**

하나의 변환을 적용한 결과에 또 다른 변환을 적용하는 것을 합성 변환이다

변환 A를 먼저 적용하고 변환 B를 나중에 적용하면, 전체 변환은 행렬 곱 $BA$로 표현된다

행렬 곱은 교환법칙이 성립하지 않기 때문에, 적용 순서를 바꾸면 결과가 달라질 수 있다.

```python
import numpy as np

theta = np.pi / 4
R = np.array([[np.cos(theta), -np.sin(theta)],
              [np.sin(theta), np.cos(theta)]])
S = np.array([[2, 0], [0, 1]])

scale_then_rotate = R @ S
rotate_then_scale = S @ R
```
## 4. 신경망 레이어와 선형 변환


**선형 변환 + 비선형 활성화 = 신경망 레이어**

신경망의 한 레이어는 입력 벡터에 가중치 행렬을 곱하는 선형 변환과, 그 결과에 비선형 함수를 적용하는 활성화 단계로 이루어져 있어요.

가중치 행렬만 반복해서 쌓으면 여러 층이어도 결국 하나의 선형 변환과 같아지기 때문에, 활성화 함수가 없으면 신경망은 표현력을 얻지 못합니다.

비선형 활성화가 있어야 층을 쌓을수록 더 복잡한 패턴을 학습할 수 있어요.
