# 벡터공간과 선형 독립

> **선형결합으로 무엇을 만들 수 있는지**, **중복되는 벡터가 있는지**가 핵심이다.<br>
> 이 질문이 **span → 선형 독립 → 기저와 차원 → rank**로 이어진다.

## 1. 선형결합과 span

**선형결합(linear combination)**은 여러 벡터에 각각 **스칼라(하나의 수)**를 곱한 뒤 모두 더하는 것이다.

$$
c_1v_1+c_2v_2+\cdots+c_kv_k
$$

여기서 $v_i$는 벡터, $c_i$는 각 벡터에 곱하는 **계수**이다.<br>
**span**은 계수들을 자유롭게 바꾸어 **선형결합으로 만들 수 있는 모든 벡터의 집합**이다.

**span이 항상 2차원 평면인 것은 아니다.**

| 주어진 벡터 | 만들어지는 span |
| --- | --- |
| 영벡터만 있음 | 영벡터 하나인 집합 $\{0\}$ |
| $[1,2]$, $[2,4]$ | 원점을 지나는 직선 |
| $[1,0]$, $[0,1]$ | 2차원 평면 전체 $\mathbb{R}^2$ |

예를 들어 $[3,5]=3[1,0]+5[0,1]$이다. **서로 평행하지 않은 두 2차원 벡터**로는 평면의 모든 벡터를 만들 수 있다.

```python
import numpy as np

v1 = np.array([1, 0])
v2 = np.array([0, 1])
target = np.array([3, 5])
A = np.column_stack([v1, v2])  # 각 벡터를 행렬의 열로 배치

coeffs = np.linalg.lstsq(A, target, rcond=None)[0]
reconstructed = A @ coeffs             # [3., 5.]
is_match = np.allclose(reconstructed, target)  # True
```

**코드의 목적:** $A\,c=\text{target}$의 계수를 찾아 목표 벡터를 선형결합으로 표현한다. `coeffs`는 `[3., 5.]`이다.<br>
`lstsq()`는 **최소제곱법(오차의 제곱합을 가장 작게 하는 방법)**으로 계수를 구한다. 목표가 span 밖에 있으면 정확히 일치하는 대신 가장 가까운 벡터를 찾는다.

`[0]`은 첫 반환값인 **계수 벡터**만 선택한다. `rcond=None`은 기본 수치 기준을 사용한다. ([NumPy 공식 문서](https://numpy.org/doc/stable/reference/generated/numpy.linalg.lstsq.html))

<br>

## 2. 벡터공간과 부분공간

**$\mathbb{R}^n$은 실수 성분 $n$개로 이루어진 모든 벡터의 공간**이다.<br>
벡터공간은 덧셈과 스칼라배가 정의되고, 결합법칙·분배법칙 등 정해진 규칙을 만족하는 집합이다. 여기서는 **$\mathbb{R}^n$과 그 부분공간**을 다룬다.

$\mathbb{R}^n$의 부분집합이 일반적인 벡터 연산에 대해 다음을 만족하면 **부분공간(더 큰 벡터공간 안에 있는 벡터공간)**이다.

- **영벡터를 포함**한다.
- 안에 있는 두 벡터를 **더해도** 결과가 안에 있다.
- 안에 있는 벡터에 **어떤 실수를 곱해도** 결과가 안에 있다.

연산 결과가 집합 밖으로 나가지 않는 성질을 **닫혀 있다**고 한다.<br>
$y=x$인 직선은 부분공간이지만, $y=x+1$인 직선은 **영벡터를 포함하지 않아 부분공간이 아니다.** 앞서 본 span은 항상 부분공간이다.

<br>

## 3. 선형 독립과 선형 종속

다음 식이 언제 성립하는지 살펴보면 벡터 사이의 중복을 판단할 수 있다.

$$
c_1v_1+\cdots+c_kv_k=0
$$

| 구분 | 판단 기준 | 의미 |
| --- | --- | --- |
| **선형 독립** | 모든 계수가 0일 때만 성립 | 어느 벡터도 나머지 벡터들의 선형결합으로 만들 수 없음 |
| **선형 종속** | 0이 아닌 계수가 하나 이상 있어도 성립 | 적어도 한 벡터를 나머지 벡터들의 선형결합으로 만들 수 있음 |

$v_1=[1,2]$, $v_2=[2,4]$라면 $2v_1-v_2=0$이다.<br>
계수 $2,-1$이 모두 0은 아니므로 **선형 종속**이다. $v_2$를 추가해도 만들 수 있는 공간은 같은 직선에 머문다.

반면 $[1,0]$, $[0,1]$은 **선형 독립**이다. 선형결합을 영벡터로 만들려면 두 계수가 모두 0이어야 한다.<br>
**영벡터가 포함된 벡터 집합은 항상 선형 종속**이다. 영벡터의 계수만 1로 두어도 위 식이 성립하기 때문이다.

<br>

## 4. 기저와 차원

**기저(basis)**는 다음 두 조건을 모두 만족하는 벡터 집합이다.

1. **그 공간 전체를 생성한다:** 기저의 span이 해당 공간과 같다.
2. **선형 독립이다:** 불필요하게 중복되는 벡터가 없다.

**차원(dimension)**은 **기저를 이루는 벡터의 개수**이다. 같은 공간의 기저는 여러 가지지만, 기저 벡터 개수는 같다.<br>
기저를 정하면 공간 안의 각 벡터를 나타내는 **선형결합의 계수도 유일**하게 정해진다.

```python
import numpy as np

basis = np.column_stack([[1, 0], [0, 1]])  # R^2의 표준 기저
dimension = np.linalg.matrix_rank(basis)  # 2
```

**코드의 목적:** 두 기저 벡터를 열로 모아 공간의 차원이 2임을 확인한다. `rank`는 다음 절에서 설명한다.

> **벡터의 성분 수와 그 벡터들이 만드는 공간의 차원은 다를 수 있다.**<br>
> $[1,2,3]$의 성분은 3개이지만, 이 벡터 하나의 span은 직선이므로 **차원은 1**이다.

<br>

## 5. 열공간·영공간·rank

$A$가 **$m$행 $n$열 행렬**이면 입력 $x\in\mathbb{R}^n$을 출력 $Ax\in\mathbb{R}^m$으로 보낸다.

| 개념 | 정의와 직관 |
| --- | --- |
| **열공간** $\operatorname{Col}(A)$ | 열벡터들의 span. **가능한 모든 출력**의 집합이며 $\mathbb{R}^m$의 부분공간 |
| **영공간** $\operatorname{Null}(A)$ | $Ax=0$인 모든 $x$의 집합. **영벡터로 보내지는 입력**들이며 $\mathbb{R}^n$의 부분공간 |
| **rank** | 열공간의 차원. 열들 중 **선형 독립인 열을 고를 수 있는 최대 개수** |

행렬곱 $Ax$는 **$x$의 성분을 계수로 하는 열벡터들의 선형결합**이므로, 가능한 출력 전체가 열공간이다.

```python
import numpy as np

v1 = np.array([1, 2])
v2 = np.array([2, 4])
A = np.column_stack([v1, v2])

rank = np.linalg.matrix_rank(A)  # 1: 열공간은 직선
is_dependent = rank < A.shape[1]  # True: 열 개수 2보다 작음
x = np.array([2, -1])
output = A @ x                  # [0, 0]: x는 영공간에 포함
```

**코드의 목적:** 열벡터의 종속과 영공간을 연결한다.<br>
**$\operatorname{rank}(A)<n$이면 열벡터들이 선형 종속**이며, 영공간에 0이 아닌 벡터가 존재한다. 위 영공간은 $[2,-1]$의 모든 실수배이다.

`matrix_rank()`는 계산 오차를 고려하는 **허용 기준**으로 rank를 판단한다. 거의 종속인 데이터는 기준에 따라 결과가 달라질 수 있다. ([NumPy 공식 문서](https://numpy.org/doc/stable/reference/generated/numpy.linalg.matrix_rank.html))

<br>

## 6. 데이터와 선형회귀에서의 의미

행을 관측값, 열을 **특성(feature: 데이터를 설명하는 항목)**으로 놓으면, 열의 선형 종속은 일부 특성이 다른 특성의 선형결합으로 표현된다는 뜻이다.

**다중공선성**은 회귀에 쓰이는 특성 사이에 강한 선형 관계가 있는 현상이다.<br>
계수 크기에 벌점을 추가하지 않는 **일반적인 최소제곱 회귀**에서는 다음을 구분한다.

- **완전한 선형 종속:** 같은 예측을 만드는 계수 조합이 여러 개여서 **회귀계수가 유일하지 않다.**
- **거의 선형 종속:** rank가 열 개수와 같아도, 데이터의 작은 변화에 계수가 크게 달라지는 **추정 불안정**이 생길 수 있다.

같은 길이를 cm와 m로 각각 넣으면 한 열이 다른 열의 100배여서 완전히 종속이다.<br>
`lstsq()`가 계수 하나를 반환해도 해가 유일하다는 뜻은 아니다. 최소제곱 해가 여러 개이면 **길이가 가장 작은 계수 벡터**를 선택한다.

<br>

## 7. 복습 체크

- **span은?** 주어진 벡터들의 모든 선형결합으로 만들 수 있는 집합이다.
- **선형 독립의 기준은?** 영벡터가 되는 선형결합의 계수가 모두 0일 때뿐이어야 한다.
- **기저의 두 조건은?** 공간 전체를 생성하고, 선형 독립이어야 한다.
- **차원은 성분 수인가?** 기저 벡터 개수이며, 성분 수와 다를 수 있다.
- **열공간과 영공간은?** 가능한 출력들의 공간과, 영벡터로 보내지는 입력들의 공간이다.
- **rank가 열 개수보다 작으면?** 열들이 선형 종속이고, 영공간에 0이 아닌 벡터가 존재한다.
