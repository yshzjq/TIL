# 머신러닝 기초

## 용어 정리

### 0-1. 데이터, 샘플, 특성, 레이블

- **데이터(Data)**
    - 우리가 모델에 넣어서 학습시키고 싶은 정보들의 집합입니다.
- **샘플(sample, 관측치)**
    - 데이터 안의 **한 줄(row)**
    - 예: 한 명의 고객, 한 채의 아파트, 한 개의 버섯
- **특성(feature, 변수)**
    - 샘플을 설명하는 **입력 값**들입니다.
    - 예: 나이, 성별, 평수, BMI, 연소득 등
- **레이블(label, 타깃, y)**
    - 우리가 **예측하고 싶은 정답**입니다.
    - 예: 의료비, 집값, 합격 여부, 독/식용 여부

### 0-1-1. X와 y 표기

머신러닝 설명에서 자주 보는 표기:

- `X` : 입력 특성들(features)
- `y` : 정답(label, target)

예시

- `X = [평수, 방개수, 지하철거리, 건축연도]`
- `y = 집값`

scikit-learn 계열 라이브러리는 보통 입력을 `(샘플 수, 특성 수)` 형태로 받습니다.

예를 들어 고객 100명, 특성 5개면 `X.shape = (100, 5)` 입니다

### 0-2. 지도학습 vs 비지도학습

- **지도학습(Supervised Learning)**
    - 입력 X와 함께 정답 y가 **붙어 있는 데이터**로 학습
    - 목표: X → y 관계를 잘 학습해서 새 X에 대해 y를 잘 맞추기
    - 예:
        - 집 정보 → 집값 예측 (회귀)
        - 이메일 내용 → 스팸/정상 분류 (분류)
- **비지도학습(Unsupervised Learning)**
    - y(정답)가 없음, X만 있음
    - 목표: X 안에서 **군집/구조/패턴**을 발견
    - 예:
        - 고객 데이터로 **비슷한 고객끼리 그룹(세그먼트)** 나누기(군집)
        - 문서들 주제별 묶기

> 이 세션에서는
> 
> - **지도학습:** **회귀(연속값 예측)**, **분류(범주 예측)**
> - **비지도학습:** **군집(K-Means)**를 중심으로 다룹니다.
